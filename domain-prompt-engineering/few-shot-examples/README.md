# Few-Shot Examples

Author, select, order, and audit few-shot examples used inside prompts.

| File | Description |
|------|-------------|
| `fewshot_example_selector.md` | Pick K examples from a corpus with coverage and budget |
| `fewshot_example_ordering.md` | Decide order; choose a policy with a rationale |
| `fewshot_synthetic_example_generator.md` | Generate examples when no corpus exists |
| `fewshot_negative_example_designer.md` | Show what NOT to do without imitation risk |
| `fewshot_edge_case_pack_builder.md` | Pack focused on boundary, malformed, refusal-worthy inputs |
| `fewshot_example_format_normalizer.md` | One delimiter convention, one field order |
| `fewshot_zero_to_one_to_few_progression.md` | Decide whether to add an example at all |
| `fewshot_contamination_audit.md` | Detect when examples are causing surface overfit |
