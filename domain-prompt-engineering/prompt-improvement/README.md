# Prompt Improvement

Take an existing prompt and make it better. Each prompt here addresses one specific quality vector: clarity, redundancy, conflicts, brittleness, production-readiness, surgical fixes, layered architecture, behavior preservation, modernization, diff explanation, and targeted repair.

| File | Description |
|------|-------------|
| `engineering_prompt_improver.md` | General-purpose prompt refiner (legacy) |
| `improve_specificity_pass.md` | Replace vague terms with operational language |
| `improve_redundancy_eliminator.md` | Find and consolidate duplicated rules |
| `improve_conflict_resolver.md` | Resolve contradictory rules with precedence or scoping |
| `improve_brittleness_audit.md` | Stress-test rules against an edge-case battery |
| `improve_promotion_to_production.md` | Apply a fixed checklist to graduate dev → prod |
| `improve_minimal_change_pass.md` | Smallest fix that passes a regression set |
| `improve_constraint_layering.md` | Restack flat rules into layered architecture |
| `improve_idempotent_rewrite.md` | Improve readability without changing behavior |
| `improve_legacy_prompt_modernization.md` | Update older patterns to current best practice |
| `improve_prompt_diff_explainer.md` | Explain a before/after prompt diff |
| `improve_failed_output_repair.md` | Repair the prompt from one specific bad output |
