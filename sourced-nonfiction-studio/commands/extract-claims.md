# /extract-claims

**Surgical: Stage 1 only.** Turn a braindump into an atomic, typed claim ledger without sourcing.

## Usage
`/extract-claims` then paste the material (wrap in `<material>...</material>`).

## What it runs
`prompts/stage-1-claim-extraction-typing.md` (needs a light Stage-0 scope: field + whether names appear).

## Output
The Claim Ledger (atomic claims, each typed: verifiable-fact / professional-judgment / original-analysis / common-knowledge / experiential-opinion / claim-about-named-person) + the source/label/named-party queues.

## Use when
You want to see what you're actually asserting — and how much is fact vs judgment — before committing to a full sourcing run.
