# Prompt Engineering Techniques

**Purpose:** Reference documentation for 250 formally defined prompt engineering techniques across 19 categories.

This directory contains the technique catalog, use case patterns, and reference materials for building effective prompts.

## Key Files

| File | Purpose |
|------|---------|
| `MASTER_TECHNIQUE_INDEX.md` | Complete catalog of 250 formally defined techniques across 19 categories |
| `USE_CASE_LOOKUP.md` | Pre-built technique combinations by task type |
| `additions/` | New techniques and experimental patterns |

## Technique Categories

- **Structural Techniques (ST-xx):** Prompt organization and architecture
- **Reasoning Techniques (RT-xx):** Step-by-step thinking and analysis
- **Domain Specialization (DS-xx):** Domain-specific expertise patterns
- **Output Formatting (OF-xx):** Response format control
- **Quality Control (QC-xx):** Validation and error handling
- **Agentic Techniques (AG-xx):** Multi-agent and autonomous patterns

1. **Know your task type?** Start with `USE_CASE_LOOKUP.md`
2. **Need technique details?** Reference `MASTER_TECHNIQUE_INDEX.md`
