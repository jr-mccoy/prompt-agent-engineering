# Pediatric Anxiety Protocol Session Plan

## Objective

Generate a structured, manualized session plan for treating child or adolescent anxiety using a Coping Cat / Cool Kids–style cognitive-behavioral framework, and document the delivered session. The plan:

1. Places the session within the protocol arc (skills-building phase → exposure phase) and identifies the target of this session.
2. Sequences the session's components: agenda, homework review, skill teaching/practice, in-session exposure (when in the exposure phase), caregiver coaching, and homework assignment.
3. Calibrates language, examples, and worksheets to the child's developmental stage.
4. Builds and uses a fear/exposure hierarchy with SUDS ratings.
5. Documents caregiver involvement and home practice, plus a brief safety check.
6. Produces a session note meeting CPT 90834/90837 requirements with a goal→intervention→response golden thread.

## When to Use

- For manualized CBT for anxiety disorders in youth (GAD, separation anxiety, social anxiety, specific phobia, panic) using Coping Cat (ages ~7–13), C.A.T. Project (adolescents), or Cool Kids (ages ~6–17).
- When planning and documenting an individual skills-building or exposure session.
- When caregiver coaching is integrated into the anxiety protocol.

## When NOT to Use

- For OCD requiring formal ERP — use an ERP-specific protocol (this plan can reference but does not replace it).
- For PTSD/trauma — use TF-CBT.
- For play-based, non-manualized therapy — use `psychology_child_play_therapy_session_note.md`.
- For acute suicidal crisis — complete risk assessment and safety planning first.

## Inputs / Context Required

- **Client:** Initials/MRN, age (years+months), developmental stage, anxiety diagnosis(es).
- **Protocol & session number:** Coping Cat / C.A.T. Project / Cool Kids; current session number and protocol phase (skills vs. exposure).
- **Treatment plan goals/objectives** this session targets.
- **Baseline/monitoring measures:** SCARED, GAD-7 (if ≥13), PARS, or session-by-session SUDS.
- **Fear hierarchy:** Existing hierarchy items and SUDS if built; otherwise this session may build it.
- **Caregiver availability:** Whether a caregiver is present for coaching this session.
- `[clinician input required: any safety findings or recent escalation that modify the session plan]`

## Constraints

### Must

- Locate the session in the protocol arc and state whether it is skills-building or exposure.
- Calibrate worksheets, metaphors, and examples to developmental stage (e.g., FEAR plan acronym work for younger children; more abstract cognitive work for adolescents).
- Use a fear hierarchy with SUDS; for exposure sessions, specify the exposure target, predicted SUDS, and post-exposure SUDS.
- Integrate caregiver coaching (reducing accommodation, reinforcing brave behavior, modeling) when a caregiver is present.
- Maintain the golden thread: each component links to a treatment goal and documents the child's response.
- Include a brief safety check (SI/self-harm) and a risk-reassessment hook.
- Flag gaps with `[clinician input required: ...]`; do not fabricate SUDS, scores, or homework completion.

### Must Not

- Do not move to exposure before the child has the prerequisite coping skills and a collaborative hierarchy.
- Do not conduct exposure that the child has not assented to or that exceeds a graded step (no flooding without rationale).
- Do not reinforce avoidance or caregiver accommodation in the documentation as therapeutic.
- Do not omit the safety check because the presenting problem is anxiety.
- Do not fabricate hierarchy items, SUDS ratings, or measure scores.

## Protocol Phase Reference

| Phase | Typical Sessions | Core Targets | Caregiver Role |
|-------|------------------|--------------|----------------|
| Skills-building | Early (≈1–7 Coping Cat) | Psychoeducation; somatic anxiety awareness; relaxation/breathing; cognitive restructuring; problem-solving; building the FEAR/coping plan and hierarchy | Psychoeducation; reduce reassurance/accommodation; learn to coach |
| Exposure | Later (≈8–16) | Graded in-session and at-home exposures up the hierarchy; coping skills applied during exposure; relapse prevention | Co-conduct/scaffold home exposures; reinforce brave behavior; fade accommodation |

## Instructions

1. **Locate the session.** Record protocol, session number, and phase; state the session target.
2. **Set the agenda collaboratively.** Note the child-friendly agenda for the session.
3. **Review homework.** Document home-practice completion, barriers, and reinforcement delivered.
4. **Teach/practice the targeted skill** (skills phase) — somatic awareness, breathing/relaxation, detective thinking/cognitive restructuring, or coping-plan building — with developmentally calibrated worksheets.
5. **Build or update the fear hierarchy** with SUDS where relevant.
6. **Conduct graded exposure** (exposure phase): specify target, baseline SUDS, predicted vs. actual, coping skills used, and learning consolidated.
7. **Coach the caregiver** (if present): reduce accommodation, reinforce brave behavior, plan home exposures.
8. **Assign homework** tied to the session target.
9. **Brief safety check** (SI/self-harm) with reassessment hook.
10. **Write the session note** using the output format below.
11. **Run verification.**

## Verification

- [ ] Protocol, session number, and phase (skills vs. exposure) stated; session target identified.
- [ ] Components calibrated to developmental stage.
- [ ] Homework reviewed; completion and barriers documented.
- [ ] Fear hierarchy with SUDS present and updated.
- [ ] Exposure sessions document target, predicted vs. actual SUDS, coping used, learning, and child assent.
- [ ] Exposure not initiated before prerequisite skills/hierarchy in place.
- [ ] Caregiver coaching documented (accommodation reduction, brave-behavior reinforcement) when present.
- [ ] Homework assigned and tied to the session target.
- [ ] Safety check documented with reassessment hook.
- [ ] Golden thread present: components linked to goals and to child response.
- [ ] CPT matches service and duration.
- [ ] Gaps flagged with `[clinician input required: ...]`; no fabricated SUDS or scores.
