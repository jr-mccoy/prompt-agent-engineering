# Adolescent DBT Skills Module

## Objective

Plan and document a single age-adapted DBT-A (Dialectical Behavior Therapy for Adolescents) skills module for a teen, delivered in individual or multifamily-group format. The module:

1. Targets one skills domain — Mindfulness, Distress Tolerance, Emotion Regulation, Interpersonal Effectiveness, or Walking the Middle Path (the DBT-A–specific module).
2. Reviews the diary card and conducts behavioral-chain/solution analysis on a target behavior when indicated.
3. Teaches the skill with adolescent-calibrated language, examples, and acronyms (e.g., DEAR MAN, TIPP, PLEASE, Wise Mind).
4. Incorporates the Middle Path triad — dialectics, validation, and behavior-change/contingency principles — for teen-caregiver conflict.
5. Includes caregiver/family participation appropriate to DBT-A's multifamily design.
6. Documents skills practice, commitment, homework, and a brief safety check, producing a CPT-appropriate note.

## When to Use

- For delivering and documenting a DBT-A skills session (individual skills coaching or multifamily skills group) for adolescents ~12–18 with emotion dysregulation, self-harm, suicidality, or BPD features.
- When teaching or reinforcing a specific skill and reviewing diary-card data.
- When teen-caregiver conflict calls for the Walking the Middle Path module.

## When NOT to Use

- For a full comprehensive DBT program design (this is a single-module plan/note, not a program).
- For acute suicidal crisis requiring immediate risk management — complete risk assessment and safety planning first (`psychology_pediatric_safety_planning_with_caregiver.md`).
- For non-DBT anxiety CBT — use `psychology_pediatric_anxiety_protocol_session_plan.md`.

## Inputs / Context Required

- **Client:** Initials/MRN, age, developmental stage, diagnosis, DBT-A stage/target hierarchy status.
- **Format:** Individual skills coaching vs. multifamily skills group; who is present (teen, caregiver(s), other families).
- **Module/skill target:** Which of the five modules and which specific skill.
- **Diary card:** Recent diary-card data — urges, target behaviors, skills used, ratings.
- **Target behavior (if chain analysis):** The behavior to analyze (self-harm, SI, conflict episode).
- **Treatment goals:** The DBT targets this session addresses (life-threatening → therapy-interfering → quality-of-life).
- `[clinician input required: any self-harm/SI on the diary card that requires chain analysis and risk reassessment]`

## Constraints

### Must

- Honor the DBT target hierarchy: address life-threatening behaviors first, then therapy-interfering, then quality-of-life.
- Review the diary card and, when a target behavior is present, conduct a behavioral chain + solution analysis.
- Use adolescent-calibrated language and the actual DBT skill acronyms/handouts by name (do not reproduce copyrighted handout text).
- For Walking the Middle Path, teach the dialectic explicitly (validation + change; acceptance + problem-solving) and apply it to a real teen-caregiver tension.
- Include caregiver/family participation consistent with DBT-A's multifamily model and document it.
- Maintain a golden thread: skill taught → practiced → homework → target behavior.
- Include a safety check and risk-reassessment hook; if self-harm/SI present, document chain analysis and risk level.
- Flag gaps with `[clinician input required: ...]`; do not fabricate diary-card data or skills practice.

### Must Not

- Do not skip the target hierarchy (e.g., teaching a QOL skill while ignoring a self-harm entry on the diary card).
- Do not invalidate the adolescent or caregiver; model dialectical balance, not siding.
- Do not reproduce copyrighted DBT handout/worksheet text — reference by name and teach the concept.
- Do not document a Middle Path session without the dialectic actually being taught.
- Do not fabricate diary-card entries, urge ratings, or homework completion.

## DBT-A Module Reference

| Module | Core Skills (by name) | Adolescent Adaptation |
|--------|------------------------|------------------------|
| Mindfulness | Wise Mind; Observe/Describe/Participate; Non-judgmentally, One-mindfully, Effectively | Shorter practices, concrete anchors, app/phone-friendly cues |
| Distress Tolerance | TIPP, STOP, ACCEPTS, Self-Soothe, Pros & Cons, Radical Acceptance | Crisis-survival framing for school/peer stressors |
| Emotion Regulation | PLEASE, Opposite Action, Check the Facts, Build Mastery/Positive Experiences (ABC) | Sleep/social-media/screen factors in PLEASE; relatable emotion examples |
| Interpersonal Effectiveness | DEAR MAN, GIVE, FAST | Peer, dating, family, and teacher scenarios |
| Walking the Middle Path (DBT-A) | Dialectics; Validation; Behavior-change/contingency (reinforcement) | Teen↔caregiver dilemmas (too loose↔too strict; forcing autonomy↔fostering dependence) |

## Instructions

1. **Set the frame.** Record format, attendees, module/skill target, and DBT stage.
2. **Review the diary card.** Summarize urges, target behaviors, and skills use; honor the target hierarchy.
3. **Chain + solution analysis (if target behavior present).** Walk the prompting event → vulnerability → links → behavior → consequences; identify skills-insertion points.
4. **Teach the skill.** Present the named skill with adolescent-calibrated examples; for Middle Path, teach the dialectic and apply to a real tension.
5. **Practice in session.** Role-play or rehearse; document the teen's response.
6. **Include caregiver/family.** Deliver the caregiver-facing component (validation skills, contingency management, dialectical dilemmas) and document.
7. **Assign homework** and a diary-card target for the coming week.
8. **Safety check.** Screen SI/self-harm; if endorsed, document risk and reassessment.
9. **Write the note** using the output format below.
10. **Run verification.**

## Verification

- [ ] Module and named skill target identified; DBT-A frame stated.
- [ ] Target hierarchy honored (life-threatening → therapy-interfering → QOL).
- [ ] Diary card reviewed; chain + solution analysis completed when a target behavior is present.
- [ ] Skill taught by name with adolescent-calibrated examples; no copyrighted handout text reproduced.
- [ ] Walking the Middle Path sessions explicitly teach the dialectic (validation + change).
- [ ] Caregiver/family participation documented per DBT-A multifamily model.
- [ ] In-session practice and teen response documented (golden thread).
- [ ] Homework and diary-card target assigned.
- [ ] Safety check documented with reassessment hook; risk handled if SI/self-harm endorsed.
- [ ] CPT matches format and duration.
- [ ] Gaps flagged with `[clinician input required: ...]`; no fabricated diary-card data.
