# Behavioral Observation Framework

**Objective:** Create comprehensive, structured observation protocols for behavioral assessment that include operationalized behavior definitions, appropriate recording methods, inter-rater reliability procedures, and context documentation requirements.

**Instructions:**

1. **Gather observation context and purpose**
   * Request the following information:
     - Target behavior(s) to observe
     - Purpose of observation (research, clinical assessment, program evaluation, functional analysis)
     - Setting(s) where observation will occur
     - Who will conduct observations (trained observers, teachers, parents, clinicians)
     - Time constraints and resources available
     - Intended use of data (baseline, progress monitoring, outcome evaluation)
   * Clarify the level of behavioral specificity required

2. **Develop operationalized behavior definitions**
   * Create definitions that are:
     - **Observable:** Can be seen or heard by an observer
     - **Measurable:** Can be counted, timed, or rated
     - **Clear:** Any trained observer could identify the behavior
     - **Complete:** Includes examples and non-examples
   * Structure each definition with:
     - **Behavior name:** Clear, neutral label
     - **Topography:** What the behavior looks like (form)
     - **Function (if known):** What purpose it serves
     - **Inclusion criteria:** What counts as the behavior
     - **Exclusion criteria:** What does NOT count
     - **Examples:** 2-3 specific instances
     - **Non-examples:** 2-3 instances that might be confused with target behavior

3. **Select appropriate recording methods**
   * Match method to behavior characteristics:
     - **Frequency/Event Recording:** For discrete behaviors with clear start/end (e.g., hand raises, requests)
     - **Duration Recording:** For behaviors where length matters (e.g., on-task time, tantrums)
     - **Latency Recording:** For time between stimulus and response (e.g., compliance latency)
     - **Interval Recording:** For behaviors that are continuous or variable
       - *Partial interval:* Record if behavior occurs at any point (overestimates)
       - *Whole interval:* Record only if behavior occurs throughout (underestimates)
       - *Momentary time sampling:* Record if behavior occurs at interval end
     - **Permanent Product:** For behaviors that leave evidence (e.g., completed assignments)
   * Specify interval lengths if using interval recording
   * Provide recording form templates with clear data entry fields

4. **Create observation protocol structure**
   * **Pre-observation procedures:**
     - Observer training requirements
     - Equipment needed (forms, timers, counters)
     - Environmental setup requirements
     - Baseline period specifications
   * **During observation:**
     - Session length and timing
     - Positioning of observer (minimize reactivity)
     - Recording procedures step-by-step
     - Handling of ambiguous instances
   * **Post-observation:**
     - Data calculation procedures
     - Storage and confidentiality
     - Session summary documentation

5. **Design inter-rater reliability procedures**
   * Specify reliability measurement approach:
     - **Total agreement:** (Agreements / Total opportunities) × 100
     - **Occurrence agreement:** Focus on instances where behavior occurred
     - **Non-occurrence agreement:** Focus on instances where behavior did not occur
     - **Kappa coefficient:** Adjusts for chance agreement
   * Include:
     - Required reliability threshold (typically 80%+ for research)
     - Training protocol until threshold is met
     - Ongoing reliability check schedule (e.g., 20-30% of sessions)
     - Procedures for resolving disagreements
     - Documentation forms for reliability data

6. **Develop context documentation requirements**
   * Capture variables that may influence behavior:
     - **Antecedent conditions:** What happened immediately before
     - **Setting factors:** Time of day, location, people present, activities
     - **Biological factors:** Sleep, medication, illness (if observable/reported)
     - **Environmental factors:** Noise level, crowding, temperature
   * Create ABC (Antecedent-Behavior-Consequence) documentation template
   * Include narrative notes section for qualitative observations
   * Specify what contextual data is required vs. optional

7. **Compile complete observation package**
   * Final protocol should include:
     - Purpose statement and observation goals
     - Complete operationalized definitions
     - Selected recording method with rationale
     - Blank recording forms (ready to use)
     - Observer training checklist
     - Inter-rater reliability procedures and forms
     - Context documentation template
     - Data analysis guidelines
     - Ethical considerations and consent requirements

**Psychology-Specific Considerations:**
- Minimize observer reactivity—participants may change behavior when observed
- Consider observer drift—regular reliability checks prevent definition drift over time
- Address observer bias—blind observers to hypotheses when possible
- Ensure cultural sensitivity in defining behaviors—same action may have different meaning across contexts
- Plan for ethical issues—what if concerning behaviors are observed?
- Include procedures for participant safety and mandated reporting if applicable
- Document limitations of observational data (does not capture internal states, motivation)

**Expected Output:** A complete behavioral observation protocol containing:
1. Clear statement of purpose and target behaviors
2. Operationalized definitions with examples/non-examples
3. Recording method selection with justification
4. Ready-to-use data collection forms
5. Inter-rater reliability procedures and documentation
6. Context/environmental documentation template
7. Observer training requirements
8. Ethical and practical considerations

## Behavioral Observation Protocol: Classroom Engagement

**Purpose:** Measure on-task behavior during independent work time for progress monitoring of a classroom-wide positive behavior intervention.

**Setting:** Elementary school classroom during independent math practice (20 minutes daily)

**Observers:** Classroom teacher and trained teaching assistant

---

### Target Behavior Definitions

#### Behavior 1: On-Task Behavior

| Element | Definition |
|---------|------------|
| **Behavior Name** | On-Task Behavior |
| **Topography** | Student is engaged with assigned academic materials through visual attention, motor engagement, or verbal participation related to the task |
| **Inclusion Criteria** | Eyes on assigned materials, writing/computing, asking task-related questions, discussing work with peer when permitted |
| **Exclusion Criteria** | Looking around room, head down on desk, talking about non-task topics, out of seat without permission, playing with non-academic materials |
| **Examples** | (1) Writing answers in math workbook, (2) Looking at problem on worksheet and appearing to think, (3) Raising hand to ask about problem 5 |
| **Non-Examples** | (1) Staring at window while pencil is in hand, (2) Talking to neighbor about recess, (3) Drawing in margins of worksheet |

#### Behavior 2: Disruptive Behavior

| Element | Definition |
|---------|------------|
| **Behavior Name** | Disruptive Behavior |
| **Topography** | Behavior that interrupts the learning of self or others |
| **Inclusion Criteria** | Talking out without permission, making noise (tapping, humming), throwing objects, leaving seat without permission, touching others/materials without permission |
| **Exclusion Criteria** | Quiet off-task behavior (daydreaming), asking permission and being denied, accidental noise (dropping pencil) |
| **Examples** | (1) Calling out answer without raising hand, (2) Tapping pencil repeatedly on desk, (3) Walking to sharpen pencil without permission |
| **Non-Examples** | (1) Quietly looking out window, (2) Raising hand and waiting, (3) Stretching in seat |

---

### Recording Method: Momentary Time Sampling

**Rationale:** On-task behavior is continuous and variable. Momentary time sampling provides efficient, representative estimates with minimal observer burden. Research supports 15-second intervals as valid for engagement measurement.

**Procedure:**
- Observe for 20 minutes (during independent work time)
- At the end of each 15-second interval (signaled by silent vibrating timer)
- Record whether each student is ON-TASK or OFF-TASK at that exact moment
- Results in 80 observation points per student per session

**Recording Form:**

```
Student: _______________ Date: _______ Observer: _____________
Setting: Independent Math Time: _____ to _____

Interval Key: + = On-Task, - = Off-Task, X = Unobservable

Minutes 0-5:
| :15 | :30 | :45 | 1:00 | 1:15 | 1:30 | 1:45 | 2:00 | ... |
|-----|-----|-----|------|------|------|------|------|-----|
|     |     |     |      |      |      |      |      |     |

[Continue for 20 minutes = 80 intervals]

Summary:
Total On-Task: ___/80 = ____%
Disruptive incidents (frequency count): ____

Context Notes:
Activity: ________________
Others present: ___________
Unusual events: ___________
```

### Inter-Rater Reliability Procedures

**Training Protocol:**
1. Both observers study operationalized definitions (20 min)
2. Review video examples together, discuss coding decisions (30 min)
3. Practice coding with video—discuss disagreements (30 min)
4. Independent coding of live observation—calculate agreement
5. Continue training until 85%+ agreement on two consecutive sessions

**Reliability Calculation:**
```
Agreement % = (# Intervals with same code ÷ Total intervals) × 100
```

**Schedule:**
- Collect reliability data for 25% of all observation sessions
- Minimum of one reliability session per week
- If reliability drops below 80%, retrain before continuing

**Reliability Documentation Form:**

```
Date: _______ Session #: _____

Observer A codes: _____ On-Task intervals
Observer B codes: _____ On-Task intervals

Interval-by-interval comparison:
Agreements: _____ Disagreements: _____
Agreement %: _____

If <80%: Disagreements reviewed: [ ] Yes
Retraining scheduled: [ ] Yes, date: _____
```

### Observer Training Checklist

**Before First Observation:**
- [ ] Read and can explain operationalized definitions
- [ ] Correctly identifies 10/10 video examples
- [ ] Correctly identifies 10/10 video non-examples
- [ ] Practiced recording method with timer
- [ ] Achieved 85%+ reliability on practice observation
- [ ] Knows procedures for handling ambiguous cases
- [ ] Understands confidentiality requirements
- [ ] Has all necessary materials

**Ongoing Requirements:**
- [ ] Participate in reliability sessions (25% of observations)
- [ ] Maintain 80%+ reliability
- [ ] Report any concerns about definitions or procedures
- [ ] Complete context documentation fully

---

### Ethical Considerations

- **Consent:** Parents informed of observation as part of classroom practice
- **Confidentiality:** Data stored securely, identified by code not name
- **Minimal disruption:** Observer positioned to minimize student awareness
- **Data use:** Results used for program evaluation and individual support planning only
- **Mandated reporting:** If concerning behaviors observed (self-harm, abuse indicators), follow school reporting protocols immediately

---

### Data Analysis Guidelines

**Calculating Summary Statistics:**
- Daily on-task percentage: (On-task intervals ÷ Total intervals) × 100
- Weekly average: Mean of daily percentages
- Trend: Graph weekly averages to visualize change over time

**Interpretation Cautions:**
- Momentary time sampling provides estimates, not exact measures
- Single low-percentage days may reflect context factors, not behavior change
- Compare to baseline and consider environmental factors before conclusions
- Individual student data more variable than class averages

---

**Techniques Used:**
- **ST-02 (Structured Sequential Instructions):** Step-by-step protocol from preparation through data analysis
- **DS-02 (Metric Specification):** Clear definitions of what to measure (on-task intervals) and how to calculate (agreement %)
- **DT-02 (Specific Focus Areas with Examples):** Detailed behavior definitions with concrete examples and non-examples for each target
- **CM-01 (Explicit Context Framing):** Comprehensive context documentation requirements to frame behavioral observations within environmental factors
