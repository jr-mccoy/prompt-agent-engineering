# IFS Polarized Parts Resolution

## Objective

Resolve a polarity between two protector parts (e.g., inner critic ↔ rebellious teen, caretaker ↔ resentful one, perfectionist ↔ procrastinator). The session structure: identify the polarity, unblend Self from each part, mediate a dialogue, hear each part's fear and the exile each protects, negotiate a role-update, and confirm joint commitment with system-level integration.

## When to Use

- Mid-IFS protocol after parts mapping.
- When two parts repeatedly war and the client is stuck cycling (e.g., binge-restrict; work-collapse; people-please / resentment).
- After protector engagement with each side separately.
- Before unburdening the exile each side protects, if accessing the exile depends on resolving the polarity.
- Not when one or both parts are firefighters in acute crisis (substance use, suicidal urge active) — stabilize first.

## Inputs / Context

- Polarity identified from parts map.
- Each part's role, fear, body location, polarity-partner.
- Exile(s) each side protects.
- Self-access status.
- Stabilization status.
- Modality, time (resolution typically 60–90 min).

## Constraints

### Must

- Confirm both parts agree to a dialogue and that Self will mediate.
- **Unblend Self from each part** before dialogue; Self must be present as a separate observer.
- Hear each part **separately first** — its fear, its protective function, the exile it guards.
- Conduct dialogue **through Self**, not part-to-part directly until trust is built.
- Validate each side's positive intent.
- Surface what each part **fears would happen** if the other part won.
- Identify the **shared exile / shared concern** that links the polarity (often the same exile).
- Negotiate a **role-update**: what could each part do differently if the underlying exile were unburdened or supported?
- Get a **specific commitment** from each part for the next week.
- Plan a **between-session check-in** practice (daily 2-minute Self-mediated check-in).
- If polarity reveals an exile that needs unburdening, schedule that as the next session.

### Must Not

- Do not let the more dominant part shout down the other.
- Do not let Self collapse into one side.
- Do not impose resolution; resolution emerges from each part's perspective and the exile beneath.
- Do not bypass the exile each part protects.
- Do not treat one part as "good" and one as "bad."
- Do not assign behavioral homework that one side will sabotage.
- Do not finalize role-updates the parts don't agree to.

## Instructions

1. Confirm the polarity; identify both parts and their fears.
2. Get each part's permission to dialogue with Self mediating.
3. Unblend Self from part A; hear A's fear, role, protected exile.
4. Unblend Self from part B; hear B's fear, role, protected exile.
5. Identify the shared exile or shared concern.
6. Self-mediated dialogue: reflect each side's fear; validate; surface common ground.
7. Negotiate role-update for each part.
8. Get specific commitments for the next week.
9. Plan daily check-in; plan unburdening if exile work is the next step.
10. Document; schedule.

## Verification

- [ ] Polarity named; both parts have roles, fears, and protected exiles documented.
- [ ] Self unblended from each part before dialogue.
- [ ] Each side heard separately first; Self mediates.
- [ ] Common ground / shared exile surfaced.
- [ ] Role-update negotiated, not imposed.
- [ ] Specific weekly commitments from each side.
- [ ] Between-session daily check-in assigned.
- [ ] Exile unburdening scheduled if indicated.
- [ ] Risk re-screen if firefighter involved.
- [ ] Power asymmetry between parts addressed.
- [ ] No "good part / bad part" framing.
- [ ] No fabricated agreement.
