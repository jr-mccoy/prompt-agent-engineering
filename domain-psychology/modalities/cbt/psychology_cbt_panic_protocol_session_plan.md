# CBT for Panic Disorder — Session Plan with Interoceptive Exposure

## Objective

Generate a 50-minute CBT for Panic Disorder session plan placed within a 10–14 session protocol (Barlow's Panic Control Treatment / Clark's cognitive model / Craske inhibitory-learning revision). The plan specifies the session's stage, in-session interoceptive exposure (IE) menu, cognitive work targeting catastrophic misinterpretation of bodily sensations, between-session homework, and outcome metrics.

## When to Use

- DSM-5-TR Panic Disorder (with or without agoraphobia) confirmed.
- Mid-protocol (sessions 3–10), where IE has been introduced and clients are tracking panic frequency / agoraphobic avoidance.
- Telehealth panic protocol (IE can be done on video with safety adjustments).
- High-functioning clients capable of in-vivo exposure homework.
- Not appropriate as a standalone session for someone who has not had panic psychoeducation.

## Inputs / Context

- Diagnosis with comorbidities (especially MDD, agoraphobia, GAD, asthma, cardiac history).
- Medical clearance for IE (cardiac, asthma, pregnancy, vertigo, recent surgery — required if any concern).
- Current PDSS / PASS / panic diary data (frequency, intensity, situational vs unexpected attacks).
- Catastrophic misinterpretation themes (cardiac, suffocation, fainting, losing control, going crazy).
- Safety behaviors (paper bag, water bottle, partner present, sitting near exit, medication carried, escape routes).
- Avoidance hierarchy (agoraphobic situations from least to most feared).
- Protocol stage (early / mid / late).
- Modality: in-office, telehealth, or hybrid.
- Whether client is on PRN benzodiazepine — if so, plan to defer use during sessions and homework where possible (per inhibitory-learning principles).

## Constraints

### Must

- Confirm medical clearance for IE before any procedure that elevates HR / induces hyperventilation; document attestation.
- Match the IE menu to the client's primary feared sensations (cardiac → step-ups, straw breathing; vestibular → spinning; dissociative → staring at lights; respiratory → hyperventilation / straw breathing).
- For each IE procedure, document: duration, expected sensation, client's pre-rating of anxiety (0–100), and post-rating after at least 30 seconds **past** the urge to stop.
- Work toward sensation **tolerance**, not sensation **reduction** (inhibitory learning).
- Identify and reduce safety behaviors during and after IE (no paper bag, no water sip, no "did that feel like a real one?" check).
- Cognitive component must target **catastrophic misinterpretation**, not the sensation itself ("My heart is racing means I'm dying" → tested vs "My heart is racing because I asked it to").
- Homework must include both interoceptive practice and one in-vivo agoraphobia step from the hierarchy.
- Plan a between-session check-in for high-acuity weeks; if not feasible, document why.
- Include a re-screen / outcome line: PDSS or panic-diary count.

### Must Not

- Do not perform IE without medical clearance.
- Do not reduce IE if anxiety is "too high" — IE works through inhibitory learning, not habituation. Reduce only for medical or trauma reasons.
- Do not allow distraction during IE (phone, conversation, breathing techniques meant to escape).
- Do not coach paced breathing as a panic-prevention technique mid-protocol; it tends to become a safety behavior. (Some protocols teach it early as psychoeducation only.)
- Do not skip the cognitive debrief; the IE is a behavioral experiment that needs interpretation.
- Do not target every feared sensation in one session; 2–3 procedures, 3–5 reps each.
- Do not approve PRN benzodiazepine use immediately before or during IE / in-vivo exposure homework unless prescriber-coordinated.

## Instructions

1. Open with PDSS / diary review and current week's data (panic count, peak intensity, situations).
2. Review previous week's homework: IE done? In-vivo step completed? Safety behaviors dropped?
3. Identify the session's target sensation(s) and catastrophic misinterpretation.
4. Set the IE plan:
   - Procedure (e.g., hyperventilation 60–90s; spin 60s; straw breathing 60–120s; step-ups 60s; head between knees then sit up).
   - Pre-rating of anxiety (0–100) and predicted catastrophic outcome ("I'll faint within 30s").
   - Run procedure; client stays through the urge to stop and 30 seconds past.
   - Post-rating; debrief: did the predicted catastrophe occur?
   - Repeat 3–5 times; vary if needed.
5. Process: what was learned? Cognitive shift from "sensation = catastrophe" to "sensation = sensation"?
6. Plan in-vivo: one step from the agoraphobia hierarchy with dropped safety behaviors.
7. Homework: daily IE (named procedure, named duration, named reps), one in-vivo, panic-diary entries.
8. Risk re-screen if PDSS rising or comorbid depression worsening.
9. Document; coordinate with prescriber if med changes warranted.

## Output Format

```
=== CBT-PANIC SESSION PLAN ===
Client: [Initials/MRN]    Session #: [N of ~12]    Date: [YYYY-MM-DD]    Modality: [In-office / Telehealth]
Diagnosis: Panic Disorder [+ agoraphobia / + comorbidities]
Medical clearance for IE: [Date attested / status]
Current PDSS: [N]    Last week's panic count: [N attacks; M situational, U unexpected]

OPENING (5 min)
- Diary review: [counts, intensity, contexts]
- Homework review: IE completed [Y/N]; in-vivo step [Y/N]; safety behaviors status

SESSION TARGET
Target sensation(s): [Cardiac / respiratory / vestibular / dissociative / GI]
Catastrophic misinterpretation: "[verbatim]"
Today's belief rating (0–100): [N]

INTEROCEPTIVE EXPOSURE PLAN (25–30 min)
Procedure 1: [Name, duration]
- Pre-rating anxiety: [0–100]
- Predicted catastrophe: "[verbatim]"
- Reps: [3–5]
- Safety behaviors to drop: [list]
- Post-rating per rep: [r1, r2, r3 ...]

Procedure 2: [Name, duration]
- [same fields]

(Procedure 3 if time)

COGNITIVE DEBRIEF (10 min)
- What did the prediction get right / wrong?
- Sensation = sensation; not sensation = catastrophe.
- Re-rate belief in catastrophic misinterpretation: [0–100]

IN-VIVO STEP (5 min plan)
Step from hierarchy: [Specific situation]
Safety behaviors dropped: [...]
When/where: [...]

HOMEWORK
- IE: [procedure, daily, N reps × N seconds]
- In-vivo: [step + frequency this week]
- Panic diary: every attack, with situation / sensation / interpretation / what client did
- Between-session check-in: [Date/method, if applicable]

OUTCOME / RISK
- PDSS trajectory: [trend]
- Risk re-screen: [If indicated]
- Prescriber coordination needed: [Y/N — why]
- Next session focus: [...]
```

## Verification

- [ ] Medical clearance documented before IE.
- [ ] IE procedures matched to feared sensations.
- [ ] Pre/post anxiety ratings per procedure rep.
- [ ] Catastrophic misinterpretation explicit and re-rated after IE.
- [ ] Safety behaviors named and reduction plan documented.
- [ ] Inhibitory-learning frame used (tolerance, not reduction).
- [ ] In-vivo step from hierarchy assigned.
- [ ] Homework specifies procedure, duration, reps, daily cadence.
- [ ] Risk re-screen if comorbid MDD or PDSS rising.
- [ ] Prescriber coordination noted if PRN benzodiazepine in play.
- [ ] No fabricated client report; pre/post ratings come from client.
