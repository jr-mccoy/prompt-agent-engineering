# DBT Emotion Regulation Module — Lesson Plan

## Objective

Generate a 90–120 minute DBT skills-group lesson plan for one Emotion Regulation skill from Linehan's manual: warmup/mindfulness, homework review, didactic teach of the target skill, in-group practice, between-session homework, and closing mindfulness. The plan specifies materials, time blocks, common stuck points, and adaptations for adolescents / ASD / cognitive limits.

Supported target skills (one per lesson):
- **Check the Facts** — verifying whether an emotion fits the facts of the situation.
- **Opposite Action** — acting opposite to the emotion's action urge when the emotion does not fit the facts or fitting at the moment is ineffective.
- **Problem Solving** — when emotion fits the facts; solve the problem rather than regulate the emotion.
- **PLEASE** — treat PhysicaL illness, balanced Eating, avoid mood-Altering substances, balanced Sleep, Exercise.
- **Build Mastery / Build Positive Experiences** — short-term and long-term.
- **Mindfulness of Current Emotion** — non-judgmental awareness of the wave.
- **ABC PLEASE** umbrella (only if the group covers it as a single lesson).

## When to Use

- Adherent DBT skills-group, Emotion Regulation rotation.
- IOP / PHP DBT module.
- Adapted DBT for adolescents, BPD, BED, SUD, ASD, or high-functioning psychotic-spectrum.
- Telehealth group (breakouts and shared docs).
- Not a substitute for chain-analysis or individual-therapy work.

## Inputs / Context

- Target skill for the lesson (one).
- Group composition: ages, diagnoses, primary targets, modality.
- Cycle position (early in the rotation, mid, end-of-rotation review).
- Linehan manual edition reference and any program-specific adaptations.
- Co-leader's role.
- Group rules (no-suicide-talk in group, confidentiality, attendance, missed-session policy).
- Risk-management framework (e.g., 4 consecutive missed sessions = dropped).
- Materials available (handouts, whiteboard, breakout rooms for telehealth).
- Time available (90 vs 120 min).

## Constraints

### Must

- Allocate time blocks summing to the available group length, with mindfulness opening and closing.
- Use Linehan's handout and worksheet numbering; cite the specific handout/worksheet for the skill.
- Include a **homework review** segment at the start; track who completed and who did not (TIB classification at the program level).
- Teach **one** new skill per lesson; review previously taught skills in context.
- Include in-group practice with a real example from a participant (or volunteered hypothetical).
- Frame Opposite Action with the **check-the-facts gate**: do not coach opposite action without first asking whether the emotion fits the facts.
- For Problem Solving, frame it as "if the emotion fits the facts, problem-solve; if it does not, opposite action."
- For PLEASE, include the link to vulnerability factors on the diary card.
- Set specific between-session homework assignments per skill (named worksheet, named application).
- Plan adaptations for the group's developmental and cognitive composition.
- Include a closing mindfulness practice and a wins-and-stuck-points roundtable.

### Must Not

- Do not invite suicide / self-harm content into group; route to individual therapy.
- Do not teach more than one new skill in one lesson.
- Do not let group time become individual therapy time; redirect to the skill.
- Do not skip the homework review even if attendance is low.
- Do not use loaded examples that risk vicarious trauma (sexual assault, child abuse) as in-group practice cases.
- Do not let participants debate the skill abstractly; require concrete application.
- Do not skip the closing mindfulness — it anchors group state for re-entry.

## Instructions

1. **Open** with a brief mindfulness practice (5 min). Name observe/describe/participate practice used.
2. **Homework review** (15 min): which assignments were attempted; barriers and wins; behavioral chain on TIB if pattern.
3. **Didactic teach** (20–30 min): handout walked through, examples, common misconceptions.
4. **In-group practice** (20–30 min): real-but-non-volatile example; participants apply the skill on a worksheet.
5. **Common stuck points**: name them and demonstrate fixes (e.g., for Opposite Action: opposite is "all the way"; partial = not opposite).
6. **Pair / breakout practice** (10–15 min): dyads or breakouts.
7. **Roundtable**: wins and stuck points from each member; 1–2 sentences each.
8. **Homework assignment** (5 min): specific worksheet, application target, due-by date.
9. **Closing mindfulness** (3–5 min).
10. Document attendance, participation level, and consultation-team items.

## Verification

- [ ] One target skill per lesson.
- [ ] Time blocks sum to lesson length; mindfulness opens and closes.
- [ ] Linehan handout/worksheet cited.
- [ ] Homework review present.
- [ ] Worked example and in-group practice present.
- [ ] Check-the-facts gate enforced before Opposite Action teach.
- [ ] Common stuck points named and fixes shown.
- [ ] Homework assignment specific to the skill and applied to real life.
- [ ] Adaptations for developmental and cognitive composition included.
- [ ] Consultation-team items captured.
- [ ] No suicidality content invited into group.
- [ ] No fabricated attendance.
