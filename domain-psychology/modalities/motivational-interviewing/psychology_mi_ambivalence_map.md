# MI Ambivalence Map (Two-Column + Double-Sided Reflections)

## Objective

Build a structured ambivalence map for a single change topic with two columns (forces for staying the same; forces for change), generate a series of double-sided reflections that integrate the two columns, and use a values-bridge to evoke commitment talk. Output is a usable in-session worksheet plus a list of double-sided reflections the clinician can deploy.

## When to Use

- Client is stuck in ambivalence and decisional balance has been done but not landed.
- Client expresses both change and sustain talk in the same turn ("I want to quit, but I also …").
- After values clarification, when the values pull is not yet connected to the change topic.
- Pre-planning for a difficult next session.
- Not when client is already past ambivalence (in preparation / action — skip to planning).

## Inputs / Context

- Change topic.
- Client's recent change-talk and sustain-talk utterances (verbatim if possible).
- Values from earlier work (or to be elicited).
- Stage of change.
- Stance (typically change-favoring at this point if values support change; equipoise if not).
- Modality, time (15–25 min).

## Constraints

### Must

- Map two columns clearly:
  - **Staying the same** — forces for, costs of (these are sustain-talk drivers).
  - **Changing** — forces for, costs of (these include change-talk drivers).
- Use the client's words verbatim where possible.
- Generate **5–10 double-sided reflections** that integrate sustain and change. Each reflection: "On one hand … and on the other hand …." End on the change-talk side to amplify when stance is change-favoring; otherwise alternate.
- Bridge to **values**: ask which values are touched by each column; note discrepancy between behavior and values.
- Surface **commitment language** ("I want to," "I need to") and reflect it.
- Use the **importance / confidence ruler** (0–10): "How important is making this change?" and "How confident?" Follow up with "Why not lower?" to elicit change talk.
- Plan **next step** consistent with the client's expressed direction; honor autonomy.
- Document MI-adherence; flag any righting reflex.

### Must Not

- Do not load the change side with clinician-added items.
- Do not over-end reflections on the sustain side; this deflates change talk.
- Do not deliver advice mid-mapping.
- Do not finalize a commitment the client hasn't made.
- Do not use the importance ruler to argue ("Why is it only a 5?"); always use "why not lower" to evoke change talk.
- Do not collapse multiple change topics into one map.

## Instructions

1. Set the topic with the client.
2. Build the two-column map; client populates both sides using their own words.
3. Reflect each side with simple reflections first.
4. Generate double-sided reflections integrating the two columns.
5. Bridge to values: which values are touched by each column.
6. Importance ruler 0–10; "why not lower?"
7. Confidence ruler 0–10; "why not lower?"
8. Reflect commitment language when it appears.
9. Set the next step the client is ready to take (or not — autonomy).
10. Document.

## Output Format

```
=== MI AMBIVALENCE MAP ===
Client: [Initials/MRN]    Date: [YYYY-MM-DD]    Topic: [Behavior change in focus]
Stage of change: [...]    Stance: [Equipoise / Change-favoring]

TWO-COLUMN MAP

| STAYING THE SAME (sustain side) | CHANGING (change side) |
|----------------------------------|------------------------|
| Forces for staying:               | Forces for changing:    |
| - [client verbatim]               | - [client verbatim]     |
| - [...]                           | - [...]                 |
| Costs of staying:                 | Costs of changing:      |
| - [...]                           | - [...]                 |

DOUBLE-SIDED REFLECTIONS (5–10)
1. "On one hand, [sustain]; and on the other hand, [change]."
2. "[...]"
3. "[...]"
4. "[...]"
5. "[...]"
(Ordering: in change-favoring stance, end most on the change side.)

VALUES BRIDGE
- Values touched by sustain column: [...]
- Values touched by change column: [...]
- Discrepancy (where current behavior conflicts with stated values): "[...]"

RULERS
- Importance (0–10): [N]    Why not lower?: "[client verbatim — change talk]"
- Confidence (0–10): [N]    Why not lower?: "[client verbatim]"

COMMITMENT LANGUAGE OBSERVED
- "I want to …": "[verbatim]"
- "I need to …": "[verbatim]"
- "I plan to …": "[verbatim if any]"

NEXT STEP (client-determined)
- [...]
- Autonomy: client retains the choice.

MI-ADHERENCE SELF-CHECK
- Righting-reflex moments: [...]
- Reflections preference: [...]
- Open vs closed questions: [...]

HOMEWORK / FOLLOW-UP
- [Open-ended noticing task]
- Next session: [Date]

CLINICIAN NOTES
- Cultural / life-context constraints: [...]
- Risk-related considerations: [...]
- Coordination needed (PCP, prescriber, family): [...]
```

## Verification

- [ ] Two columns built with client's own words.
- [ ] 5–10 double-sided reflections; ordering matches stance.
- [ ] Values bridge present; discrepancy named.
- [ ] Importance and confidence rulers with "why not lower" follow-ups.
- [ ] Commitment language identified verbatim.
- [ ] Next step is client-determined.
- [ ] Autonomy preserved.
- [ ] MI-adherence self-check completed.
- [ ] No clinician-added forces / no righting reflex.
- [ ] No fabricated client wording.
