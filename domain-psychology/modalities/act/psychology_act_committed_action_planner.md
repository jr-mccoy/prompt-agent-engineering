# ACT Committed Action Planner

## Objective

Convert a single value (in client's verb-phrase voice) into a committed-action plan: specific behavior, time, place, willingness rating, anticipated barriers (the FEAR acronym — Fusion, Evaluation, Avoidance, Reason-giving), and a graduated willingness ladder so the client commits to a step they are ≥ 70% willing to take.

## When to Use

- Following values clarification or matrix work.
- Mid-ACT protocol when commitment is the next step.
- Re-engagement after a stuck patch in treatment.
- Group / brief ACT settings.
- Pre-termination consolidation.
- Not when client is in acute crisis or when value direction is itself unclear.

## Inputs / Context

- One value (client's words, verb-phrase form).
- Importance and current-living-alignment ratings (from card sort or matrix).
- Recent toward / away moves data.
- Known fusion patterns and avoidance behaviors.
- Workability frame already established.
- Cultural / life-context constraints on action (work schedule, caregiving, finances).
- Time available in session (committed-action planning runs 20–40 min).
- Risk plan / safety considerations if acting toward values requires exposure to risk (e.g., re-entering a conflicted relationship).

## Constraints

### Must

- Anchor the action to **one** value statement in client's voice.
- Specify the action with **who / what / where / when / how long / how often**. Smartphone-photo specific.
- Confirm the action is a **value-consistent behavior**, not a goal or outcome (running 10 minutes Tuesday morning is a value-consistent behavior; "lose 20 lbs" is a goal).
- Conduct a **willingness check (0–100)**: how willing is the client to take this step **with whatever shows up internally**? If < 70, downsize the step (ladder).
- Anticipate **FEAR barriers**: Fusion, Evaluation, Avoidance, Reason-giving — specifically.
- Pre-plan **defusion / acceptance moves** for each anticipated barrier.
- Frame willingness as **all or nothing** at the step level (you either step on the field or you don't), even though the step itself can be small.
- Build a **graduation plan**: if this step is workable, what's the next? If it's not, the issue is willingness, not difficulty.
- Plan **tracking**: how the client will log it.
- Bridge to next-session debrief: what counts as "tried" vs "didn't try."

### Must Not

- Do not let committed action become outcome-contingent ("if I feel good"); willingness is in the showing-up, not the result.
- Do not skip the workability link to the named value.
- Do not assign actions the client is not ≥ 70% willing to take.
- Do not collapse multiple actions in one plan; one action per plan.
- Do not let goal-setting language replace values language.
- Do not promise that taking the action will reduce the unwanted internal experience; the goal is the value direction.
- Do not skip the FEAR pre-plan; barriers always arise.

## Instructions

1. Confirm the value statement (verb-phrase, client's words).
2. Brainstorm 3–5 candidate value-consistent behaviors for the next 1–2 weeks.
3. Pick **one** (client chooses).
4. Specify it: who/what/where/when/duration/frequency.
5. Willingness check (0–100). If < 70: downsize until ≥ 70.
6. FEAR pre-plan:
   - **Fusion** — likely thought ("I'll fail again"). Defusion move planned.
   - **Evaluation** — likely judgment ("This is stupid"). Defusion / "thank your mind."
   - **Avoidance** — likely escape behavior. Replacement plan.
   - **Reason-giving** — likely reasons not to do it ("I'm too tired"). Plan: notice the reason-machine, act anyway.
7. If applicable: identify a values-buddy or accountability cue (text after).
8. Build a graduation ladder (next step if completed; next step if not — usually downsize).
9. Tracking method.
10. Schedule debrief.

## Output Format

```
=== ACT COMMITTED-ACTION PLAN ===
Client: [Initials/MRN]    Date: [YYYY-MM-DD]    Session #: [N]    Modality: [...]

VALUE (anchor)
"[Verb-phrase, client's words]"
Linked domain: [...]
Importance (0–10): [N]    Current alignment (0–10): [N]

CANDIDATE BEHAVIORS (brainstorm)
- [...]
- [...]
- [...]

SELECTED COMMITTED ACTION (one)
What:      [Specific behavior]
Who:       [With whom, if any]
Where:     [Specific location]
When:      [Specific date/time]
Duration:  [How long]
Frequency: [How often this week]

WORKABILITY ANCHOR
"If I take this step, does it move me toward my value?" [Y/N from client]

WILLINGNESS CHECK
Initial willingness (0–100): [N]
If < 70: downsized step → [New action] → willingness now [N ≥ 70]

FEAR PRE-PLAN
- Fusion likely thought: "[verbatim]" → defusion move: [...]
- Evaluation likely: "[verbatim]" → response: [...]
- Avoidance likely behavior: [...] → replacement: [...]
- Reason-giving likely: "[reason]" → response: [notice reason-machine, act anyway]

VALUES-CONSISTENT, NOT OUTCOME-CONTINGENT
- This step counts as "tried" if: [Action attempted regardless of feelings]
- This step does NOT count as "tried" if: [Did not show up at all]

TRACKING
- Method: [Daily log / app / paper / text to clinician]
- Buddy / accountability cue: [...]

GRADUATION LADDER
- If completed: next step → [...]
- If not completed: down-step → [...] (issue likely willingness, not difficulty)

NEXT SESSION DEBRIEF
- Date: [...]
- Debrief format: [Workability review, not performance review]

CLINICIAN NOTES
- Risk / safety considerations: [...]
- Cultural / life-context constraints honored: [...]
- Defusion / acceptance work needed before next step: [...]
```

## Verification

- [ ] Single value anchor, in client's verb-phrase voice.
- [ ] One committed action selected, fully specified.
- [ ] Workability link to value confirmed.
- [ ] Willingness ≥ 70 (downsized if not).
- [ ] FEAR pre-plan addresses all four sources.
- [ ] "Counts as tried" defined behaviorally, not by outcome.
- [ ] Tracking method specified.
- [ ] Graduation ladder present.
- [ ] Debrief scheduled.
- [ ] No outcome-contingent framing.
- [ ] No fabricated client willingness.
