# ACT Values Card Sort (Facilitated Clarification)

## Objective

Facilitate an ACT values card sort to clarify the client's freely chosen, intrinsically valued life directions across standard life domains. Output is a values map: domains, value statements in client's voice, importance ratings, current-living alignment ratings, and discrepancy patterns ready for committed-action planning.

## When to Use

- Early ACT protocol (sessions 2–4) after creative-hopelessness and willingness work.
- When clients are stuck on goals because the underlying values are unclear.
- Mid-treatment reset when committed actions have plateaued.
- Re-clarification at major life transitions (divorce, retirement, relocation, identity transitions).
- Group ACT or workshop settings (adapted to short-format).
- Not appropriate as a substitute for risk assessment or for clients in acute crisis where stabilization is primary.

## Inputs / Context

- Card deck choice: Personal Values Card Sort (PVCS, Miller et al.), Values Card Sort from Hayes/Strosahl, or program-developed deck (~50–100 cards or domain-list).
- Life-domain framework (Hayes': intimate relationships, family, friends, work, education, recreation, spirituality, citizenship, physical well-being, parenting).
- Presenting problem and treatment targets.
- Cognitive / language considerations (reading level, English fluency, cultural fit of value categories).
- Modality: physical cards in-office, telehealth screen-share, or worksheet.
- Time available (typically 30–60 min for full sort).
- Prior values work or ACT exposure.

## Constraints

### Must

- Use **freely chosen, present-tense verb phrases** for value statements ("Showing up for my kids in the morning," not "Being a good parent").
- Distinguish **values** (ongoing directions, like "west") from **goals** (achievements that can be completed, like "arrive in Denver").
- Rate **importance (0–10)** and **current-living alignment (0–10)** per value, separately.
- Identify **discrepancy** (importance − alignment) per value; flag highest-discrepancy values for committed-action work.
- Use the client's words; do not import clinician's preferred values.
- For values that conflict (work vs family time), name the conflict; do not force a hierarchy unless client wants one.
- Connect to **workability**: a value that is high-importance and low-alignment is a candidate for committed action, not a verdict on the client.
- For grief / loss / identity-loss work, recognize values that have changed across life stages.
- Document cultural / religious values without flattening them into Western categories.
- Adapt the deck if standard cards do not fit (add cards, translate cards, remove non-applicable).

### Must Not

- Do not present values as a moral inventory ("are you a good person?").
- Do not allow the activity to become a goal-setting exercise prematurely.
- Do not let the client default to "all of them are important"; force-sort into tiers if helpful (top 10 / next 10 / not now).
- Do not introduce clinician-imported values (e.g., "you should value self-care").
- Do not force a single dominant value; values are multiple and dynamic.
- Do not skip the in-client-voice rewording step.
- Do not finalize values that the client experiences as "shoulds" from family/religion/culture without checking whether they are also freely chosen.

## Instructions

1. Brief frame: explain values vs goals; "west, not Denver."
2. First pass: client sorts cards into **Very important / Important / Not important / Not now** stacks.
3. Reduce Very important to a working list (10–15).
4. For each, rewrite in client's verb-phrase voice (present tense, action-oriented).
5. Rate **importance (0–10)** for each.
6. Rate **current-living alignment (0–10)** for each.
7. Compute discrepancy (importance − alignment) per value.
8. Identify top-3 highest-discrepancy values.
9. Note conflicts and "shoulds" — distinguish chosen from imposed.
10. Output values map; bridge to committed-action planning if appropriate.

## Verification

- [ ] Value statements are verb-phrases in client's voice.
- [ ] Values vs goals distinction enforced.
- [ ] Importance and alignment each rated 0–10.
- [ ] Discrepancy computed; top values identified.
- [ ] Domain coverage noted; absent domains addressed.
- [ ] Chosen vs imposed check completed.
- [ ] Cultural / religious framing preserved.
- [ ] Conflicts noted, not resolved by clinician.
- [ ] No clinician-imported values.
- [ ] Bridge to committed-action planning set up.
- [ ] No fabricated client wording.
