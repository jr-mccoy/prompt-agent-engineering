# Behavioral Parent Training Module (PCIT / BPT)

## Objective

Construct a parent-mediated behavioral parent training (BPT) session/module anchored to Parent-Child Interaction Therapy (PCIT) and the broader Hanf-model lineage (Kazdin Parent Management Training, Incredible Years, Triple P). The intervention coaches the **parent** — not the child — to deliver differential attention, effective commands, labeled praise, and a correctly executed time-out. Output is a PRIDE-skills coaching tracker, a command-quality review, an antecedent → behavior → consequence behavior plan, and daily parent homework.

## When to Use

- Disruptive behavior in young children (primary scope ~2–7 years: oppositional, noncompliant, aggressive, tantrums); adapt structure for older children.
- After a functional/behavioral picture is established and child-directed interaction is appropriate.
- When the change agent is the parent/caregiver and the clinician's role is live coaching.
- Two-phase delivery: CDI (Child-Directed Interaction — relationship/attention skills) before PDI (Parent-Directed Interaction — compliance/discipline skills).
- Not for use as the primary intervention where active abuse/neglect, untreated parental crisis, or child safety risk requires prior referral; not a substitute for clinician judgment, DPICS-coded mastery decisions, or a safety/risk assessment.

## Inputs / Context

- Child age, presenting disruptive behaviors, frequency/intensity, and settings.
- Current parenting strategies and the praise-to-command pattern observed.
- Phase (CDI vs PDI) and prior session mastery data (e.g., DPICS-style counts).
- Caregiver(s) participating; co-parent consistency across homes/settings.
- Developmental, language, sensory, or neurodivergence considerations (e.g., ADHD, ASD).
- [clinician input required] — mastery thresholds, time-out modifications, and any safety constraints (e.g., medical, elopement, self-injury during time-out).

## Constraints

### Must

- Frame the intervention as **parent-mediated**: skills are coached into the parent; the child is not the direct client of the technique.
- For CDI, structure the five **PRIDE** skills — **P**raise (labeled), **R**eflection (of appropriate talk), **I**mitation, **D**escription (behavioral), **E**njoyment — and the "don't" skills to reduce (commands, questions, criticism).
- Build **differential attention**: attend to/praise prosocial behavior; use **selective (active) ignoring** for attention-maintained minor misbehavior, with planned re-engagement the moment appropriate behavior returns.
- Distinguish **effective vs ineffective commands**: direct, positively stated, one-step, developmentally appropriate, specific, given one at a time, with wait-time — vs. vague, chained, question-form, or "let's"/indirect commands.
- For PDI, structure the **effective command → wait → labeled praise for compliance OR two-choice/warning → time-out sequence** as a coherent contingency, with time-out executed correctly (clear instruction, consistent location, brief and quiet, no negotiation, return to the original command afterward).
- Track a **praise:command ratio** and shift it toward praise; specify labeled (not global) praise.
- Provide **DPICS-style coding** of parent skills (counts of labeled praise, reflections, behavior descriptions vs. commands, questions, criticism) to gauge mastery.
- Include **live coaching** language (what the clinician says in-the-ear/in-the-moment to the parent).
- Assign **5-minute daily special-time** homework and a tracking method.

### Must Not

- Do not make the child the recipient of the technique or coach the child instead of the parent.
- Do not blend CDI and PDI in a way that introduces discipline before relationship/attention skills are established.
- Do not present time-out as punishment-by-isolation without the surrounding contingency (command, warning, return-to-command); do not endorse harsh, lengthy, shaming, or physical discipline.
- Do not count global praise ("good job") as labeled praise.
- Do not fabricate DPICS thresholds, session counts, or program-specific figures; mark protocol-specific cutoffs as [clinician input required].
- Do not ignore safety: if time-out escalates to danger or abuse/neglect surfaces, route to clinician/safety pathway rather than proceeding.
- Do not finalize a behavior plan the caregiver is not willing or able to implement consistently.

## Instructions

1. Confirm phase (CDI or PDI), child age, and target behaviors; restate the parent-mediated frame.
2. For CDI: define each PRIDE skill with a parent-facing example; identify the "avoid" skills and why.
3. Set up differential attention and selective ignoring: name which behaviors get attention, which get planned ignoring, and the re-engagement trigger.
4. Review the parent's current commands; sort recent examples into effective vs ineffective and rewrite the ineffective ones.
5. For PDI: lay out the command → wait → praise/compliance OR two-choice warning → time-out → return-to-command sequence as a single contingency.
6. Build the A-B-C behavior plan for 1–2 priority behaviors (antecedent supports, the behavior defined observably, the consequence/contingency).
7. Provide live-coaching scripts the clinician can deliver in the moment.
8. Generate DPICS-style coding targets and the current praise:command ratio with a goal ratio.
9. Assign 5-minute daily special time plus tracking; set the next mastery checkpoint.
10. Note adaptations for the child's developmental/neurodivergent profile.

## Verification

- [ ] Intervention framed as parent-mediated; parent (not child) is coached.
- [ ] All five PRIDE skills defined with examples; "avoid" skills named.
- [ ] Differential attention + selective ignoring with a re-engagement trigger.
- [ ] Effective vs ineffective commands distinguished and ineffective ones rewritten.
- [ ] Praise:command ratio recorded with a goal.
- [ ] Full PDI contingency (command → wait → praise/two-choice → time-out → return) present and correct.
- [ ] A-B-C behavior plan completed for priority behaviors.
- [ ] Live-coaching scripts and DPICS-style mastery targets included.
- [ ] 5-minute daily special-time homework with tracking assigned.
- [ ] CDI sequenced before PDI; no harsh/physical discipline endorsed.
- [ ] Safety/abuse pathway preserved; protocol-specific thresholds marked [clinician input required].
- [ ] No fabricated DPICS thresholds, session counts, or program figures.
