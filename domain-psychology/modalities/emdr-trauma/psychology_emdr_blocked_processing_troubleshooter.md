# EMDR Blocked Processing Troubleshooter

## Objective

Diagnose the form of blocked processing in an active Phase 3–4 EMDR session — looping, SUDS not moving, intellectualization, somatic freeze, dissociation, blocking belief, feeder memory — and select a matched intervention: cognitive interweave, resource link, feeder-memory check, pacing change, or pause-and-stabilize.

## When to Use

- Mid-Phase-3 (desensitization) when SUDS has stalled for 3+ sets without movement or has rebounded.
- Mid-Phase-4 (installation) when VOC of the positive cognition is not strengthening.
- When the client begins to dissociate, freeze, or "go away" during BLS.
- When the client gets stuck on the same image or thought set after set.
- Not for routine slow movement; some clusters take time. Apply when stagnation or worsening is clear.

## Inputs / Context

- Current target memory, NC, PC, SUDS, VOC, body scan.
- Sets-since-movement count.
- Form of stuckness observed (loop, intellectualization, body-only, affect-only, dissociation).
- Therapist's hypothesis (blocking belief? feeder? pacing?).
- Stabilization status; resource access in the room.
- Risk modifiers and dissociation profile.
- Time remaining in session.
- Whether a between-session check-in is available.

## Constraints

### Must

- Diagnose the **form** of block before intervening:
  - **Loop**: same image/thought returning unchanged after multiple sets.
  - **No SUDS movement**: SUDS rating unchanged after 3+ sets.
  - **Intellectualization**: client narrates rather than experiences.
  - **Somatic freeze**: client reports inability to feel anything; flat affect.
  - **Dissociation**: depersonalization / derealization / parts switching / time loss.
  - **Blocking belief**: a held belief preventing movement ("If I let go of this, something bad will happen").
  - **Feeder memory**: an earlier memory feeding the current target — accessing it may move the work forward.
- Pick **one** matched intervention; do not stack.
- If dissociation: pause processing, ground, resource, end Phase 3 if needed; do not push.
- Use cognitive interweaves **sparingly** — they are nudges, not lectures; one short interweave then another set.
- Interweave types and matches:
  - **Responsibility** ("Whose fault is it?") for blocking beliefs about blame.
  - **Safety** ("Are you safe now?") for present-moment fusion.
  - **Choice / Control** for powerlessness loops.
  - **Education** (brief psychoed) for cognitive errors.
  - **Time** ("How old are you now? Where are you now?") for orientation loops.
  - **Compassion / Adult-self** for shame.
- For feeder-memory check: ask "Where do you first remember feeling this way?" with grounding readiness.
- For somatic block: shift to body resource (containment, somatic experiencing micro-resource) or end the set and resource.
- Document each intervention used and the response.
- Plan between-session check-in if processing was paused mid-target.

### Must Not

- Do not push through dissociation with more BLS.
- Do not deliver multiple interweaves in one set.
- Do not lecture or therapize within the interweave; it's a brief redirect.
- Do not access a feeder memory without grounding readiness and stabilization.
- Do not end Phase 3 without containment and orientation when an incomplete target is left open.
- Do not blame the client for blocked processing; reformulate.
- Do not abandon the target altogether; document for next session.

## Instructions

1. Pause; observe and name the form of blocked processing.
2. Check stabilization, orientation, and the window of tolerance.
3. Pick the matched intervention from the menu above.
4. Deliver in 1–2 sentences; run another short set.
5. Re-check SUDS / VOC / body / orientation.
6. If still blocked after 1–2 attempts: switch interventions, or pause and stabilize.
7. If dissociating: end Phase 3, ground, resource, plan for next session.
8. Document intervention type, response, sets done, end-of-session SUDS/VOC.
9. Plan between-session check-in if incomplete.
10. Update the AIP formulation if a new feeder/cluster emerged.

## Verification

- [ ] Form of block diagnosed before intervention.
- [ ] One matched intervention selected.
- [ ] Interweaves brief (1–2 sentences).
- [ ] No pushing through dissociation; pause and ground.
- [ ] Feeder access only with grounding readiness.
- [ ] End-of-session orientation and containment.
- [ ] Incomplete target documented; between-session plan in place.
- [ ] AIP formulation updated if new material emerged.
- [ ] Consultation flag set when warranted.
- [ ] No lecturing or therapizing within interweaves.
- [ ] No fabricated client report.
