# EMDR Target Sequence Organizer (Past / Present / Future)

## Objective

Organize an EMDR target sequence plan that orders past memories, present triggers, and future templates by cluster and theme, identifying touchstone memories per cluster and a processing order consistent with Shapiro's three-pronged protocol and the Adaptive Information Processing (AIP) model.

## When to Use

- EMDR Phase 1 (history-taking and treatment planning) and Phase 2 (preparation) wrap-up before Phase 3 begins.
- Re-planning mid-treatment when targets accumulate.
- Complex / chronic PTSD where targets multiply and need cluster organization.
- After resourcing has been completed and stabilization markers are in place.
- Not appropriate before stabilization is achieved or if dissociative phenomena are unaddressed.

## Inputs / Context

- Phase 1 history including adverse childhood experiences, single-incident traumas, attachment ruptures.
- Symptom map: PTSD criteria endorsed, recent triggers, current functional impairment.
- Outcome instruments: PCL-5, ITQ (for complex PTSD), CAPS-5 if available, dissociation screen (MID / DES-II).
- Negative and positive cognitions per memory where known.
- Stabilization status: resourcing completed; container/safe-place established; affect tolerance window.
- Modality, frequency, session length.
- Comorbidities (substance use, eating disorder, suicidality) requiring concurrent management.
- Cultural / spiritual context shaping memory and resource selection.

## Constraints

### Must

- Map memories into **clusters** by theme (e.g., abandonment, humiliation, body-violation, betrayal, lack-of-safety), not by chronology only.
- Identify a **touchstone memory** per cluster — the earliest / most charged memory the cluster radiates from.
- Sequence within each cluster: process the touchstone first, then more recent contributors, then present triggers, then future template.
- Use the **three-pronged protocol**: past contributors → present triggers → future template (per cluster, not across the whole plan).
- Confirm **stabilization markers** before scheduling Phase 3:
  - Affect-tolerance window adequate.
  - Resources (calm place, container, protector figure) installed.
  - Dissociation screened and managed.
  - No imminent suicide risk; safety plan in place.
- For complex / chronic trauma, sequence by **cluster acuity** (the one most active in current functioning first) rather than chronological.
- Document **risk modifiers**: targets that may activate suicidality, substance urges, or dissociation; pace accordingly.
- For attachment / developmental trauma, consider longer Phase 2 and resource-installation cycles before Phase 3.
- Update the sequence each phase 1–2 cycle as new clusters emerge.

### Must Not

- Do not start Phase 3 without confirmed stabilization markers.
- Do not begin with a memory the client cannot tolerate; cluster acuity does not override window of tolerance.
- Do not sequence purely chronologically when later memories drive current functional impairment.
- Do not skip dissociation screen.
- Do not assume a single-incident PTSD path when adverse childhood experiences are unaddressed.
- Do not finalize a plan without explicit informed consent including reprocessing length, intensity, and possible distress between sessions.
- Do not fabricate memories the client did not report.

## Instructions

1. Review Phase 1 history; list discrete memories with brief tags and current charge (SUDS 0–10).
2. Cluster memories by theme.
3. For each cluster, identify the touchstone memory (earliest / most charged).
4. Within each cluster, order: touchstone → contributors → present triggers → future template.
5. Across clusters, order by current functional acuity unless contraindicated.
6. Confirm stabilization markers; document.
7. Risk modifiers per target.
8. Set the next 3–5 sessions' target order.
9. Plan re-administration of PCL-5 / ITQ at a defined cadence.
10. Schedule reformulation review (every 4–6 sessions or after each cluster).

## Verification

- [ ] Memories clustered by theme; touchstones identified.
- [ ] Within-cluster order: touchstone → contributors → present → future.
- [ ] Across-cluster order by acuity with rationale.
- [ ] Stabilization markers confirmed before Phase 3 scheduling.
- [ ] Dissociation screen documented; plan for windowing in place.
- [ ] Risk modifiers per target.
- [ ] Outcome monitoring cadence set.
- [ ] Informed consent for reprocessing documented.
- [ ] Consultation / supervision item flagged.
- [ ] No fabricated memories.
- [ ] Reformulation review scheduled.
