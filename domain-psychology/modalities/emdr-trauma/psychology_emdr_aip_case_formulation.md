# EMDR AIP Case Formulation

## Objective

Produce an Adaptive Information Processing (AIP) case formulation: a model of how unprocessed (maladaptive) memory networks drive current symptoms, what positive (adaptive) networks are available to link to in reprocessing, and how the planned EMDR sequence will move material from maladaptive into adaptive storage. The formulation explicitly links each presenting symptom to a memory cluster and a treatment hypothesis.

## When to Use

- End of Phase 1, before target-sequence organization and Phase 2 wrap-up.
- Reformulation mid-treatment when blocked processing or new clusters arise.
- Consultation / supervision case presentation.
- Documentation for insurance authorization or program admission.
- Not appropriate as a stand-in for stabilization work — formulation can be drafted while stabilization continues but Phase 3 requires confirmed markers.

## Inputs / Context

- Phase 1 history including ACEs, single-incident events, attachment disruptions, medical traumas, identity-based traumas.
- Symptom map (PTSD criteria, complex PTSD criteria, depression / anxiety / dissociation / somatic symptoms).
- Negative / positive cognition clusters per memory.
- Adaptive resources / strengths: relationships, mastery, competence, body capacities, spiritual / cultural protective resources.
- Outcome instruments: PCL-5, ITQ, MID/DES-II, PHQ-9, GAD-7.
- Comorbidities (substance use, eating disorder, suicidality, chronic pain) and how they may have been adaptive in the past.
- Cultural / spiritual frame.
- Modality, frequency, anticipated treatment length.

## Constraints

### Must

- Identify **maladaptive memory networks** by cluster theme, with the touchstone and contributors per cluster.
- For each presenting symptom, link it to one or more maladaptive networks and explain the AIP mechanism (state-dependent learning, blocked processing).
- Identify **adaptive networks** (positive memory clusters, mastery experiences, attachments) available to link to during reprocessing.
- Specify **negative and positive cognitions** per cluster.
- Specify **stabilization plan**: which resources will be installed, in what order, before Phase 3 begins.
- Specify **dissociation considerations** (windowing risk, parts work, structural dissociation framing if indicated).
- Specify **risk modifiers** including suicide / NSSI / substance use that may activate during reprocessing.
- Specify **outcome instruments and cadence**.
- Specify **estimated treatment length** with explicit uncertainty.
- Frame symptoms as **products of unprocessed memory**, not as character; this is a treatment-orienting move, not a diagnosis-erasing one.
- Where complex / dissociative material is present, reference an appropriate model (e.g., Theory of Structural Dissociation; Knipe's CIPOS) without overclaiming expertise.

### Must Not

- Do not promise outcomes or specific number of sessions.
- Do not skip the adaptive-network mapping; reprocessing depends on linkage.
- Do not minimize comorbidities; they shape pacing.
- Do not omit cultural / spiritual context.
- Do not finalize the formulation without informed consent and shared understanding with the client.
- Do not fabricate memories or psychiatric history.
- Do not declare touchstones the client cannot tolerate even imagining; revise pacing.
- Do not present AIP as a metaphor that erases the reality of the events.

## Instructions

1. Review Phase 1 data; list all known events with brief tags, ages, and current charge.
2. Cluster events by theme; identify touchstones.
3. Map symptoms → memory networks via AIP logic (state-dependent learning of perceptions, sensations, affect, beliefs).
4. List positive / adaptive networks available.
5. Specify NC / PC per cluster.
6. Identify risk and dissociation considerations.
7. Specify stabilization steps.
8. Draft treatment hypothesis: which clusters processed first, expected mechanism of change, expected outcome shifts on instruments.
9. Estimate treatment length with uncertainty ranges.
10. Review with client; obtain informed consent.

## Verification

- [ ] Events clustered with touchstones identified.
- [ ] Each presenting symptom linked to a memory network via AIP logic.
- [ ] Adaptive networks mapped.
- [ ] NCs / PCs per cluster.
- [ ] Stabilization plan documented.
- [ ] Dissociation considerations addressed.
- [ ] Risk modifiers identified.
- [ ] Treatment hypothesis explicit.
- [ ] Length / cadence stated with uncertainty.
- [ ] Informed consent confirmed.
- [ ] Reformulation review trigger conditions present.
- [ ] No fabricated history.
- [ ] No outcome promises.
