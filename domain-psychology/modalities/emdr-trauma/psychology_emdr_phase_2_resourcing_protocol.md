# EMDR Phase 2 Resource Development and Installation Protocol

## Objective

Deliver a Phase 2 Resource Development and Installation (RDI; Korn & Leeds) sequence: identify needed resources for the upcoming reprocessing work, develop them experientially (image, body, affect, narrative), and install with short slow bilateral stimulation (BLS) to strengthen access. The output is a per-resource installation record plus a between-session practice plan.

## When to Use

- Phase 2 of standard EMDR for any client; expanded for complex / chronic / developmental trauma.
- After AIP case formulation and before any Phase 3 reprocessing.
- Re-installation during reprocessing when resources weaken or new resources are needed.
- Between trauma processing cycles for stabilization maintenance.
- Not as a substitute for processing in clients who are stabilized and ready — RDI is preparatory.

## Inputs / Context

- AIP formulation indicating which resources are needed (e.g., calm-place for affect regulation; container for memory containment; protector figure for inner-child work; adult-self for re-parenting interweaves).
- Dissociation profile and parts-work considerations.
- Client's available imagery and somatic capacities (some clients have alexithymia or limited imagery).
- Cultural / spiritual context shaping resource choices.
- Risk plan.
- Modality (in-office BLS / telehealth alternatives like self-tapping / EMDR app).
- Time available (one resource takes 15–30 min; full Phase 2 may span multiple sessions).

## Constraints

### Must

- Use **short slow BLS** (typically 4–8 saccades / taps) per set during RDI; not long sets used in reprocessing.
- Stop BLS immediately if any disturbance arises during installation — RDI uses only positive associations; pivot to grounding.
- Install **one resource per session block**; do not stack.
- Include all four channels per resource: **image, body sensation, affect, words/narrative**.
- For each resource: confirm **felt-sense access** before and after installation; rate strength (0–10).
- Standard resource menu:
  - **Calm / safe place** (note that "safe" can be triggering for trauma survivors; use "calm" or client-chosen language).
  - **Container** (visualized vessel for not-now-ready material).
  - **Protector figure** (real, fictional, animal, archetypal — client-chosen).
  - **Nurturer figure** (someone or something that conveys care).
  - **Wise figure** (someone who can hold perspective).
  - **Adult-self resource** (the client's adult capacities, for child-self interweaves).
  - **Body resources** (areas of safety in the body, postural anchors).
  - **Cultural / spiritual resources** (deity, ancestor, community, place).
- For clients with limited imagery: use somatic, narrative, or symbolic alternatives.
- Plan between-session practice: 1–2 minutes daily, named resource.
- If a resource cannot be installed cleanly (any disturbance), pause; do not push; revise plan.

### Must Not

- Do not use long BLS sets typical of reprocessing.
- Do not continue BLS through disturbance — switch to grounding.
- Do not impose clinician's preferred resource on the client.
- Do not finalize Phase 2 with only a calm-place installed if formulation requires more.
- Do not skip the felt-sense access check.
- Do not use the word "safe" if the client has reactivity to it.
- Do not install resources that are tied to the trauma (e.g., a person who was both caregiver and abuser) without careful structuring.
- Do not begin Phase 3 unless resources have been confirmed accessible between sessions.

## Instructions

1. Identify needed resources from the AIP formulation.
2. Start with the calm place (or client-chosen first resource).
3. Develop the resource experientially: image, body, affect, words.
4. Rate access strength (0–10) before installation.
5. Install with short slow BLS (4–8 saccades); reassess after each set.
6. If disturbance arises: stop BLS, ground, revise resource, do not push.
7. Re-rate access strength; aim ≥ 6 before moving on.
8. Plan a cue word / image / gesture for between-session access.
9. Assign 1–2 minute daily practice.
10. Document; repeat with next resource next session block.

## Verification

- [ ] One resource per session block; not stacked.
- [ ] Four-channel development (image, body, affect, words).
- [ ] Short slow BLS; stop if disturbance.
- [ ] Pre and post access ratings recorded; aim ≥ 6 post.
- [ ] Cue established for between-session access.
- [ ] Daily 1–2-minute practice assigned.
- [ ] Trauma-tied resource caveats addressed.
- [ ] Client-chosen, not clinician-imposed.
- [ ] Cultural / spiritual fit honored.
- [ ] Phase-3 readiness implication noted.
- [ ] No fabricated client imagery.
