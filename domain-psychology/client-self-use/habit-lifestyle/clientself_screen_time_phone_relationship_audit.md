# Screen Time & Phone Relationship Audit

## Objective

Help you look honestly at your relationship with your phone or screens — starting from curiosity, not guilt. Output should surface what the phone is doing *for* you (its real function), where it genuinely costs you, a few changes that fit your actual values, and concrete friction tweaks. The phone is a tool that's meeting real needs; the goal is alignment, not punishment.

## When to Use

- You feel uneasy about how much you're on your phone but don't want a guilt spiral.
- You've tried "digital detoxes" that didn't last.
- You want to understand the pull before trying to change it.
- A specific moment bothers you (scrolling instead of sleeping, phone-checking mid-conversation).

## Inputs / Context

- Your rough daily screen time and the top apps (from your phone's own report if handy).
- The moments you reach for it most (waking, transitions, boredom, anxiety, before sleep).
- What you're usually feeling right before you pick it up.
- What you'd be doing instead if the phone vanished — and whether you'd actually want to.
- One or two things you wish you had more time or attention for.

## Constraints

### Must

- Treat phone use as serving real functions (soothing, connection, stimulation, avoidance, information, downtime) and name them without judgment.
- Separate "use that costs me" from "use that's fine" — not all screen time is a problem.
- Anchor any proposed change to one of the user's stated values, not to a generic "less is better."
- Offer friction tweaks (environmental nudges), not willpower demands.
- Keep proposed changes small and reversible.

### Must Not

- Don't moralize, catastrophize ("dopamine," "rotting brain," "addiction" unless the user names a clinical concern), or imply the user is weak.
- Don't prescribe a total detox or hard daily limits as the default answer.
- Don't pathologize ordinary use.
- If the user describes use that feels compulsive and distressing, or tied to gambling, pornography, or self-harm content, note that this is worth raising with a therapist — without lecturing.

## Instructions

1. Mirror back the user's screen time and top apps neutrally.
2. For each heavy-use moment, name what it's doing FOR them (the function).
3. Identify which uses they're genuinely fine with vs. which cost them something they care about.
4. Connect each desired change to a stated value.
5. Design friction tweaks for the costly moments and reduce friction for the alternative they'd actually want.
6. Pick one small experiment to run this week.

## Output Format

```
=== MY PHONE RELATIONSHIP — HONEST AUDIT ===

The picture (neutral):
- Daily screen time: [~ ___]
- Top apps: [...]
- Heaviest moments: [...]

What my phone is doing FOR me (function — no judgment):
- When I [moment], the phone gives me: [soothing / connection / stimulation / escape / info / downtime]
- The real need underneath: [...]

Where it's fine vs. where it costs me:
- Fine / I'm good with: [...]
- Costs me something I care about: [what it costs] — and the value it's stepping on: [...]

Value-aligned changes (small, mine — not generic):
- Because I care about [value], I want to [specific change] in [specific moment].

Friction tweaks (nudge, not willpower):
- Make the costly pull harder: [e.g., charge phone outside the bedroom, grayscale, app off home screen, log-out]
- Make the thing I'd rather do easier: [e.g., book on the nightstand, walking shoes by the door]

One experiment this week:
[Single small, reversible change + how I'll know if it felt better]

Worth mentioning to a therapist? (optional):
[Only if the use feels compulsive/distressing or tied to gambling/porn/self-harm content]
```

## Verification

- [ ] Phone use framed by function, without judgment.
- [ ] "Fine" use distinguished from "costly" use.
- [ ] Each change anchored to a stated value.
- [ ] Friction tweaks offered in both directions.
- [ ] One small, reversible experiment chosen.
- [ ] No moralizing, no default detox, no pathologizing of ordinary use.
- [ ] Compulsive/distressing patterns gently routed to a therapist (not lectured).
