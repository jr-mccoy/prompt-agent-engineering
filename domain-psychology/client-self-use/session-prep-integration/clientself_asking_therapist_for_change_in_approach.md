# Asking My Therapist for a Change in Approach

## Objective

Help a client name and request a specific change in how their therapist is working with them. Output should:

1. Name what's not working — concretely, with examples from sessions.
2. Translate "this isn't working" into a specific request.
3. Generate the script for raising it without sounding like a complaint.
4. Anticipate that the therapist may push back, agree, or want to explore the request itself.

## When to Use

- The pace feels too fast or too slow.
- Sessions feel like venting with no direction, or like assignments with no space to feel.
- The modality (CBT / psychodynamic / EMDR / DBT) feels mismatched.
- The therapist talks too much or too little.
- Sessions feel scripted vs. exploratory in a way the client wants flipped.
- The relational style (warmth, humor, formality, directness) is off.
- Frequency needs to change (more or less often).

## Inputs / Context

- What's not working, with 1–2 specific session examples.
- What the client thinks would help — even if vague.
- How long the client has been in therapy with this therapist.
- The therapist's stated orientation if known.
- Whether the client has raised this before, and how it landed.

## Constraints

### Must

- Output sections in order: **What's Not Working (with examples)**, **What I Think Would Help**, **The Request, Said Directly**, **Three Branch Responses to Anticipate**, **What I'll Do With Each Response**.
- Translate vague feedback into a concrete request ("more space to feel" → "Could we try keeping the first 20 minutes unstructured before we go to skills?").
- Acknowledge that the therapist may experience the request as feedback on their work; client gets to make the request anyway.
- Distinguish "the modality is wrong" (may need a different therapist) from "the pacing is off" (often adjustable with current therapist).

### Must Not

- Don't tell the client what they need from therapy.
- Don't reframe the client's complaint into something more therapist-friendly that loses the original signal.
- Don't promise the therapist will change.
- Don't recommend the client switch therapists; that's a bigger decision the client owns.

## Instructions

1. Elicit 1–2 concrete session examples of what's not working.
2. Translate to a specific request.
3. Generate a 3–5 sentence script that names the issue, makes the request, and invites collaboration.
4. Generate branch responses (agreement, exploration, pushback) and how the client wants to handle each.

## Output Format

```
=== REQUESTING A CHANGE IN APPROACH ===

What's Not Working:
- Pattern: [...]
- Example session 1: [Date / general — what happened, what felt off]
- Example session 2: [...]

What I Think Would Help:
- [Even if vague — "more space," "less assignments," "more direction," "less interpretation"]
- Translated to a concrete request: [...]

The Request, Said Directly (script for the session):
"I want to talk about how our work has been feeling. [Specific observation: 'For the past few weeks, I've noticed that we tend to spend most of the session [pattern].'] What I'd find more useful would be [specific request]. Can we try that for a few sessions and check in?"

Three Branch Responses to Anticipate:

If they say: "Yes, let's try that" — 
   I'll say: "Thank you. Can we set a check-in for [date] to see if it's helping?"

If they say: "Tell me more about why this isn't working for you" —
   I'll say: [stay with the specifics from above; don't get pulled into self-analysis if the issue is structural]
   What I want to hold: this is feedback on the work, not on me.

If they push back ("I think we need to stay with this approach because..."): 
   I'll say: "I hear the rationale. I'd still like to try [request] for [interval] and see. If it doesn't work I'm open to going back."
   If they're not open to that: I'll consider whether this is a fit issue worth bringing back next session or with a consultation outside.

What I'll Do With Each Response:
- Agreement: schedule check-in
- Exploration: stay with specifics
- Pushback: ask for time-bounded trial; if denied, hold the question of fit
```

## Verification

- [ ] Two concrete session examples grounded the feedback.
- [ ] Vague "doesn't work" translated to specific request.
- [ ] Script names the issue, requests, and invites collaboration.
- [ ] Three branch responses prepared.
- [ ] Distinction between adjustable approach and modality mismatch addressed.
- [ ] Client retains agency over the larger fit question.
- [ ] No instruction to switch therapists.
