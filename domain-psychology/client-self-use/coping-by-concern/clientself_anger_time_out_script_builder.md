# Anger Time-Out Script Builder

## Objective

Build a personalized anger time-out script: the words to use, the physical action to take, the duration, and the return. Time-outs done right de-escalate without abandoning the relationship; done wrong, they entrench the rupture.

## When to Use

- Anger surges that escalate verbally or behaviorally beyond the client's values.
- Couples / family conflicts that recurrently spiral.
- A client in DBT, CBT, or couples work who needs scaffolding between sessions.

## When Not to Use

- Domestic violence — escalation patterns require safety planning, not couple-style time-outs.
- Anger driven by intoxication — sobriety / harm-reduction first.
- Acute psychosis or mania — different intervention.
- Following clinician-recommended different protocol.

## Inputs / Context

- Common contexts where the surge happens (with whom, around what topics).
- The client's typical surge signature (body, cognition, behavior).
- Past attempts at time-outs and what failed.
- The other person's typical reaction to time-outs (felt-abandoned, escalation, follow-out).
- A safe physical space available.
- Substances / sleep / hunger as common amplifiers.

## Constraints

### Must

- Output sections: **Surge Signature**, **Pre-Surge Cues**, **The Time-Out Script (exact words)**, **The Action (where I go, what I do)**, **Duration**, **The Return**, **What Goes Wrong and How to Fix It**, **When to Repair**.
- Script includes naming the time-out (so it doesn't read as walking out), naming the duration commitment, and naming when the conversation will resume.
- Action involves leaving the room / vehicle / proximity, not just turning away.
- Duration: minimum 20 minutes (physiological return-to-baseline typically takes ~20+ min); maximum 1 hour for most relational time-outs (longer feels like punishment).
- Return is committed: "I'll be back at [time]" is a contract; missing it damages trust more than the surge would have.
- "What goes wrong" addresses follow-out, partner escalation, time-out as silent treatment, time-out as punishment.

### Must Not

- Don't recommend leaving without naming when you're returning.
- Don't recommend silent treatment.
- Don't recommend driving in a high-arousal state.
- Don't push the time-out as a tool in DV contexts.

## Instructions

1. Identify surge signature.
2. Identify pre-surge cues to catch earlier.
3. Build the script (exact words).
4. Plan the action: where, what.
5. Set duration commitment.
6. Plan the return.
7. Address common failure modes.

## Output Format

```
=== ANGER TIME-OUT SCRIPT ===

My Surge Signature:
- Body: [jaw clenching / heat in chest / fists / pacing]
- Cognition: [tunnel vision / "I have to win" / "this is the last time" / catastrophizing about partner]
- Behavior: [voice rises / interrupting / approaching / sarcasm / threats]

Pre-Surge Cues (catch it earlier):
- [Sensation that arrives 60+ seconds before the surge — e.g., "throat tightens" or "I notice I'm leaning forward"]
- [Topic / phrase that triggers]

The Time-Out Script (exact words I will say):
"I'm getting too activated to keep this conversation safe. I need a time-out. I'll be back at [specific time, ≥ 20 min from now]. We'll pick this back up then. I'm not walking away from you; I'm walking away from doing damage."

(For a partner who has heard this before: a single agreed-upon code phrase can replace the script — e.g., "I need 20.")

The Action (where I go, what I do):
- I leave the room / car / proximity. Physically leaving signals to my body the threat is over and lets it downshift.
- I go to: [specific place — bedroom / porch / car (parked, not driving) / walk]
- What I do: [physical activity — walk briskly, push-ups, splash cold water, slow exhale 4 in / 8 out]
- What I do NOT do: scroll, text, ruminate, drink, write angry messages, drive while activated.

Duration:
- Minimum: 20 minutes (my body needs ~20+ min to return to baseline arousal)
- My commitment: [exactly N minutes]
- I will set a timer.

The Return:
- I will return at [time].
- I will name what I'm returning to: "I'm back. Are you okay to pick this up, or do you need more time?"
- If they need more time: I respect that. New return time.
- I will not return louder than I left.

What Goes Wrong and How to Fix It:
- "My partner follows me out / blocks my exit." → Pre-conversation agreement that time-outs are honored. If repeatedly violated and pattern is controlling, this is bigger than a time-out tool.
- "I leave and never come back to it." → Time-out as avoidance; that's a different problem and corrodes the relationship faster than the surge.
- "I leave silently." → That's silent treatment, not a time-out. The script is what makes it a time-out.
- "I leave but I'm still raging while I'm out." → I rumination during the break. Use the activity (walk, cold, push), not mental replay.
- "I drive when activated." → Don't. Park, walk, sit on a bench. Driving while raging is dangerous to me and others.
- "My partner punishes me when I return." → Bring this to therapy — the time-out tool needs both people honoring it.

When to Repair (after I'm back in window):
- Acknowledge the surge without making excuses: "I got really activated and said [thing]. That wasn't okay."
- Ask what landed for them: "What hit hardest from what I said?"
- Don't problem-solve the original argument until both of you are in window.
- If I crossed a line that needs more than an apology, name it and ask what would help.

When to Get Help:
- If surges happen often, escalate, or include verbal/physical/sexual contempt or violence → couples or individual therapy with someone who works with anger.
- If alcohol or substances precede most surges → addressing that comes first.
- If a partner is afraid of me → DV-trained help, not couples therapy first.
```

## Verification

- [ ] Surge signature documented.
- [ ] Pre-surge cues identified.
- [ ] Script in exact words.
- [ ] Action involves physical exit and engaged activity.
- [ ] Duration ≥ 20 min and bounded.
- [ ] Return time committed.
- [ ] Failure modes addressed.
- [ ] Repair guidance included.
- [ ] DV / substance / partner-fear escalation paths present.
- [ ] No silent-treatment recommendation.
- [ ] No driving-while-activated recommendation.
