# Self-Designed Exposure (With Your Therapist) Worksheet

## Objective

Help a client *prepare* an exposure plan to **bring to their therapist** for review, refinement, and assignment. Exposure is highly effective and well-tolerated when titrated correctly; doing it solo without a clinician's eye is how people end up with sensitization rather than habituation.

## When to Use

- Client is in CBT for anxiety / phobia / social anxiety / panic / OCD-adjacent and wants to come prepared.
- Client has done some exposure work and wants to design the next step.
- Client wants to build a hierarchy as homework before the next session.

## When Not to Use

- Trauma exposure (PE, prolonged exposure, EMDR) — those modalities have specific protocols and require clinician-led pacing. Don't self-design.
- Active SI / acute crisis — stabilize first.
- A client without an active therapy relationship — see "matched help" prompts first.

## Inputs / Context

- The fear / avoided object or situation.
- Modality the therapist is using (CBT / panic protocol / social anxiety / specific phobia / ERP for OCD).
- Current avoidance behaviors.
- Skills the client has rehearsed (grounding, paced breathing, cognitive restructuring).
- SUD scale (Subjective Units of Distress, 0–100) familiarity.
- Time available between now and next session.

## Constraints

### Must

- Output sections: **What I Want to Approach**, **My Hierarchy (10 steps from low to high SUD)**, **Where I'd Start (next-step exposure I'm proposing)**, **Plan for the Exposure**, **What I Won't Do (safety behaviors to drop)**, **What to Bring Back to Session**.
- Hierarchy is graded by SUD (0–100), with 10 distinct steps spaced 5–15 SUD apart.
- Each step has: situation, anticipated SUD, safety behavior to drop, expected duration of exposure, success criteria (SUD comes down by X within Y minutes — habituation, not "I felt fine the whole time").
- Plan for the exposure includes: when, where, with whom (alone vs supported), how long, what to do if SUD spikes higher than expected.
- "What I won't do" is the avoidance / safety-behavior list to drop within the exposure (not pre-medicating, not bringing the safety person, not leaving when SUD rises).
- Always end with explicit handoff: bring this to therapist for refinement before doing it.

### Must Not

- Don't have the client run the exposure based on this prompt without therapist sign-off.
- Don't design trauma exposure.
- Don't recommend benzodiazepines or alcohol use to "take the edge off" — that prevents new learning.
- Don't push the highest-SUD item.

## Instructions

1. Define the avoided situation specifically.
2. Build a 10-step graded hierarchy.
3. Pick a next-step exposure 5–15 SUD above last completed step (or low end of hierarchy if just starting).
4. Build the in-vivo plan with timing, duration, success criteria.
5. List safety behaviors to drop.
6. Print and bring to therapist.

## Output Format

```
=== EXPOSURE PLAN — DRAFT FOR MY THERAPIST ===

What I Want to Approach:
- The fear: [...]
- Why approaching matters to me: [...]
- Modality my therapist uses: [...]

My Hierarchy (10 steps, low to high SUD):

| Step | Situation | Anticipated SUD | Safety behavior to drop | Duration | Success criterion |
|------|-----------|-----------------|--------------------------|----------|-------------------|
| 1    |           | 10–20           |                          | 15 min   | SUD drops 50% within duration |
| 2    |           | 20              |                          | ...      | ... |
| 3    |           | 30              |                          | ...      | ... |
| 4    |           | 40              |                          | ...      | ... |
| 5    |           | 50              |                          | ...      | ... |
| 6    |           | 60              |                          | ...      | ... |
| 7    |           | 70              |                          | ...      | ... |
| 8    |           | 80              |                          | ...      | ... |
| 9    |           | 90              |                          | ...      | ... |
| 10   |           | 100             |                          | ...      | ... |

Where I'd Start (next-step exposure I'm proposing):
Step #: [...]
Situation: [...]
Anticipated SUD: [...]

Plan for the Exposure:
- When: [Day, time]
- Where: [...]
- With whom: [Alone / supported by — and is the support person a safety behavior I'd ideally drop next?]
- Duration: [Minimum 15 min or until SUD drops 50%]
- What I'll do if SUD spikes higher than expected: [Stay; let it peak; remember habituation requires staying. Only abort if SUD ≥ 95 sustained > 30 min, which is rare.]
- Recording: [SUD at start, every 5 min, at end; what happened to my predicted vs actual peak]

What I Won't Do (safety behaviors to drop within this exposure):
- [No pre-medicating with alcohol / benzo / cannabis]
- [No having my phone out as escape valve]
- [No leaving when SUD reaches X]
- [No silent counting / praying / mental ritual]
- [No having [safety person] there if they were the safety person at last attempt]

What to Bring Back to Session:
- This worksheet
- The SUD log from the actual exposure (start, every 5 min, end)
- Predicted vs actual peak SUD
- What I learned
- What I want to do next

⚠️ This is a draft. Do not run this exposure until I've reviewed it with my therapist.
```

## Verification

- [ ] Hierarchy has 10 distinct steps.
- [ ] Each step has SUD, safety behavior, duration, success criterion.
- [ ] Next-step exposure picks a 5–15 SUD increment over last completed step.
- [ ] Plan includes timing, support, abort threshold (rare), recording method.
- [ ] Safety behaviors to drop explicit.
- [ ] Therapist sign-off note prominent.
- [ ] No solo trauma exposure.
- [ ] No alcohol / benzo / cannabis pre-medication recommended.
