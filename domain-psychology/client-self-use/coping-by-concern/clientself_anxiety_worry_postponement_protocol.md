# Worry Postponement Protocol

## Objective

Help a client set up worry postponement: capture worries throughout the day, defer engagement to a specific 15–20 minute "worry window," and stop fighting the worries (which doesn't work) without giving them all day (which also doesn't work).

## When to Use

- Generalized anxiety pattern with chronic, diffuse worry across many topics.
- Worry that interferes with sleep, focus, or presence.
- A client who's tried "thought stopping" and found it backfires.

## When Not to Use

- Acute crisis content (suicidal planning, abuse disclosure) — that goes to therapy / 988, not the worry window.
- OCD compulsive worry — uses ERP, not postponement.
- Trauma re-experiencing — different intervention.

## Inputs / Context

- Typical worry topics.
- Current pattern (when, where, how often).
- Available daily window for the worry block (15–20 min, same time each day).
- Client's typical bedtime (worry window placed ≥ 2 hours before).
- Where the client will keep the capture list.

## Constraints

### Must

- Output a 4-step protocol: **Capture**, **Postpone**, **Worry Window**, **Review**.
- Capture is one sentence per worry, deferred immediately to the window.
- Worry window is 15–20 min, same time each day, ≥ 2 hours before bedtime.
- In the window: review captured items; sort into solvable / unsolvable; if solvable, take one specific next action; if unsolvable, name it as such and let it sit.
- Track: % of captured worries that still felt urgent at window time; this number drops over weeks for most users.

### Must Not

- Don't recommend thought-stopping ("just push it away").
- Don't push problem-solving for genuinely unsolvable worries.
- Don't put the worry window right before bed.
- Don't substitute for trauma / OCD / crisis interventions.

## Instructions

1. Set worry window time and location.
2. Set capture method (notebook, notes app, voice memo).
3. Practice for 1 week before judging effectiveness.

## Output Format

```
=== WORRY POSTPONEMENT PROTOCOL ===

My worry window: [Day, time, duration 15–20 min, location]
At least 2 hours before bedtime: [Yes — bedtime is X, window is X]

Capture method:
- [Notebook on bedside / Notes app titled "worry capture" / voice memo / index cards in pocket]

The 4 Steps:

1. CAPTURE
   - When a worry shows up, write one sentence: what the worry is about.
   - Don't elaborate.
   - Set it down: "I'll think about this at [window time]."
   - Return attention to what I was doing.

2. POSTPONE
   - I am not pushing the worry away. I am scheduling it.
   - If the worry returns: re-capture (sometimes the same one many times) and re-postpone.
   - This isn't avoidance — I am going to think about it, just at the time I chose.

3. WORRY WINDOW (15–20 min, daily)
   - Sit down with the captured list.
   - For each item:
     a. Is this still urgent? (Often: no.)
     b. Solvable or unsolvable?
        - Solvable: what is the one next action? Schedule it. Done.
        - Unsolvable: name it as unsolvable. Sit with it for 30 sec. Move on.
   - When the timer ends, the window closes. Items I didn't get to roll forward to tomorrow's window — they're not lost.

4. REVIEW (weekly, 5 min)
   - % of captured worries still urgent at window time: [Track]
   - Which solvable worries got resolved through the protocol
   - Which worries keep recurring without resolving — these are worth bringing to therapy

What to do if I worry outside the window:
- Capture and postpone. Always.
- I am training my mind that worry has a time and a place.

What this is NOT:
- Avoidance — I'm engaging at the scheduled time.
- Suppression — I'm allowing the worry to exist; just elsewhere.
- A solution to crisis content — SI / abuse / acute danger don't go in the worry window. Those go to my therapist or 988.

Time to evaluate: 7 days.
```

## Verification

- [ ] Worry window set with specific time, location, duration.
- [ ] Window is ≥ 2 hours before bedtime.
- [ ] Capture method specified.
- [ ] 4-step protocol documented.
- [ ] Review schedule set.
- [ ] Crisis-content carve-out explicit.
- [ ] Distinction from suppression / avoidance made clear.
- [ ] No thought-stopping recommended.
