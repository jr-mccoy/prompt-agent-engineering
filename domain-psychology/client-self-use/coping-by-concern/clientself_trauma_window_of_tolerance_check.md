# Window of Tolerance Check

## Objective

Help a client identify their current arousal state — within window (engaged, present), above window (hyperaroused: panic, anger, racing, fight/flight), or below window (hypoaroused: numb, frozen, dissociated, shutdown) — and pick a matched skill rather than running the wrong one.

## When to Use

- Mid-day check when something feels off.
- Before a therapy session, to know what state you're entering it in.
- After a triggering event.
- When a coping skill that "usually works" isn't working.

## Inputs / Context

- Current body state (breath, heart rate, muscle tension, gut, temperature).
- Current cognitive state (racing / blank / clear).
- Current emotional state (panicked, angry, numb, sad, present, mixed).
- Recent triggers or events.

## Constraints

### Must

- Output sections: **Quick Body Check**, **Where Am I**, **Matched Skill (within / above / below)**, **Re-Check**, **If I Can't Get Back**.
- Skills for **above window** (hyperaroused): downshift skills — slow exhale, cold sensory, paced movement.
- Skills for **below window** (hypoaroused): upshift skills — bilateral tapping, naming surroundings out loud, gentle movement, warmth, social contact.
- Skills for **within window** (oriented and engaged): stay; do the thing; this is when therapy work, problem-solving, decisions happen.
- Re-check at 5 and 10 minutes; if not back in window, reassess.

### Must Not

- Don't push trauma processing in either above- or below-window states.
- Don't apply downshift skills in below-window state (will deepen shutdown).
- Don't apply upshift skills in above-window state (will worsen panic).
- Don't shame either state.

## Instructions

1. Walk a 30-second body check.
2. Identify the state.
3. Apply the matched skill for 3–5 minutes.
4. Re-check.
5. Escalate if not regulating.

## Output Format

```
=== WINDOW OF TOLERANCE CHECK ===

Quick Body Check (30 seconds):
- Breath: [shallow & fast / shallow & slow / normal / held / sighing]
- Heart: [racing / normal / slow]
- Muscles: [bracing / shaky / loose / heavy]
- Gut: [knotted / fluttery / normal / numb]
- Temperature: [hot / flushed / normal / cold / numb]
- Cognition: [racing / clear / foggy / blank]
- Emotion: [panic / anger / numb / sad / present / mixed]
- Time orientation: [present / past / future / lost]

Where Am I:

Above window (hyperaroused — fight/flight):
- Racing thoughts; can't focus
- Heart racing; breath shallow & fast
- Muscles tense, shaky, restless
- Anger or panic
- Hot, flushed, sweaty
- Want to flee, fight, or argue
- Difficulty being still

Within window (regulated):
- Body and mind feel reasonably present
- Can think, feel, and act
- Stress is here but I can work with it
- I can do the thing in front of me

Below window (hypoaroused — freeze/shutdown):
- Numb, blank, foggy
- Heavy or limp
- Cold extremities
- Detached from body or surroundings
- Time feels off
- Voice quiet, slow, or absent
- Dissociation
- "I should care but I can't access it"

Where I am right now: [Above / Within / Below]

Matched Skill:

If above (downshift):
- 4-second inhale, 8-second exhale, x 10 (vagal nerve via long exhale)
- Cold water on wrists or face; ice in hand; cold can on chest
- Push against a wall for 30 sec, release; repeat
- Walk briskly for 5 min
- Sigh out loud
- Listen to slow rhythmic music
- Stay seated, feet flat, hands on knees

If below (upshift):
- Bilateral tapping (alternating hands on thighs, slow then steadier)
- Name 5 things I see OUT LOUD
- Stand up, stretch, move limbs
- Wrap in a warm blanket / warm drink in hands
- Step outside; let sunlight or temperature change hit my face
- Call or text a person I'm connected to
- Sing or hum (vocal cords activate vagal pathway upward)
- Do something with hands (washing dishes, kneading, drawing)

If within window:
- Stay. This is where the work happens. Do the next right thing.

Re-Check (in 5 minutes, then 10):
- Body: [...]
- Cognition: [...]
- Emotion: [...]
- State now: [Above / Within / Below]

If I Can't Get Back:
- After 15–20 minutes of trying matched skills, if I'm still significantly outside window and:
  - Have SI / NSSI urges → contact clinician / 988
  - Have flashback / dissociation that's affecting safety → ground per trauma flashback script; contact clinician if not resolving
  - Am chronically below or above window most days → bring this pattern to therapy

This is not a substitute for trauma-focused therapy. It's a between-session skill for noticing and matching.
```

## Verification

- [ ] Quick body check covers physiology, cognition, emotion, time orientation.
- [ ] State identified.
- [ ] Matched skill given (downshift / upshift / stay).
- [ ] Re-check schedule.
- [ ] No mismatched skill applied.
- [ ] Escalation triggers explicit.
- [ ] No trauma processing pushed in above/below states.
