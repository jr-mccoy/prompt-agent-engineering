# Rumination Interrupt Protocol

## Objective

Help a client interrupt depressive rumination — the repetitive, abstract, "why am I like this" thinking that feels like processing but maintains depression. Output a personalized interrupt protocol with: detection cue, concrete-thinking shift, action default.

## When to Use

- Stuck in long internal monologues about why-things-are-bad / what's-wrong-with-me / what-I-should-have-done.
- Lying awake re-running.
- Spending hours mentally rehearsing past conversations.
- "Processing" that doesn't lead to insight or action.

## Inputs / Context

- Typical rumination topics (self, past, "why").
- Times of day rumination peaks.
- What's been tried (distraction, journaling, "letting it pass").
- Whether the rumination ever leads anywhere useful (often: no).

## Constraints

### Must

- Output a 3-component protocol: **Detect**, **Shift**, **Default Action**.
- Detect: name the cue (it can be hard — rumination feels like thinking, not like a problem).
- Shift: from abstract ("Why am I like this?") to concrete ("What is one thing I can do in the next 5 minutes?").
- Default Action: a small, body-engaging activity (walking outside, washing a dish, stretching, calling someone) — not another mental task.
- Distinguish rumination from problem-solving (problem-solving leads to action and ends; rumination loops without ending).
- Distinguish rumination from emotional processing (processing has direction and integration; rumination has rehearsal without movement).

### Must Not

- Don't tell the client to "stop thinking about it."
- Don't substitute for grief work (grief needs space, not interrupt).
- Don't substitute for trauma work.
- Don't recommend mental distraction as default — that's mind-on-mind. Body-engaging is the shift.

## Instructions

1. Map the typical rumination cue.
2. Build the abstract→concrete shift script.
3. Set a default body-engaging action.
4. Set practice frequency (every catch counts).
5. Track number of catches per day; the catching itself is the skill.

## Output Format

```
=== RUMINATION INTERRUPT PROTOCOL ===

How I'll Know I'm in Rumination (Detect):
- Topic markers: [my "usual" rumination topics]
- Quality markers:
  - Abstract ("why," "what does this mean about me," "what if")
  - Past- or future-oriented (not present)
  - Self-focused
  - Repetitive (same loops)
  - No new information arriving
  - I've been doing this for [N min] without movement
- Body markers: [tight chest / flat / heavy / pacing / staring]
- Time-of-day markers: [...]

The Shift (Abstract → Concrete):
When I catch myself ruminating, I will say (out loud or silently):
"This is rumination. The questions don't have answers right now. What is ONE thing I can do in the next 5 minutes?"

Concrete substitute questions:
- What is one thing I can do in the next 5 minutes?
- What is the next physical action I'd take if I weren't ruminating?
- What does the room look like right now?
- What would I do for someone else who said what I'm saying?

Default Action (body-engaging, not mental):
- [Specific, short, body-engaging activity I'll default to]
- Examples: walk outside for 5 min, wash a dish, stretch, water a plant, take a shower, call [name]
- Why body-engaging: shifting from one mental activity to another keeps me in the same mode that maintains rumination.

Distinguishing Rumination from:
- Problem-solving: leads to a decision or action; ends. → If I'm problem-solving, schedule 15 min, write the action, end.
- Processing emotion: has direction, integration, often tears or release; ends. → If I'm processing grief / a real loss, give it space; this protocol is not for that.
- Trauma re-experiencing: intrusive, sensory, body-loaded. → Different intervention; see trauma flashback grounding.

Practice:
- Every catch counts, even if I "catch" 30 seconds late.
- Track catches per day for 1 week. The number going up = the skill is forming.
- Don't try to "never ruminate." Aim to spend less time per round.

When to escalate to clinician:
- Rumination is feeding active SI
- I'm losing significant function (work, sleep, relationships)
- The pattern hasn't shifted with practice over 2–3 weeks
```

## Verification

- [ ] Detect cues include topic, quality, body, time-of-day markers.
- [ ] Shift script names "this is rumination" and reorients to concrete.
- [ ] Default action is body-engaging, not mental.
- [ ] Distinctions from problem-solving, emotional processing, trauma re-experiencing made.
- [ ] Practice tracking included.
- [ ] No "stop thinking" instruction.
- [ ] Escalation triggers present.
