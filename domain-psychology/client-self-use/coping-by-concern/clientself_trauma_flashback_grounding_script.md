# Flashback Grounding Script

## Objective

Generate a personalized, readable-off-the-phone flashback grounding script. Cognition is impaired during a flashback; the script must be short, sensory, present-tense, and findable when needed.

## When to Use

- During a flashback (sensory, somatic, or full reliving).
- After someone has had flashbacks before and wants a tool ready.
- As a backup when other skills don't break the state.

## Inputs / Context

- Typical flashback signals (visual, auditory, olfactory, somatic, emotional).
- The current date / age / location the client wants to anchor to.
- A safe-place anchor (image, person, song) if available.
- Trusted person to contact afterward if needed.

## Constraints

### Must

- Output a script designed to be saved to phone — readable in 60 seconds.
- Use short sentences. Present tense. Body-focused. Sensory-rich.
- Include: orientation to today's date / age / location (the flashback collapses time; orientation is the antidote), sensory anchoring, body anchoring, and a "this is a flashback" naming line.
- Include: post-flashback steps (water, person, write).
- Add a "if I can't read this, what do I do" line — a two-word backup the client memorizes.

### Must Not

- Don't elicit flashback content.
- Don't provide trauma-processing steps (that's clinician work).
- Don't push deep breathing in someone who is breath-triggered.

## Instructions

1. Capture the typical flashback signals.
2. Anchor today's date / age / location.
3. Build sensory grounding lines that work for this person.
4. Build the body anchor.
5. Generate post-flashback steps.
6. Set the two-word backup.
7. Save to phone.

## Output Format

```
=== FLASHBACK GROUNDING — READ THIS NOW ===

[SAVE THIS TO PHONE. Title it FLASHBACK so you can find it.]

THIS IS A FLASHBACK.
What I'm seeing / feeling / hearing is a memory.
The thing is not happening now.
I am safe in this moment unless I look around and find I'm not.

ORIENT:
Today is [day, date, year].
I am [age] years old.
I am at [city / room].
The people who would be here if it were happening are NOT here.

LOOK:
Look around. Name 5 things I see, out loud or silently:
1. ____  2. ____  3. ____  4. ____  5. ____

LISTEN:
Name 4 things I hear:
1. ____  2. ____  3. ____  4. ____

TOUCH:
Name 3 things I touch right now:
1. ____  2. ____  3. ____

BODY ANCHOR:
- Press both feet into the floor.
- Press both hands into [chair / wall / thighs].
- Notice the weight of my body in the chair.

[If breath helps me — slow exhale, longer than inhale, x 5.]
[If breath does NOT help me — skip the breath, do bilateral tapping on thighs instead.]

ANCHOR LINE:
"I am [name]. It is [year]. I am [age]. I am here. The thing is not happening now."

If I can't read this:
   Two-word backup: "[FEET. FLOOR.]" — say it, do it.

AFTER:
- Cold water on hands or face.
- Warm drink in my hands.
- Reach to: [trusted person — name, contact].
- Write: 3 sentences about what just happened, what triggered it, how long it lasted.
- Bring to: my therapist next session.

If after:
- I'm still dissociating after 30 min → contact my therapist or person.
- I'm having SI / NSSI urges → 988 (call/text), or my crisis line.
- This is the worst flashback I've had → therapist contact this week.
```

## Verification

- [ ] Script readable in 60 seconds.
- [ ] Orientation to today / age / location.
- [ ] Sensory anchoring (5-4-3 modified).
- [ ] Body anchor (feet, hands).
- [ ] Breath optional based on triggering profile.
- [ ] "This is a flashback" naming line.
- [ ] Two-word backup memorizable.
- [ ] Post-flashback steps.
- [ ] Escalation triggers explicit.
- [ ] No flashback content elicited.
