# Anxiety Grounding Menu Builder

## Objective

Build a context-matched grounding menu so the client has the right technique for the situation they're actually in — not a generic list. A technique that requires standing up doesn't work in a board meeting; cold water doesn't work mid-commute; box breathing doesn't work mid-presentation.

## When to Use

- Building a coping toolkit at the start of treatment.
- After noticing the same generic techniques fail in specific situations.
- Pre-event prep (flight, meeting, family gathering, medical appointment).

## Inputs / Context

- The 4–6 contexts where anxiety actually shows up for this client.
- What's already worked at least once and where.
- Sensory and physical preferences (some people freeze in cold; some get more anxious with breath focus).
- Time available in each context (30 sec to 5 min).
- Visibility constraints (what can be done without being noticed).

## Constraints

### Must

- Output a context-by-context menu, with 2–3 options per context, each with: technique name, exact steps, time required, visibility level, materials needed.
- For "breath-sensitive" clients (often trauma history), include grounding options that don't rely on breath manipulation.
- Include at least one stealth technique per context.
- Include a "if nothing else, then..." floor option per context.

### Must Not

- Don't generate a generic list and call it personalized.
- Don't recommend techniques requiring materials the client doesn't have access to in that context.
- Don't push breath-focused techniques on someone who reports breath manipulation triggers them.
- Don't moralize about substance / nicotine use as the previous coping strategy.

## Instructions

1. Elicit the 4–6 specific contexts.
2. For each, build a 2–3 option menu by visibility and time.
3. Add a floor option that always works (even if minimal).
4. Print as a phone-friendly card the client can save.

## Output Format

```
=== MY GROUNDING MENU ===

Context 1: [Specific situation]
- Time available: [...]
- Visibility constraint: [...]
- Option A (preferred): [Technique — steps — 30 sec / 1 min / 3 min — stealth / visible — materials]
- Option B: [...]
- Floor: [Smallest possible action that still counts]

Context 2: [...]
[same structure]

[...repeat 4–6 contexts...]

Universal floor (always works):
- Feet: notice the contact between my feet and the ground for 30 seconds
- Hand: clench, hold 5 sec, release; repeat 3 times
- Name: silently name the room I'm in and one object I see

Breath-sensitive note (if applicable):
[For breath-triggered clients — alternatives that don't require breath focus.]

Save to phone as: "Grounding card"
```

## Verification

- [ ] 4–6 specific contexts addressed.
- [ ] 2–3 options per context with time, visibility, materials.
- [ ] Floor option per context.
- [ ] Universal floor included.
- [ ] Breath-sensitive note included if relevant.
- [ ] No generic list; everything tied to context.
