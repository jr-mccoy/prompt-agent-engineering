# ADHD External Scaffold Designer

## Objective

Help an adult with ADHD design external scaffolds for the executive-function gaps they actually have — not generic productivity advice. Output should match scaffold to specific gap (initiation, time-blindness, working memory, task-switching, follow-through, emotional dysregulation, sensory regulation).

## When to Use

- Newly diagnosed adult ADHD, building systems.
- Long-standing ADHD where prior systems collapsed.
- Coaching with therapist on between-session implementation.
- Pre-school-year setup.

## Inputs / Context

- Specific gaps the client struggles with most (in their words).
- What's been tried and how it failed.
- Living situation (alone, partner, kids, roommate).
- Tech stack (phone OS, calendar, task app).
- Time-of-day energy patterns.
- Sensory profile (under-stimulated → fidget; over-stimulated → noise-cancel).
- Whether stimulant / non-stimulant medication is in the picture.

## Constraints

### Must

- Output a per-gap scaffold matrix: **Initiation**, **Time-Blindness**, **Working Memory**, **Task-Switching**, **Follow-Through**, **Emotional Regulation**, **Sensory Regulation**.
- Each scaffold is external (object, alarm, person, environment), not "just remember to."
- Scaffolds must survive ADHD's specific failure modes: novelty fatigue (will fail when bored), tab/notification overload (will be ignored), all-or-nothing (will be abandoned at first miss).
- Include "rebuild after collapse" rules — every system collapses for ADHD; the work is rebuilding without shame.
- Match scaffolds to client's actual gaps, not all 7.

### Must Not

- Don't recommend pure productivity-app stacks; ADHD breaks these.
- Don't moralize about willpower.
- Don't assume medication is the answer or not.
- Don't shame past failures of organization systems.

## Instructions

1. Have client name top 2–3 gaps.
2. For each, design 1–2 external scaffolds with: object/system, trigger, what it does, how it survives ADHD failure modes, rebuild rule.
3. Stack scaffolds intentionally — too many at once collapses.
4. Set a one-week trial; review what stuck.

## Output Format

```
=== ADHD EXTERNAL SCAFFOLD DESIGN ===

Top gaps for me right now (pick 2–3):
- [Initiation / Time-Blindness / Working Memory / Task-Switching / Follow-Through / Emotional Regulation / Sensory Regulation]

INITIATION (the start cost is the problem)
Scaffolds that work:
- Tiny first action — first 30 seconds, body-engaged. "Open the laptop and read one line."
- Body double — work next to another person (in person or video).
- Pre-commit to a specific 5-minute starter; permission to stop after.
- Visible cue at the trigger point: post-it on the laptop, item placed where I'll see it.
ADHD failure mode: novelty wears off → rotate cues / methods every 2–4 weeks.
Rebuild rule: when initiation collapses, don't expand — shrink. The next first-action is 30 seconds smaller.

TIME-BLINDNESS (time isn't experienced as a continuous stream)
Scaffolds that work:
- Visual timer (analog Time Timer, hourglass, phone widget showing elapsed time).
- Alarms for transitions, not just deadlines (10-min, 5-min, 1-min before a switch).
- Pre-mortem on time: "If past me planned this, what did past me forget?"
- Calendar that shows blocks, not lists.
- "What time is it actually" check 3x/day on my own initiative.
ADHD failure mode: alarms ignored when overloaded → fewer alarms, louder, harder to dismiss; phone face-down with alarm ringing requires standing up.
Rebuild rule: collapse usually = too many alarms; cut to 3 daily anchor alarms.

WORKING MEMORY (it falls out of mind the moment I look away)
Scaffolds that work:
- Capture-everywhere: notebook in pocket, voice memo, notes app pinned to home screen.
- One inbox, not seven; consolidate weekly.
- Object cues — keys on a hook by the door, supplements next to coffee maker.
- "Two things at once" as a rule violated; if I have to remember the second thing, I write it.
- For meds: physical pill organizer + cap timer; never "did I take it?" — check the cap.
ADHD failure mode: capture systems get crowded → 5-minute weekly purge.
Rebuild rule: if I missed something important, the system needs upgrading, not me being more careful.

TASK-SWITCHING (transition cost is the killer)
Scaffolds that work:
- Transition rituals (3-min walk, glass of water, alarm) between high-cognitive tasks.
- Theme blocks: morning = focus work, afternoon = meetings, evening = admin.
- 1 task open at a time; close the others (yes, really close, not minimize).
- "Bookmark before switch" — one sentence about where I'm leaving off.
ADHD failure mode: hyperfocus rolls past the switch alarm → set a hard external switch (someone walks in, partner texts, calendar holds the next thing).
Rebuild rule: when switching collapses, the issue is usually too many context switches per day; consolidate.

FOLLOW-THROUGH (the start happened; the finish didn't)
Scaffolds that work:
- "Last 10%" allotted as its own appointment.
- Visible end state — write down what "done" actually looks like before starting.
- Accountability ping — text a person when started AND when finished.
- Closing ritual — file the artifact, mark complete, archive.
ADHD failure mode: 90% done feels done → the last 10% becomes a graveyard.
Rebuild rule: scan the graveyard weekly; pick one to finish, not all.

EMOTIONAL REGULATION (rejection sensitivity, intensity surges)
Scaffolds that work:
- "Wait 10 minutes before responding" rule for triggering emails / messages.
- Body interrupt — cold water, walk, push against wall.
- Name the surge to a trusted person ("rejection sensitivity is firing").
- For repeated triggers — therapy, possibly medication, structural changes.
ADHD failure mode: emotion arrives before noticing → physical pre-cue (specific body sensation) is the catch.
Rebuild rule: when it lands hard, don't problem-solve in the surge; surge first, decide second.

SENSORY REGULATION
Scaffolds that work (under-stimulated → add):
- Fidget, gum, walking meeting, music, weighted lap pad.
Scaffolds that work (over-stimulated → reduce):
- Noise-canceling, sunglasses, fewer tabs, body breaks, low-stim work environment.
ADHD failure mode: same scaffolds at same setting all day → vary across day.
Rebuild rule: notice if I'm dysregulated before assuming the task is the problem.

ONE-WEEK TRIAL
- Pick the gap with highest cost.
- Pick 1–2 scaffolds.
- Trial 7 days.
- Review: what stuck, what didn't, what to adjust.

REBUILD-WITHOUT-SHAME RULES
1. Every ADHD system collapses. The collapse isn't failure; it's data about what to redesign.
2. The shame of a collapsed system is more disabling than the collapse.
3. After collapse: don't add complexity. Shrink and restart smaller.
4. Medication, if part of the picture, is a scaffold too — not a substitute for them.

If gaps are severe enough that scaffolds aren't enough:
- Adult ADHD assessment with a clinician
- Possible medication consult
- ADHD coach (different from therapist; often complementary)
```

## Verification

- [ ] Top 2–3 gaps prioritized.
- [ ] Scaffolds are external objects/systems, not willpower.
- [ ] Each scaffold addresses a specific ADHD failure mode.
- [ ] Rebuild-without-shame rules included.
- [ ] One-week trial set.
- [ ] No moralizing.
- [ ] No assumption about medication.
- [ ] Path to clinician / ADHD coach if scaffolds insufficient.
