# Anti-Avoidance Prompt for Depression

## Objective

Help a client surface the avoidance pile that depression accumulates — unread emails, unmade calls, unmade decisions, unfinished forms, conversations dodged — and convert exactly one item into the smallest action possible. The pile shrinks one item at a time; trying to clear it all increases avoidance.

## When to Use

- "I have so much I'm behind on I don't know where to start."
- After a few weeks of low energy when the backlog has built.
- Before bed, with the avoidance accumulating into shame.

## Inputs / Context

- Honest list of what's been avoided.
- How long each item has been avoided.
- Why the client thinks each is being avoided (overwhelm, dread, shame, conflict, decision-paralysis).
- Time and energy available right now.

## Constraints

### Must

- Output: **The Pile**, **The Reason Per Item**, **Pick One**, **Smallest Possible Action**, **What I'm Not Doing Today**, **What This Costs Me**.
- "Smallest Possible Action" must be ≤ 2 minutes for first item, then ≤ 10 min for follow-ups.
- Acknowledge that avoidance is a depression symptom, not a character flaw.
- Make explicit what is being deliberately NOT done today (deferring the rest is a feature, not failure).

### Must Not

- Don't try to make a plan for everything.
- Don't moralize ("you've been avoiding this for weeks").
- Don't shame.
- Don't recommend "just do it" energy.
- Don't substitute for risk routing if SI present.

## Instructions

1. Surface the pile honestly.
2. Diagnose each item's specific avoidance reason.
3. Pick ONE — preferably the smallest, oldest, or most-rotting one.
4. Convert to the smallest action.
5. Explicitly defer the rest.
6. Name the cost of continued avoidance for the chosen item.

## Output Format

```
=== ANTI-AVOIDANCE — JUST ONE TODAY ===

The Pile (be honest, no judgment):
1. [Item — N days/weeks avoided]
2. [...]
3. [...]
[...continue list...]

The Reason Per Item:
- [Item 1] → [Overwhelm / dread / shame / conflict / decision-paralysis / waiting on someone / unclear next step]
- [Item 2] → [...]
- [...]

The One I'm Picking:
[Item — why this one: smallest? oldest? most-rotting? most-blocked-by?]

Smallest Possible Action (≤ 2 minutes):
- [The first physical motion: open the email, dial the number, find the form, write a 1-line text, walk to the cabinet, etc.]
- I am NOT committing to finishing the task. Just this first motion.
- When: [in the next [N min] — concrete trigger like "after I send this prompt back"]

What I'm Not Doing Today:
- [The rest of the pile]
- This is deliberate. Trying to clear all of it is how the pile grew.

What This Costs Me If I Don't Do the One:
- [Concrete cost — late fee, missed appointment, relationship strain, increased shame load tomorrow]
- And: the avoidance itself is consuming energy. Doing one shrinks the energy cost.

After:
- Mark the one done.
- Don't take a "while I'm at it" detour into another item; the rule is one.
- Tomorrow, repeat with one more.

If I can't do even the smallest:
- Then the smaller version: write the item on a sticky note and put it where I'll see it. That counts.
- If literally nothing is available: this may not be the right intervention right now; this is the depression speaking loudly. Reach out to my therapist or a person.
```

## Verification

- [ ] Pile listed without judgment.
- [ ] Avoidance reason per item.
- [ ] One item chosen.
- [ ] Action ≤ 2 minutes.
- [ ] Explicit deferral of the rest.
- [ ] Cost of avoidance named.
- [ ] No "do everything" plan.
- [ ] Smaller-than-smallest fallback included.
- [ ] No shame language.
