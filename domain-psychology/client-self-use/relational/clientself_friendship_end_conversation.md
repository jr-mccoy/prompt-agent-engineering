# Friendship-End or Hibernation Conversation Drafter

## Objective

Help someone first get clear on what they actually want with a friendship — to end it, to pause/hibernate it, or to let it fade — and then draft the actual message at the directness they choose, plus how to handle the likely responses. Ending or pausing a friendship rarely has a script; this builds one.

## When to Use

- A friendship has become draining, one-sided, or misaligned and you're unsure how to address it.
- You want a clean ending vs. a ghost.
- You want a pause ("I need space right now") rather than a permanent end.
- You keep avoiding the conversation and want concrete words.

## Inputs / Context

- The friendship and what's changed.
- What you actually want (end / pause / fade / talk it through first).
- What you fear about saying it (drama, guilt, mutual friends, being the bad guy).
- The friend's likely reaction style.
- Whether anything unsafe or harassing is involved (if so, see note).

## Constraints

### Must

- Start with **What Do I Actually Want?** — distinguish end vs pause vs fade vs repair-first, since the message depends on it.
- Output sections in order: **What I Actually Want**, **The Message Options (low / medium / high directness)**, **Handling Their Likely Responses**, **If I'd Rather Fade Than Talk**, **After**.
- Generate the actual messages, not "you could say…".
- Match warmth to the relationship; an ending can be kind and final at once.

### Must Not

- Don't default to "you must have a big closure conversation" — fading is a valid choice for low-stakes ties.
- Don't write cruelty or a grievance list; the goal is clarity, not a verdict.
- Don't promise the friend will react well.
- If there's harassment, stalking, or safety concern, note that no explanation is owed and routing to blocking / support / authorities is appropriate.

## Instructions

1. Clarify the actual goal (end / pause / fade / talk-first).
2. Draft messages at three directness levels matched to that goal.
3. Prepare responses for the likely reactions (hurt, anger, "let's talk," silence).
4. Offer a no-conversation fade option for lower-stakes ties.
5. Add a short "after" note (what to do with the urge to over-explain or re-engage).

## Output Format

```
=== FRIENDSHIP CONVERSATION ===

What I Actually Want (pick one, name it honestly):
- [ ] End it cleanly        - [ ] Pause / hibernate (reassess later)
- [ ] Let it fade           - [ ] Try one honest talk first, then decide

The Message Options:

Low directness (soft, open):
"Hey — I've felt some distance between us lately and I've been sitting with it. I care about you and I wanted to be honest rather than just go quiet."

Medium directness (naming the change):
"I've realized I need to step back from our friendship for a while. It's not about one thing — it's where I am right now. I didn't want to just disappear on you."

High directness (clear ending):
"I've decided I'm not able to keep this friendship going. I wish you well, and I wanted to say it directly rather than fade out."

Handling Their Likely Responses:
- If they're hurt and ask why: "I don't have a tidy reason, and I don't want to turn this into a list. This is just where I've landed."
- If they get angry: "I understand you're upset. I'm not going to argue it." [then disengage]
- If they want to fix it and I don't: "I appreciate that. For me, this isn't something I'm looking to repair right now."
- If they go silent: I let it be silent. I don't chase to feel less guilty.

If I'd Rather Fade Than Talk (valid for lower-stakes ties):
- Slow my replies, stop initiating, let it quiet down. No announcement required.

After:
- The urge to over-explain or re-open to relieve guilt is normal — I don't have to act on it.
- If I keep churning on it, I'll bring it to my therapist.

Safety note (only if relevant): If this person is harassing or unsafe, I owe no explanation — blocking and, if needed, support/authorities come first.
```

## Verification

- [ ] Goal (end / pause / fade / talk-first) clarified before drafting.
- [ ] Three directness levels as actual messages.
- [ ] Responses prepared for at least 3 reactions.
- [ ] Fade option offered as legitimate.
- [ ] No closure conversation forced; no grievance list.
- [ ] Safety note present where relevant.
