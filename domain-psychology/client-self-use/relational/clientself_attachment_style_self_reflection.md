# Attachment-Style Self-Reflection

## Objective

Offer a gentle, non-deterministic reflection on attachment tendencies. Map the user's actual relationship behaviors to attachment patterns *as tendencies that shift by context and relationship*, name what each pattern is trying to protect, and point toward earned security — not toward a permanent label.

## When to Use

- Curiosity about why you react the way you do in close relationships.
- A recurring relational pattern (pulling away, over-pursuing, fearing abandonment).
- Wanting language to bring to therapy or to a partner conversation.

## Inputs / Context

- A couple of recent relational moments (how you reacted when close, when distant, when in conflict).
- What you remember wanting/feeling as the connection got closer or more uncertain.
- Whether the pattern is the same across people or shows up only with some.

## Constraints

### Must

- Frame attachment styles as **tendencies, not types** — describe behavior patterns and what they protect.
- Output sections in order: **The Lens (plain-language styles)**, **What I Notice in My Own Behavior**, **What This Pattern Is Trying to Protect**, **It's a Lens, Not a Label**, **One Small Experiment**.
- Use an analogy or two to make the styles concrete (RT-04).
- State explicitly that styles can vary by relationship and can move toward security over time (earned security).

### Must Not

- Don't assign the user a single fixed "type" or diagnose.
- Don't frame any style as broken or as a life sentence.
- Don't infer childhood causes the user didn't offer; keep it descriptive.
- Don't substitute this for therapy if a pattern is causing real distress — name the handoff.

## Instructions

1. Describe the four patterns in plain language with a short analogy.
2. Reflect back the tendencies the user's own examples suggest — without locking them to one box.
3. Name the protective function under the pattern.
4. Reinforce that this is a lens and that change is possible.
5. Offer one small, concrete experiment.

## Output Format

```
=== ATTACHMENT REFLECTION ===

The Lens (plain language — these are tendencies, not boxes):
- Secure-leaning: closeness and space both feel okay; conflict isn't catastrophic.
- Anxious-leaning: closeness feels safest, distance reads as danger — like a smoke alarm that's a bit too sensitive.
- Avoidant-leaning: independence feels safest, closeness can feel like pressure — like keeping one hand on the exit.
- Disorganized/mixed: pulled toward AND away at once, especially when stakes are high.

What I Notice in My Own Behavior (from my examples):
- When connection felt close, I tended to: [...]
- When it felt uncertain, I tended to: [...]
- In conflict, I tended to: [...]
- Read: this looks more [anxious- / avoidant- / secure-leaning] in THIS relationship — and may differ elsewhere.

What This Pattern Is Trying to Protect:
- The behavior makes sense as a way to protect: [e.g., "against being left," "against being engulfed"]. It's a strategy, not a flaw.

It's a Lens, Not a Label:
- This can shift by relationship and over time. "Earned security" is real — people move toward secure functioning through safe relationships and work like therapy.

One Small Experiment:
- Next time I notice [trigger], I'll try [one different micro-move], and just observe what happens.

If this pattern is causing real pain or keeps wrecking relationships, that's worth bringing to a therapist.
```

## Verification

- [ ] Styles framed as tendencies, not fixed types.
- [ ] Behaviors mapped to the user's own examples.
- [ ] Protective function named.
- [ ] Earned security / changeability stated.
- [ ] At least one analogy used.
- [ ] No diagnosis; therapist handoff for distress.
