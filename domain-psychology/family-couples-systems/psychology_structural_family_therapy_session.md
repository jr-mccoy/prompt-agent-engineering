# Structural Family Therapy Session Planner (Minuchin)

## Objective

Produce a Structural Family Therapy (SFT) session plan faithful to Salvador Minuchin's model. The plan begins with joining and accommodation, builds a structural map of the family (boundaries, subsystems, hierarchy, and alignments/coalitions/triangulation), then sequences the SFT interventions — enactments, boundary-making, unbalancing, reframing, and restructuring — to shift the family's organization so that symptoms maintained by the structure are no longer required. Output includes a structural map using standard SFT notation and an in-session intervention sequence with the specific structural change each move targets.

## When to Use

- For families where a presenting symptom (often in a child/"identified patient") is maintained by family organization: enmeshment, disengagement, cross-generational coalitions, or an inverted hierarchy.
- When the clinician wants to work with present-moment process (enactments) rather than narrative/history.
- When the planning question is "what structural change does this family need and how do I sequence it?"
- For supervision/consultation requiring the case framed in structural terms with a map.

## Inputs / Context Required

- **Family composition and who attends.**
- **Presenting problem and the identified patient (if any).**
- **Observed interactional sequences**: who speaks to/for whom; who interrupts; who aligns with whom against whom.
- **Boundary quality** around and between subsystems (spousal, parental, sibling): rigid / clear / diffuse.
- **Hierarchy**: is the parental/executive subsystem in charge, or is it inverted/undermined?
- **Coalitions/triangulation**: any cross-generational coalition (e.g., parent + child vs other parent) or a child triangulated into spousal conflict.
- **Family developmental stage / recent transitions** stressing the structure.
- **Safety screen**: IPV / child-safety screen. `[clinician input required: IPV and child-maltreatment screen results; unbalancing/intensity techniques are contraindicated where they would increase risk]`
- `[clinician input required: cultural norms around hierarchy and boundaries to avoid pathologizing culturally normative structure]`

## Constraints

### Must

- Begin with joining and accommodation (mimesis, tracking, respecting the family's style) before challenging structure.
- Produce a structural map using standard notation (see legend) showing subsystems, boundary types, and any coalition/triangulation.
- Classify boundaries as rigid (→ disengagement), clear (healthy), or diffuse (→ enmeshment), and name the consequence.
- Assess hierarchy and flag inversion or an undermined executive subsystem.
- Use enactments to bring the problem interaction into the room (have the family interact, not just describe), then observe, then modify the enactment in vivo.
- Sequence restructuring moves with the specific structural target of each: boundary-making (strengthen or loosen a boundary), unbalancing (temporarily side with one member to shift a stuck hierarchy/coalition), reframing (shift the meaning so change is possible), intensity/repetition.
- Tie the symptom to the structure: state how the current organization maintains the presenting problem and what new structure would make it unnecessary.
- Include a safety re-assessment hook; do not use unbalancing/intensity where it would raise IPV or child-safety risk.
- Use `[clinician input required: ...]` for clinician-supplied content.

### Must Not

- Do not challenge or restructure before joining; an unjoined family will reject interventions.
- Do not pathologize culturally normative hierarchy or boundary patterns; calibrate to the family's cultural context.
- Do not use unbalancing (siding with one member) without a plan to rebalance and without safety clearance.
- Do not work only from family report; require enactment to see the actual structure.
- Do not fabricate observed sequences; flag with `[clinician input required]`.

## Instructions

1. **Plan joining and accommodation.** Specify how the therapist will join each subsystem (maintenance, tracking content, mimesis of style) and earn leadership before challenging structure.

2. **Build the structural map.** Use the legend to diagram subsystems, boundary types, hierarchy, and coalitions/triangulation.

   | Notation | Meaning |
   |----------|---------|
   | `———` (solid line) | Clear boundary (permeable, healthy) |
   | `- - -` (dotted line) | Diffuse boundary → enmeshment |
   | `▮▮▮` (thick/solid bar) | Rigid boundary → disengagement |
   | `———/` or `→|` | Conflict / boundary crossed |
   | `[ ]` grouping | A subsystem (e.g., [Mom Dad] = spousal/parental) |
   | `═══` (double line) | Coalition / over-involvement (alliance) |
   | `]——[` overarching | Cross-generational coalition (parent+child vs parent) |
   | Vertical placement | Hierarchy (executive subsystem above) |

   Example map line: `[Mom ═══ Child] ▮▮▮ Dad` = mother-child enmeshed coalition, rigid boundary excluding a disengaged father.

3. **Diagnose the structure.** State boundary quality per boundary, hierarchy status (intact / inverted / undermined), and any triangulation (child triangulated into spousal conflict; detouring through the IP).

4. **Link symptom to structure.** Write the structural hypothesis: how the organization maintains the symptom (e.g., "the child's symptom detours spousal conflict and is maintained by the cross-generational coalition").

5. **Plan enactments.** Choose a problem interaction to elicit in the room. Specify: how to spontaneously create it or assign it, what to observe, and how to modify it in vivo (e.g., "have the parents resolve the bedtime issue together while the child sits with you," blocking the usual coalition).

6. **Sequence restructuring moves**, each with its structural target:
   - Boundary-making: strengthen the spousal/parental boundary; loosen an enmeshed dyad; create distance or proximity by seating, blocking interruptions, or assigning who talks to whom.
   - Unbalancing: temporarily affiliate with the under-powered member (e.g., support the disengaged parent's authority) to shift a stuck hierarchy/coalition — with a rebalance plan.
   - Reframing: shift the meaning of the symptom/behavior so the family can act differently (e.g., from "bad kid" to "loyal child protecting the marriage").
   - Intensity / repetition: hold focus and repeat to make the structural shift stick.

7. **State the target structure** the session is moving toward (clear spousal boundary, restored executive hierarchy, dissolved cross-generational coalition).

8. **Re-screen safety; run verification.**

## Output Format

```
=== STRUCTURAL FAMILY THERAPY SESSION PLAN ===

SAFETY SCREEN
IPV / child-maltreatment screen: [Clear / Flag → action; restrict unbalancing/intensity if risk]

────────────────────────────────────────────────────────
JOINING & ACCOMMODATION PLAN
Per subsystem: [maintenance / tracking / mimesis approach]
Leadership stance: [how therapist earns the position to challenge structure]

────────────────────────────────────────────────────────
STRUCTURAL MAP (standard notation)

[diagram using legend — e.g.]
        [ Mom ═══ Child ]  ▮▮▮  Dad
              (enmeshed coalition)   (disengaged)
Hierarchy: [intact / inverted / undermined]

Boundary inventory:
  Spousal subsystem boundary: [rigid/clear/diffuse] → [consequence]
  Parental–child boundary: [rigid/clear/diffuse] → [consequence]
  Sibling subsystem boundary: [rigid/clear/diffuse] → [consequence]
Coalition / triangulation: [describe; who vs whom; is the IP triangulated/detoured?]

────────────────────────────────────────────────────────
STRUCTURAL HYPOTHESIS (symptom ↔ structure)
"The presenting problem ([symptom]) is maintained by [structural feature];
a structure in which [target change] would make the symptom unnecessary."

────────────────────────────────────────────────────────
IN-SESSION INTERVENTION SEQUENCE
1. Enactment: [interaction to elicit] → observe [what] → modify [how, in vivo]
2. Boundary-making: [target boundary] → [move: seating/blocking/who-talks-to-whom]
3. Unbalancing (if used): side temporarily with [member] to shift [coalition/hierarchy]
   Rebalance plan: [how/when]
4. Reframing: from "[old meaning]" to "[new meaning]"
5. Intensity / repetition: [focus to hold]

TARGET STRUCTURE (this session moves toward):
[clear spousal boundary / restored executive hierarchy / dissolved cross-gen coalition]

────────────────────────────────────────────────────────
SAFETY RE-ASSESSMENT HOOK
Re-screen IPV/child-safety before unbalancing/intensity. [clinician input required: supervisor consult if risk]
```

## Verification

- [ ] Joining/accommodation planned before any restructuring.
- [ ] Structural map drawn with standard notation (boundary types, subsystems, hierarchy, coalition).
- [ ] Boundaries classified rigid/clear/diffuse with consequence (disengagement/enmeshment).
- [ ] Hierarchy status assessed; inversion/undermining flagged.
- [ ] Triangulation/coalition identified (incl. whether the IP is triangulated/detoured).
- [ ] Symptom explicitly linked to structure (structural hypothesis).
- [ ] At least one enactment planned with elicit → observe → modify.
- [ ] Restructuring moves each state their structural target; unbalancing includes a rebalance plan.
- [ ] Cultural calibration applied so normative structure is not pathologized.
- [ ] IPV/child-safety screen documented; intensity/unbalancing restricted under risk.
- [ ] Missing observations flagged with `[clinician input required]`.
