# Autism Assessment Battery Design (Masking-Aware, Multi-Informant)

## Objective

Design a masking-aware, multi-informant autism assessment battery that:

1. Anchors the assessment in a **developmental history** of social-communication and restricted/repetitive patterns across the lifespan (e.g., ADI-R structure), not current presentation alone.
2. Plans **observational assessment** appropriate to the client's language level and developmental stage (e.g., ADOS-2 module selection), while recognizing observation-based tools can under-detect in skilled maskers.
3. Combines **self-report and informant screeners** (e.g., AQ, RAADS-R, SRS-2) with a **masking/camouflaging measure** (e.g., CAT-Q), so that camouflaging is measured rather than missed.
4. Includes **cognitive and adaptive** measures (e.g., Vineland) to characterize the profile and support-needs picture.
5. Builds a structured **differential** (ADHD, social anxiety, trauma, PDA/demand-avoidant profile, personality, language disorder) and is explicitly attentive to **adult and female/late-identified presentations** where masking is common.

This is a battery-design scaffold. It does not interpret scores or diagnose; it assembles the data sources and the masking-aware frame. All selections require clinician confirmation.

## When to Use

- An autism referral arrives — especially for an adult, an adolescent/woman, or a late-identified or high-masking presentation — and the clinician must assemble the data sources before testing.
- A request that would otherwise rest on a single observational tool needs broadening to capture masking and lifespan developmental evidence.
- Differential-heavy presentations where ADHD, social anxiety, trauma, or a demand-avoidant profile must be actively distinguished or co-identified.

Not appropriate as a stand-alone diagnostic instrument, and not a substitute for a clinician trained in the observational tools proposed. Observational-tool administration (e.g., ADOS-2) requires specific training/qualification.

## Inputs / Context Required

- **Age, developmental stage, and language level** (drives observational module selection and informant set) `[clinician input required]`
- **Referral question and source** (self, family, school, treating clinician, disability/accommodations) `[clinician input required]`
- **Presenting concerns** and the contexts where social-communication differences appear
- **Developmental-history availability:** early childhood records, caregiver who can report on early development, school history `[clinician input required]`
- **Masking/camouflaging indicators:** self-reported effort to appear neurotypical, exhaustion after social contact, scripting, observed vs. reported discrepancy `[clinician input required]`
- **Available informants:** self, partner, parent/caregiver who knew early development, teacher `[clinician input required]`
- **Differential history:** ADHD, social anxiety, trauma/ACEs, personality, language/communication disorder, intellectual disability, sensory profile `[clinician input required]`
- **Identity/presentation factors:** adult, female/late-identified, gender-diverse, culturally/linguistically diverse — all affect masking likelihood and tool fit `[clinician input required]`
- **Constraints:** time, authorization, language, prior testing and dates

## Constraints

### Must

- Require a **lifespan developmental-history** component (e.g., ADI-R structure) covering early social-communication and restricted/repetitive patterns; flag when an early-development informant is unavailable and how that limits conclusions.
- Select **observational assessment by language level / developmental stage** (e.g., ADOS-2 module choice) and explicitly note that observation can **under-detect in skilled maskers** — a non-elevated observation does not rule out autism in a high-masking presentation.
- Include a **masking/camouflaging measure** (e.g., CAT-Q) and self/informant screeners (e.g., AQ, RAADS-R, SRS-2) by name only; treat self-report and observation as **complementary, not interchangeable**.
- Include **adaptive functioning** (e.g., Vineland) and a **cognitive** estimate to characterize the profile and support needs, distinguishing autism from intellectual disability.
- Build a structured **differential** (ADHD, social anxiety, trauma, PDA/demand-avoidant profile, personality, language disorder, ID) with co-occurrence explicitly allowed (autism + ADHD is common).
- Be **explicitly attentive to adult and female/late-identified presentations**: note that many standard tools were normed on young boys and may under-identify these groups; recommend masking-aware interpretation.
- Note **norm, language, gender, and cultural fit** per instrument and flag where norms may not apply.
- State **what the battery can and cannot establish** and the **referral thresholds** (e.g., speech-language evaluation, neuropsychology, genetics/medical, trauma-specialist).

### Must Not

- Do not reproduce copyrighted item content, verbatim screener/observation items, proprietary scoring/coding keys, copyrighted algorithms, or copyrighted normative tables. Reference instruments by name, module/subscale structure, and score-range bands only.
- Do not treat a non-elevated observational result as ruling out autism in a high-masking presentation.
- Do not base a conclusion on a single instrument or a single source; observation and self/informant report must be integrated.
- Do not apply tools normed primarily on young boys to adults or women without flagging the fit limitation.
- Do not interpret scores or assign a diagnosis — the output stops at battery design.
- Do not fabricate developmental history, informant data, or scores; use `[clinician input required: ___]`.

## Instructions

1. **Set the frame by age, stage, and language level.** This fixes observational-module selection, informant set, and which screeners/norms apply. Flag adult / female / late-identified / gender-diverse / culturally-diverse status as masking-relevant.

2. **Plan the lifespan developmental-history component.** Specify how early social-communication and restricted/repetitive patterns will be established (caregiver interview per ADI-R structure, early records, school history). Flag if no early-development informant is available and state the limitation.

3. **Select observational assessment.** Choose the observational approach/module by language level and developmental stage (e.g., ADOS-2 module). State the masking caveat explicitly and confirm administration qualification is in place or route to a qualified examiner.

4. **Design the self/informant + masking layer.** Select named screeners (e.g., AQ, RAADS-R, SRS-2) and a camouflaging measure (e.g., CAT-Q). Plan to compare self-report, informant report, and observation, attending to discrepancies that signal masking.

5. **Add cognitive and adaptive measures.** Include an adaptive measure (e.g., Vineland) and a cognitive estimate to characterize profile, support needs, and to distinguish autism from intellectual disability.

6. **Construct the masking-aware differential.** For each condition, specify how it will be assessed and whether co-occurrence is being evaluated:

   | Differential | Relationship to autism | How this battery addresses it |
   |--------------|------------------------|-------------------------------|
   | ADHD | Frequently co-occurs | [screen/measure] |
   | Social anxiety | Overlapping social avoidance | [screen/interview] |
   | Trauma / ACEs | Can mimic/co-occur (hypervigilance, shutdown) | [trauma screen] |
   | PDA / demand-avoidant profile | Profile within/alongside autism | [history/interview] |
   | Personality | Differential for adult social-relational patterns | [as indicated] |
   | Language / communication disorder | Differential for communication features | [SLP referral] |
   | Intellectual disability | Differential/co-occurring | [cognitive + adaptive] |

7. **State scope and referral thresholds.** Write what the battery can/cannot establish and the conditions routing to speech-language evaluation, neuropsychology, genetics/medical, or trauma specialist.

8. **Run verification.**
