# Mobile Development Commands

> Commands for Android and iOS project initialization, upgrades, and mobile-specific workflows.

## Commands

| Command | Syntax | Description |
|---------|--------|-------------|
| [android_adb_health_check.md](./android_adb_health_check.md) | `/android-adb-health-check` | Quick device and app health check via ADB. Captures device state, app memory usage, running services, battery impact, and recent crash logs in a single report. Designed to run in under 60 seconds. |
| [android_behavior_audit.md](./android_behavior_audit.md) | `/android-behavior-audit` | Orchestrate comprehensive Android app behavior audit across survey, deep code tracing, behavioral scrutiny, developer clarification, and fix planning to align actual code behavior with developer intent |
| [android_beta_launch.md](./android_beta_launch.md) | `/android-beta-launch` | Orchestrate comprehensive Android beta launch preparation across security, performance, Firebase validation, test coverage, and Play Store compliance with go/no-go release decision |
| [android_daily_standup.md](./android_daily_standup.md) | `/android-daily-standup` | Morning startup command that reviews last session's changes, checks CI status, pulls latest crash reports, reviews support inbox, and suggests daily priorities based on impact and urgency |
| [android_gradle_upgrade.md](./android_gradle_upgrade.md) | `/android-gradle-upgrade` | Upgrade Android Gradle Plugin and dependencies with compatibility verification |
| [android_init.md](./android_init.md) | `/android-init` | Initialize Android projects with MVVM, Hilt, Jetpack Compose, and best practices |
| [android_monetization_setup.md](./android_monetization_setup.md) | `/android-monetization-setup` | Orchestrate complete Android monetization implementation including Google Play Billing, subscriptions, AdMob, paywalls, server-side verification, and policy compliance |
| [android_ship_check.md](./android_ship_check.md) | `/android-ship-check` | Pre-release verification command that runs the full test suite, checks for regressions, validates ProGuard rules, verifies Play Store policy compliance, checks Firebase security rules, and produces a go/no-go report |
| [android_weekly_review.md](./android_weekly_review.md) | `/android-weekly-review` | Weekly review command that pulls metrics from Play Console, Firebase, and codebase to produce a weekly summary with key metrics, trend analysis, and next-week recommendations |
| [mobile_ui_addictiveness_audit.md](./mobile_ui_addictiveness_audit.md) | `/mobile-ui-addictiveness-audit` | Orchestrate a comprehensive audit of an app's engagement and habit-forming potential across behavioral psychology frameworks, analyzing triggers, core loops, reward systems, retention mechanics, and emotional design… |
| [mobile_ui_element_audit.md](./mobile_ui_element_audit.md) | `/mobile-ui-element-audit` | Orchestrate a comprehensive UI element audit across trend research, element-level analysis, engagement optimization, and implementation planning to transform specific mobile UI elements from functional to exceptional |
| [mobile_ui_trend_report.md](./mobile_ui_trend_report.md) | `/mobile-ui-trend-report` | Generate a comprehensive mobile UI trend report covering visual design, interaction patterns, engagement mechanics, and platform-specific innovations with actionable recommendations tailored to the user's app… |

## Usage

These commands are invoked using slash syntax: `/command-name [arguments]`
