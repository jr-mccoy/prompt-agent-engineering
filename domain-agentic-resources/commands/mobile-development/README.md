# Mobile Development Commands

> Commands for Android and iOS project initialization, upgrades, and mobile-specific workflows.

## Commands

| Command | Syntax | Description |
|---------|--------|-------------|
| [android_gradle_upgrade.md](./android_gradle_upgrade.md) | `/android-gradle-upgrade` | Upgrade Android Gradle Plugin and dependencies with compatibility verification |
| [android_init.md](./android_init.md) | `/android-init` | Initialize Android projects with MVVM, Hilt, Jetpack Compose, and best practices |

## Usage

These commands are invoked using slash syntax: `/command-name [arguments]`
