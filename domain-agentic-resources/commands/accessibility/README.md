# Accessibility Commands

> Commands for comprehensive accessibility auditing and WCAG compliance verification.

## Commands

| Command | Syntax | Description |
|---------|--------|-------------|
| [accessibility_audit.md](./accessibility_audit.md) | `/accessibility-audit` | Comprehensive accessibility audit with WCAG compliance checking and remediation guidance |
| [component_scaffold.md](./component_scaffold.md) | `/component-scaffold` | Scaffold production-ready accessible React/React Native components with TypeScript |

## Usage

These commands are invoked using slash syntax: `/command-name [arguments]`
