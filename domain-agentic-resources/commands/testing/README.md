# Testing Commands

> Commands for test-driven development, test generation, and comprehensive test automation.

## Commands

| Command | Syntax | Description |
|---------|--------|-------------|
| [tdd_cycle.md](./tdd_cycle.md) | `/tdd-cycle` | Execute comprehensive TDD workflow with strict red-green-refactor discipline |
| [tdd_green.md](./tdd_green.md) | `/tdd-green` | Implement minimal code to make failing tests pass in TDD green phase |
| [tdd_red.md](./tdd_red.md) | `/tdd-red` | Generate comprehensive failing tests following TDD red phase principles |
| [tdd_refactor.md](./tdd_refactor.md) | `/tdd-refactor` | Refactor code with confidence using comprehensive test safety net |
| [test_generate.md](./test_generate.md) | `/test-generate` | Generate comprehensive, maintainable unit tests across multiple languages |

## Usage

These commands are invoked using slash syntax: `/command-name [arguments]`
