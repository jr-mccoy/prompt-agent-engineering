| Command | Syntax | Description |

| [error_analysis.md](./error_analysis.md) | `/error-analysis` | Systematic error analysis and resolution for distributed systems |
| [error_trace.md](./error_trace.md) | `/error-trace` | Implement comprehensive error monitoring and tracking solutions |

| [smart_fix.md](./smart_fix.md) | `/smart-fix` | Intelligent issue resolution with multi-agent debugging orchestration |

## Usage

These commands are invoked using slash syntax: `/command-name [arguments]`
