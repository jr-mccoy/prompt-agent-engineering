# Git Workflows Commands

> Commands for Git workflow automation, PR management, and team onboarding.

## Commands

| Command | Syntax | Description |
|---------|--------|-------------|
| [git_workflow.md](./git_workflow.md) | `/git-workflow` | Orchestrate comprehensive git workflow from code review through PR creation |
| [onboard.md](./onboard.md) | `/onboard` | Comprehensive team onboarding with knowledge transfer and integration workflows |
| [pr_enhance.md](./pr_enhance.md) | `/pr-enhance` | Optimize pull requests for efficient code reviews with detailed descriptions |

## Usage

These commands are invoked using slash syntax: `/command-name [arguments]`
