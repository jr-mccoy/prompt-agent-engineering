# Database Commands

> Commands for database optimization, cost analysis, and performance tuning.

## Commands

| Command | Syntax | Description |
|---------|--------|-------------|
| [cost_optimize.md](./cost_optimize.md) | `/cost-optimize` | Optimize database costs through query analysis, indexing, and resource management |
| [sql_migrations.md](./sql_migrations.md) | `/sql-migrations` | SQL database migrations with zero-downtime strategies and rollback plans |

## Usage

These commands are invoked using slash syntax: `/command-name [arguments]`
