# Commands/Non Coding

## Scope
This directory contains reusable non-coding commands organized by business and knowledge-work domains rather than software engineering domains.

## Inclusion criteria
- Designed for non-coding tasks as the primary use case.
- Broadly reusable across teams in the same domain.
- Documented with clear intent, inputs, and expected outputs.

## Examples
- Education-focused resources for planning and assessment workflows.
- Healthcare-focused resources for policy communication and patient-facing materials.
- Cross-domain patterns that can be adapted for multiple non-coding contexts.

## Quality gates checklist
Use the [Non-Coding Quality Gates Checklist Template](../../documentation/templates/non_coding_quality_gates.md) before publishing or promoting any non-coding resource from this folder.
