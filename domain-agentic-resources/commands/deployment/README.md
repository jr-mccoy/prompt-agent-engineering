# Deployment Commands

> Commands for configuration validation, deployment verification, and release management.

## Commands

| Command | Syntax | Description |
|---------|--------|-------------|
| [config_validate.md](./config_validate.md) | `/config-validate` | Validate deployment configurations for correctness and best practices compliance |
| [migration_observability.md](./migration_observability.md) | `/migration-observability` | Set up CDC, monitoring, and alerting for migration and rollout deployments |

## Usage

These commands are invoked using slash syntax: `/command-name [arguments]`
