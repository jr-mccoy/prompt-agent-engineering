# Orchestration Commands

> Commands for multi-agent coordination, context management, and full-stack feature development.

## Commands

| Command | Syntax | Description |
|---------|--------|-------------|
| [context_restore.md](./context_restore.md) | `/context-restore` | Intelligent semantic-aware context retrieval and reconstruction across workflows |
| [context_save.md](./context_save.md) | `/context-save` | Comprehensive context capture and serialization for multi-session collaboration |
| [full_stack_feature.md](./full_stack_feature.md) | `/full-stack-feature` | Orchestrate full-stack feature development across backend, frontend, and infrastructure |
| [improve_agent.md](./improve_agent.md) | `/improve-agent` | Systematic improvement of agents through performance analysis and prompt engineering |
| [issue.md](./issue.md) | `/issue` | GitHub issue resolution with systematic bug investigation and feature implementation |
| [multi_agent_optimize.md](./multi_agent_optimize.md) | `/multi-agent-optimize` | Holistically improve system performance through intelligent agent coordination |
| [solo_dev_retro.md](./solo_dev_retro.md) | `/solo-dev-retro` | Solo developer retrospective that reviews the past sprint/week. |
| [solo_dev_sprint_plan.md](./solo_dev_sprint_plan.md) | `/solo-dev-sprint-plan` | Sprint planning optimized for a team of one. Analyzes current project state, backlog, past velocity, and available capacity to produce a realistic 1-2 week plan using half-day estimates instead of story points. |
| [standup_notes.md](./standup_notes.md) | `/standup-notes` | Generate async standup notes from commit history, Jira, and Obsidian sources |

## Usage

These commands are invoked using slash syntax: `/command-name [arguments]`
