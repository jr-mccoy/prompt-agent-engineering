# Framework Migration Commands

> Commands for codebase migration, legacy modernization, and dependency upgrades.

## Commands

| Command | Syntax | Description |
|---------|--------|-------------|
| [code_migrate.md](./code_migrate.md) | `/code-migrate` | Migrate codebases between frameworks with compatibility verification |
| [deps_upgrade.md](./deps_upgrade.md) | `/deps-upgrade` | Upgrade dependencies with compatibility checking and migration guidance |
| [legacy_modernize.md](./legacy_modernize.md) | `/legacy-modernize` | Modernize legacy systems using strangler fig pattern and incremental migration |

## Usage

These commands are invoked using slash syntax: `/command-name [arguments]`
