# Architecture Commands

> Commands for software architecture documentation, analysis, and C4 model generation.

## Commands

| Command | Syntax | Description |
|---------|--------|-------------|
| [c4_architecture.md](./c4_architecture.md) | `/c4-architecture` | Generate C4 architecture diagrams and documentation for system visualization |
| [data_pipeline.md](./data_pipeline.md) | `/data-pipeline` | Design scalable batch and streaming data pipeline architectures |

## Usage

These commands are invoked using slash syntax: `/command-name [arguments]`
