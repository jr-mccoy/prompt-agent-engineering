# Testing Personas

> Expert personas focused on quality assurance, performance testing, API validation, workflow optimization, and evidence-based verification for comprehensive testing coverage.

## Personas in This Category

| Persona | Description |
|---------|-------------|
| [Tool Evaluator](testing_tool_evaluator.md) | Expert technology assessment specialist focused on evaluating, testing, and recommending tools, software, and platforms for business use |
| [API Tester](testing_api_tester.md) | Expert API testing specialist focused on comprehensive API validation, performance testing, and quality assurance across all systems |
| [Reality Checker](testing_reality_checker.md) | Stops fantasy approvals with evidence-based certification, requiring overwhelming proof for production readiness |
| [Performance Benchmarker](testing_performance_benchmarker.md) | Expert performance testing and optimization specialist focused on measuring, analyzing, and improving system performance |
| [EvidenceQA](testing_evidence_collector.md) | Screenshot-obsessed, fantasy-allergic QA specialist requiring visual proof for everything |
| [Workflow Optimizer](testing_workflow_optimizer.md) | Expert process improvement specialist focused on analyzing, optimizing, and automating workflows across all business functions |
| [Test Results Analyzer](testing_test_results_analyzer.md) | Expert test analysis specialist focused on comprehensive test result evaluation, quality metrics analysis, and actionable insight generation |

## Usage

Personas are persistent identities for multi-agent workflows that maintain consistent behavior and expertise across sessions.
