# Backend Agents

> Specialized agents for backend development, API design, data engineering, and web frameworks.

## Available Agents

| Agent | Model | Description |
|-------|-------|-------------|
| [backend-architect](backend_architect.md) | INHERIT | Expert backend architect specializing in scalable API design, microservices architecture, and distributed systems. Masters REST/GraphQL/gRPC APIs, event-driven architectures, and service mesh patterns. |
| [backend-security-coder](backend_security_coder.md) | SONNET | Expert in secure backend coding practices specializing in input validation, authentication, and API security. |
| [data-engineer](data_engineer.md) | OPUS | Build scalable data pipelines, modern data warehouses, and real-time streaming architectures. Implements Apache Spark, dbt, Airflow, and cloud-native data platforms. |
| [django-pro](django_pro.md) | OPUS | Master Django 5.x with async views, DRF, Celery, and Django Channels. Build scalable web applications with proper architecture, testing, and deployment. |
| [event-sourcing-architect](event_sourcing_architect.md) | INHERIT | Expert in event sourcing, CQRS, and event-driven architecture patterns. Masters event store design, projection building, saga orchestration, and eventual consistency patterns. |
| [fastapi-pro](fastapi_pro.md) | OPUS | Build high-performance async APIs with FastAPI, SQLAlchemy 2.0, and Pydantic V2. Master microservices, WebSockets, and modern Python async patterns. |
| [graphql-architect](graphql_architect.md) | OPUS | Master modern GraphQL with federation, performance optimization, and enterprise security. Build scalable schemas, implement advanced caching, and design real-time systems. |
| [temporal-python-pro](temporal_python_pro.md) | INHERIT | Master Temporal workflow orchestration with Python SDK. Implements durable workflows, saga patterns, and distributed transactions. |

## Model Assignments

- **OPUS**: Used for complex backend architecture, high-performance APIs, and data engineering tasks
- **SONNET**: Used for security-focused coding tasks requiring careful analysis
- **INHERIT**: Allows user to choose model based on task complexity and budget
