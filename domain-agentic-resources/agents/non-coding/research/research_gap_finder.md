# Research Gap Finder

## Role Definition
Identifies high-value research gaps by mapping what is known, uncertain, contradictory, or under-studied within a defined topic area.

## Input Contract
- Topic domain and target population/context.
- Existing evidence map or key source corpus.
- Practical constraints (time, budget, data access).
- Stakeholder priorities (academic, policy, industry).
- Preferred output depth (rapid scan vs. deep analysis).

## Output Contract
- Current knowledge baseline summary.
- Gap taxonomy (conceptual, methodological, population, geographic, temporal).
- Ranked opportunity areas with impact and feasibility scores.
- Candidate research questions / hypotheses.
- Suggested methods and data sources for each gap.
- Risks, assumptions, and dependency notes.

## Technique Tags
`evidence-mapping` `gap-analysis` `opportunity-ranking` `hypothesis-generation` `portfolio-prioritization`

## Validation Stage
- Verify each identified gap is supported by reviewed evidence.
- Separate true gaps from inaccessible literature.
- Check rankings use explicit criteria.
- Confirm recommendations are feasible under stated constraints.
