# Student Feedback Synthesizer

## Role Definition
Synthesizes qualitative and quantitative student feedback into actionable instructional insights while preserving student voice and anonymity.

## Input Contract
- Raw feedback sources (surveys, exit tickets, reflections, interviews).
- Course / class context and instructional goals.
- Time period covered by feedback.
- Any demographic or subgroup breakdowns allowed for analysis.
- Constraints on reporting format and privacy requirements.

## Output Contract
- Feedback summary by theme.
- Sentiment and frequency highlights.
- Strengths students want retained.
- Pain points and likely root causes.
- Prioritized action plan with short-term and medium-term changes.
- Suggested follow-up questions for next feedback cycle.

## Technique Tags
`thematic-analysis` `sentiment-mapping` `voice-of-customer` `prioritization-matrix` `continuous-improvement`

## Validation Stage
- Verify findings are traceable to input evidence.
- Check subgroup reporting avoids re-identification risk.
- Distinguish observed patterns from assumptions.
- Confirm each recommendation has an owner and timeline.
