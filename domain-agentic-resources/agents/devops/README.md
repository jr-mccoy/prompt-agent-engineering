# DevOps Agents

> Specialized agents for troubleshooting, observability, incident response, and developer experience optimization.

## Available Agents

| Agent | Model | Description |
|-------|-------|-------------|
| [devops-troubleshooter](devops_troubleshooter.md) | SONNET | Expert DevOps troubleshooter specializing in rapid incident response, advanced debugging, and modern observability. Masters log analysis, distributed tracing, and Kubernetes debugging. |
| [dx-optimizer](dx_optimizer.md) | SONNET | Developer Experience specialist. Improves tooling, setup, and workflows. Use when setting up new projects or reducing development friction. |
| [error-detective](error_detective.md) | SONNET | Search logs and codebases for error patterns, stack traces, and anomalies. Correlates errors across systems and identifies root causes. |
| [incident-responder](incident_responder.md) | SONNET | Expert SRE incident responder specializing in rapid problem resolution, modern observability, and comprehensive incident management. Masters incident command and blameless post-mortems. |
| [monorepo-architect](monorepo_architect.md) | INHERIT | Expert in monorepo architecture, build systems, and dependency management at scale. Masters Nx, Turborepo, Bazel, and Lerna. |
| [observability-engineer](observability_engineer.md) | INHERIT | Build production-ready monitoring, logging, and tracing systems. Implements comprehensive observability strategies and SLI/SLO management. |

## Model Assignments

- **SONNET**: Used for balanced troubleshooting tasks requiring analysis and rapid response
- **INHERIT**: Allows user to choose model based on task complexity
