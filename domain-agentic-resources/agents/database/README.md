# Database Agents

> Specialized agents for database architecture, administration, optimization, and SQL expertise.

## Available Agents

| Agent | Model | Description |
|-------|-------|-------------|
| [database-admin](database_admin.md) | SONNET | Expert database administrator specializing in modern cloud databases, automation, and reliability engineering. Masters AWS/Azure/GCP database services, high availability, and disaster recovery. |
| [database-architect](database_architect.md) | OPUS | Expert database architect specializing in data layer design from scratch, technology selection, schema modeling, and scalable database architectures. |
| [database-optimizer](database_optimizer.md) | INHERIT | Expert database optimizer specializing in modern performance tuning, query optimization, and scalable architectures. Masters advanced indexing and N+1 resolution. |
| [sql-pro](sql_pro.md) | INHERIT | Master modern SQL with cloud-native databases, OLTP/OLAP optimization, and advanced query techniques. Expert in performance tuning and data modeling. |

## Model Assignments

- **OPUS**: Used for critical database architecture and design decisions
- **SONNET**: Used for balanced database administration and operations tasks
- **INHERIT**: Allows user to choose model for optimization and SQL tasks
