# SEO-Marketing Agents

> Specialized agents for SEO optimization, content marketing, and search strategy.

## Available Agents

| Agent | Model | Description |
|-------|-------|-------------|
| [content-marketer](content_marketer.md) | HAIKU | Elite content marketing strategist specializing in AI-powered content creation, omnichannel distribution, SEO optimization, and data-driven performance marketing. |
| [search-specialist](search_specialist.md) | HAIKU | Expert web researcher using advanced search techniques and synthesis. Masters search operators, result filtering, and multi-source verification. |
| [seo-authority-builder](seo_authority_builder.md) | SONNET | Analyzes content for E-E-A-T signals and suggests improvements to build authority and trust. Identifies missing credibility elements for YMYL topics. |
| [seo-cannibalization-detector](seo_cannibalization_detector.md) | HAIKU | Analyzes multiple provided pages to identify keyword overlap and potential cannibalization issues. Suggests differentiation strategies. |
| [seo-content-auditor](seo_content_auditor.md) | SONNET | Analyzes provided content for quality, E-E-A-T signals, and SEO best practices. Scores content and provides improvement recommendations. |
| [seo-content-planner](seo_content_planner.md) | HAIKU | Creates comprehensive content outlines and topic clusters for SEO. Plans content calendars and identifies topic gaps. |
| [seo-content-refresher](seo_content_refresher.md) | HAIKU | Identifies outdated elements in provided content and suggests updates to maintain freshness. Finds statistics, dates, and examples that need updating. |
| [seo-content-writer](seo_content_writer.md) | SONNET | Writes SEO-optimized content based on provided keywords and topic briefs. Creates engaging, comprehensive content following best practices. |
| [seo-keyword-strategist](seo_keyword_strategist.md) | HAIKU | Analyzes keyword usage in provided content, calculates density, suggests semantic variations and LSI keywords. Prevents over-optimization. |
| [seo-meta-optimizer](seo_meta_optimizer.md) | HAIKU | Creates optimized meta titles, descriptions, and URL suggestions based on character limits and best practices. |
| [seo-snippet-hunter](seo_snippet_hunter.md) | HAIKU | Formats content to be eligible for featured snippets and SERP features. Creates snippet-optimized content blocks. |
| [seo-structure-architect](seo_structure_architect.md) | HAIKU | Analyzes and optimizes content structure including header hierarchy, suggests schema markup, and internal linking opportunities. |

## Model Assignments

- **SONNET**: Used for comprehensive content analysis and writing tasks (E-E-A-T, content auditing, content writing)
- **HAIKU**: Used for fast, high-volume SEO tasks (meta optimization, keyword analysis, structure analysis)
