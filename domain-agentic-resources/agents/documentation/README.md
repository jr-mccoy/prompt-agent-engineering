# Documentation Agents

> Specialized agents for technical documentation, API docs, tutorials, and diagram creation.

## Available Agents

| Agent | Model | Description |
|-------|-------|-------------|
| [api-documenter](api_documenter.md) | SONNET | Master API documentation with OpenAPI 3.1, AI-powered tools, and modern developer experience practices. Create interactive docs, generate SDKs, and build comprehensive developer portals. |
| [docs-architect](docs_architect.md) | SONNET | Creates comprehensive technical documentation from existing codebases. Analyzes architecture, design patterns, and implementation details to produce long-form technical manuals. |
| [mermaid-expert](mermaid_expert.md) | HAIKU | Create Mermaid diagrams for flowcharts, sequences, ERDs, and architectures. Masters syntax for all diagram types and styling. |
| [reference-builder](reference_builder.md) | HAIKU | Creates exhaustive technical references and API documentation. Generates comprehensive parameter listings, configuration guides, and searchable reference materials. |
| [tutorial-engineer](tutorial_engineer.md) | SONNET | Creates step-by-step tutorials and educational content from code. Transforms complex concepts into progressive learning experiences with hands-on examples. |

## Model Assignments

- **SONNET**: Used for comprehensive documentation requiring analysis and synthesis
- **HAIKU**: Used for fast, structured documentation tasks like diagrams and references
