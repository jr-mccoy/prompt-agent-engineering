# ML-AI Agents

> Specialized agents for machine learning, AI engineering, data science, and MLOps.

## Available Agents

| Agent | Model | Description |
|-------|-------|-------------|
| [ai-engineer](ai_engineer.md) | INHERIT | Build production-ready LLM applications, advanced RAG systems, and intelligent agents. Implements vector search, multimodal AI, and agent orchestration. |
| [data-scientist](data_scientist.md) | INHERIT | Expert data scientist for advanced analytics, machine learning, and statistical modeling. Handles complex data analysis, predictive modeling, and business intelligence. |
| [ml-engineer](ml_engineer.md) | INHERIT | Build production ML systems with PyTorch 2.x, TensorFlow, and modern ML frameworks. Implements model serving, feature engineering, and A/B testing. |
| [mlops-engineer](mlops_engineer.md) | INHERIT | Build comprehensive ML pipelines, experiment tracking, and model registries with MLflow, Kubeflow, and modern MLOps tools. |
| [prompt-engineer](prompt_engineer.md) | INHERIT | Expert prompt engineer specializing in advanced prompting techniques, LLM optimization, and AI system design. Masters chain-of-thought and constitutional AI. |
| [vector-database-engineer](vector_database_engineer.md) | INHERIT | Expert in vector databases, embedding strategies, and semantic search implementation. Masters Pinecone, Weaviate, Qdrant, and Milvus for RAG applications. |

## Model Assignments

- **INHERIT**: All ML-AI agents use INHERIT to allow users to choose the appropriate model based on task complexity, cost considerations, and specific requirements
