# Content Creation Skills

> Skills for video processing, transcript handling, CLI demonstrations, and content generation workflows.

## Skills in This Category

| Skill | Description |
|-------|-------------|
| [cli-demo-generator](cli-demo-generator/) | Create animated CLI demos, terminal recordings, and command-line demonstration GIFs with automated or manual control |
| [teams-channel-post-writer](teams-channel-post-writer/) | Create educational Teams channel posts for internal knowledge sharing about Claude Code features and best practices |
| [transcript-fixer](transcript-fixer/) | Correct speech-to-text transcription errors in meeting notes, lectures, and interviews using dictionary rules and AI |
| [video-comparer](video-comparer/) | Compare two videos to analyze compression results with quality metrics (PSNR, SSIM) and frame-by-frame visual comparisons |
| [youtube-downloader](youtube-downloader/) | Download YouTube videos and HLS streams from platforms like Mux, Vimeo using yt-dlp and ffmpeg |
