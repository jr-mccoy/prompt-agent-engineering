# Editorial Quality Pass

Run a structured final editorial pass that systematically improves clarity, consistency, tone, factual correctness, and publication readiness across any document type.

## When to Use This Skill

- Preparing a document for publication, executive review, or client delivery
- Standardizing tone and style across multiple contributors
- Running final QA on grammar, consistency, and factual claims
- Reviewing translated or AI-generated content for quality
- Onboarding new editors with a repeatable quality process

## Core Concepts

### The Four Editing Passes

Professional editing is not one pass. It's four distinct passes with different goals:

| Pass | Focus | When | What Changes |
|------|-------|------|--------------|
| **Structural edit** | Organization, flow, completeness | After first draft | Sections reordered, added, removed |
| **Substantive edit** | Clarity, argument strength, audience fit | After structural | Paragraphs rewritten, examples added |
| **Copyedit** | Grammar, punctuation, consistency, style | After substantive | Sentence-level fixes, style guide enforcement |
| **Proofread** | Typos, formatting, final errors | After layout/formatting | Character-level fixes only |

**Critical rule:** Never proofread a document that needs structural editing. Fix the big problems first.

### Style Guide Hierarchy

When multiple style guides apply, resolve conflicts using this precedence:

1. **House style** (organization's own guide) — highest priority
2. **Domain guide** (AP for journalism, AMA for medicine, APA for academic)
3. **General guide** (Chicago Manual of Style as fallback)

### Consistency Dimensions

| Dimension | Examples | Check Method |
|-----------|----------|-------------|
| **Terminology** | "user" vs "customer" vs "client" | Search for variants; pick one |
| **Capitalization** | "Internet" vs "internet", title case vs sentence case | Create a style sheet |
| **Formatting** | Date formats, number styles, list punctuation | Compare first and last occurrence |
| **Tone** | Formal vs conversational, "we" vs "the team" | Read first and last sections back-to-back |
| **Tense** | Past vs present, consistent within sections | Scan verb forms |
| **Spelling** | US vs UK English | Search common divergences (-ize/-ise, -or/-our) |

## Workflow

### Phase 1: Pre-Edit Assessment

1. Identify the document type and purpose
2. Determine the target audience and their expectations
3. Identify the applicable style guide(s)
4. Read the full document once without editing (get the big picture)
5. Note major structural or conceptual issues before starting line-level work

### Phase 2: Structural Edit

1. Check overall organization — does it follow a logical progression?
2. Verify all promised content is present (does the intro promise things the body doesn't deliver?)
3. Assess section balance — is one section disproportionately long or short?
4. Check for redundancy — are the same points made in multiple places?
5. Verify the opening and closing are the strongest sections

### Phase 3: Substantive Edit

For each section:
1. Is the main point clear within the first 1-2 sentences?
2. Is every claim supported with evidence or reasoning?
3. Is the level of detail appropriate for the audience?
4. Are transitions between sections smooth?
5. Are examples concrete and relevant?

Apply the **"so what?" test**: After each paragraph, ask "so what does this mean for the reader?" If the answer isn't clear, the paragraph needs work.

### Phase 4: Copyedit

Create a **style sheet** before starting:

```markdown
## Style Sheet for [Document]

### Terminology
- Use "user" (not "customer" or "client")
- Use "sign in" (not "log in")

### Formatting
- Dates: Month DD, YYYY (January 15, 2026)
- Numbers: Spell out 1-9, numerals 10+
- Lists: Period after complete sentences, no period after fragments

### Capitalization
- Title case for H1, sentence case for H2+
- Lowercase "internet", "email"

### Tone
- Second person ("you"), active voice
- Contractions OK in body, not in headings
```

Then systematically check:
1. Grammar and punctuation
2. Subject-verb agreement
3. Consistent terminology (using the style sheet)
4. Parallel structure in lists and headings
5. Correct use of hyphens, em dashes, and en dashes
6. Citation formatting (if applicable)

### Phase 5: Fact Verification

1. Verify all dates, names, and numbers
2. Check that links work and point to the right destination
3. Confirm quoted text matches the original source
4. Verify statistics have citations
5. Flag any claims that need source verification

### Phase 6: Proofread

1. Read the formatted/laid-out version (not the editing draft)
2. Check for orphaned headings, widows, and awkward page breaks
3. Verify all images have captions/alt text and are correctly placed
4. Check table of contents matches actual headings
5. Read backwards (last sentence first) to catch typos — this breaks your brain's auto-correction

## Templates

### Editorial Checklist Template

```markdown
## Editorial Pass: [Document Title]
**Date:** [Date]  **Editor:** [Name]  **Style Guide:** [Guide]

### Structural Edit
- [ ] Logical organization and flow
- [ ] All promised content delivered
- [ ] No redundant sections
- [ ] Opening and closing are strong

### Substantive Edit
- [ ] Main points clear within 1-2 sentences per section
- [ ] Claims supported with evidence
- [ ] Detail level appropriate for audience
- [ ] Smooth transitions between sections

### Copyedit
- [ ] Style sheet created and applied
- [ ] Terminology consistent throughout
- [ ] Grammar and punctuation correct
- [ ] Parallel structure in lists and headings
- [ ] Formatting consistent (dates, numbers, capitalization)

### Fact Check
- [ ] Dates, names, numbers verified
- [ ] Links tested and working
- [ ] Quotes match original sources
- [ ] Statistics have citations

### Proofread
- [ ] No typos remaining
- [ ] Formatting clean in final layout
- [ ] Images correctly placed with captions
- [ ] TOC matches headings
```

### Common Error Pattern Reference

| Error Pattern | Where to Look | Fix |
|--------------|---------------|-----|
| Dangling modifier | Sentence openings with -ing phrases | Ensure the subject follows the modifier |
| Comma splice | Two independent clauses joined by comma | Use semicolon, period, or conjunction |
| Passive voice overuse | "was done by" constructions | Rewrite with active subject |
| Nominalizations | "make a determination" vs "determine" | Use the verb form |
| Wordiness | "in order to", "due to the fact that" | Simplify: "to", "because" |
| Mixed metaphors | "We need to hit the ground running while keeping our eye on the ball" | Use one metaphor at a time |

## Best Practices

- **Edit in the right order**: Structure → substance → copy → proof. Fixing commas in a paragraph you'll later delete is wasted effort.
- **Create the style sheet before copyediting**: Consistency decisions made in advance prevent page-by-page deliberation.
- **Read aloud for rhythm**: Awkward phrasing and run-on sentences become obvious when spoken.
- **Edit in a different format**: If you wrote on screen, print it. If you wrote in Word, export to PDF. Format changes reveal errors.
- **One pass, one focus**: Don't try to catch everything simultaneously. Specialized passes catch more.
- **Track your own error patterns**: Keep a list of your recurring mistakes. Check for those specifically.
- **Fresh eyes always help**: After self-editing, have someone else review. Authors are blind to their own patterns.
- **Time-box each pass**: Set a deadline per pass to prevent perfectionism from stalling publication.

## Common Pitfalls

| Pitfall | Why It Happens | How to Avoid |
|---------|----------------|--------------|
| Copyediting before structural edit | Line editing feels productive | Always assess structure first |
| No style sheet | "I'll be consistent by feel" | Create the sheet; consistency by memory fails |
| Over-editing voice | Editor imposes their own style | Edit for clarity, not personal preference |
| Skipping fact-check | Assumes writer verified everything | Verify independently — trust but verify |
| Editing while fatigued | Deadline pressure | Take breaks; edit in 45-minute blocks |
| Inconsistent feedback | Different standards for different sections | Use the editorial checklist for every section |

## Quality Checklist

- [ ] All four editing passes completed in order (structural → substantive → copy → proof)
- [ ] Style sheet created and applied consistently
- [ ] Terminology consistent throughout the document
- [ ] All facts, dates, and numbers verified
- [ ] All links tested and working
- [ ] Tone consistent and audience-appropriate
- [ ] No orphaned headings or formatting artifacts
- [ ] Document read aloud at least once
- [ ] Final proofread done on formatted/laid-out version
- [ ] Changes tracked and reviewer comments resolved
