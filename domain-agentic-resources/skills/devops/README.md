# DevOps Skills

> Skills for incident response, runbooks, postmortems, on-call management, infrastructure drift, and operational excellence.

## Skills in This Category

| Skill | Description |
|-------|-------------|
| [executable-runbook-authoring](executable-runbook-authoring/) | Write runbooks as step contracts (precondition, command, expected output, verification, stop condition, rollback), link them from alerts, test them by dry run or drill, and keep them fresh |
| [incident-runbook-templates](incident-runbook-templates/) | Create structured incident response runbooks with step-by-step procedures, escalation paths, and recovery actions |
| [infrastructure-drift-detection](infrastructure-drift-detection/) | Detect, classify and reconcile drift between IaC and live state (Terraform/OpenTofu, Pulumi, CloudFormation, GitOps Kubernetes) |
| [on-call-handoff-patterns](on-call-handoff-patterns/) | Master on-call shift handoffs with context transfer, escalation procedures, and documentation |
| [postmortem-writing](postmortem-writing/) | Write effective blameless postmortems with root cause analysis, timelines, and action items |

## Usage

These skills provide specialized knowledge for Claude Code. They are automatically invoked when relevant to your task, or can be explicitly referenced.
