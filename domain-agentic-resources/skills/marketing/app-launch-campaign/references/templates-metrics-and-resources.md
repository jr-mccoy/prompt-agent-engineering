# App Launch Campaign — Templates, Metrics, and Resources

## Templates

### Press Release Template

```markdown
FOR IMMEDIATE RELEASE

# [App Name] Launches on Google Play: [Headline Benefit]

**[City, State] -- [Date]** -- Solo developer [Your Name] today launched
[App Name], a [category] app that [key differentiator]. Available now
on the Google Play Store, [App Name] is [free / priced at $X / free
with premium features].

## The Problem

[2-3 sentences describing the problem in relatable terms. Use the
language your target users would use.]

## The Solution

[2-3 sentences about how your app solves it. Focus on the user
experience, not technical details.]

## Key Features

- **[Feature 1]:** [User benefit, not technical spec]
- **[Feature 2]:** [User benefit]
- **[Feature 3]:** [User benefit]

## Early Traction

[If applicable: beta tester count, early reviews, waiting list size,
community size. Only include real numbers.]

## Availability and Pricing

[App Name] is available now on the Google Play Store for Android devices.
[Pricing details. Link to app.]

## About [Your Name]

[2-3 sentences. Background, motivation for building the app, relevant
experience. Include personal angle if comfortable.]

## Press Kit

[Link to press kit with screenshots, logo, demo video, and additional
information.]

## Contact

[Your Name]
[Email]
[Website]
[Social media handle]
```

## Validation Checklist

Run this checklist before launch day:

```markdown
## Pre-Launch Validation

### App Readiness
- [ ] App published on Google Play (even if unlisted initially)
- [ ] Crash-free rate above 99% in beta testing
- [ ] Core user flow tested on 3+ different devices
- [ ] All permissions justified and minimized
- [ ] Privacy policy published and linked

### Store Listing
- [ ] Title includes primary keyword
- [ ] Short description is compelling and under 80 characters
- [ ] Full description includes keywords naturally (not stuffed)
- [ ] 4-8 screenshots uploaded with text overlays
- [ ] Feature graphic designed and uploaded
- [ ] App icon is clear at small sizes

### Marketing Assets
- [ ] Landing page live with app store link
- [ ] Press kit complete and accessible
- [ ] Press release written
- [ ] Social media launch posts drafted for each platform
- [ ] Launch email to subscribers drafted
- [ ] Launch email to beta testers drafted
- [ ] Community announcement posts drafted
- [ ] Demo GIF or video created

### Outreach
- [ ] PR target list of 15-20 journalists compiled
- [ ] Personalized pitches drafted for top 5 targets
- [ ] Community list of 10-15 announcement targets compiled
- [ ] Product Hunt submission prepared (if applicable)

### Infrastructure
- [ ] Analytics installed and tracking (Firebase, GA4, or equivalent)
- [ ] UTM parameters configured for all marketing links
- [ ] Email automation set up (welcome email, onboarding sequence)
- [ ] Crash reporting active (Crashlytics or equivalent)
- [ ] Review monitoring set up

### Launch Day Preparedness
- [ ] Calendar blocked for launch day (full day)
- [ ] Launch day timeline printed/saved
- [ ] Emergency contacts ready (if something breaks)
- [ ] Response templates ready for reviews and comments
- [ ] Backup plan if app store approval is delayed
```

## Troubleshooting

### Common Launch Issues

| Issue | Cause | Solution |
|-------|-------|---------|
| App not appearing in Play Store search | New app, no ranking signals yet | Focus on direct links. SEO ranking builds over weeks. |
| Zero downloads on launch day | No audience built pre-launch | Revisit Week 1-6 steps. You cannot skip audience building. |
| Negative reviews on day 1 | Bug or UX issue missed in beta | Fix immediately. Respond to every review. Ship update within 48 hrs. |
| Press did not respond | Pitch not compelling or wrong targets | Do not follow up more than once. Refine angle for next milestone. |
| Community post removed | Violated subreddit rules | Read rules carefully. Re-approach with genuine community contribution. |
| Landing page not converting | Messaging unclear or CTA weak | A/B test headline. Simplify page. See `marketing_landing_page_conversion.md`. |
