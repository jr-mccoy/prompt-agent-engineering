# Accessibility Skills

> Skills for conducting accessibility audits, testing with assistive technologies, specifying and testing accessible components, and gating accessibility regressions in CI.

## Skills in This Category

| Skill | Description |
|-------|-------------|
| [accessibility-regression-gate](accessibility-regression-gate/) | Gate CI on new axe-detectable violations across a page/state inventory, with a committed baseline that only shrinks and a per-release screen-reader smoke script |
| [component-accessibility-contracts](component-accessibility-contracts/) | Write a per-component contract (native-first decision, role, name, states, keyboard map, focus rules) and turn each clause into an automated component test |
| [screen-reader-testing](screen-reader-testing/) | Test web applications with screen readers including VoiceOver, NVDA, and JAWS for validating screen reader compatibility and debugging accessibility issues |
| [wcag-audit-patterns](wcag-audit-patterns/) | Conduct WCAG 2.2 accessibility audits with automated testing, manual verification, and remediation guidance |

## Usage

These skills provide specialized knowledge for Claude Code. They are automatically invoked when relevant to your task, or can be explicitly referenced.
