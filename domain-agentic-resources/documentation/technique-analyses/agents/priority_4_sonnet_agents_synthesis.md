## Cross-Cutting Patterns

### Pattern 1: Domain-Specific Defaults
Multiple agent groups use domain-specific defaults as behavioral traits:
- **Security:** Allowlist-first validation, HTTPS-only, input sanitization
- **Infrastructure:** Cost-conscious design, documentation-required
- **Operations:** Defensive programming, error trapping, strict mode

**Insight:** Effective agents embed domain best practices as automatic behaviors, not optional guidelines.

### Pattern 2: Multi-Dimensional Specialization
Agents demonstrate specialization across multiple dimensions:
- **Platform:** iOS/Android/Web (mobile-security-coder)
- **Provider:** AWS/Azure/GCP (cloud-architect)
- **Industry:** E-commerce/SaaS/Healthcare (business-analyst)
- **Version:** Bash 3.x/4.x/5.x (bash-pro)

**Insight:** Sophisticated agents handle multiple variants of their domain rather than single-path expertise.

### Pattern 3: External Authority Grounding
Agents reference external authoritative sources:
- **C4 Model:** c4model.com for architecture standards
- **OWASP:** OWASP Top 10, MASVS for security standards
- **Regulations:** GDPR, CCPA, HIPAA for compliance
- **Bash Guides:** Google Shell Style Guide, Bash Hackers Wiki

**Insight:** Grounding in external methodologies increases agent credibility and alignment with industry standards.

### Pattern 4: Tool Ecosystem Integration
Multiple agents list specific tools by name:
- **Business:** Tableau, Power BI, Snowflake, BigQuery
- **Infrastructure:** Terraform, Pulumi, Istio, Linkerd
- **Testing:** Playwright, Selenium, Testsigma, K6
- **Operations:** ShellCheck, bats-core, PagerDuty, Opsgenie

**Insight:** Tool-specific expertise is more valuable than generic "use appropriate tools" guidance.

### Pattern 5: Metrics and Measurement
Agents include quantitative measurement frameworks:
- **Business:** North Star metrics, OKRs, KPIs
- **Security:** Compliance checklists, security metrics
- **Infrastructure:** Cost metrics, FinOps KPIs
- **Testing:** TDD cycle time, test-first compliance percentage
- **Operations:** MTTR, MTTD, error budgets, SLOs

**Insight:** Sophisticated agents include measurement frameworks for tracking effectiveness.

### Pattern 6: Multi-Audience Communication
Agents adapt output for different audiences:
- **C4:** Developers → Architects → DevOps → Business stakeholders
- **Security:** Developers → Security auditors → Compliance teams
- **Business:** Technical teams → Executives → External stakeholders
- **Incident Response:** Engineers → Executives → External customers

**Insight:** Effective agents translate between technical and non-technical domains.

### Pattern 7: Progressive Complexity
Agents structure information from simple to complex:
- **C4:** Code → Component → Container → Context
- **Documentation:** Executive summary → Overview → Deep dives
- **Network:** Physical → Data Link → Network → Transport → Application

**Insight:** Progressive disclosure enables engagement at appropriate expertise levels.

### Pattern 8: Workflow Integration
Agents integrate with standard workflows:
- **Security:** CI/CD security scanning, pre-commit hooks
- **Infrastructure:** GitOps, Infrastructure-as-Code pipelines
- **Documentation:** Docs-as-code, automated deployment
- **Testing:** TDD red-green-refactor, continuous testing

**Insight:** Agents that fit existing workflows have higher adoption than standalone tools.
