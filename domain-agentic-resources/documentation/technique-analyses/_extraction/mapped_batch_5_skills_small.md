3. **DS code collisions:** Five batch techniques were assigned DS/QA codes that already belong to completely different techniques in master. This is a systematic issue — the analysis files appear to have assigned codes without checking the master index for conflicts.

4. **Within-batch self-references:** Entries #51 and #55 cite "ST-28" as existing, but ST-28 was actually proposed as a novel technique in entry #30 of this same batch. This is not a master index mapping — it's an internal batch cross-reference that got recorded as "Maps To Existing."
