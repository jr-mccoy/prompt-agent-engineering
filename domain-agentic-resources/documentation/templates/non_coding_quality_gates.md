# Non-Coding Quality Gates Checklist Template

Use this checklist before finalizing any non-coding agent, command, or skill output.

## 1) Accuracy Verification Method
- [ ] **Source quality:** Confirm primary/authoritative sources are preferred over tertiary summaries.
- [ ] **Recency:** Verify time-sensitive claims against current references; include publication/access dates where relevant.
- [ ] **Confidence notes:** Mark confidence level per critical claim (e.g., high/medium/low) and call out assumptions.

## 2) Safety and Compliance Review
- [ ] **Boundary check:** Flag where output may be interpreted as healthcare, legal, financial, or regulated business advice.
- [ ] **Healthcare/business guardrails:** Add clear non-diagnostic, non-prescriptive framing and escalation guidance to licensed/professional review when applicable.
- [ ] **Risk language:** Remove absolute guarantees and include risk-aware phrasing for uncertain recommendations.

## 3) Role Separation and Bias Checks (Multi-Perspective Outputs)
- [ ] **Role clarity:** Ensure each perspective/role has a distinct mandate and does not collapse into a single viewpoint.
- [ ] **Conflict handling:** Document disagreements and rationale rather than forcing false consensus.
- [ ] **Bias scan:** Check for framing bias, omitted stakeholder groups, and culturally narrow assumptions.

## 4) Measurable Output Criteria
- [ ] **Clarity:** Output is easy to parse, with explicit structure and minimal ambiguity.
- [ ] **Completeness:** Required sections are present and no critical step is missing.
- [ ] **Actionability:** Recommendations map to concrete next steps, owners, and/or timelines.
- [ ] **Factual support:** Key assertions are linked to evidence or explicitly labeled as assumptions.

## 5) Validation Step
- [ ] **Self-check:** Run a final pass against this checklist before delivery.
- [ ] **Quality score:** Assign a rubric score (e.g., /10 or pass/fail by section).
- [ ] **Reviewer pass:** If high impact, require a second reviewer approval before publishing.
