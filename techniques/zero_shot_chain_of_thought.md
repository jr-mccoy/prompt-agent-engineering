# Zero-Shot Chain-of-Thought Structure Template

**Source:** ADVANCED_PROMPTING_TECHNIQUES.md
**Category:** Reasoning Scaffold (Tier 3)

## Prompt

```
Problem: [YOUR QUESTION OR ANALYSIS REQUEST]

Break this down using the following structure:

Step 1 - Define the scope:

Step 2 - Identify key variables:

Step 3 - Analyze relationships:

Step 4 - Consider edge cases:

Step 5 - Synthesize conclusion:

Verification check: [What would prove this analysis wrong?]

Final Answer:
```

## Usage Notes

The blank structure triggers chain-of-thought automatically. Adapt the steps to your specific problem domain - the key is creating progression that forces sequential reasoning rather than jumping to conclusions.
