# Mentor Equipping

**8 prompts** for the person doing the discipling — getting ready, getting trained, getting better,
knowing the limits, lasting, taking a hard case somewhere, and staying present when the person they are
discipling stops believing.

The load-bearing prompt here is
[`discipleship_mentor_boundaries_and_referral.md`](discipleship_mentor_boundaries_and_referral.md).
A discipleship relationship gives one person standing influence over another's spiritual life; that is
structurally vulnerable to harm in a way ordinary friendship is not. Every other prompt in this
subdirectory assumes the boundaries prompt has been worked.
