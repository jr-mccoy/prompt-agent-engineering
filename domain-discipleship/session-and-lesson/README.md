# Session & Lesson

**6 prompts** for what actually happens when two people meet — the hour itself, and whether its shape
lets everyone into it.

Everything upstream produces plans; this subdirectory produces the meeting. All of it assumes the
Scripture work has been done elsewhere: `discipleship_lesson_builder.md` names passages by address and
hands exegesis to
[`domain-biblical-studies/exegesis-interpretation/`](../../domain-biblical-studies/exegesis-interpretation/)
rather than attempting it.

[`discipleship_hard_conversation_navigation.md`](discipleship_hard_conversation_navigation.md) is
**event-triggered**, not scheduled. It fires when a mentee discloses something the session plan did not
anticipate, and it routes aggressively rather than trying to handle everything in the room.

## Prompt Index

### The recurring meeting
| Prompt | What It Produces |
|---|---|
| [`discipleship_session_plan_builder.md`](discipleship_session_plan_builder.md) | A reusable one-on-one session structure with time allocation and a next-step commitment |
| [`discipleship_lesson_builder.md`](discipleship_lesson_builder.md) | A teaching lesson inside a module, with Scripture referenced by address and handed off |
| [`discipleship_conversation_question_bank.md`](discipleship_conversation_question_bank.md) | Questions graded by depth and topic, with an explicit too-far line for each tier |

### When it goes off-plan
| Prompt | What It Produces |
|---|---|
| [`discipleship_hard_conversation_navigation.md`](discipleship_hard_conversation_navigation.md) | An in-the-moment response plan for a hard disclosure, with classification and routing |

|---|---|
