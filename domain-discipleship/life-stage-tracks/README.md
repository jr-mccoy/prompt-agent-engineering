# Life-Stage Discipleship Tracks

**5 prompts** adapting the domain's curriculum machinery to the five life stages where a generic
pathway reliably fails — because the constraint is not the content, it is the conditions.

Each track takes the same underlying architecture (`../curriculum-architecture/`) and rebuilds it
around what is actually true of the participants: what safeguarding requires, how long they will be
present, who else is in the room, how much uninterrupted time exists, and what they can physically
reach.

Two carry heavier structure than the domain baseline. **Youth and teen** is STRONG-GUARD and
subordinate to the safeguarding policy — it will return "cannot be designed yet" if no policy exists.
**Married couples** gates on an abuse and coercive-control screen run separately with each spouse
before any joint work begins.

| [`discipleship_track_college_and_young_adult.md`](discipleship_track_college_and_young_adult.md) | People leave within three or four years | A track designed backwards from the exit, modular against irregular attendance, with the handoff as a real deliverable |

| [`discipleship_track_parents.md`](discipleship_track_parents.md) | Fragmented time and outcome-shaped guilt | A track that refuses to measure parents by their children, with a floor practice that survives the worst week |
| [`discipleship_track_seniors.md`](discipleship_track_seniors.md) | Access, accumulated loss, and being treated as a recipient | Access designed before content, a giving strand with real recipients, and a screen that does not become surveillance |

## The shared move

All five separate **structure from content and settle structure first** — safeguarding, screen, window,
capacity, access. Every one of these tracks fails in the same way when that order is reversed: the
content is good, and it cannot be delivered to the people it was written for.
