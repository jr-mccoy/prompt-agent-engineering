## Key Patterns

### Teach Me To Code
Interactive learning prompts that:
- Assess current skill level
- Provide progressive challenges
- Give immediate feedback
- Adapt to learning pace

### Code Exercises
- **Refactoring Exercises** - Improve existing code
- **Debugging Challenges** - Find and fix bugs
- **Implementation Tasks** - Build from specifications

### Explanations
- **Concept Deep Dives** - Thorough explanations
- **Visual Analogies** - Mental models for abstract concepts
- **Real-World Examples** - Practical applications

---

## When to Use This Domain

Use these prompts when you need to:
- Learn a new programming language
- Practice coding skills
- Understand programming concepts
- Create coding exercises for others

**Do NOT use for:**
- Production code review (use domain-software-engineering)
- Non-coding education (use domain-education-teaching)
- General worksheets (use domain-image-generation for visual worksheets)
