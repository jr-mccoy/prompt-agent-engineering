# Board Deck Image Visual Prompts

This directory contains board-deck-specific image-generation prompts authored for executive slide visuals.

## Scope

- Output type: **single-slide visual images** for board and executive decks.
- Naming: `boarddeck_*.md`.
- Format lock: **16:9 landscape** (`1920 x 1080 px`, 150 DPI).
- Constraint model: enforced 8-technique image-generation structure (SV-11 to SV-18).
