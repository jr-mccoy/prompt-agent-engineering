**Purpose:** Give a caregiver a usable script library for holding limits across the most common boundary-domains, calibrated by age and adapted to common kid profiles.

**When to use:** A specific boundary the caregiver is struggling to hold; recurring power-struggle around a known limit; setting up new limit; revising after a limit collapse; pre-loading the script before the situation.

**When NOT to use:** Acute safety crisis (act first; script later). Caregiver in flooded state (regulate first; script later).

---

## Core Principles

1. **A boundary is what the caregiver does, not what the kid stops.** "I don't let kids play in the street" is a boundary; "stop running into the street" is a wish.
2. **Calm + firm > loud + firm.** Volume signals out-of-control caregiver; calm signals certainty.
3. **Few words, repeated.** Long explanations during enforcement give the kid something to argue with.
4. **Empathy + limit, not empathy then collapse.** "I know you want it. The answer is no." Both can be true.
5. **Repair after.** Holding a limit doesn't end the relationship; it tests it. Repair restores.
6. **Pre-load, don't improvise.** A scripted line you've practiced lands better than something you make up while flooded.

## Constraints

**Must:**
- Provide concrete verbatim language.
- Adapt by age and domain.
- Include "what I do" not just "what I say."
- Include repair-after language.
- Adapt to kid profile.

**Must Not:**
- Default to one-size-fits-all script.
- Use punishment-as-script.
- Recommend long explanations during enforcement.
- Skip the caregiver-regulation prerequisite.

## Instructions

### Stage 1 — The Universal Structure

For most boundary moments:

```
1. Empathy + limit (one breath).
   "I see you really want [X]. I'm not going to let you [Y]."

2. Brief reason (optional, brief).
   "It's not safe / it's bedtime / that's the rule."

3. What you'll do.
   "I'm going to [specific action]."

4. Hold while the kid reacts.
   [No more arguing. Stay calm. Repeat the line if needed.]

5. Repair after.
   "That was hard. I love you."
```

### Stage 2 — Physical Safety (Non-Negotiable)

**Toddler running into street:**
```
[Pick up the kid first; talk after.]
"Streets aren't for running into. We hold hands or stay back."
[If kid wails: "I know. We hold hands."]
```

**Older kid climbing dangerously:**
```
"I'm going to bring you down. That's too high without a way to land."
[Bring down.]
[If they argue: "Not from there. We can find somewhere with a soft landing."]
```

**Teen substance impairment + driving:**
```
"You're not driving. Hand me the keys."
[Take keys. Drive them or arrange ride.]
[Conversation later, not now.]
```

### Stage 3 — Screen Time

**Young kid time's-up:**
```
"Five more minutes, then off."
[Set timer, audible to kid.]
[At time: "Time's up."]
[If meltdown: "I know. It's hard to stop. Off now."]
[Take device or close screen. Hold the meltdown.]
```

**Tween / teen on the late-night phone:**
```
"Phones to the kitchen at 9."
[At 9: "Time."]
[If "five more": "Now."]
[Take phone or wait. Don't lecture about sleep.]
```

**Recurring screen-time bargaining:**
```
"We're not negotiating tonight. The agreement is the agreement.
Tomorrow at family meeting we can talk about whether the rule
should change."
```

### Stage 4 — Food

**Young kid refusing dinner / wanting only snack:**
```
"This is what's for dinner. You can eat it or not. I'm not making
something else. The kitchen closes after dinner; if you don't eat
now, you'll be hungry until breakfast."
[Hold. If they don't eat: hold. They will eat tomorrow.]
[Don't shame; don't bargain.]
```

**Older kid demanding specific food at non-meal times:**
```
"Snack is at 3. We'll have [meal] at 6. You can wait."
[If pushback: same line repeated, briefly.]
```

**Avoid this domain becoming control battle if eating-disorder context. Different prompt.**

### Stage 5 — Sleep

**Young kid bedtime resistance:**
```
"Books, brush, bed. That's the order."
[Move through the routine.]
[If kid resists: minimal reaction. Continue routine.]
[At bed: "I love you. See you in the morning."]
[Walk out. If they get up: walk back, return to bed, minimal words.]
```

**School-age kid won't go to sleep:**
```
"Lights out at 9. You don't have to sleep. You have to be in bed,
quiet, lights out."
[Hold the in-bed-quiet limit; don't try to enforce sleep itself.]
```

**Teen up too late:**
```
"Phone to the kitchen by 10. After that, what time you sleep is
your call. If you can't function tomorrow, that's information."
[Hold the phone-out-of-room piece. Let natural consequence on
sleep work.]
```

### Stage 6 — Social

**Young kid hurting another kid:**
```
[Step in physically. Calm.]
"Hands not on bodies. We can [alternative]."
[Move kid to different activity if needed.]
[Brief conversation later about feelings + alternative.]
```

**Older kid not invited to thing:**
```
"That's hard. I'm sorry. You wanted to be included."
[Don't try to fix by calling other parent or insisting on inclusion.]
[Sit with the disappointment. Find separate plan if useful.]
```

**Teen wants to do something you said no to:**
```
"My answer is no. I can hear you again at family meeting if you
want to make a case for the next time."
[Don't relitigate now. Hold the no.]
```

### Stage 7 — Money

**Young kid wants thing in store:**
```
"That's not on our list today."
[Walk past. Brief acknowledgment of disappointment.]
[Don't lecture about money.]
```

**Older kid demanding expensive item:**
```
"That's not in the budget. You can save toward it or it's not
happening this month."
[Help with savings plan if interested. Don't rescue.]
```

**Teen pushing for caregiver-funded big-ticket item:**
```
"I can do [X amount]. The rest is on you to figure out — earnings,
savings, or wait. I'm not going to keep negotiating about whether
I'll cover the full amount."
```

### Stage 8 — Language / Behavior

**Kid swearing at caregiver:**
```
"That language doesn't land here. Try again."
[If repeats: "I'm not staying for this. I'll come back when you
can talk to me."]
[Walk away. Return when calm.]
```

**Teen contemptuous tone:**
```
"You're talking to me with contempt. I don't talk to you that way.
I'm not going to be talked to that way either. Let me know when
you want to talk."
[Walk away. Repair later.]
```

### Stage 9 — Adapting by Profile

**Strong-willed:**
- Few words. Strong-willed kids feed on caregiver explanation.
- Choices within the limit ("you can put on the pajamas yourself or I help you put them on").
- Don't engage the argument.
- Honor autonomy on smaller things; hold firm on the limit.

**Anxious:**
- Connection-rich limit-holding ("I'm right here. The answer is no.").
- Predictability matters; stick to limits set in advance.
- Repair-after doubly important.
- Avoid surprise limits.

**Autistic:**
- Clear, literal language.
- Visual / written cue if relevant ("the chart says X").
- Predictable; don't introduce limits in flooded moment.
- Sensory-aware (a limit + sensory overload = double meltdown).
- Processing time before compliance is normal.

**ADHD:**
- Limit + cue + brief.
- Body-double helpful (caregiver doing parallel activity rather than commanding from distance).
- Don't expect time-blind kid to monitor own time-limit independently.

**Trauma history:**
- Calm, predictable, repair-rich.
- Avoid power-display; choose collaborative language.
- Hold limits; don't punish reaction.

**Strong-willed + autistic / PDA:**
- Demand-avoidance is acute; reframe as collaboration where possible.
- "Here's what needs to happen; how do you want to do it" rather than direct command.
- Specialist support if pattern is consistent.

**ND with caregiver of different ND profile:**
- Caregiver own regulation more visible; therapy / coaching for caregiver helpful.

### Stage 10 — When You Lose It

You will sometimes. The repair script:

```
[After regulating yourself.]

"I yelled at you / lost my temper / said something cutting.
That wasn't your fault. I should have held that limit calmly.
I'm sorry.

The limit still stands. But the way I held it isn't how I want to.
I'll do that better next time."

[Don't relitigate the limit during repair.]
```

## False-Positive Prevention

| ❌ Don't | ✅ Do |
|---|---|
| Lecture during enforcement | Few words; reasons brief or skipped |
| Use volume to enforce | Calm + firm |
| Collapse limit when kid escalates | Hold; empathy + limit |
| Treat strong-willed kid like compliant kid | Few words; choices within limit |
| Punish autistic kid's processing time | Build it in |
| Skip repair after | Repair restores |
| Treat one limit-collapse as failure | Repair, recalibrate |
| Use boundaries as control | Limit, not domination |
| Negotiate during enforcement | Family meeting for negotiation |
| Threat-based language ("if you don't, then…") | What-I-do language |
| Embarrass in public | Limit can be quiet |
| Skip caregiver-regulation prerequisite | Self-regulation first |
| Apply same script to all profiles | Profile-aware |
| Skip pre-loading for known recurring boundaries | Pre-loading lands better than improvising |
| Make every limit a teaching moment | Limit, then move on |
| Skip when-you-lose-it script | You will sometimes; have the repair ready |
