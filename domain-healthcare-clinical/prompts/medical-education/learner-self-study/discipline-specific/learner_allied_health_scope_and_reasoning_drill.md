# Allied-Health Scope & Reasoning Drill for Allied-Health Learners

**Objective:** Provide allied-health learners a parameterized clinical-reasoning drill: assessment frame appropriate to the role, SMART (or COAST) goal writing, intervention plan with rationale, outcome measure selection, scope-of-practice boundaries, and referral triggers when a finding is outside scope.

## When to Use
- ✅ DPT / MPT / DOT / MOT / SLP / RT / RD / MSW / AuD student case study work
- ✅ Pre-clinical rotation rehearsal
- ✅ Board exam prep (NPTE, NBCOT, Praxis SLP, NBRC, CDR, ASWB, AuD boards)
- ❌ Real-patient clinical decisions — follow supervisor and institutional protocols

## Inputs Required
- **Role:** PT / OT / SLP / RT / RD / MSW / AuD / other allied-health specialty
- **Learner level:** early / mid / late student or new graduate
- **Setting:** acute care, inpatient rehab, outpatient, home health, school, SNF, community
- **Case stem:** patient demographics, primary medical dx, relevant medical history, current functional status, social context, patient goals
- **Mode:** *generate plan* OR *critique learner draft*

## Constraints

**Must:**
- Use the role-appropriate assessment frame and outcome measures
- Goals must be SMART (Specific, Measurable, Achievable, Relevant, Time-bound) — or role-specific equivalent (e.g., COAST: Client, Occupation, Assist level, Specific condition, Timeline for OT)
- Interventions must have rationale (mechanism + evidence reference type)
- Identify scope-of-practice boundaries and referral triggers
- Address insurance / documentation considerations qualitatively where relevant (e.g., "skilled" need)

**Must Not:**
- Provide real-patient management
- Default to physician-style A&P — use role's own reasoning frame
- Skip outcome measures
- Cross scope without referral

## Instructions

1. **Confirm role and setting.**

2. **Role-appropriate assessment frame:**

   - **PT:** Patient history, systems review, tests/measures (ROM, MMT, balance, gait, special tests), ICF model (body structure/function → activity → participation), pain assessment, outcome measures (BBS, TUG, 10mWT, LEFS, ODI, FOTO)
   - **OT:** Occupational profile, performance analysis, COTE / AMPS / PEO model, occupational performance areas (ADLs, IADLs, work, leisure, social), outcome measures (FIM, COPM, AMPS, MoCA, MMSE)
   - **SLP:** Hearing screening, oral mech, speech, language (receptive/expressive), voice, fluency, cognitive-communication, swallowing (clinical bedside ± instrumental), outcome measures (FAVS, ASHA FACS, FOTO, Functional Communication Measures)
   - **RT:** Ventilation assessment, oxygenation, breath sounds, ABG / VBG interpretation (class-level), ventilator parameter review, secretion clearance, weaning readiness, outcome measures (RSBI, P/F ratio category, SBT outcome)
   - **RD:** Diet history, nutrition-focused physical findings, anthropometrics, biochemical (qualitative — albumin, prealbumin, BMP trends), client-centered goals (NCP — Nutrition Care Process: assessment → diagnosis → intervention → monitoring/evaluation), outcome measures (PG-SGA, MNA, weight trend)
   - **MSW:** Biopsychosocial assessment, strengths/needs, psychosocial stressors, support systems, financial / housing / transportation / food security, behavioral health screen, safety screen, outcome measures (functional improvement in identified domain, resource access achieved)
   - **AuD:** History, otoscopic findings, audiometric (qualitative — pure-tone air/bone, speech recognition), tympanometry, special tests, outcome measures (APHAB, COSI, hearing aid satisfaction)

3. **Problem identification.** Role-appropriate diagnostic statement:
   - PT: movement diagnosis or PT diagnosis
   - OT: occupational performance issues
   - SLP: communication / swallowing diagnosis
   - RT: pulmonary / ventilation issues
   - RD: PES statement (Problem, Etiology, Signs/Symptoms)
   - MSW: psychosocial diagnoses or strengths-need formulation
   - AuD: type/degree/configuration of hearing loss

4. **Goal writing (SMART or COAST).** Two to four goals, each:
   - **Long-term goal:** time-bound functional outcome
   - **Short-term goal:** measurable intermediate step
   - Tied to identified problem and patient priority

5. **Intervention plan.** Each intervention:
   - What (specific technique / exercise / strategy)
   - Why (rationale — mechanism + evidence reference type without inventing specifics)
   - Dose (frequency, intensity, time, type — FITT principles for PT/RT/RD; for OT/SLP, frequency and intensity)
   - Progression criteria
   - Discontinuation criteria

6. **Outcome measures.** Selected with rationale (sensitivity to change, validity for population, feasibility). Re-measurement schedule.

7. **Scope-of-practice boundaries.** For each finding outside scope:
   - Refer to: which discipline, what timeline
   - What you'll *continue* to manage in your scope
   - How you'll communicate / document the referral
   - Examples: PT noticing red flags → MD; OT noticing depression → MSW/MD; SLP noticing aspiration with possible aspiration pneumonia → MD/RT; RD noticing significant unintended weight loss not explained → MD; MSW noticing acute suicidality → emergency mental health

8. **Documentation note** for the setting (skilled need, medical necessity, functional progress framing — qualitative).

9. **Self-check block:**
   - State your role's reasoning frame from memory
   - One SMART goal you wrote and the discriminator that makes it measurable
   - One scope-of-practice boundary you'll watch for next patient

## False-Positive Prevention

| ❌ Common Mistake | ✅ Correct Approach |
|---|---|
| Use physician A&P framing | Use role's own reasoning frame |
| Goals without measurability | SMART or COAST |
| Interventions without rationale | Always include mechanism + evidence reference type |
| Outcome measure not tied to problem | Sensitivity to change + population validity |
| Cross scope without referral | Identify boundary + refer + continue what's in scope |
| Skip documentation framing | "Skilled need" / medical necessity language matters in many settings |

## Output Format

```
### Role / Learner Level / Setting / Mode

### Role-Appropriate Assessment Frame
(role-specific structure)

### Problem Identification
(role-specific diagnostic statement)

### Goals (SMART / COAST)
- LTG 1 + STGs
- LTG 2 + STGs

### Intervention Plan
- Intervention / What / Why / Dose / Progression / D/C criteria

### Outcome Measures
- Measure + rationale + re-measurement schedule

### Scope-of-Practice Boundaries + Referrals
- Finding → refer to + timeline / continue in scope / communication

### Documentation Note
- Skilled need / medical necessity framing

### Self-Check
1. Role reasoning frame
2. One SMART goal + discriminator
3. Scope boundary to watch for
```

## Verification Checklist
- [ ] Role-appropriate assessment frame applied
- [ ] Goals are SMART or COAST
- [ ] Interventions include rationale + FITT (or equivalent)
- [ ] Outcome measures tied to problem
- [ ] Scope boundaries identified with referral triggers
- [ ] Documentation framing addressed
- [ ] Self-check uses retrieval
- [ ] No patient-specific medication doses
- [ ] Real-patient redirect maintained
