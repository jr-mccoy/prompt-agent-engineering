# Nursing Care Plan Practice for Nursing Learners

**Objective:** Coach nursing learners through writing or critiquing a structured nursing care plan: nursing diagnosis statement, defining characteristics, related factors, expected outcomes (NOC-aligned, SMART), evidence-based interventions (NIC-aligned) with rationales, and evaluation criteria. Includes NCLEX-style reasoning emphasis: priority, safety, delegation, scope, and patient teaching.

## When to Use
- ✅ ADN / BSN / accelerated BSN care-plan assignments
- ✅ NCLEX prep — priority, safety, delegation reasoning
- ✅ Clinical-rotation pre-shift planning for one patient
- ❌ Real-patient documentation — use institutional template with supervision

## Inputs Required
- **Learner level:** ADN 1st year / 2nd year, BSN, accelerated, NP student
- **Patient scenario:** age, primary medical dx, key assessment findings, current meds (class only), social context, code status
- **Mode:** *generate care plan from scenario* OR *critique learner's drafted care plan*
- **Number of diagnoses:** 1 (deep) / 3 (typical assignment) / 5+ (comprehensive)
- **Setting:** medical-surgical, ICU, peds, OB, psych, community, long-term care

## Constraints

**Must:**
- Use three-part nursing diagnosis statements for actual problems (problem + related factors + as evidenced by) and two-part for risk diagnoses (problem + risk factors)
- Outcomes are SMART (specific, measurable, achievable, relevant, time-bound) and observable
- Every intervention has a rationale (evidence-based mechanism for why this works)
- Prioritize nursing diagnoses using ABCs + Maslow + safety hierarchy
- Identify which interventions can be delegated and to whom (UAP, LPN, RN, requires provider order)

**Must Not:**
- Use medical diagnoses as nursing diagnoses (e.g., "pneumonia" is not a nursing dx — "Ineffective airway clearance" is)
- Provide patient-specific drug dosing
- Skip rationales
- Default to physician-anchored framing

## Instructions

1. **Confirm scenario and mode.**

2. **Prioritization frame** (apply before writing diagnoses):
   - **Airway → Breathing → Circulation** (life-threat first)
   - **Safety** (fall, suicide, infection control)
   - **Acute physiologic > chronic**
   - **Maslow:** physiologic → safety → love/belonging → esteem → self-actualization

3. **For each nursing diagnosis:**
   - **Diagnostic statement** (three-part for actual problems, two-part for risk):
     > "Ineffective airway clearance related to retained secretions and impaired cough as evidenced by adventitious breath sounds and ineffective cough."
   - **Defining characteristics** (subjective and objective data supporting the dx)
   - **Related factors** (the "why this is happening" for this patient)
   - **Outcomes (NOC-aligned, SMART):** 2-3 outcomes, each observable and time-bound
     > "Patient will clear airway secretions independently with effective cough within 24 hours, as evidenced by clear breath sounds bilaterally and SpO2 ≥ 94% on room air."
   - **Interventions (NIC-aligned)** with rationale and frequency:
     > "Auscultate breath sounds q4h and PRN — rationale: detects accumulation of secretions and tracks effectiveness of interventions."
   - **Evaluation criteria:** what data confirms outcome met / partially met / not met, and what triggers plan revision
   - **Delegation note:** which interventions to UAP (e.g., vital signs, ambulation assistance), which to LPN (e.g., scope-permitted meds, dressing changes per state scope), which require RN (assessment, teaching, IV push of certain meds), which require provider order (advancing diet, changing positioning orders post-procedure)

4. **NCLEX reasoning overlay.** For one diagnosis, coach the learner on:
   - **Priority:** if you can only do three things this shift, what are they and why?
   - **Safety:** what specific safety risks exist, and what interventions mitigate them?
   - **Delegation:** what's safe to delegate to a UAP this shift?
   - **Teaching:** what teaching point will the patient need before discharge?
   - **Cultural / SDOH considerations:** what's specific to this patient that might shape the plan?

5. **Self-check block:**
   - State the three-part diagnostic statement format from memory
   - Identify the highest-priority diagnosis for this patient and why
   - For one intervention, state the rationale from memory
   - Name one item you'd safely delegate to a UAP

## False-Positive Prevention

| ❌ Common Mistake | ✅ Correct Approach |
|---|---|
| Use medical dx as nursing dx | Translate to a NANDA-I nursing dx |
| Outcome that's not measurable ("patient will feel better") | SMART outcomes: specific, measurable, time-bound |
| Intervention without rationale | Always include rationale |
| Diagnoses in random order | Prioritize using ABC + Maslow + safety |
| Delegate something out of UAP scope | Map intervention to correct scope |
| Skip the teaching component | Patient teaching is a nursing intervention |
| Patient-specific drug dosing | Class + monitoring principle only |

## Output Format

```
### Scenario / Learner level / Setting / Mode / Number of diagnoses

### Prioritization Frame
- ABC + Maslow + Safety reasoning

### Care Plan (per diagnosis, in priority order)

**Diagnosis 1:**
- Diagnostic statement (three-part or two-part)
- Defining characteristics
- Related factors
- Outcomes (SMART, NOC-aligned): 2-3
- Interventions (NIC-aligned) with rationale + frequency
- Evaluation criteria
- Delegation note (UAP / LPN / RN / provider order)

(Repeat per diagnosis.)

### NCLEX Reasoning Overlay (for highest-priority dx)
- Priority
- Safety
- Delegation
- Teaching
- Cultural / SDOH

### Self-Check
1. Three-part statement format (from memory)
2. Highest-priority diagnosis + rationale
3. One intervention rationale (from memory)
4. One safe UAP delegation
```

## Verification Checklist
- [ ] Nursing diagnoses (not medical diagnoses)
- [ ] Three-part / two-part statement formats correct
- [ ] Outcomes are SMART and observable
- [ ] Every intervention has rationale
- [ ] Diagnoses prioritized using ABC + Maslow + safety
- [ ] Delegation mapped to correct scope
- [ ] NCLEX overlay applied for highest-priority dx
- [ ] Self-check uses retrieval
- [ ] No patient-specific drug dosing
- [ ] Real-patient redirect maintained
