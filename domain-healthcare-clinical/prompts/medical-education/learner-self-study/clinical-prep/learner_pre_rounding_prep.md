# Pre-Rounding Prep Scaffold for Health-Professions Learners

**Objective:** Help an inpatient learner pre-round efficiently and present cleanly. Produce a scaffold that walks through the morning data review, focused exam plan, problem-list updates, A&P bullets, anticipated attending questions, and the specific decisions the team needs to make today.

## When to Use
- ✅ Daily inpatient rounding prep (medicine, surgery, peds, FM, etc.)
- ✅ Sub-internship and intern prep for efficient pre-rounding
- ✅ Standardizing personal pre-rounding template
- ❌ Real-patient documentation or order entry — use institutional EHR / supervision

## Inputs Required
- **Discipline & learner level**
- **Service:** medicine, surgery, peds, OB/Gyn, neuro, ICU, FM, geriatrics, etc.
- **Number of patients to round on**
- **Time available**
- **Patient(s) overnight summary:** the data the learner gathered or will gather (events, vitals trend, I/O, telemetry, labs, imaging, microbiology, nursing notes)

## Constraints

**Must:**
- Produce a per-patient scaffold with overnight events → trends → focused exam plan → problem list updates → A&P bullets → today's decisions → likely attending questions
- Force prioritization: which patient is least stable / most needs decisions made today
- Make A&P specific (workup / treatment / monitoring / contingency)
- Include a "what's the disposition?" question for every inpatient

**Must Not:**
- Generate orders or write real-patient notes
- Skip the disposition question
- Default to a checklist without prioritization

## Instructions

1. **Triage the list.** Quick stratification:
   - **Unstable / decompensating:** sees first
   - **Pending major decision today** (consult, OR, procedure, escalation/de-escalation of care, disposition)
   - **Stable, routine progress**

2. **Per-patient scaffold.** For each patient:

   - **Overnight events:** what happened (call-backs, rapid responses, rhythm changes, new orders, family discussions)
   - **Vital trends:** specifically the trend (not just the last value) for any vital that's been a problem
   - **I/O and weight:** trend over 24-72h if fluid status is on the problem list
   - **Telemetry / monitor data:** rhythm changes, hemodynamics, oxygen saturation patterns
   - **Labs:** new labs since rounds yesterday, trends in problem-related labs
   - **Imaging / micro:** new results
   - **Nursing notes:** patient-reported issues, function, mood, pain
   - **Meds:** any new starts/stops, antibiotics duration check, anticoagulation status
   - **Focused exam plan:** what specifically to examine this morning given problems

3. **Problem-list update.** For each active problem:
   - Status (improved / unchanged / worsened / new)
   - One-sentence reasoning supporting that status
   - Plan delta: what changes today and why

4. **Today's decisions.** Bullets — what specifically needs to happen / be decided today:
   - Imaging order
   - Consult call
   - Antibiotic change or stop
   - Anticoag start / hold
   - Discharge readiness check
   - Family meeting
   - Goals-of-care conversation

5. **Disposition question.** Every patient: what does discharge look like? What are the remaining barriers?

6. **Likely attending questions** the learner should pre-think:
   - Why is this patient still inpatient?
   - What's the goal of today's hospitalization?
   - What are you worried about?
   - What's the discharge plan?
   - Are we re-evaluating the working diagnosis?

7. **Discipline anchors:**
   - Medicine / PA: full A&P with reasoning
   - Surgery / surgical sub-I: focused on post-op course, drains, pain, ambulation, diet advancement, discharge readiness
   - Peds: weight, feeding, growth, parent concerns, anticipatory guidance
   - Nursing: handoff-receiving framing — what info do I need to safely take this patient for the shift; pre-shift assessment plan; anticipated nursing escalations

8. **Self-check block:**
   - State which patient needs the most decisions today
   - For one patient, give the disposition plan
   - One thing you'll prepare for likely attending pushback

## False-Positive Prevention

| ❌ Common Mistake | ✅ Correct Approach |
|---|---|
| Same depth for every patient | Triage first; spend time where decisions live |
| Last value rather than trend | Trends drive decisions |
| A&P bullets without reasoning | Each problem gets a one-sentence rationale |
| Skip disposition question | Every patient, every day |
| Generic attending questions | Service-specific (surgery vs medicine vs peds) |

## Output Format

```
### Service / Discipline / Learner level / Patient count / Time

### Triage
- Unstable: ...
- Decisions today: ...
- Stable routine: ...

### Per-Patient Scaffold (one per patient)
**Patient 1:**
- Overnight events
- Vitals trend
- I/O, weight, tele, labs, imaging, micro, nursing, meds
- Focused exam plan
- Problem-list update
- Today's decisions
- Disposition
- Likely attending questions

(Repeat for each patient, with depth proportional to triage)

### Discipline Anchor

### Self-Check
1. Which patient needs the most decisions
2. Disposition plan for one patient
3. Anticipated attending pushback
```

## Verification Checklist
- [ ] Triage performed before per-patient scaffold
- [ ] Each per-patient block covers overnight / trends / focused exam / problem updates / decisions / disposition / attending qs
- [ ] A&P bullets include reasoning, not relisting
- [ ] Disposition addressed for every patient
- [ ] Discipline anchor applied
- [ ] Self-check uses retrieval
- [ ] Real-patient documentation redirect maintained
