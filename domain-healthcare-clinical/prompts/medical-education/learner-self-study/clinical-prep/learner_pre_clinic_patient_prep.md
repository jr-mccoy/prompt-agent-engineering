# Pre-Clinic Patient Prep Scaffold for Health-Professions Learners

**Objective:** Produce a structured pre-visit chart-review scaffold for outpatient learners. For each scheduled patient, surface: chronic-condition status and what's due, preventive-care gaps, medication reconciliation questions, agenda priorities, sensitive-topic talking points, and what the learner specifically needs from the preceptor.

## When to Use
- ✅ Pre-clinic morning prep on outpatient rotations (FM, IM, peds, geriatrics, subspecialty clinic)
- ✅ Pharmacy ambulatory care clinic prep
- ✅ Dental hygiene / dental new-patient or recall prep
- ✅ Building an efficient personal pre-clinic template
- ❌ Real-patient documentation or order entry

## Inputs Required
- **Discipline & learner level**
- **Clinic type:** primary care / specialty / ambulatory pharmacy / dental
- **Patients scheduled:** count + visit types (new, established, annual, problem-focused, follow-up)
- **Patient chart highlights** (learner-extracted): active problems, meds, allergies, last visit summary, last labs, last imaging, gaps in care

## Constraints

**Must:**
- Produce a per-patient scaffold appropriate to visit type
- Surface preventive-care opportunities and chronic-condition monitoring due
- Identify medication reconciliation questions before the patient is in front of the learner
- Specify the agenda (what the patient asked to discuss vs what is medically due)
- Identify what the learner needs from the preceptor (consult / staffing question / second opinion)

**Must Not:**
- Generate orders
- Provide patient-specific dosing
- Skip the patient-stated agenda — the patient's reason for the visit is the entry point
- Default to physician-centric framing for pharmacy or dental learners

## Instructions

1. **Visit-type triage.** Different visit types need different prep depth:
   - **New patient (annual / well visit):** comprehensive — full PMH, FH, SH, immunizations, screenings due
   - **Annual / wellness visit:** preventive-care focus
   - **Chronic disease follow-up:** disease-control parameters, med titration history, monitoring due
   - **Acute / problem-focused:** chief complaint focused; limited preventive intrusion unless overdue
   - **Pharmacy ambulatory:** medication therapy management; adherence; side effects; titration
   - **Dental recall:** caries / perio / oral hygiene; medical update; medications; allergies

2. **Per-patient scaffold.** For each:

   - **Patient summary:** age, key chronic problems, last visit takeaway
   - **Chronic problem status check:** for each chronic dz, last lab / measurement / disease-control parameter
   - **Preventive care due:** age / sex / risk-factor-appropriate screenings overdue or due (qualitative — "BP screen due," "cancer screen overdue per general guidelines; confirm against current local guidance")
   - **Medication reconciliation questions:** what to specifically ask (changes? OTCs? supplements? alcohol? generic substitution? adherence? side effects?)
   - **Patient-stated agenda:** what they booked for; what they mentioned at scheduling
   - **Medically-due agenda:** what *should* be discussed today regardless
   - **Sensitive topics:** if due (substance use screen, IPV screen, mood screen, sexual health, end-of-life preferences) — note opener language
   - **What you need from preceptor:** specific staffing questions ("Should we add ACE-I to this patient's regimen now that microalbuminuria is rising?")
   - **Anticipated complexity:** time estimate; flag if likely to overflow the slot

3. **Agenda merge.** Negotiate patient-stated agenda + medically-due agenda within the time budget. Patient-stated comes first; medically-due weaves in if time allows or is rescheduled if not.

4. **Discipline anchors:**
   - Medicine / PA: full primary care framework
   - Nursing (ambulatory): vital trends, teaching needs, care-plan progress, navigation needs
   - Pharmacy: indication → drug → dose adjustment principle → adherence → SE → monitoring → counseling points
   - Dental: medical update (anticoagulants, bisphosphonates, immunosuppression, latex allergy), pain assessment, hygiene status, scheduled procedures

5. **Self-check block:**
   - State each patient's primary agenda from memory
   - One sensitive-topic opener you'll use
   - One thing you'll specifically need from the preceptor

## False-Positive Prevention

| ❌ Common Mistake | ✅ Correct Approach |
|---|---|
| Same depth for every visit type | Visit-type triage |
| Skip patient-stated agenda | Patient agenda is the entry point |
| Add preventive care to every visit regardless | Calibrate to time and visit type |
| Patient-specific dosing decisions | Class + principle; staff with preceptor |
| Generic preceptor questions | Be specific |
| Same scaffold across disciplines | Apply discipline anchor |

## Output Format

```
### Clinic / Discipline / Patient count / Visit types

### Visit-Type Triage
- New: ...
- Annual: ...
- Chronic FU: ...
- Acute: ...

### Per-Patient Scaffold
**Patient 1 (visit type):**
- Summary
- Chronic status check
- Preventive due
- Med rec questions
- Patient-stated agenda
- Medically-due agenda
- Sensitive topics (if due)
- Preceptor staffing question
- Complexity / time flag

(Repeat per patient.)

### Discipline Anchor

### Self-Check
1. Each patient's primary agenda
2. Sensitive-topic opener
3. Specific preceptor question
```

## Verification Checklist
- [ ] Visit-type triage performed
- [ ] Per-patient scaffold covers all categories
- [ ] Agenda merge includes patient-stated AND medically-due
- [ ] Sensitive topics with opener language where due
- [ ] Specific preceptor staffing question per patient
- [ ] Discipline anchor applied
- [ ] Self-check uses retrieval
- [ ] No patient-specific dosing; redirect to preceptor / verified reference
