# CBME Implementation Roadmap (Program-Level)

**Objective:** Design a competency-based medical education (CBME) implementation roadmap for a specific program (residency, fellowship, UME) — moving from time-based or hybrid training toward CBME with EPAs, milestones, programmatic assessment, clinical competency committee (CCC) processes, learning-environment redesign, and faculty development.

## When to Use
- ✅ Residency program transitioning to CBME (Internal Medicine, Family Medicine, Pediatrics, Surgery, etc.)
- ✅ Fellowship program implementing competency-based progression
- ✅ UME program adopting EPAs for medical school graduates
- ✅ Auditing an in-flight CBME implementation for completeness
- ❌ Single-EPA design (use `meded_epa_implementation_designer.md`)
- ❌ Mapping existing curriculum to milestones (use `meded_residency_curriculum_mapper.md`)

## Inputs Required
- **Program identity:** specialty, learner count, training duration, current model (time-based / hybrid / CBME)
- **ACGME / accreditor framework:** specialty Milestones version, EPAs from AAMC or specialty body
- **Existing assessment system:** current tools (mini-CEX, DOPS, ITER, in-training exam, milestone evaluations)
- **CCC structure** (existing or planned)
- **Faculty capacity:** number, distribution, current competency assessment training
- **IT / portfolio infrastructure**
- **Learning sites:** core hospital + ambulatory + other rotation sites
- **Implementation timeline** target

## Constraints

**Must:**
- Address all five CBME core components: outcomes framework / sequenced progression / tailored learning / competency-focused instruction / programmatic assessment
- Honor ACGME requirements (milestones, CCC, Program Evaluation Committee, milestone reporting)
- Build EPA framework aligned to specialty (or AAMC Core EPAs for UME)
- Design programmatic assessment (multi-source, multi-occasion, longitudinal portfolio)
- Build CCC processes (composition, cadence, decision rules, narrative writing)
- Address faculty development (assessor training, direct observation, narrative feedback)
- Address learning environment (psychological safety, well-being, time for feedback)

**Must Not:**
- Treat CBME as just adding milestone evaluations to existing time-based curriculum
- Skip faculty development (the rate-limiting step in most implementations)
- Invent ACGME requirements or specialty Milestone language
- Design assessment without portfolio infrastructure to support it
- Ignore the learning environment requirements for CBME (feedback time, supervision capacity)

## Instructions

1. **Confirm program identity and current state.** Echo specialty, learners, duration, current model, ACGME version, existing assessment system, CCC status, faculty capacity, IT.

2. **Map the five CBME components for this program:**

   **Outcomes framework:**
   - Specialty Milestones (verbatim language from ACGME publication for the specialty)
   - Specialty-specific EPAs (from specialty board or program-defined within framework)
   - Local program-specific competencies (if any)

   **Sequenced progression:**
   - Stage definitions (e.g., Foundational → Developmental → Proficient → Aspirational for ACGME 1-5)
   - Expected stage at each PGY year
   - Allowance for variable pace (some learners faster, some slower)

   **Tailored learning:**
   - Individualized learning plans (ILPs)
   - Coaching structure
   - Remediation pathway

   **Competency-focused instruction:**
   - Workplace-based learning emphasis
   - Direct observation and feedback
   - Deliberate practice opportunities

   **Programmatic assessment:**
   - Multi-source, multi-occasion evidence
   - Portfolio architecture
   - CCC review and narrative writing
   - Milestone reporting cadence

3. **Design EPA implementation** (or use existing framework).
   - Identify program's EPAs (specialty body's list or AAMC Core EPAs)
   - For each EPA: entrustment-supervision scale (1-5), assessment evidence types, expected entrustment trajectory by PGY year

4. **Design CCC processes.**
   - Composition (program director, associate program directors, core faculty, with diversity)
   - Cadence (semi-annual minimum per ACGME)
   - Pre-meeting evidence preparation
   - Discussion protocols
   - Decision rules
   - Narrative writing standards
   - Documentation
   - Communication to learners

5. **Build faculty development plan.**
   - Frame-of-reference training
   - Direct observation skills
   - Narrative feedback writing
   - Workplace-based assessment tool training
   - Entrustment decision calibration

6. **Build IT / portfolio infrastructure.**
   - Evidence capture
   - Learner dashboard
   - CCC review interface
   - Reporting to ACGME

7. **Address learning environment.**
   - Adequate supervision and feedback time
   - Psychological safety
   - Well-being structures
   - Equity considerations (assessor bias monitoring)

8. **Build implementation timeline.**
   - Year 0: planning, faculty development pilot, IT setup
   - Year 1: pilot rotations, CCC ramp-up, initial milestone reporting under new system
   - Year 2: full implementation, refinement
   - Years 3+: continuous improvement

9. **Audit.**

## False-Positive Prevention

| Common Mistake | Why It's Wrong | Correct Approach |
|---|---|---|
| Adding milestone evaluations to existing curriculum | Doesn't actually move to CBME | Address all five components |
| Skipping faculty development | Implementation fails at point of contact | FacDev is foundational, not optional |
| Inventing ACGME Milestone language | Damages credibility | Cite ACGME publication for specialty |
| Assessment without portfolio infrastructure | Evidence collected but unusable | Build IT in parallel |
| CCC without trained membership | Decisions inconsistent | Build CCC training and calibration |
| Ignoring learning environment | CBME requires feedback culture | Address explicitly |
| No timeline realism | Implementation collapses under timeline pressure | Multi-year phased approach |
| Generic EPA framework | Specialty-specific EPAs differ | Use specialty body's EPA list |

## Verification Checklist

- [ ] Five CBME components mapped (current vs. target)
- [ ] EPA framework specialty-specific
- [ ] CCC design complete
- [ ] Faculty development planned
- [ ] Portfolio infrastructure planned
- [ ] Learning environment addressed
- [ ] Implementation timeline phased
- [ ] ACGME requirements verified or flagged
