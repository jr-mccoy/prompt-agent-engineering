## Distinction From Sister Directories

- **`case-scenario-design/`** — Cases for instruction (PBL, OSCE, simulation, vignettes)
- **`assessment-tools/`** — Individual assessment instrument design (MCQ, OSCE stations, milestone narratives)
- **`teaching-methods/`** — Pedagogy and faculty development (preceptor scripts, lecture redesign, FD modules)
- **`feedback-remediation/`** — Individual learner feedback and remediation plans
- **`curriculum-design/` (this directory)** — **Program-level** structure: how the rotations, milestones, EPAs, and assessment system fit together

## Verification Note

All ACGME-related content (Common Program Requirements, specialty Milestones, EPA frameworks) requires verification against the current published ACGME documents. The prompts maintain verification flags throughout. Specialty Milestone versions change; always cite version and check against the specialty's currently posted document.
