## Competency Frameworks Used

Prompts in this subdomain reference these validated HPE frameworks. Educators should specify which framework their program uses:

| Framework | Used In | Key Constructs |
|-----------|---------|----------------|
| **ACGME Milestones** | Residency programs (US) | 6 competencies, 0-5 milestone levels |
| **CanMEDS 2015** | Residency programs (Canada, international) | 7 roles |
| **CBME / EPA** | Competency-based programs | Entrustment levels 1-5 |
| **Miller's Pyramid** | Assessment design universally | Knows / Knows How / Shows How / Does |
| **Dreyfus Model** | Learner level calibration | Novice → Expert |
| **Kirkpatrick Model** | Faculty development evaluation | Reaction → Learning → Behavior → Results |

## Learner Level Taxonomy

Every prompt requires learner level specification. Use this taxonomy:

| Code | Level | Approximate Stage |
|------|-------|------------------|
| M1 | First-year medical student | Pre-clinical |
| M2 | Second-year medical student | Pre-clinical, USMLE Step 1 |
| M3 | Third-year medical student | Core clerkships |
| M4 | Fourth-year medical student | Sub-internships, audition rotations |
| Intern | PGY-1 intern | First post-graduate year |
| PGY2-3 | Junior resident | Building independence |
| PGY4-5 | Senior resident | Near-independent |
| Fellow | Post-residency subspecialty | Advanced competency |
| Attending | Faculty / practicing physician | Teaching role |
| NP/PA student | Advanced practice learner | Program-specific milestones |
| Nursing student | Pre-licensure | NCLEX-aligned |

## Common Failure Modes

Educators using these prompts should watch for:

1. **Level mismatch:** Case or question calibrated to wrong learner level. A PBL case for M3 students written at M1 complexity insults learners; at fellow complexity, it frustrates them.

2. **Missing facilitator guide:** Producing only learner-facing materials. Every case, scenario, and exercise requires a parallel educator guide with facilitation moves and common tangents.

3. **Omitting standard-setting:** Assessment instruments without passing criteria are unusable in high-stakes contexts. Always specify how the pass score is set.

4. **Conflating formative and summative:** Using summative language (grades, pass/fail) in a formative tool, or omitting judgment in a summative tool.

5. **One-size assessments:** Using a single OSCE checklist for M3 students AND residents. Calibration to level is required.

6. **Passive faculty development:** Designing a module that transmits information rather than practices the educator behavior. Kirkpatrick Level 3 (behavior change) requires active skill rehearsal.
