# Stage 2 — Structure & Beat Map

## Objective

Convert the foundation into a concrete, form-appropriate **structure** the draft can be built on — sequenced beats that fit the form's page/chapter economy and word-count band, and that preserve the child's agency and the action-carried theme.

## When to Use

- After the concept foundation is set, before drafting.
- When a draft sprawls or stalls and the underlying structure needs to be made explicit.

## Inputs / Context

- The Stage 1 concept foundation (premise, protagonist + agency moment, theme).
- The Stage 0 form, age band, and word-count target.

## Constraints

**Must:**
- Use the structure native to the form (route to the matching workshop prompt for its beat framework):
  - **Board/concept:** page-by-page concept logic; sound/repetition; a refrain if applicable.
  - **Picture book:** ~32-page beat map with page-turn tension and a refrain.
  - **Early reader/chapter:** short chapters with mini-cliffhangers; controlled scope per chapter.
  - **Middle grade / upper-MG:** chapter outline with escalating stakes and a midpoint shift.
  - **Verse novel:** poem-as-chapter sequence; white space as pacing.
  - **Graphic novel:** page and panel beats; page-turn cliffhangers; the text/art division.
  - **Nonfiction:** a deliberate text structure (chronological, compare/contrast, problem/solution, sequence) + planned text features + back-matter slots.
- Keep the climactic beat the child's action (carry agency from Stage 1).
- Keep the projected length inside the form's word-count band.

**Must Not:**
- Apply prose-chapter structure to a picture book, or vice versa.
- Plan a structure whose obvious draft length blows the word-count band.
- Bury the agency moment in an adult character's beat.

## Instructions

1. Route to the form's workshop prompt for its native beat framework.
2. Lay out the beats/pages/chapters with one line each.
3. Mark the beat where the **child** acts decisively (the agency moment).
4. Estimate the resulting word count and confirm it sits in the band.
5. **Nonfiction:** name the chosen text structure, list the text features (sidebars, diagrams-as-art-notes, glossary), and reserve back-matter slots (sources, author's note, further reading).

## Output Format

```
STRUCTURE / BEAT MAP — [FORM]
[for PB] Page 1: ... / Page 2-3 (spread): ... / ... / Page 32: ...
[for prose] Ch 1: ... / Ch 2: ... / Midpoint: ... / Climax (child acts): ... / Resolution: ...
[for verse] Poem 1 (title): beat ... / ...
[for GN] Page 1 (panels): ... / Page-turn cliffhanger at p.X ...
[for NF] Text structure: ...; sections: ...; text features: ...; back-matter slots: ...

AGENCY BEAT: located at [page/chapter] — child does ...
PROJECTED LENGTH: ~N words (band: ...) — IN BAND | OVER | UNDER
```

## Verification Checklist (the orchestrator gates on this)

- [ ] The structure is the one native to the form (no cross-form mismatch).
- [ ] Every beat/page/chapter has a clear purpose; none is filler.
- [ ] The climactic beat is the child protagonist's action.
- [ ] Projected length is inside the form's word-count band.
- [ ] (NF) A deliberate text structure is named and back-matter slots are reserved.

## False-Positive Prevention

- **A beat map that's really a summary** — beats with no escalation or turn. Each beat should change the situation.
- **A 32-page map that will obviously draft to 1,500 words.** Re-scope now, not after drafting.
- **An agency moment that quietly migrated to a parent.** Re-anchor it to the child.
- **Nonfiction structured as an undifferentiated info-dump.** Pick a real text structure.
