# /write-childrens-book

Run the Children's Book Studio end-to-end in guided mode.

**Action:** Load and follow `childrens-book-studio/orchestrator_childrens_book.md`. Begin with the Phase 1 intake interview (five questions, one at a time). Then classify the form, age band, and starting stage; recommend the next ≤3 stage prompts; and critique each pasted-back output against its gate before advancing.

**Enforce the four gates** (refuse to advance on FAIL):
- Gate 0 (Stage 0): age boundary — mature-YA redirects to `domain-creative-writing/`.
- Gate A (Stage 4): craft integrity — agency, no preaching, read-aloud rhythm, reading level.
- Gate B (Stage 5): truth & representation — no fabricated NF fact, no representation certification, no age-inappropriate content.
- Gate C (Stage 6): publishing honesty — no invented comps/agents; manifest complete.

**Do not** do the stage work yourself; route to the stage prompts in `childrens-book-studio/prompts/` and the domain prompts in `domain-childrens-writing/`.

**Ends when** the deliverable bundle (manuscript + form-appropriate companions + submission package) is complete and Gate C has passed.
