# `domain-science/public-engagement/`

The public-engagement layer for scientists communicating beyond academic peers: press releases, media interviews, op-eds, policy briefs, legislative testimony, social media, lay explainers, and misinformation response.

**Core theme — overclaim avoidance.** Every prompt calibrates certainty to the evidence (correlation ≠ causation; a single study ≠ settled science; effect size and limitation stated), keeps empirical claims separate from value/policy judgments, links the primary source, discloses funding/COI, and bans hype vocabulary ("breakthrough / cure / proves / groundbreaking"). Findings, statistics, and quotes are user-supplied — never invented — and others' positions are represented fairly.

## Floor (per [`../README.md`](../README.md))

Every prompt requires discipline + study type + the finding + audience; forbids fabricated findings, statistics, quotes, citations, opponents' positions, and unwarranted certainty (`[user-supplied]`); locks the output format; aligns to science-communication best practice (overclaim avoidance, uncertainty disclosure) and, for corrections, inoculation theory / the Debunking Handbook; preserves the association-vs-causation and confirmatory-vs-exploratory distinctions when translating for lay audiences; links primary sources and discloses COI; and ends with a verification checklist + false-positive matrix.
