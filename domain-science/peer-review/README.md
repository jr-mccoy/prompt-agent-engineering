# `domain-science/peer-review/`

The peer-review layer for scientists serving as reviewers and editors: drafting and self-auditing reviews, writing editorial decisions, arbitrating reviewer disagreement, critiquing published work, and reviewing replication / robustness studies. Aligned to COPE peer-review guidance.

**Stance:** every criticism is evidence-based and located; fatal flaws are distinguished from improvements-of-degree; the language is constructive and never ad hominem; honest error is assumed over misconduct (and suspected misconduct is *routed*, via [`../ethics-integrity/`](../ethics-integrity/), not accused).

## Map (Phase 2F — 6 prompts)

| File | Coverage |
|---|---|
| [`science_peer_review_drafter.md`](science_peer_review_drafter.md) | Structured review: summary, significance, major vs minor concerns (each located + reasoned), reporting/Open-Science check, calibrated recommendation; comments-to-editor kept separate |
| [`science_peer_review_self_check.md`](science_peer_review_self_check.md) | Pre-submission audit of your own review: evidence vs taste, scope creep, bias, COI, tone, major/minor triage |
| [`science_editorial_decision_drafter.md`](science_editorial_decision_drafter.md) | Decision letter that synthesizes divergent reviews + the editor's own read (adjudicates, doesn't average) into an actionable path |
| [`science_review_disagreement_arbitration_memo.md`](science_review_disagreement_arbitration_memo.md) | AE / third-reviewer memo: map each claim to evidentiary strength, find the crux, recommend without splitting the difference |
| [`science_post_publication_critique_drafter.md`](science_post_publication_critique_drafter.md) | PubPeer-style critique anchored to checkable evidence; honest-error default; suspected misconduct stated factually and routed |
| [`science_review_for_replication_or_robustness.md`](science_review_for_replication_or_robustness.md) | Replication/robustness review lens that sets aside "is it novel?"; power, fidelity, multiverse, correct (non-)replication interpretation |

## Floor (per [`../README.md`](../README.md))

Every prompt requires discipline + study type; forbids fabricated citations, data, or manuscript facts (`[user-supplied]` or phrased as an author query); locks the output format; names COPE and the relevant EQUATOR/TOP standard; ties every criticism to its evidentiary basis and severity; keeps language constructive and non-ad-hominem; includes an Open-Science review dimension (data/code/preregistration); and ends with a verification checklist + false-positive matrix.

See [`../EXPANSION_ROADMAP.md`](../EXPANSION_ROADMAP.md) for the remaining phases and build order.
