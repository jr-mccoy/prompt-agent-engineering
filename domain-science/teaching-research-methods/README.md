# `domain-science/teaching-research-methods/`

The teaching layer for scientists who teach **research craft itself** — authentic-research courses, methods syllabi, journal clubs, science-specific code review, and hands-on data-analysis / reproducibility workshops.

**Domain boundary:** this is distinct from [`../../domain-education-teaching/`](../../domain-education-teaching/) (generic K-12 / higher-ed pedagogy and assessment mechanics) and from [`../../domain-software-engineering/`](../../domain-software-engineering/) (generic code quality) because the *subject matter is the doing of science*: rigor, reproducibility, and critical appraisal. Cross-reference those domains for generic pedagogy and engineering depth; these prompts own the research-craft content.

## Map (Phase 2L — 6 prompts)

| File | Coverage |
|---|---|
| [`science_undergraduate_lab_course_designer.md`](science_undergraduate_lab_course_designer.md) | CURE-style authentic-research lab course (open question, real measurement, calibrated process+product rubric) |
| [`science_research_methods_syllabus_designer.md`](science_research_methods_syllabus_designer.md) | Semester methods syllabus aligned to discipline + Open Science; assignments that practice the craft (write a prereg, reproduce a result) |
| [`science_journal_club_facilitation_guide.md`](science_journal_club_facilitation_guide.md) | Paper selection, pre-read questions, structured critical-appraisal facilitation, follow-up |
| [`science_code_review_for_science_software.md`](science_code_review_for_science_software.md) | Science-specific review: correctness vs known cases, reproducibility, numerical stability, ML leakage — taught as an exercise |
| [`science_data_analysis_workshop_designer.md`](science_data_analysis_workshop_designer.md) | Carpentries-style live-coding workshop with formative checks, scripted reproducibility, post-workshop scaffolding |
| [`science_reproducibility_workshop_designer.md`](science_reproducibility_workshop_designer.md) | One-day workshop converting a paper into a fully reproducible, archived (DOI) artifact |

## Floor (per [`../README.md`](../README.md))

Every prompt requires discipline + level/audience; forbids fabricated course requirements, papers, datasets, or citations (`[user-supplied]`); locks the output format; aligns to the relevant framework (CURE, constructive alignment / backward design, The Carpentries pedagogy, FAIR / FAIR4RS); teaches research rigor and reproducibility as the content with assessment aligned to outcomes; weaves the Open-Science default into the teaching; and ends with a verification checklist + false-positive matrix.

See [`../EXPANSION_ROADMAP.md`](../EXPANSION_ROADMAP.md) — with Phase 2L, the domain-science roadmap is fully built out.
