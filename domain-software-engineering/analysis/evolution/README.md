# Evolution Analysis Prompts

> Prompts for analyzing codebase evolution over time, identifying technical debt, tracking code churn, and generating refactoring recommendations based on historical patterns.

## Prompts in This Category

| Prompt | Description |
|--------|-------------|
| [evolution_code_churn_hotspot_analysis](evolution_code_churn_hotspot_analysis.md) | Identify high-churn files indicating complexity or instability |
| [evolution_code_evolution_report_generation](evolution_code_evolution_report_generation.md) | Generate comprehensive codebase evolution reports |
| [evolution_codebase_evolution_visualization](evolution_codebase_evolution_visualization.md) | Create visualizations of codebase evolution over time |
| [evolution_impact_analysis_of_code_changes](evolution_impact_analysis_of_code_changes.md) | Analyze ripple effects of code changes to predict impacts |
| [evolution_refactoring_recommendation_generation](evolution_refactoring_recommendation_generation.md) | Generate prioritized refactoring recommendations |
| [evolution_technical_debt_estimation](evolution_technical_debt_estimation.md) | Estimate technical debt from historical code analysis |

## Usage

These prompts help analyze how codebases have changed over time using version control data. Use them to identify areas needing refactoring, estimate technical debt, understand code churn patterns, and plan improvement priorities.
