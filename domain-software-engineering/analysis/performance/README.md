# Performance Analysis Prompts

> Prompts for identifying performance bottlenecks, analyzing concurrency issues, profiling resource usage, and generating optimization recommendations.

## Usage

These prompts help analyze codebases for performance issues including algorithmic inefficiencies, database bottlenecks, concurrency problems, and resource constraints. Use them when applications are slow, planning for scale, or optimizing critical paths.
