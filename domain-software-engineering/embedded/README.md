## Coverage

These prompts address the key areas of embedded systems development:

- **Prototyping:** Arduino, Raspberry Pi, hobby and prototype-to-production workflows
- **Firmware:** Bare-metal super-loops, RTOS (FreeRTOS, Zephyr), interrupt-driven architectures
- **Communication:** MQTT, CoAP, BLE, Zigbee, LoRa/LoRaWAN protocol implementations
- **Linux:** Yocto, Buildroot, device trees, kernel configuration, boot optimization
- **Real-Time:** Schedulability analysis, WCET, priority inversion, determinism
- **Hardware Interface:** HAL design, register access, peripheral drivers, DMA, bus protocols
- **Sensing:** Sensor configuration, signal filtering, calibration, data pipelines
- **Edge Computing:** On-device ML (TinyML), data reduction, constrained device optimization
