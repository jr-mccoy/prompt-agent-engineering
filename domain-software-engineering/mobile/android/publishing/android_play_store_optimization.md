# Android Play Store Optimization (ASO)

**Objective:** Optimize an Android app's Play Store presence through comprehensive App Store Optimization (ASO), improving discoverability, conversion rates, and user acquisition through strategic keyword optimization, compelling creative assets, and effective store listing content.

**When to Use:** Use this prompt when preparing to launch a new app, refreshing an existing store listing, experiencing low organic downloads despite good app quality, or when competitors are outranking you in search results. This prompt helps maximize the value of your Play Store presence without additional marketing spend.

**Prompt Type:** Comprehensive (350-450 lines)

---

## Context Gathering

Before beginning the ASO audit, gather essential context:

1. **App Context:**
   - "What is your app's primary function and value proposition?"
   - "Who is your target audience (demographics, interests, pain points)?"

2. **Competitive Landscape:**
   - "Who are your main competitors in the Play Store?"
   - "What keywords do you currently target (if any)?"

3. **Current Performance:**
   - "What are your current download numbers and conversion rates?"
   - "Do you have access to Play Console analytics?"

4. **Goals:**
   - "What's your primary goal (increase downloads, improve conversion, specific keyword ranking)?"
   - "Are there specific markets or languages you're targeting?"

---

## Instructions

### CRITICAL: Verification Requirements

**Before recommending ANY ASO change, you MUST:**

1. **Trace actual performance data** - Don't recommend changes without understanding current conversion and search performance.
2. **Check for existing optimization** - Search for previous ASO efforts, A/B tests, or keyword research.
3. **Understand the context** - Consider the app's brand, target audience, and competitive position.
4. **Confirm actual impact** - Will this change likely improve discovery or conversion?
5. **Provide specific recommendations** - Every suggestion must include exact copy or actionable steps.

**Finding the listing is ALREADY OPTIMIZED is an acceptable outcome.** If the store presence is effective for its goals, say so with confidence.

### False-Positive Prevention

- ❌ Do NOT recommend keyword stuffing that hurts readability
- ❌ Do NOT suggest changes without considering brand voice
- ❌ Do NOT assume competitors' strategies work for every app
- ❌ Do NOT recommend changes without considering conversion trade-offs
- ✅ DO balance keyword optimization with compelling copy
- ✅ DO consider A/B testing for significant changes
- ✅ DO understand Play Store search algorithm basics
- ✅ DO prioritize changes with highest potential impact

### Phase 1: Current Store Listing Audit

Analyze the current state of the app's Play Store listing.

#### 1.1 App Title Analysis

**Evaluate current title:**

```
Title Requirements:
- Maximum 30 characters
- Brand name + primary keyword (if space allows)
- Front-load important keywords
- Avoid keyword stuffing
- Consider brand recognition vs discoverability trade-off
```

**Audit checklist:**
- [ ] Title length is within limit (30 chars)
- [ ] Primary keyword is included
- [ ] Title is readable and professional
- [ ] Brand name is present and recognizable
- [ ] No policy-violating characters or claims

**Title patterns that work:**
```
Pattern 1: [Brand] - [Primary Function]
Example: "Spotify - Music and Podcasts"

Pattern 2: [Brand]: [Value Proposition]
Example: "Calm: Sleep & Meditation"

Pattern 3: [Descriptive Name]
Example: "Step Counter - Pedometer"
```

#### 1.2 Short Description Analysis

**Evaluate short description:**

```
Short Description Requirements:
- Maximum 80 characters
- Highly visible on store page
- Should include top 1-2 keywords
- Clear value proposition
- Compelling hook
```

**Audit checklist:**
- [ ] Within 80 character limit
- [ ] Includes primary keyword naturally
- [ ] Communicates core value proposition
- [ ] Creates interest to read more
- [ ] No keyword stuffing

#### 1.3 Full Description Analysis

**Evaluate full description:**

```
Full Description Requirements:
- Maximum 4000 characters
- First 167 characters most important (above the fold)
- Include keywords throughout (3-5% density)
- Use formatting for readability
- Include call to action
- Address user pain points and solutions
```

**Structure to evaluate:**

```
Recommended Structure:
1. Hook (first 2 lines) - Capture attention
2. Value Proposition - What makes app unique
3. Key Features - Bullet points (using Unicode bullets)
4. Social Proof - Awards, press mentions, user count
5. How It Works - Brief explanation
6. Call to Action - Encourage download
7. Keywords Section - Natural inclusion of target keywords
```

**Audit checklist:**
- [ ] First 167 characters are compelling
- [ ] Features are clearly listed
- [ ] Benefits are emphasized (not just features)
- [ ] Keywords are naturally integrated
- [ ] Formatted for easy scanning
- [ ] No policy violations (claims, competitors, etc.)
- [ ] Call to action is present
- [ ] Contact/support info if applicable

#### 1.4 Visual Asset Review

**Evaluate screenshots:**

```
Screenshot Requirements:
- Minimum 2, maximum 8 screenshots
- First 2-3 are most important (visible without scrolling)
- Supported sizes and orientations per device type
- Should tell a story or highlight key features
- Include device frames (optional but recommended)
- Add text overlays explaining features
```

**Screenshot audit:**
- [ ] Sufficient quantity (4-8 recommended)
- [ ] High quality resolution
- [ ] First screenshot highlights key value
- [ ] Text overlays are readable
- [ ] Consistent visual style
- [ ] Show actual app UI (not just marketing graphics)
- [ ] Different screenshots for phone and tablet

**Evaluate feature graphic:**

```
Feature Graphic Requirements:
- 1024 x 500 pixels
- Displayed at top of store listing
- Used in promotional placements
- Should work with and without text overlay
- Brand-forward design
```

**Feature graphic audit:**
- [ ] Correct dimensions
- [ ] Brand identity clear
- [ ] Works at small sizes (search results)
- [ ] Not text-heavy (may be cropped/scaled)
- [ ] Visually appealing and professional

**Evaluate video (if present):**

```
Promo Video Guidelines:
- YouTube video link
- 30 seconds to 2 minutes ideal
- First 10 seconds crucial
- Show real app usage
- Include captions (many watch muted)
```

#### 1.5 App Icon Review

**Evaluate app icon:**

```
Icon Best Practices:
- Simple, recognizable design
- Works at small sizes (16x16 to 512x512)
- Consistent with brand
- Stands out from competitors
- No text (generally)
- Follows current design trends
```

**Icon audit:**
- [ ] Distinctive and recognizable
- [ ] Works at all sizes
- [ ] Matches brand identity
- [ ] Not cluttered
- [ ] Doesn't rely on text
- [ ] Follows Play Store guidelines

### Phase 2: Keyword Research & Strategy

Develop a comprehensive keyword strategy.

#### 2.1 Keyword Discovery

**Sources for keyword research:**

```
Research Methods:
1. Competitor Analysis
   - Analyze top 5-10 competitor titles and descriptions
   - Note frequently used keywords

2. Play Console Suggestions
   - Review suggested keywords in Play Console
   - Check current keyword performance

3. Auto-complete Research
   - Type partial queries in Play Store search
   - Note auto-complete suggestions

4. User Language
   - Review user reviews for terminology
   - Note how users describe the app

5. Related Searches
   - Search for your category
   - Note related app suggestions
```

**Build keyword list:**

| Keyword | Search Volume | Competition | Relevance | Priority |
|---------|--------------|-------------|-----------|----------|
| [keyword] | High/Med/Low | High/Med/Low | 1-10 | P1/P2/P3 |

#### 2.2 Keyword Categorization

**Organize keywords by type:**

```
Categories:
1. Brand Keywords
   - Your app name
   - Variations and misspellings

2. Category Keywords
   - Generic category terms
   - "fitness app", "photo editor"

3. Feature Keywords
   - Specific features
   - "calorie counter", "face filter"

4. Problem Keywords
   - Pain points users search for
   - "lose weight", "track expenses"

5. Competitor Keywords
   - Competitor names (careful with policy)
   - Alternative to [competitor]

6. Long-tail Keywords
   - Specific phrases
   - "best free meditation app for beginners"
```

#### 2.3 Keyword Placement Strategy

**Optimize keyword placement:**

```
Keyword Placement Priority:
1. Title (highest impact) - 30 chars
   - Include 1-2 primary keywords

2. Short Description (high impact) - 80 chars
   - Include 1-2 keywords naturally

3. Full Description (moderate impact) - 4000 chars
   - Include all keywords 2-3 times each
   - Use in first paragraph
   - Use in feature bullets
   - Use in closing section
```

## Customization Guide

### For Different App Categories

**Games:**
- Emphasize gameplay screenshots/video
- Include game category keywords (puzzle, action, RPG)
- Highlight progression and rewards
- Show social features if applicable

**Productivity:**
- Focus on efficiency and time-saving
- Show before/after or workflow improvement
- Include integration keywords (sync, cloud, export)
- Professional, clean visual style

**Social/Communication:**
- Emphasize user base size
- Show conversation/interaction features
- Include privacy/security messaging
- Fun, vibrant visual style

### For Different Markets

**US Market:**
- English optimization primary
- Focus on "app" terminology
- Competitive, differentiation crucial

**Emerging Markets:**
- Emphasize free/lite versions
- Highlight offline functionality
- Consider lower-end device compatibility
- Local language crucial

**Premium Markets (EU, Japan):**
- Quality messaging over price
- Privacy and security emphasis
- Localization quality matters more

### For Different Launch Stages

**New App Launch:**
- Focus on category keywords first
- Build initial review base
- More aggressive A/B testing
- Screenshot iteration important

**Established App Refresh:**
- Protect existing rankings
- Incremental changes with monitoring
- Leverage existing reviews in messaging
- Focus on conversion over discovery

**Competitive Response:**
- Differentiation messaging
- Alternative positioning
- Unique feature emphasis
- Consider comparison keywords carefully
