## Usage

These prompts help with rapidly prototyping functional applications. Use them to generate complete specifications for AI code generators that produce working apps with data models, views, and interactions defined.

Each prompt includes:
- Complete data model with field types
- UI/UX specifications for all views
- Design guidelines (mobile-responsive, dark mode, etc.)
- Technical requirements (local storage, export, etc.)
