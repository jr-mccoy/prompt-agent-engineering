# Goals & Habits

Prompts for setting goals, building habits, tracking progress, and diagnosing breakdowns. All prompts in this directory are operational — they produce concrete plans, templates, and recommendations, not reflection exercises.

---

## Prompts

| File | Purpose | Difficulty |
|------|---------|------------|
| `goals_annual_goal_breakdown.md` | Decompose 1–5 annual goals into quarterly milestones, monthly commitments, and weekly minimum viable actions. Flags conflicts between goals. | Intermediate |
| `goals_habit_stack_designer.md` | Design a habit stack anchored to an existing routine. Produces the stack structure and a graduated 30-day starter plan. | Beginner |
| `goals_monthly_progress_check_in.md` | Run a structured progress check-in on active goals. Returns green/yellow/red status and a specific course-correction plan. | Intermediate |
| `goals_goal_reality_check.md` | Before committing to a goal, test it against available time and existing priorities. Returns pursue / scale / defer / drop. | Intermediate |
| `goals_habit_repair.md` | Diagnose why a previously maintained habit broke down. Designs a re-entry smaller than the maintained version plus a 7-day tracking commitment. | Beginner |
| `goals_personal_tracking_dashboard.md` | Design a minimal tracking system for goals and habits. Produces a concrete template and weekly review protocol adaptable to any tool. | Beginner |

## When to Use This Directory

**Use `domain-productivity/goals-habits/` when:**
- The person has a goal or habit and needs a concrete operational plan
- The question is about what to track, how to structure milestones, or how to restart a lapsed habit
- The output should be a template, a plan, or a recommendation — not a reflection or self-assessment

**Use `domain-personal-development/` instead when:**
- The question is about identity, values, or whether the right goal is being pursued (use `identity_values_clarification.md`, `identity_purpose_reignition.md`)
- The question is about career-level repositioning (use `career-transformation/`)
- The question is about agency, execution blocks, or stuckness beyond habit and goal mechanics (use `prompts/agency/`)

**Use `domain-productivity/reviews/` instead when:**
- The question is about reviewing a week, month, or quarter as a whole — not just one goal or habit (use `reviews_weekly_systems_review.md`, `reviews_monthly_quarterly_cadence.md`)

**Use `domain-productivity/bottlenecks/` instead when:**
- The question is about why nothing is getting done at a systemic level — not a specific habit or goal (use `bottleneck_locator.md`, `bottleneck_procrastination_systems_diagnostic.md`)

## Typical Usage Sequences

**Starting a new goal:**
1. `goals_goal_reality_check.md` — is this goal actually feasible right now?
2. `goals_annual_goal_breakdown.md` — build the milestone structure
3. `goals_personal_tracking_dashboard.md` — set up a tracking system
4. `goals_monthly_progress_check_in.md` — run each month

**Starting a new habit:**
1. `goals_habit_stack_designer.md` — design the stack and 30-day plan
2. `goals_personal_tracking_dashboard.md` — track completion
3. `goals_habit_repair.md` — if the habit breaks after being established

**Fixing a habit that broke:**
1. `goals_habit_repair.md` — diagnose and re-enter
2. `goals_personal_tracking_dashboard.md` — re-establish tracking

**Annual planning:**
1. `goals_goal_reality_check.md` for each candidate goal
2. `goals_annual_goal_breakdown.md` for the surviving goals
3. `goals_personal_tracking_dashboard.md` for the operating system
4. `goals_monthly_progress_check_in.md` each month throughout the year
