# Daily Planning

Prompts for the within-day planning cycle: building a task list, triaging priorities, running a morning startup, closing the day cleanly, breaking through overwhelm, batching errands, managing life-mode transitions, and sequencing work to match energy levels. These prompts operate at the scale of a single day — not a week, sprint, or quarter.

Each prompt is designed to produce output in a single interaction. They pair with each other naturally (morning planning → shutdown → next morning) and integrate with the Deep Work and Bottlenecks directories for longer-horizon planning concerns.

---

## Prompts in This Directory

| Filename | Title | Description |
|----------|-------|-------------|
| `daily_task_list_builder.md` | Daily Task List Builder | Convert a brain dump and calendar into a sized, prioritized daily list. Enforces a block budget so the list fits the day's actual available hours. |
| `daily_priority_triage.md` | Daily Priority Triage | Triage an existing task list of 10–20 items using urgency-importance quadrants. Challenges self-imposed urgency and produces a single concrete start-here recommendation. |
| `daily_morning_planning_sequence.md` | Daily Morning Planning Sequence | A 10–15 minute startup routine: close yesterday's loops, read today's calendar, pick 1–3 MITs with completion definitions, sketch the day. |
| `daily_end_of_day_shutdown.md` | Daily End-of-Day Shutdown | A structured workday-close: capture open loops, log new commitments, name tomorrow's starter task, write a close statement. Pairs with morning planning. |
| `daily_overwhelm_triage.md` | Daily Overwhelm Triage | When everything feels urgent and nothing feels startable, extract one concrete first action. Output is a single task and a single physical starting motion — nothing else. |
| `daily_errand_batching.md` | Daily Errand Batching | Cluster and sequence a list of errands by geography, operating hours, and dependencies to minimize trips and total time. |
| `daily_context_switch_protocol.md` | Daily Context Switch Protocol | Produce a close protocol for the outgoing life-mode and an open protocol for the incoming one, so mental state carries cleanly across substantially different daily roles. |
| `daily_energy_task_matching.md` | Daily Energy-Task Matching | Classify tasks by cognitive demand, map the user's energy curve, and resequence the day's schedule to match deep work to high-energy windows and admin to low-energy ones. |

## When to Use This Directory vs. Others

**Use Daily Planning when** you are working at the scale of one day — building, triaging, or sequencing what happens today or tomorrow. These prompts assume a task list already exists or can be built in the session.

**Use `domain-productivity/deep-work/`** when the goal is protecting and designing extended focus blocks, managing interruptions structurally, or capturing context at the end of a focus session. Deep Work prompts operate at the block-and-session level, while Daily Planning prompts operate at the day level.

**Use `domain-productivity/bottlenecks/`** when the problem is not "how do I organize today" but "why do I keep failing to execute" — chronic procrastination, capture system failure, perfectionism, or a structural clarity problem. Bottleneck prompts diagnose the system; Daily Planning prompts operate within it.

**Use `domain-productivity/reviews/`** when the goal is weekly, monthly, or quarterly retrospective and planning — auditing what actually happened over time, tuning systems, and setting direction for the next period. Reviews operate at a longer cadence than Daily Planning.

**Use `domain-personal-development/prompts/agency/`** when the issue is ownership, motivation, or execution psychology — converting vague goals into projects, diagnosing stuckness, repairing broken habits. The Agency prompts address the person's relationship to their work; Daily Planning prompts address the logistics of a single day.
