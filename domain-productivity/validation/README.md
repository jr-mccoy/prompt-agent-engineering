## Usage

These prompts help with validating decisions before commitment and evaluating content quality before publication. Use them to prevent costly mistakes, calibrate confidence, and catch "slop" (generic, low-quality AI-generated content).

**Decision Validation prompts** provide:
- Structured assessment frameworks
- Evidence discipline (facts vs. inference vs. assumption)
- Stakes and reversibility analysis
- STOP/GO recommendations

**Slop Evaluators** provide:
- Multi-dimensional quality scores (0-5 scale)
- ACCEPT/REVISE/REJECT verdicts
- Specific anti-pattern detection
- Actionable fixes with exact locations
