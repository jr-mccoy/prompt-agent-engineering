# Workplace Productivity Prompts

Prompts for the recurring operational tasks of knowledge-work: meeting prep and facilitation, written communication, deadline management, and delegation. These are the mechanics of getting things done in a professional context — not career strategy, not team-level project management, not creative work.

---

## Prompts in This Directory

| File | Title | When to use |
|------|-------|-------------|
| `work_meeting_agenda_builder.md` | Meeting Agenda Builder | Before any meeting you are facilitating — builds a time-boxed agenda with named owners and outcomes per item |
| `work_status_update_writer.md` | Status Update Writer | Writing a project status update calibrated to the audience (executive, team, client, all-hands) |
| `work_follow_up_email_drafter.md` | Follow-Up Email Drafter | After any meeting or conversation where commitments were made — drafts a structured follow-up with action items and owners |
| `work_inbox_triage_protocol.md` | Inbox Triage Protocol | When email is out of control — builds a one-time backlog clearing plan and a repeatable daily maintenance protocol |
| `work_deadline_juggler.md` | Deadline Juggler | When multiple deadlines converge and you need a priority sequence and daily allocation |
| `work_task_delegation_spec.md` | Task Delegation Spec | Before handing off a task — produces a delegation brief with outcome, authority, resources, and escalation triggers |
| `work_1on1_prep.md` | 1:1 Meeting Prep | Before a one-on-one, from either side — surfaces what each person actually needs from the conversation |

## When to Use This Directory vs. Others

### This directory vs. `domain-engineering-workflows/`

`domain-engineering-workflows/` covers team-level technical and engineering processes: sprint planning, debugging workflows, postmortems, AI-native rollouts, and team-level task prioritization. Use it for process design and team coordination on engineering work.

This directory covers individual knowledge-worker mechanics: running a meeting, writing a status email, managing your inbox, juggling your own deadlines. The scope is personal and operational, not team architecture.

### This directory vs. `domain-business-strategy/`

`domain-business-strategy/` covers executive and organizational decisions: competitive analysis, market sizing, strategy frameworks, OKRs, and org-level planning. Use it for strategic business thinking.

This directory covers the day-to-day execution mechanics that apply regardless of whether your work is strategic: how to run a meeting, how to write an update, how to hand off a task. These prompts assume you already know what to work on — they help you work on it effectively.

### This directory vs. `domain-professional-communication/`

`domain-professional-communication/` covers external-facing documents and product deliverables: PRDs, product specs, stakeholder briefings, and market communications.

This directory covers the internal operational communication that runs an organization: meeting agendas, project status updates, follow-up emails, 1:1 prep. The audience is internal or ongoing client relationships, not new external audiences.

### This directory vs. `domain-productivity/deep-work/`

`domain-productivity/deep-work/` is about protecting and optimizing focused solo work time: blocking focus time, reducing interruptions, designing your work environment.

This directory is about the work that happens between focus blocks: the meetings, the emails, the handoffs, the juggling. Use deep-work prompts to protect your time; use these prompts to make the inevitable collaborative and communication tasks as efficient as possible.

### This directory vs. `domain-productivity/daily-planning/`

`domain-productivity/daily-planning/` covers the daily personal planning cycle: building your task list, triaging priorities for the day, ending the day with a shutdown ritual.

This directory handles specific workplace tasks — a meeting to run, an email to write, a task to hand off — that arise within the day. Use daily-planning prompts to figure out what to do; use these prompts to do the specific workplace tasks well.

## Common Entry Points

**I have a meeting coming up and no agenda:** `work_meeting_agenda_builder.md`

**I need to send a project update to my boss or to a client:** `work_status_update_writer.md`

**I just got out of a meeting and need to send a summary:** `work_follow_up_email_drafter.md`

**My email is a disaster and I need a system:** `work_inbox_triage_protocol.md`

**Everything is due at once and I don't know what to work on:** `work_deadline_juggler.md`

**I need to hand off a task to someone on my team:** `work_task_delegation_spec.md`

**I have a 1:1 tomorrow and want it to be more than status updates:** `work_1on1_prep.md`
