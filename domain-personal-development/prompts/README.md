# Personal Development Prompts

This directory groups the personal-development prompts by function. Start with the parent
[domain guide](../README.md) for triggers, personas, techniques, and quality standards, then
jump to the relevant cluster below. Each cluster has its own README with scope, composition
patterns, and out-of-scope boundaries.

| Cluster | Count | What it's for |
|---------|-------|---------------|
| [`agency/`](./agency/README.md) | 18 | Self-directed work: vague goal → owned project → shipped, weekly review, stuck diagnosis, habit repair, burnout recovery, decision post-mortem |
| [`identity/`](./identity/README.md) | 13 | The third axis — values, self-talk, comparison/envy, confidence, purpose, life audit, taste |
| [`habits/`](./habits/README.md) | 10 | Behavior change: habit design, breaking bad habits, stacking, streak recovery, keystone habits, environment design |
| [`resilience/`](./resilience/README.md) | 11 | Non-clinical resilience & motivation: setback recovery, motivation diagnosis, self-discipline, failure reframe, anti-fragility, momentum rebuild |
| [`relationships/`](./relationships/README.md) | 13 | Personal (non-work) relationships & social skills: boundaries, hard conversations, friendship, network cultivation, social-skill practice, difficult family, apology, conflict repair, loneliness, relationship audit, dating after divorce, early-dating safety |
| [`goals/`](./goals/README.md) | 10 | Goal systems, reflection cadence, skill-breakdown blueprint, learning-task decomposition |
| [`thinking/`](./thinking/README.md) | 12 | Cognitive tools: blind spots, fresh perspective, interrogative/question modes, reframing, regret minimization, memory palace, simplification, constraint analysis |
| _(moved)_ | — | Work-effectiveness prompts now live in [`domain-productivity/`](../../domain-productivity/) — automation, meeting triage, open-loop audit, and energy audit were consolidated there so productivity has a single home. |
| [`solo-dev/`](./solo-dev/README.md) | 10 | Solo founders/freelancers: automation audit, burnout prevention, context-switching, network building, skill-gap assessment |
| [`stakeholder/`](./stakeholder/README.md) | 9 | Workplace dynamics: stakeholder navigation, org politics (cross-links `domain-negotiation/`, `domain-product-management/`) |
| [`career/`](./career/README.md) | 17 | Interactive qualification assessments for AI/ML career paths |
| [`life-transitions/`](./life-transitions/README.md) | 10 | Navigating a life change during or after it happens: new role, relocation, new parenthood, empty nest, retirement, job loss, breakup, return from leave, identity after change, transition map |
| [`emotional-fitness/`](./emotional-fitness/README.md) | 11 | Everyday non-clinical emotional skills: naming feelings, disappointment, jealousy, worry vs. action, reactivity, mixed feelings, self-compassion, reset, shame vs. guilt, charged-event debrief, money beliefs |

Three sibling clusters live one level up (not under `prompts/`):
- [`../career-transformation/`](../career-transformation/README.md) — 8 prompts for assessing and repositioning a role under structural pressure
- [`../job-search/`](../job-search/README.md) — 8 prompts for running an external job search from the candidate side
- [`../major-decisions/`](../major-decisions/README.md) — 16 prompts for high-stakes personal decisions

**Boundary reminder:** this domain is non-clinical. Acute distress, abuse/safety risk, or
mental-health crises route to a licensed professional / `domain-psychology/`. Deep-work and review
cadences live in `domain-productivity/`; money mechanics in `domain-finance/`; formal learning
curricula in `domain-learning/`.
