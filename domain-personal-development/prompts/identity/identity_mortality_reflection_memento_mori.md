# Scope a Realistic Remaining Horizon and Stop Deferring One Thing

**Objective:** Use a sober estimate of remaining time to scope — not to frighten — surface which deferred items actually have closing windows, cross-check them against how the user's weeks are really spent, and produce one first step to stop deferring the single highest-regret item.

**When to use:** A birthday or milestone has the user thinking about time; they keep saying "someday" about things that matter; or they want to reallocate attention against what is actually finite. Not for a person in acute grief, a recent bereavement, or facing a serious health diagnosis — those need care, not a scoping exercise.

**Audience:** An individual reflecting on their own finite time, with enough stability to do so calmly. **Not clinical, not morbid.** If thinking about death produces persistent dread, intrusive fear, or existential distress, this prompt is the wrong tool — see `domain-psychology/` and a licensed professional. Stop and refer if that is present.

---

## Inputs Required

1. **Age and health baseline.** Current age; rough family longevity; any major ongoing health condition; general fitness, plainly.
2. **High-mobility estimate.** The user's own guess (or ask them to derive it) of how many years of high-energy, high-mobility life are realistically ahead — not lifespan, but the vigorous years.
3. **Deferred list.** 10–20 "someday" items across categories: experiences, places, relationships, conversations, creative work, changes, risks. Specific, not "travel more."
4. **Regret probe.** What the user would most regret not doing or not becoming if the horizon turned out shorter than expected. 3–5 items.
5. **Weekly allocation.** Where a typical week actually goes, in rough hour buckets (work, obligations, screens, rest, people, the deferred priorities — if any).
6. **The recurring "later."** The one thing the user keeps saying they'll do "when things settle." One item.

If input 3 has fewer than 8 items or input 5 is missing, ask for more — the cross-check between what's deferred and where weeks go is the core of the exercise.

---

## Instructions

### Step 1 — Set a sober horizon

State a realistic remaining-years range and the high-mobility subset within it, from inputs 1–2. Acknowledge the uncertainty explicitly (it's a range, not a prediction). The purpose is to scope decisions, not to alarm. Keep the tone plain and steady — this is arithmetic, not a warning.

### Step 2 — Classify each deferred item by window

Label every item in input 3 with exactly one window type. This is where finitude becomes actionable — only some "somedays" actually degrade with time.

| # | Window | Signature | Implication |
|---|---|---|---|
| 1 | **Closing** | Depends on health, mobility, a biological window, or other people's finite time (aging parents, growing kids). Degrades year by year. | Real deadline. These are the only ones finitude makes urgent. |
| 2 | **Open** | Can happen in most any decade; no meaningful deadline (much learning, writing, many places). | No urgency from time itself. Can wait honestly. |
| 3 | **Perpetual-someday** | On the list for years, never acted on, no external block. | Often reveals the user doesn't actually want it. Dropping it is a valid, freeing outcome — not a loss. |
| 4 | **Foreclosed** | The window has genuinely passed. | Name it honestly; allow the grief; stop re-listing it. False hope keeps it costing attention. |

### Step 3 — Cross-check deferral against the week

Put the closing-window items (Type 1) next to the weekly allocation (input 5). Name plainly where the finite weeks are actually going versus what has a closing window. No moralizing — just the contrast between the arithmetic of Step 1 and the spend of input 5.

### Step 4 — Find the single highest-regret closing item

Cross the regret probe (input 4) with the Type-1 items and the recurring "later" (input 6). Name **one** item: the closing-window thing whose non-doing the user would most regret. If input 6 turns out to be a Type-2 or Type-3 (no real deadline, or not actually wanted), say so — that's a useful finding, and re-select from Type 1.

### Step 5 — One de-deferral move

Produce the **smallest concrete first step** on that one item, scheduled this week or this month. A booking, a message sent, a first hour blocked, a conversation opened, a deposit made. Physical and dated. Not "start living fully," not a bucket list, not "make the most of your time." One item, one first step, one date.

---

## Constraints

### Must
- State the horizon as a range with acknowledged uncertainty.
- Classify every deferred item into exactly one window type.
- Cross-check closing-window items against the weekly allocation.
- Name exactly one highest-regret closing item and one dated first step.
- Treat dropping a perpetual-someday item as a legitimate, non-loss outcome.

### Must Not
- Use fear, urgency-panic, or "you could die tomorrow" framing.
- Prescribe a generic bucket list or a "seize the day" program.
- Deny or gloss the grief of a genuinely foreclosed window.
- Turn the reflection into productivity-optimization of remaining lifespan.
- Continue if the user shows existential distress — refer instead.

---

## False-Positive Prevention

1. **Don't treat every deferral as a failure.** Correct sequencing exists — many Type-2 items are rightly waiting. Only closing windows (Type 1) carry urgency; don't manufacture it for the rest.
2. **Don't mourn perpetual-somedays.** A Type-3 item deferred for a decade is usually a borrowed aspiration, not a suppressed want. Naming it droppable frees attention; that's a win, not a loss.
3. **Don't manufacture panic.** The tone is sober scoping, not a countdown. Alarm produces reactive decisions, which is the opposite of the goal.
4. **Don't false-hope a foreclosed window.** "It's never too late" is untrue for some biological and time-bound things; name the closure honestly and let it be grieved — while not over-foreclosing things that are merely harder.
5. **Route existential distress out.** If the user's material shows death-anxiety, intrusive fear, or a spiral rather than reflection, stop and refer to professional support; do not push through.
6. **Don't confuse this with the full life audit.** This prompt scopes finitude and picks one deferral; `identity_life_audit_reckoning.md` cross-references six life dimensions. Route there if the reflection opens wider than one item.

## Output Format

```
## Sober horizon
Realistic remaining range: [X–Y years]. High-mobility subset: [~N years]. (A range, not a prediction.)

## Deferred items by window
| Item (input 3) | Window | Note |
|---|---|---|
| ... | Closing / Open / Perpetual / Foreclosed | ... |

Drop honestly (perpetual-someday): [items]
Grieve and stop re-listing (foreclosed): [items, if any]

## Deferral vs the week
Closing-window items: [list]. Where weeks actually go (input 5): [buckets]. The contrast: [one plain sentence].

## Highest-regret closing item
[One item], from regret probe × closing window × recurring "later."
(If input 6 was not Type 1: note it, and the re-selected item.)

## De-deferral move (this week/month)
[Smallest concrete first step, dated.]

Predicted check: after this step, [observable — booked, sent, blocked, opened].
```

## Verification

- [ ] Horizon stated as a range with acknowledged uncertainty, tone sober not alarming.
- [ ] Every deferred item classified into one window type.
- [ ] Perpetual-someday items offered as droppable, not mourned.
- [ ] Foreclosed windows named honestly without false hope.
- [ ] Closing items cross-checked against weekly allocation.
- [ ] Exactly one highest-regret closing item and one dated first step.
- [ ] No fear-framing, no bucket-list, no lifespan-optimization; distress routed to professional help if present.
