# Read In-the-Moment Jealousy as a Pointer and Convert It Into One Pursuit

**Objective:** Decode one specific flash of jealousy or envy into the precise want it's pointing at, then convert that want into one concrete pursuit you can start this week.

**When to use:** You scrolled past someone's news and felt a sting; a peer got the thing you wanted; you notice you're rooting against someone. Use it on a *specific, recent* flash. Not for a deep, long-running pattern of comparison that colors your whole self-image — that's the `identity_comparison_envy_diagnostic.md` job; this prompt is the fast, situational conversion and points there when the pattern runs deeper.

**Audience:** An individual doing this for themselves. Not for analyzing someone else's envy. Not clinical. If comparison has curdled into persistent worthlessness, obsessive rumination, or bitterness that won't lift, this skill practice is not a substitute for professional support — see `domain-psychology/client-self-use/` and a licensed professional.

---

## Inputs Required

1. **The trigger, specific.** Who or what set it off and where (a post, a promotion, a friend's trip). Name the actual thing.
2. **The exact thing they have.** Precisely what you noticed — not "their life," but "the freedom to travel," "the recognition," "the ease with people," "the body," "the money."
3. **Your first internal reaction.** Verbatim if possible ("must be nice," "I could've done that," "why not me").
4. **What you currently do toward that thing.** Honestly: are you pursuing it, avoiding it, or have you told yourself it's off-limits?
5. **Optional — a recent pattern.** If this same sting keeps recurring around the same theme, note it. (If yes, this prompt will route you to the deeper diagnostic.)

If input 2 is still "their whole life," push: envy is almost always about one specific thing. Name it before continuing.

---

## Instructions

### Step 1 — Isolate the object of envy
From input 2, name the single specific thing you actually want. Test it: if that one thing were subtracted from their situation, would the sting mostly disappear? If not, you haven't found the object yet — narrow further.

### Step 2 — Classify what the envy is telling you
Sort the want into one of these fixed categories, because the response differs by category:

| Category | Meaning | Right response |
|---|---|---|
| Signal | a real, live want you're not pursuing | convert to a pursuit |
| Access gap | you want it but believe it's off-limits to you | test the belief, then pursue or release |
| Status echo | you don't want the thing itself, only the ranking/recognition | redirect to what you actually value |
| Misfit | on inspection you don't want it; the sting is habit/comparison | release, name why it isn't yours |

Use inputs 3 and 4 as evidence for which category fits.

### Step 3 — Pressure-test the category
- If **Signal:** what have you actually done toward it (input 4)? Envy toward something you're not pursuing is the loudest signal there is.
- If **Access gap:** state the belief blocking you ("people like me don't get to X") as a claim, and note whether it's a fact or an assumption.
- If **Status echo:** ask what you'd feel if you got the recognition without the thing — if that's enough, it was never the thing.
- If **Misfit:** name the real value the comparison is trampling (your own path, timing, or priorities).

### Step 4 — Convert or release
- **Signal / Access gap:** define one concrete pursuit — a specific, bounded action toward the wanted thing this week. Physical and small: send one message, make one thing, ask one question, book one hour.
- **Status echo / Misfit:** define one concrete release move — unfollow the trigger source for a set period, or write the one-line reason it isn't yours and move on. Releasing is a legitimate outcome, not a failure.

### Step 5 — Route if it's a pattern
If input 5 shows this same theme recurs (three-plus times), flag it and route to `identity_comparison_envy_diagnostic.md` for the deeper work. This prompt handles the moment; the pattern needs the diagnostic.

---

## Constraints

### Must
- Isolate one specific object of envy before doing anything else.
- Classify into exactly one of the four categories with evidence.
- Produce one move — a pursuit or a release.
- Route recurring patterns to the deeper diagnostic.

### Must Not
- Shame the user for feeling envy — it's information, not a character flaw.
- Moralize ("comparison is the thief of joy") in place of decoding.
- Convert every case into a pursuit; release and misfit are real outcomes.
- Recommend an affirmation, a gratitude list, or "focus on your own journey" as the action.

---

## False-Positive Prevention

1. **Don't accept "their whole life" as the object.** Envy is specific; if it's still global, the decode isn't done.
2. **Don't default to Signal.** Some envy is status echo or misfit — forcing a pursuit toward something you don't want wastes effort. Check inputs 3–4.
3. **Don't confuse wanting the thing with wanting the ranking.** Status echo feels identical in the moment; the "recognition-without-the-thing" test separates them.
4. **Don't treat an access-gap belief as a fact.** "People like me don't get X" is usually an assumption; label it as such.
5. **Don't pursue on a whim you'll drop in two days.** The pursuit must be one small bounded action, not a life pivot decided from a sting.
6. **Don't mistake recurring corrosive comparison for a one-off.** If input 5 flags a pattern, route out — this prompt isn't the container for chronic comparison.

## Output Format

```
## The object of envy
Specific thing you actually want: [one thing]. (Subtract-test: [pass/fail].)

## What it's telling you
Category: [Signal / Access gap / Status echo / Misfit]
Evidence: [from inputs 3–4]

## Pressure test
[Category-specific finding in 1–2 lines.]

## The move
[Pursuit OR release — one concrete, bounded action this week.]

## Pattern check
[One-off — done. | Recurring theme → run identity_comparison_envy_diagnostic.md.]

Predicted check: next time this trigger appears, [observable difference — you act on the want, or the sting is quieter because you named it a misfit].
```

## Verification

- [ ] One specific object of envy isolated and subtract-tested.
- [ ] Exactly one category assigned, backed by input evidence.
- [ ] Category-appropriate move produced (not every case a pursuit).
- [ ] Move is one bounded action, not a life change.
- [ ] Recurring pattern routed to the identity diagnostic.
- [ ] No shaming, no gratitude-list filler.
- [ ] Persistent/corrosive comparison routed to professional support.
