# Turn a Vague 'Bad' Feeling Into Named Emotions and the Need Underneath

**Objective:** Resolve one vague feeling ("bad," "off," "weird," "meh") into 2–4 precisely named emotions and the specific unmet need each is pointing at, ending with one concrete thing to do about the top need.

**When to use:** You feel "off" and can't say why; you're irritable or flat and it's leaking into how you treat people; you want to name what's happening before a conversation or decision. Not for a feeling you can already name precisely and act on — you don't need this for that.

**Audience:** An individual doing this for themselves. Not for labeling someone else's emotions, and not clinical. If low or anxious feelings are persistent (most days for two-plus weeks), intense, or safety-relevant, this skill practice is not a substitute for professional support — see `domain-psychology/client-self-use/` and a licensed professional.

---

## Inputs Required

1. **The raw feeling, in your words.** Whatever you'd actually say: "bad," "off," "heavy," "wired," "meh." One to five words.
2. **When it started / when it's worst.** Rough timing and any situation it attaches to (a meeting, a text, evenings, Sunday nights).
3. **Body signal.** Where you feel it and how (tight chest, clenched jaw, heavy limbs, restless legs, nothing physical). Guessing is fine.
4. **What just happened before it (last 24h).** 2–4 concrete events, neutral facts only — what occurred, not what it meant.

If you can only give input 1 and nothing else, that's enough to start, but say so — the naming will be coarser.

---

## Instructions

### Step 1 — Widen the vocabulary
Map the raw word onto a fixed emotion family, then get specific inside it. Use this taxonomy:

| Family | Specific emotions to test against the evidence |
|---|---|
| Fear/anxiety | worried, nervous, dread, overwhelmed, insecure, exposed |
| Anger | irritated, resentful, frustrated, indignant, contempt |
| Sadness | disappointed, lonely, discouraged, grief, wistful |
| Shame/guilt | embarrassed, inadequate, regretful, self-critical |
| Disgust | put-off, contempt, revulsion |
| Fatigue/flat | depleted, bored, numb, restless, indifferent |

Pick the 2–4 specific words that best fit inputs 2–4. "Bad" almost always contains more than one.

### Step 2 — Attach evidence to each name
For each named emotion, cite the specific input that supports it (an event, the timing, the body signal). An emotion with no supporting evidence gets dropped — you're naming, not free-associating.

### Step 3 — Find the need underneath each
Every emotion points at a need. Name the specific unmet need behind each named emotion using this map, then make it concrete:

- Fear/anxiety → safety, predictability, competence, control
- Anger → a boundary crossed, fairness, respect, autonomy
- Sadness → connection, meaning, something lost
- Shame/guilt → belonging, living up to a standard you hold, repair
- Fatigue/flat → rest, stimulation, or a want that's been ignored

State the need as *this specific* need ("I need to know the deadline is real," not "I need security").

### Step 4 — Rank and pick the load-bearing one
Rank the 2–4 needs by which is doing the most weight right now — the one that, if met, would deflate most of the feeling. Choose one.

### Step 5 — One concrete move on the top need
Propose one physical, bounded action that addresses the top need — a specific message to send, a question to ask, a thing to put down, a 20-minute rest, a boundary to state. Not "process it" or "sit with it." If the honest answer is that the need is rest, name rest as the action.

---

## Constraints

### Must
- Produce at least 2 named emotions, each with cited evidence from the inputs.
- Name one specific unmet need per emotion, stated concretely.
- Converge on exactly one need and one action.
- Keep the action physical and time-bounded.

### Must Not
- Return the raw word ("you feel bad") as if it were a named emotion.
- Name an emotion with no supporting evidence in the inputs.
- Offer generic advice (journal, breathe, self-care) as the action.
- Diagnose (no "this is anxiety/depression"); name the situational feeling only.
- Moralize about the feeling or reassure it away.

---

## False-Positive Prevention

1. **Don't inflate a single mood into a condition.** One flat evening is fatigue or disappointment, not "depression." Stay at the level of this feeling, today.
2. **Don't over-name.** If only one emotion is genuinely supported, say one — padding to four dilutes the signal.
3. **Don't confuse the trigger with the need.** "A rude email" is the trigger; the need might be respect or clarity. Push past the event to the want.
4. **Don't treat physical fatigue as an emotion to interpret.** If input 3 is "exhausted" and input 4 is "slept 4 hours," the answer is sleep, not analysis.
5. **Don't accept borrowed labels.** If the named emotion is one the user thinks they *should* feel rather than what the evidence shows, drop it.
6. **Don't force a need where the honest read is "I don't know yet."** Mark it uncertain rather than inventing one.

---

## Output Format

```
## Raw feeling
[input 1], noticed [timing], felt as [body signal].

## Named emotions (with evidence)
1. [specific emotion] — evidence: [event / timing / body]
2. [specific emotion] — evidence: ...
[up to 4]

## The need under each
- [emotion] → [specific unmet need]
- ...

## Load-bearing need
[The one need carrying the most weight, in one sentence, and why.]

## One move
[Physical, bounded action addressing that need, by when.]

Predicted check: after this, the [raw feeling] should [specific expected shift]. If it doesn't move at all, the real need was mis-named.
```

---

## Verification

- [ ] At least 2 emotions named at specific-word level, not "bad/off."
- [ ] Every named emotion cites evidence from the inputs.
- [ ] Each emotion is mapped to one concrete unmet need.
- [ ] Exactly one need chosen and one physical action produced.
- [ ] No diagnosis or condition language.
- [ ] No generic self-care filler; rest named plainly if that's the answer.
- [ ] Persistent/intense/safety-relevant distress routed to professional support.
