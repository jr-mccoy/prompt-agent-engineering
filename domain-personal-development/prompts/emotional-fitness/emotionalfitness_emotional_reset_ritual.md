# Design a Personal Cooldown Ritual for After a Charged Moment

**Objective:** Build one short, repeatable cooldown ritual — a physiological down-regulation step plus a re-entry cue — tuned to what has actually worked for you before, so a charged moment (an argument, bad news, a tense call) doesn't spill into the next hours.

**When to use:** You know you get hijacked after certain moments and stay wound up long past the event; you want a default you can run instead of doom-scrolling, snapping at the next person, or stewing. Design it *before* you need it. Not a panic protocol and not a substitute for de-escalating a live crisis — for panic or crisis, see the clinical resources below.

**Audience:** An individual doing this for themselves. Not clinical. If you experience panic attacks, dissociation, flashbacks, or distress you can't bring down with an everyday cooldown, this skill practice is not a substitute for professional support — see `domain-psychology/client-self-use/coping-by-concern/clientself_anxiety_grounding_menu_builder.md`, `domain-psychology/client-self-use/coping-by-concern/clientself_trauma_flashback_grounding_script.md`, and a licensed professional.

---

## Inputs Required

1. **The kind of charged moment this is for.** Be specific: after conflict, after bad news, after a high-stakes performance, after a tense work call.
2. **What already helps you settle.** Anything you've noticed actually brings you down — a walk, cold water, a specific song, silence, a shower, being outside, tidying, a particular person. Evidence from your own past, not what "should" help.
3. **What you currently do instead.** The default that doesn't help — scrolling, venting to the wrong person, replaying it, eating, snapping.
4. **Constraints.** How much time you realistically have after these moments (2 minutes / 15 minutes / an hour), and where you usually are (office, home, car, in public).
5. **The re-entry you need.** What you have to be able to do next (go back into a meeting, be present with your kids, sleep, keep working).

If input 2 is empty ("nothing helps"), start the ritual from the physiological menu in Step 2 and treat the first run as an experiment.

---

## Instructions

### Step 1 — Set the ritual's job
State plainly what the ritual has to accomplish given inputs 1 and 5: bring the body down *from* [activated state] enough to *do* [re-entry task] within [time from input 4]. This defines success and rules out rituals that are too long or don't match the re-entry.

### Step 2 — Pick one down-regulation step
Choose one physiological down-regulation action that fits input 4's time and place, prioritizing anything from input 2 that already works. Use this menu only to fill gaps:

| Down-regulation lever | Examples (pick what fits time/place) |
|---|---|
| Breath | slow exhale-longer-than-inhale for ~1–2 min |
| Temperature | cold water on face/wrists, step into cool air |
| Movement | a brisk walk, stairs, shaking out the arms |
| Sensory anchor | name 5 things you see/hear; hold a textured object |
| Discharge | tidy one surface, wash the mug, a physical task |

One lever, not five. It must be doable in the actual time and place from input 4.

### Step 3 — Add the re-entry cue
Attach a single cue that signals "cooldown over, re-entering" — because the risk is either never coming back or re-entering still hot. The cue is small and concrete: a sentence to say ("okay, back"), a physical marker (stand up, splash face, put the phone down in another room), or a specific first task of the re-entry. Tie it to input 5.

### Step 4 — Block the old default
Name the specific counter-move to input 3's unhelpful default: if the default is scrolling, the ritual starts with the phone going face-down in another room; if it's venting to the wrong person, the ritual routes the venting to a note or the right person later. The ritual has to *displace* the old habit, not just sit beside it.

### Step 5 — Write it as a fixed sequence and set the trial
Write the ritual as a short numbered sequence (2–4 steps, under the time budget). State when you'll first run it and one observable check: after running it, can you do the re-entry task without the charge leaking in? Treat the first three runs as tuning — swap the down-regulation lever if it doesn't settle you.

---

## Constraints

### Must
- Fit the ritual inside input 4's real time and place.
- Include exactly one down-regulation step and one re-entry cue.
- Displace the specific unhelpful default from input 3.
- Prioritize levers with personal evidence (input 2) over generic ones.
- End as a fixed, short, numbered sequence with a trial check.

### Must Not
- Prescribe a long meditation or a multi-part routine that won't survive a real charged moment.
- Recommend generic "self-care" (bubble baths, journaling for an hour) untethered to the re-entry need.
- Assume a lever works because it's popular — use the user's own evidence.
- Present a menu as the deliverable — converge on one ritual.

---

## False-Positive Prevention

1. **Don't design for ideal conditions.** If the charged moment usually happens at the office with 3 minutes before the next call, a 20-minute walk isn't the ritual. Match input 4 exactly.
2. **Don't skip the re-entry cue.** A down-regulation with no re-entry either becomes avoidance or leaves you re-entering still hot.
3. **Don't ignore the personal-evidence input.** A lever that has never settled this person won't start now because a table listed it.
4. **Don't let the ritual coexist with the old default.** If it doesn't physically displace the scrolling/venting, it won't run.
5. **Don't over-engineer.** More than 4 steps and it won't happen under pressure. Fewer, fixed, repeatable.
6. **Don't use this for panic or trauma activation.** If the "charge" is a panic attack, dissociation, or flashback, an everyday cooldown is the wrong tool — route to the clinical grounding resources and professional support.

## Output Format

```
## The ritual's job
Bring me down from [activated state] enough to [re-entry task] within [time].

## The ritual (fixed sequence)
1. [Block the old default — the specific counter-move to input 3.]
2. [One down-regulation step, fitted to time/place.]
3. [Re-entry cue tied to input 5.]
(≤4 steps, under [time budget].)

## Why these levers
Down-regulation: [chosen lever] — [personal evidence or experiment note].
Re-entry cue: [cue] — matches needing to [input 5].

## Trial
First run: [when]. Check: after it, can I [re-entry task] without the charge leaking in? Tune the lever if not, over the first 3 runs.
```
