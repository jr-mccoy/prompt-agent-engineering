# Resilience & Motivation Prompts

Structured tools for recovering from setbacks, diagnosing flagging motivation, building consistency that doesn't depend on willpower, and reducing fragility under stress. These sit alongside the agency (action) and identity (self) clusters: resilience is about how the user **absorbs hits and keeps moving** rather than how they start or who they are.

These prompts assume the user is willing to look at their own evidence — what actually happened, what they controlled, how their circumstances respond to shocks — rather than reach for affirmations, "catch-up" heroics, or generic "be more disciplined" advice. Each prompt picks one bounded diagnosis or produces one concrete next move, and verifies by prediction.

## Clinical boundary (read first)

**These are non-clinical self-direction tools, not therapy or crisis support.** They help with ordinary setbacks, dips in motivation, inconsistency, and structural fragility. They are **not** appropriate when the underlying issue is clinical, and every prompt in this cluster carries an explicit boundary note to that effect.

**Refuse and refer** when the user shows:
- Persistent hopelessness, depression, or anhedonia (nothing feels good for weeks) → licensed professional / `domain-psychology/`
- Burnout that rest does not touch → `agency_burnout_recovery.md`, and a clinician if it persists
- Panic, severe anxiety, trauma response, eating disorder, or substance dependence → professional support
- **Any thought of self-harm** → immediate professional support; in the US, call or text **988**

Resilience framing — recovery ladders, antifragility, discipline systems, streak charts — does not substitute for clinical care and can compound self-blame when misapplied to a clinical problem. When in doubt, refer.

## Scope

**In scope:**
- Recovery sequencing after a specific setback or failure
- Motivation-driver diagnosis (clarity / energy / reward / identity)
- Willpower-independent discipline/behavior systems
- Signal extraction from failure between toxic positivity and self-condemnation
- Fragility / robustness / antifragility audits across life domains
- Momentum rebuilding after a long stall
- Recovery from a specific rejection (job / pitch / submission / relationship)
- Processing harsh criticism — separating delivery-sting from testable signal
- Rebuilding grounded confidence after a visible failure via evidence and proof-reps
- Building tolerance for one bounded, unresolved high-uncertainty situation
- Non-clinical re-entry after a low period that is already lifting

**Out of scope (refuse and refer):**
- Clinical mental health (depression, anxiety, trauma, eating disorders, addiction, suicidal ideation) → professional support / `domain-psychology/`
- Medical decisions → physician
- Specific financial planning → out of repository
- "Why"/identity questions about whether to continue at all → `domain-personal-development/prompts/identity/`

## Composition patterns

These prompts are designed to compose. Common chains:

- **Setback route:** `resilience_setback_recovery_framework` (stabilize → re-enter) → if learning is wanted → `resilience_failure_reframe` → if a stall followed → `resilience_momentum_rebuild`.
- **Low-motivation route:** `resilience_motivation_diagnosis` → if "reward" or structure is the gap → `resilience_self_discipline_system`; if "identity" → `identity_purpose_reignition`; if "energy" (global) → `agency_burnout_recovery`.
- **Stall route:** `resilience_momentum_rebuild` (complements `agency_stuck_diagnosis` category 10/12 — depletion and loss-of-why route out before momentum tactics).
- **Structural-exposure route:** `resilience_anti_fragility_audit` → de-fragilizing moves stuck in place with `resilience_self_discipline_system`; career-specific exposure → `career_role_structural_vulnerability`.
- **Rejection/criticism route:** `resilience_rejection_recovery` (a no) or `resilience_criticism_processing` (harsh feedback) → if either dented confidence in a domain → `resilience_confidence_rebuild_after_failure`; if the self-story turned global → `identity_self_talk_audit`.
- **Uncertainty route:** `resilience_uncertainty_tolerance_builder` for one bounded open situation; a pattern of chronic worry across everything routes out to `domain-psychology/`.
- **Low-period route:** `resilience_comeback_after_burnout_dip` (whole-life re-entry, dip already lifting) — distinct from `resilience_momentum_rebuild` (single stalled project); an unlifted dip routes to `agency_burnout_recovery` / `domain-psychology/`.

## What the prompts refuse

- Affirmations and "you've got this" reassurance unconnected to evidence
- Toxic positivity ("it was a blessing," "everything happens for a reason")
- "Just be more disciplined / want it more" as a mechanism
- Catch-up heroics and make-up-for-lost-time pushes
- Uncapped-downside risk taken in the name of "antifragility"
- Clinical interpretation of any kind

## File map

| Prompt | Purpose |
|---|---|
| `resilience_setback_recovery_framework.md` | After a concrete setback: stabilize → contain → attribute cause (controllable/influenceable/uncontrollable) → one re-entry action. |
| `resilience_motivation_diagnosis.md` | Diagnose which single driver is missing — clarity / energy / reward / identity — and prescribe the matching move. |
| `resilience_self_discipline_system.md` | Build a consistency system on four levers (default / friction / commitment / feedback) that runs without willpower. |
| `resilience_failure_reframe.md` | Extract transferable lessons from a failure while avoiding both toxic positivity and self-condemnation. |
| `resilience_anti_fragility_audit.md` | Classify life domains as fragile / robust / antifragile, rank fragilities, prescribe ≤3 barbell moves. |
| `resilience_momentum_rebuild.md` | Rebuild momentum after a long stall via a graded re-entry ladder (anti-heroic); cross-links `agency_stuck_diagnosis`. |
| `resilience_rejection_recovery.md` | After a specific rejection (job/pitch/submission/relationship): separate the no from self-worth → classify the signal type → extract only real signal → base-rate check → one re-entry action. |
| `resilience_criticism_processing.md` | Process harsh criticism: split delivery from content → decompose into discrete claims → verdict each (true/partly/false/taste) weighted by source credibility → decide one change or none. |
| `resilience_confidence_rebuild_after_failure.md` | Rebuild grounded confidence after a visible failure via cited evidence + graded real proof-reps (not affirmations); diagnoses miscalibrated-low vs. accurately-lowered. |
| `resilience_uncertainty_tolerance_builder.md` | Build tolerance for one unresolved high-uncertainty situation: sort knowable-now / knowable-later / unknowable → resolve, control, and park with a mechanism. Not a generalized-anxiety protocol. |
| `resilience_comeback_after_burnout_dip.md` | Non-clinical whole-life re-entry after a low period that is *already lifting*: screen → restore baseline → sequence one gentle re-contact at a time → no catch-up heroics. Refers unlifted dips out. |
