# Rebuild Grounded Confidence After a Visible Failure Through Proof-Reps

**Objective:** Restore confidence after a visible failure using cited evidence and a graded sequence of real proof-reps — not affirmations — so the rebuilt confidence tracks demonstrated capability.

**When to use:** A public or high-stakes failure (a botched launch, a demo that flopped, a project that collapsed on your watch) has left the user believing they "can't do this anymore." Useful when the confidence drop feels larger than the actual competence change. **Not for this:** general impostor feelings or overconfidence unattached to a specific failure — use `identity_confidence_calibration.md`; or extracting lessons from the failure itself — use `resilience_failure_reframe.md`.

**Audience:** An individual rebuilding their own confidence. Not for coaching someone else, and not clinical. If the failure has produced pervasive worthlessness, hopelessness, or any thought of self-harm, this is not a substitute for professional support — see `domain-psychology/` and a licensed professional. In the US, call or text 988.

---

## Inputs Required

1. **The visible failure**, specifically, and how public it was.
2. **The current confidence claim**, verbatim ("I can't lead a project," "I've lost my touch").
3. **The domain** the confidence collapsed in — as narrow as it really is.
4. **Pre-failure track record.** Real, cited evidence of past competence in this domain — completed work, prior wins, skills demonstrated.
5. **What the failure revealed**, honestly — a genuine, nameable gap, or just a bad result.

If input 4 is empty (no prior track record in the domain at all), this is not confidence *rebuilding* — it's confidence *building* from zero, which is a different task; say so. If input 5 is unclear, ask whether the failure exposed a real gap before proceeding.

---

## Instructions

### Step 1 — Bound the collapse to its domain

Confidence should track evidence, not the last data point. State precisely which narrow domain took the hit (input 3) and refuse to let it generalize — "this launch failed" is not "I fail at everything." Name any generalization in input 2 and bound it.

### Step 2 — Inventory disconfirming evidence

From input 4, list the real, specific past performances the single failure does not erase. Cite each concretely. No affirmations, no "you're talented" — only demonstrated facts. This is the evidence base the rebuild stands on.

### Step 3 — Diagnose the confidence gap

Classify with this fixed two-way split:

| Case | Signal | Rebuild path |
|---|---|---|
| **Miscalibrated low** | Track record (Step 2) shows capability; the failure was situational/unlucky, but the feeling collapsed anyway. | Reconverge feeling with evidence via proof-reps; no new skill needed. |
| **Accurately lowered** | The failure revealed a real, nameable gap (input 5); confidence dropped for a true reason. | Close the specific gap *first*, then proof-reps. Don't reassure past a real deficit. |

### Step 4 — Design proof-reps

Build a graded sequence of **3–5 real, verifiable performances** in the domain. Each rep must be:
- **Real** — an actual task with an observable outcome, not a rehearsal or a mantra.
- **Genuinely uncertain** — a true test (a rep you're guaranteed to win proves nothing).
- **Winnable** — sized so success is plausible; the first rep is small.

If Step 3 returned "accurately lowered," rep 1 targets the named gap directly.

### Step 5 — Set the evidence rule

Confidence updates on **completed reps**, not on how the user feels before or during them. State this rule explicitly: feelings lag evidence, so the user acts first and lets the completed reps move the needle — the opposite of waiting to "feel ready."

---

## Constraints

### Must
- Bound the confidence collapse to its specific domain.
- Inventory only real, cited disconfirming evidence.
- Diagnose miscalibrated-low vs. accurately-lowered before prescribing.
- Design 3–5 real, uncertain, winnable proof-reps.
- State the rule that confidence updates on completed reps, not feelings.

### Must Not
- Rebuild via affirmations, mantras, or "you've got this" reassurance.
- Reassure past a real, named gap (the accurately-lowered case).
- Make proof-reps trivially easy (no evidence value) or oversized (manufactures another failure).
- Generalize one domain's failure to global confidence, or vice versa.
- Diagnose any mental-health condition.

---

## False-Positive Prevention

1. **Don't substitute affirmations for evidence.** Unearned confidence built on self-talk collapses at the next real test. Only completed reps count.
2. **Don't treat an accurate drop as miscalibration.** If the failure exposed a genuine gap, the confidence drop is *correct* — close the gap; don't talk the user out of an accurate read.
3. **Don't rig the proof-reps.** A rep you cannot lose generates no evidence; a rep you cannot win generates a second failure. Hold the middle.
4. **Don't let the domain creep.** Keep the collapse and the reps inside the narrow domain; "I failed at this pitch" must not become "I'm rebuilding my whole self-worth."
5. **Don't conflate confidence with competence.** Reps build both, but a competent person can still feel unready — the rule (act, then update) is what closes that gap.
6. **Don't run this on clinical worthlessness.** Pervasive, self-defining hopelessness is not a proof-rep target — refer (see Audience).

## Output Format

```
## Bounded domain
The hit is confined to: [narrow domain]. Your claim "[input 2]" overgeneralizes — corrected to [bounded statement].

## Disconfirming evidence (cited, real)
- [Past performance 1 — concrete]
- [Past performance 2 — concrete]
- ...

## Diagnosis
[Miscalibrated low / Accurately lowered] — because [evidence vs. input 5]. Rebuild path: [reconverge / close gap then reps].

## Proof-reps (graded)
1. [Small, real, uncertain, winnable task — observable outcome] (targets the gap, if any)
2. [Next rep]
3. [Next rep]
...

## Evidence rule
Confidence updates on completed reps, not on how you feel going in. Act first; let the reps move the needle.

Predicted check: after reps 1–2, your confidence claim shifts from "I can't" to a claim your completed reps support.
```

## Verification

- [ ] The collapse is bounded to a specific narrow domain.
- [ ] Disconfirming evidence is real and cited — no affirmations.
- [ ] Miscalibrated-low vs. accurately-lowered is diagnosed before prescribing.
- [ ] 3–5 proof-reps are real, genuinely uncertain, and winnable; rep 1 targets any named gap.
- [ ] The "update on completed reps, not feelings" rule is stated.
- [ ] No generalization across domains; competence and confidence kept distinct.
- [ ] Clinical boundary honored; referral issued if worthlessness is pervasive/clinical.
