# Deepen One Pleasant-but-Shallow Friendship Without Forcing It

**Objective:** Move one specific friendship from pleasant-but-surface toward genuine closeness — by calibrating self-disclosure and shared experience to what the other person actually reciprocates, so depth grows instead of being forced.

**When to use:** You have a friend you like and see somewhat regularly, but it never gets past small talk, logistics, or activity-only contact, and you want more. Also useful for a friendship that plateaued after an initial promising start. Not for making new friends from scratch — use `relationships_making_friends_as_adult.md`; not for a friendship in conflict or after a rupture — use `relationships_conflict_repair_guide.md`.

**Audience:** An individual doing this for themselves. Not for assessing someone else, not clinical. If the wish for closeness is entangled with a fear of being fundamentally unlovable or persistent loneliness, this is not a substitute for professional support — see domain-psychology/ and a licensed professional.

---

## Inputs Required

1. **The friendship.** Who (role/context), how long, how often you actually interact, and in what mode (in person, texts, activity-only, group-only).
2. **What "shallow" looks like here.** The specific ceiling — e.g., "we only ever talk about the game," "always in a group, never one-on-one," "she shares real things but I keep it light," "we text memes but never call."
3. **Their reciprocation signals so far.** Concrete evidence of how the other person has responded when things got slightly more personal — did they open up back, deflect, change the subject, follow up later? Required, because it sets the safe pace.
4. **What you're hoping for.** The kind of closeness wanted — a confidant, a regular one-on-one, someone for a specific shared pursuit. One line.
5. **Your own pattern.** Whether you tend to over-disclose too fast or stay guarded. Optional but useful for calibration.

If input 3 is missing (no read on how the other person responds to any personal touch), do not prescribe escalating vulnerability. State the minimum bar: depth is co-created, so the first task is a small disclosure test to read reciprocation before planning further.

---

## Instructions

### Step 1 — Name the specific depth that's missing

Depth is not one thing. Classify which dimension is thin using this fixed taxonomy:

| Dimension | Shallow version | Deep version |
|---|---|---|
| **Disclosure** | Facts, logistics, opinions | Feelings, fears, what's actually going on |
| **Frequency/mode** | Group-only, or text-only | One-on-one, real-time |
| **Shared experience** | Same activity, low stakes | Something meaningful done together |
| **Reliability** | Fun when convenient | Shows up when it counts |

Pick the **one** dimension whose absence is the real ceiling. That's the lever.

### Step 2 — Read the reciprocation gradient

From input 3, gauge how the friend responds to a slightly-more-personal move: **Opens back / Neutral-receptive / Deflects / Withdraws**. This sets the pace. Reciprocity is the rule of intimacy — disclosure that isn't returned, repeated, feels like a leak, not closeness. Do not plan escalation faster than the friend has shown they'll match.

### Step 3 — Design one graduated step, not a leap

Vulnerability builds in matched increments, each roughly one notch past the last. Propose the **next single step** on the chosen dimension:
- Disclosure: share one real (not raw) thing and watch whether it's met — e.g., name an actual worry instead of "busy, you know how it is."
- Frequency/mode: convert one group hang or text thread into one one-on-one — a walk, a call, a coffee.
- Shared experience: propose one thing with more meaning than the usual — help with a move, a longer trip, showing up to something they care about.
- Reliability: show up unprompted at a moment that matters to them.

The step must be reversible and low-cost if unreciprocated — a probe, not a declaration.

### Step 4 — Match, don't outrun

State the rule explicitly: after the step, read the response. If reciprocated, the next step can go one notch further. If deflected or unreturned, hold at the current level — the friendship may be a good light one, and forcing depth erodes even that. Depth is offered, not extracted.

### Step 5 — Guard against the two failure modes (QA-20)

- **Forcing:** intensity, trauma-dumping, "why aren't we closer?" conversations, or pushing one-on-one on someone who keeps it group. This scares people.
- **Waiting forever:** staying at meme-level indefinitely because any move feels risky. This guarantees the ceiling holds.
Name which failure mode this user is more prone to (from input 5) and rail against it specifically.

### Step 6 — Set the next single move

One concrete step for the next two weeks: the disclosure, invitation, or gesture, with when. Not a campaign — the next probe, and the observable signal that tells the user whether to go further or hold.

## Constraints

### Must
- Identify the one depth dimension that is the real ceiling.
- Set pace by the friend's demonstrated reciprocation, not the user's desire.
- Propose one graduated, reversible step — not a leap.
- State the match-don't-outrun rule explicitly.
- End with one concrete next move and its read-signal.

### Must Not
- Prescribe escalating vulnerability without evidence the friend reciprocates.
- Recommend a "let's define this friendship" conversation as the opening move.
- Treat forced closeness or intensity as depth.
- Pathologize a friend who prefers a lighter tie — not every friendship is meant to be deep.
- Promise the friendship will deepen; the user controls the offer, not the response.

---

## False-Positive Prevention

1. **One-sided escalation.** Disclosing deeply to someone who doesn't return it isn't building closeness — it's a leak that leaves the user exposed. Gate every step on reciprocation.
2. **Intensity mistaken for intimacy.** A dramatic heart-to-heart doesn't create a deep friendship; matched, repeated, ordinary disclosure does. Watch for a plan that front-loads intensity.
3. **The DTR trap.** "Define the relationship" talks belong to romance, not friendship. A friend asked "why aren't we closer?" usually gets more distant. Deepen through behavior, not meta-conversation.
4. **Forcing a light tie to be heavy.** Some friends are activity-buddies and that's genuinely good. If the evidence shows they keep it light, the finding may be "enjoy this as-is," not "push."
5. **Guarded user reading caution as safety.** If the user always waits for the other person to go first, nothing moves. Prompt a small first offer, calibrated but real.
6. **Depth-hunger from loneliness, not from this friend.** If any pleasant friend would do and the real driver is broad loneliness, route to `relationships_loneliness_diagnostic_plan.md` rather than over-investing in one person.
