# Startup Brainstorming Prompts

A comprehensive library of prompts designed to help founders and teams brainstorm, develop, and refine all aspects of their startup's brand identity—from naming to messaging.

## Overview

This collection provides structured prompts for every stage of startup branding:

| Category | Purpose | Prompts |
|----------|---------|---------|
| **Naming** | Generate company and app names | 2 |
| **Brand Identity** | Define strategy, values, personality | 3 |
| **App Store Assets** | Create icons, screenshots | 2 |
| **Copy** | Write taglines, descriptions, tone guides | 4 |
| **Story** | Craft origin stories and narratives | 2 |
| **Monetization** | Choose and tune a revenue model | 7 |
| **Founder Operations** | Decisions, metrics, and support for a solo operator | 3 |
| **Positioning Diagnostics** | Stage, hypothesis, and product-market-fit checks | 3 |

**Total: 26 prompts**

## Quick Start

### New to Startups?
Start with these prompts in order:
1. [Brand Strategy](brand-identity/startup_brand_strategy.md) - Establish your foundation
2. [Company Name Generator](naming/startup_company_name_generator.md) - Name your venture
3. [Brand Personality](brand-identity/startup_brand_personality.md) - Define your character
4. [Value Proposition](copy/startup_value_proposition.md) - Articulate your value

### Launching an App?
Follow this sequence:
1. [App Name Generator](naming/startup_app_name_generator.md)
2. [App Icon Concept](app-store-assets/startup_app_icon_concept.md)
3. [Screenshot Strategy](app-store-assets/startup_screenshot_strategy.md)
4. [App Store Description](copy/startup_app_store_description.md)

```
Brand Strategy → Brand Values → Brand Personality → Company Name
      ↓
Tagline → Value Proposition → Tone of Voice
      ↓
Origin Story → Brand Narrative
```

### Mobile App Launch
```

      ↓
App Store Description
```
