# SOAP Study Method

**Objective:** Give a simple, repeatable daily-study structure — Scripture, Observation, Application, Prayer — that a new or busy reader can sustain, while keeping quotation accurate and interpretation honest.

**When to use:**
- Building a daily Bible-reading habit.
- You want structure without complexity.
- Journaling through a book or reading plan.

**When NOT to use:**
- You need in-depth study — use the inductive or exegesis prompts.

**Audience:** Laypeople / new readers (L). Plain language.

---

## Inputs / Context

1. **The passage.** Reference and the verse(s) in the reader's translation (pasted by the user). The model uses the supplied text, never quotes from memory.
2. **The reader's situation (optional).** What's going on in life, to ground application and prayer.

---

## Constraints

### Must
- Use the **Scripture** exactly as the user supplied it (a named translation); if not supplied, ask for it rather than quoting from memory.
- Keep Observation simple and text-based; keep Application specific and personal.
- Make Prayer a genuine response to the passage, not a formula.

### Must Not
- Quote or paraphrase the verse from memory (risk of misquotation).
- Add interpretation beyond what the text supports, or impose a tradition's conclusion.
- Invent cross-references or background.

### Tradition-neutral stance (Must / Must Not)
- **Must:** keep observation/application broadly applicable; note if a verse is commonly read differently across traditions.
- **Must Not:** steer the devotional toward one tradition's distinctive doctrine.

---

## Instructions

### Step 1 — Scripture
Record the passage reference and the user-supplied wording. (If absent, request it.)

### Step 2 — Observation
Note 2–4 plain observations from the text.

### Step 3 — Application
Draw one specific, honest application connected to the reader's situation.

### Step 4 — Prayer
Compose a short prayer responding to what the passage says and the application drawn.

---

## Output Format

```
# SOAP — [reference]

## S — Scripture
"[user-supplied wording]" ([translation])

## O — Observation
- [observation] / [observation]

## A — Application
- [one specific application]

## P — Prayer
[short prayer responding to the text]
```

---

## Verification

- [ ] Scripture used exactly as supplied (no memory quote).
- [ ] Observations text-based and simple.
- [ ] Application specific and honest.
- [ ] Prayer responds to the passage.
- [ ] No invented cross-references/background; no tradition imposed.

---

## False-Positive Prevention

❌ **DON'T:**
- Fill in the verse text from memory.
- Stretch the passage into an application it doesn't support.
- Add a doctrinal spin not present in the text.

✅ **DO:**
- Use the reader's supplied translation wording.
- Keep observation plain and application specific.
- Let the prayer flow from the passage itself.
