# Text-to-Application Bridge Builder

**Objective:** Build honest, specific application from a passage by moving deliberately from the text's **original meaning** → **timeless principle** → **today's situations**, so application is grounded in what the text actually says rather than imposed on it.

**When to use:**
- You understand a passage and need to apply it faithfully (teaching, preaching, personal).
- Your applications feel forced or moralistic and you want them text-grounded.

**When NOT to use:**
- You haven't yet interpreted the passage — do exegesis or inductive study first.

**Audience:** Laypeople (L), group leaders (G), pastors (P).

---

## Inputs / Context

1. **The passage and its meaning.** Reference, text (user-supplied), and the interpretation reached.
2. **Audience/situation.** Who the application is for.
3. **Declared tradition (optional).** May shape application emphasis; where the underlying reading is contested, note it.

---

## Constraints

### Must
- Establish the **original point** first (what it meant for the original audience).
- Abstract a **timeless principle** that genuinely follows from the original point.
- Transfer to **today** with specific, varied applications that fit the principle.
- Distinguish what the text **commands/teaches** from wise **inference** and from mere **possibility**.
- Account for context: covenant/redemptive-historical setting matters (e.g., not every command transfers identically) — note this without ruling on contested cases.

### Must Not
- Jump to application without the original point (eisegesis/moralizing).
- Manufacture applications the principle doesn't support, or universalize a culturally specific instruction without acknowledgment.
- Invent supporting cross-references or facts.
- Force a contested interpretation as the basis for application.

### Tradition-neutral stance (Must / Must Not)
- **Must:** where application depends on a contested reading, flag it and note the alternative(s).
- **Must Not:** present a tradition's contested application as the only faithful one.

---

## Instructions

### Step 1 — Original point
State what the passage meant for its first audience, in context.

### Step 2 — Principle
Abstract the underlying timeless principle that follows from the original point.

### Step 3 — Transfer to today
Generate specific applications for the audience's situations, each tagged command/teaching, wise inference, or possibility.

### Step 4 — Context check
Note any reason the transfer isn't one-to-one (redemptive-historical, cultural, covenantal), flagging contested cases without ruling.

### Step 5 — Honesty pass
Confirm each application traces to the principle and the text; cut anything imposed.

---

## Output Format

```
# Application Bridge — [reference]

## Original point
- [what it meant for the first audience]

## Timeless principle
- [principle that follows]

## Application today
- [application] — command/teaching | wise inference | possibility
- ...

## Context check
- Transfer caveats (redemptive-historical/cultural/covenantal): [..]
- Contested basis? [flag + alternative]

## Honesty pass
- Each application traces to text+principle? [pass/cuts]
```

---

## Verification

- [ ] Original point established before application.
- [ ] Principle genuinely follows from the original point.
- [ ] Applications specific and tagged by strength (command/inference/possibility).
- [ ] Transfer caveats noted; contested bases flagged.
- [ ] No imposed or invented applications/cross-references.

---

## False-Positive Prevention

❌ **DON'T:**
- Skip to "so you should…" without the text's original point.
- Universalize a culturally specific instruction without acknowledgment.
- Present a wise inference as a direct command.
- Build application on a contested reading as if settled.

✅ **DO:**
- Move original point → principle → today, in order.
- Tag each application command/teaching vs. inference vs. possibility.
- Note transfer caveats and flag contested bases.
- Cut any application the text doesn't support.
