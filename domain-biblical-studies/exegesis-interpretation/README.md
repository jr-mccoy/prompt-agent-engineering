# Exegesis & Interpretation

Prompts for drawing meaning *out of* the biblical text (exegesis) rather than reading meaning *into* it (eisegesis). Covers passage exegesis, original-language word study, genre-aware reading, historical-cultural and literary context, narrative and rhetorical analysis, ancient Near Eastern comparative context, canonical/intertextual reading, beginner observation, multi-view interpretation, and translation comparison.

**Neutrality & anti-fabrication:** these prompts present the text and the range of credible readings, attributing contested interpretations to identifiable streams without endorsing one. They are the most citation- and language-intensive in the domain, so several carry STRONG-GUARD anti-fabrication language — no invented glosses, etymologies, citations, manuscript data, ANE text references, or scholar attributions; reference verses by address and verify wording against named real resources.

## Which prompt for which question

- **"What does this passage say?"** (new reader) → `biblical_passage_observation_beginner.md`
- **"Work through this passage carefully"** → `biblical_passage_exegesis_workflow.md` (the flagship; routes to the specialist prompts below)
- **"What kind of text is this and how do I read it?"** → `biblical_genre_aware_reading.md` (then a genre-specific guide below)
- **"How do I read a parable / prophecy / psalm / proverb / OT law / an epistle's argument?"** → `biblical_parable_interpretation.md` · `biblical_prophecy_apocalyptic_interpretation.md` · `biblical_hebrew_poetry_psalms_reading.md` · `biblical_wisdom_literature_reading.md` · `biblical_law_torah_reading.md` · `biblical_epistle_argument_tracing.md`
- **"How does it fit its surroundings / what's its shape?"** → `biblical_literary_context_structure.md`
- **"How is this *story* told?"** (character/plot/narrator) → `biblical_narrative_analysis.md`
- **"How does this text *persuade*?"** (devices/strategy) → `biblical_rhetorical_analysis.md`
- **"What world was this written into?"** → `biblical_historical_cultural_context.md`; for specific ANE text parallels → `biblical_ane_comparative_context.md`
- **"What does this word mean?"** → `biblical_word_study_original_language.md`
- **"How does it connect to the rest of Scripture?"** → `biblical_canonical_intertextual_reading.md`
- **"Why do translations differ here?"** → `biblical_translation_comparison.md`
- **"What are the competing interpretations?"** → `biblical_multiview_interpretation_map.md`
