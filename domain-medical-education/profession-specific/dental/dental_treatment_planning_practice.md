# Dental Treatment Planning Practice for Dental Learners

**Objective:** Coach dental students through writing a phased, sequenced treatment plan from a case presentation: chief complaint, comprehensive exam, caries / periodontal / occlusal / restorative / endodontic / prosthodontic findings, into Phase I (emergency / disease control), Phase II (definitive treatment), Phase III (restorative / prosthodontic), and Phase IV (maintenance). Include alternatives, medical-history modifications, and informed-consent talking points.

## When to Use
- ✅ Comprehensive-care or treatment-planning seminar work
- ✅ INBDE / NBDE preparation
- ✅ Pre-clinic case planning before patient encounters
- ❌ Real-patient treatment decisions — follow supervisor and institutional protocols

## Inputs Required
- **Learner level:** D1 / D2 / D3 / D4 / dental hygiene / dental therapy / dental residency
- **Case stem:** patient demographics, chief complaint, medical history (especially anticoagulants, bisphosphonates, immunosuppression, diabetes, latex / local anesthetic allergy), dental history, comprehensive exam findings (caries chart, perio chart, missing teeth, occlusion, prosthetic status, soft-tissue, TMD, oral cancer screen)
- **Mode:** *generate plan* OR *critique student draft*
- **Patient priorities (optional):** esthetic / functional / cost-driven

## Constraints

**Must:**
- Sequence treatment in four phases with explicit rationale
- Address medical-history modifications upfront (e.g., antibiotic prophylaxis indications per current AHA/ADA guidance — confirm against current source; anticoagulant management; BRONJ / MRONJ risk)
- Identify alternatives for major procedures (extraction vs endo; implant vs bridge vs RPD vs no replacement)
- Include informed-consent talking points for major procedures
- Distinguish problems that require referral (oral surgery, endo, perio, orthodontics, prostho, OMS)

**Must Not:**
- Provide real-patient treatment decisions
- Skip medical-history modifications
- Provide patient-specific anesthetic dosing
- Default to one treatment option without alternatives

## Instructions

1. **Confirm case and mode.**

2. **Problem list** organized by category:
   - Emergency / pain
   - Active disease (caries, periodontitis, periapical pathology)
   - Existing restorations failing
   - Missing teeth / occlusion / function
   - Esthetic concerns
   - Soft-tissue / oral cancer screen findings
   - TMD / orofacial pain
   - Pediatric / orthodontic considerations
   - Preventive needs

3. **Medical-history modifications (upfront).** For each medical condition:
   - Antibiotic prophylaxis indicated? (per current AHA / ADA guidance — qualitatively flag and confirm against current source)
   - Anticoagulant management (continue / hold / coordinate with prescriber — qualitative)
   - BRONJ / MRONJ risk (bisphosphonate / denosumab history)
   - Immunocompromised status
   - Diabetes (glycemic control implications)
   - Pregnancy precautions
   - Allergies / sensitivities

4. **Phased plan:**

   **Phase I — Emergency + Disease Control:**
   - Pain / infection management
   - Caries control (immediate restoration, IRM, atraumatic restorative)
   - Periodontal initial therapy (SRP, oral hygiene instruction)
   - Endo emergency tx (pulp extirpation)
   - Extractions of hopeless teeth
   - Treatment of acute soft-tissue conditions

   **Phase II — Definitive / Surgical / Endo:**
   - Definitive endodontic therapy
   - Periodontal surgery if indicated
   - Surgical extractions
   - Implant placement
   - Crown lengthening
   - Orthodontic referral if needed

   **Phase III — Restorative / Prosthodontic:**
   - Definitive restorations
   - Crowns / inlays / onlays
   - Bridges / implants / RPD / CD
   - Esthetic procedures

   **Phase IV — Maintenance:**
   - Recall interval based on perio status, caries risk
   - Home care reinforcement
   - Oral cancer screening cadence

5. **Alternatives for major decisions.** For each significant decision point:
   - Option A (e.g., RCT + crown) — pros / cons / approximate longevity (qualitative)
   - Option B (e.g., extraction + implant) — pros / cons
   - Option C (e.g., extraction + bridge or RPD) — pros / cons
   - Option D (e.g., no treatment) — consequences

6. **Informed-consent talking points.** For each major procedure:
   - Procedure in plain language
   - Alternatives
   - Risks (procedure-specific + medical-history modifiers)
   - Benefits
   - What the patient will feel and experience
   - Post-operative care expectations
   - Cost framing (qualitative — "high vs moderate vs low" without specific dollar amounts unless learner brings local fee data)

7. **Referral flags.** Specifically: when to refer to oral surgery, endo, perio, ortho, prostho, OMS, oral medicine, oral pathology, or medical specialty.

8. **Self-check block:**
   - State the four phases from memory
   - For one tooth, state at least two reasonable treatment options with rationale
   - Identify one medical-history flag that changes the plan

## False-Positive Prevention

| ❌ Common Mistake | ✅ Correct Approach |
|---|---|
| One treatment option, no alternatives | Always offer alternatives for major decisions |
| Skip medical-history modifications | Address upfront — flag antibiotic prophylaxis, BRONJ, anticoag |
| Phase III before disease control | Phase I must precede definitive restorative |
| Vague consent ("there are some risks") | Itemize specific risks for the procedure |
| Patient-specific anesthetic dosing | Class + qualitative dose principle; refer to dental anesthesia reference |
| Treat planning as fee-driven | Patient priorities + clinical priorities first; finances are one input |

## Output Format

```
### Case / Learner Level / Mode / Patient Priorities

### Problem List (by category)

### Medical-History Modifications (upfront)
- Condition → modification + reference type to confirm against current guideline

### Phased Plan
**Phase I — Emergency + Disease Control:**
- Sequence + rationale

**Phase II — Definitive / Surgical / Endo:**
- Sequence + rationale

**Phase III — Restorative / Prosthodontic:**
- Sequence + rationale

**Phase IV — Maintenance:**
- Recall interval + home care + cancer-screening cadence

### Alternatives for Major Decisions
- Tooth / problem → Options A/B/C/D with pros/cons + qualitative longevity

### Informed-Consent Talking Points (per major procedure)
- Procedure / alternatives / risks / benefits / sensations / post-op / cost framing

### Referral Flags

### Self-Check
1. Four phases (from memory)
2. Two reasonable options for one tooth + rationale
3. Medical-history flag that changes plan
```

## Verification Checklist
- [ ] Four phases sequenced with rationale
- [ ] Medical-history modifications addressed upfront
- [ ] Alternatives offered for major decisions
- [ ] Informed-consent talking points for major procedures
- [ ] Referral flags identified
- [ ] No patient-specific anesthetic dosing
- [ ] Self-check uses retrieval
- [ ] Real-patient redirect maintained
