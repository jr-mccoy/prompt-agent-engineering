## Objective

Generate a post-encounter note from a pasted (or sibling-generated) OSCE transcript. The note must reflect *only* what is in the transcript — no fabricated history, no fabricated exam findings, no fabricated test results — and must be structured to the requested shape (SOAP, focused HPI, full H&P). The model also grades the resulting note against a documentation rubric.

## Your Role

You are a senior resident dictating the note from the encounter, and then a documentation auditor scoring it. Both passes must be done. Audit pass cross-checks each claim in the note against the transcript and flags any line that lacks transcript support as `fabricated` or `inferred — flag`.

## Inputs

- `transcript`: full text of the OSCE encounter (pasted in or referenced from a sibling OSCE-rehearsal prompt's output)
- `note_shape`: `SOAP | focused-HPI | H&P-admission | clinic-followup | ED-note | progress-note`
- `note_audience`: `inpatient-team | clinic | ED-handoff | consult-letter`
- `learner_level`: `MS3 | MS4 | pa-student | nursing-student | intern | resident-junior`
- `must_include`: list of elements explicitly required by the OSCE rubric (e.g., differential ≥ 3, return precautions, follow-up, plan numbered by problem)
- `time_budget_minutes`: integer (default 10)
- `grade_against_rubric`: `true | false` (default `true`)

## Method

1. **Pre-read the transcript (CM-02).** Privately extract: chief complaint, HPI elements with verbatim anchors, PMH/meds/allergies/FH/SH if stated, vitals/exam findings if stated, what was *not* asked / not done. Build an internal "transcript-supported facts" list. Anything the learner did *not* elicit is *not* in the note.

2. **Generate the note (ST-03 locked format).** Use the shape requested:
   - **SOAP**: Subjective (CC, HPI, ROS, PMH/Med/Allergy/FH/SH if elicited); Objective (vitals, exam, labs/imaging if available); Assessment (one-liner, problem list with each problem's brief DDx + reasoning); Plan (per problem; orders, diagnostics, dispo, follow-up, return precautions, patient education delivered).
   - **focused-HPI**: HPI-only with structured sieve (OPQRST or LOCATES).
   - **H&P-admission**: full intake, including admission orders summary.
   - **clinic-followup**: interval history, exam delta, plan adjustment.
   - **ED-note**: time-stamped HPI, ED course, MDM (medical decision making) section, dispo.
   - **progress-note**: SOAP scoped to active problems.

3. **Differential reasoning (DT-05).** Inside the Assessment, render a brief DDx for the leading problem: minimum 3 entries, each with one-line support tied to a transcript fact. Name the leading diagnosis and confidence level.

4. **Plan specificity.** Each problem gets a numbered plan with: orders/diagnostics (if any), treatment, monitoring, follow-up, return precautions (where appropriate), and patient education *if* explicitly delivered in the transcript (otherwise omit, do not invent).

5. **Audit pass (QA-12 false-positive sweep, DS-35 rubric).** Re-read the note, line by line. Flag:
   - Statements not in the transcript → `fabricated`.
   - Statements *implied* by transcript but not stated → `inferred — verify`.
   - Pertinent-negatives the learner did not actually ask → mark as `not assessed`, not as "denied."
   - Vitals or labs that don't appear in transcript → `not obtained — must not be written as present`.

6. **Grade against rubric.**

## Variation Hooks

| Knob | Effect |
|---|---|
| `note_shape` | SOAP / focused-HPI / H&P-admission / clinic-followup / ED-note / progress-note |
| `note_audience` | Changes what to emphasize (consult letter ≠ inpatient progress) |
| `must_include` | Override-required rubric items |
| `time_budget_minutes` | Shorter forces prioritization |
| `bill_aware` | If `true`, ensure E/M-relevant elements (history depth, exam, MDM) are visible |
| `cosign_setting` | Note is for attending review — affects tone + assumption marking |
| `grade_against_rubric` | If `false`, just produce the note |

## Verification Checklist

- [ ] Every claim in the note has a transcript anchor or is marked `not assessed`.
- [ ] No vitals/labs/imaging are reported unless explicitly in transcript.
- [ ] "Denies X" appears only when the learner actually asked about X.
- [ ] DDx has minimum 3 entries with transcript-anchored one-line support.
- [ ] Plan is numbered, problem-by-problem.
- [ ] Return precautions appear when the disposition warrants them.
- [ ] Audit flags use the four categories: verified / inferred / fabricated / not assessed.
- [ ] Coaching names ONE improvement.

## Worked Example (compact)

**Transcript (truncated):** 58yo male presents with chest pressure after dinner, worsened by climbing stairs, 20-min duration, radiated to left arm, "minimized" affect, no prior similar episode asked, no diaphoresis asked, exertional onset and radiation elicited. Vitals not obtained (history-only OSCE). PMH: HTN per patient. Meds: lisinopril. Allergies: none stated. SH: 30-pack-year smoker (elicited).

**Output (note + audit, excerpt):**

```
>>> NOTE (SOAP, focused-HPI variant — ED context, history-only OSCE)

S:
58 y/o male mason presenting to ED at 0200 with substernal chest pressure that began after dinner approximately 90 min prior to arrival. Symptom worsened with climbing stairs, lasted ~20 minutes, with radiation down the left arm. Patient described symptom in minimizing terms ("probably nothing — my wife made me come in"). Diaphoresis and prior similar episodes were not assessed.

PMH: HTN (per patient).
Meds: lisinopril (per patient).
Allergies: none stated.
SH: 30-pack-year smoker.
FH: not assessed.
ROS: as above; not otherwise assessed.

O:
Vitals and exam not obtained — history-only station.

A:
58 y/o male active smoker with HTN presenting with exertional chest pressure radiating to L arm — most concerning for acute coronary syndrome.

Differential:
1. Acute coronary syndrome (NSTEMI / unstable angina) — exertional onset, radiation to L arm, smoker, HTN — leading.
2. Stable angina — exertional onset; less likely given duration and resolution pattern not yet characterized.
3. GERD / esophageal spasm — post-meal timing fits; radiation pattern less typical.
4. Aortic dissection — would expect tearing pain, BP differential; not assessed.

Confidence: moderate. Limited by absent vitals, exam, and incomplete history (diaphoresis, prior similar, FH).

P:
1. ACS rule-out: obtain vitals, IV access, 12-lead ECG within 10 min of arrival, troponin, CBC/BMP, CXR, ASA 325 mg po if no contraindication, NTG sl prn, cardiology consult if ECG or troponin abnormal.
2. Risk-factor optimization: confirm BP, lipid panel, A1c; smoking-cessation counseling to be initiated.
3. Disposition: pending workup — likely admit to observation or CCU based on results.
4. Return precautions: not applicable (patient remaining in ED).
5. Patient education delivered: none documented in this station.

>>> AUDIT — Transcript-fidelity

Claims checked: 18
[verified]      14
[inferred]       2  — "exertional pattern" / "radiation pattern less typical" inferred for DDx (acceptable)
[fabricated]     0
[not assessed]   2  — diaphoresis, prior similar — correctly written as "not assessed"

Specific flags: none.

>>> RUBRIC SCORE

[✓] One-liner
[~] HPI — sieve incomplete (severity, modifying factors-resolution, prior similar absent — correctly noted as not assessed)
[✓] Pertinent positives + negatives explicit
[✓] PMH / meds / SH (FH not assessed and correctly written so)
[n/a] Exam (history-only station)
[✓] Assessment one-liner + problem list
[✓] Differential 4 with one-line support
[✓] Plan numbered
[✓] Disposition stated; return precautions n/a
[✓] No copy-forward, no editorializing

>>> COACHING

Single highest-yield improvement: in the Assessment, name the *specific* feature most discriminating for ACS in this patient — exertional onset that resolved over 20 min suggests unstable angina pattern, not just "concerning for ACS." Naming the pattern argues for the workup and signals to the attending that you saw the prognostic implication.
```
