# Microbiology Bug Drill for Health-Professions Learners

**Objective:** Drill the learner on a target organism using a canonical pattern (Gram stain, morphology, oxygen requirement, key virulence factors, clinical syndromes caused, host risk factors, diagnosis approach, first-line antimicrobial class), then test pattern flexibility with twist-cases, and finish with a bug-drug-disease pairing exercise.

## When to Use
- ✅ Preclinical micro course prep
- ✅ Board prep (Step 1, NAPLEX, NCLEX, PANCE, NREMT — adapted)
- ✅ Building durable bug-drug-disease links before clinical rotations
- ❌ Real-patient antimicrobial selection — use ID guidelines, antibiogram, and ID consult

## Inputs Required
- **Discipline & learner level**
- **Organism or category:** e.g., *Staphylococcus aureus*, *Streptococcus pneumoniae*, *Pseudomonas aeruginosa*, *Mycobacterium tuberculosis*, *Clostridioides difficile*, HSV, HIV, *Plasmodium falciparum*, *Candida albicans*, *Aspergillus*
- **Depth:** quick (5 min) / standard (15 min) / deep (incl. twist-cases and resistant variants)

## Constraints

**Must:**
- Use the canonical pattern: Gram or stain category → morphology → oxygen / growth → virulence factors → clinical syndromes → host risk factors → diagnosis → first-line treatment class
- Tie virulence factors to clinical features (e.g., *S. aureus* protein A → immune evasion; toxin TSST-1 → toxic shock)
- Use *antimicrobial class* language for treatment; do not generate patient-specific dosing
- Generate at least two twist-cases at depth ≥ standard
- End with retrieval

**Must Not:**
- Provide real-patient antimicrobial regimens or dosing
- Treat the organism as a memorized list without mechanism
- Use specific antibiogram percentages — defer to local antibiogram
- Default to physician-centric emphasis

## Instructions

1. **Canonical pattern block:**
   - Stain / category (Gram +/−, acid-fast, fungal, viral, parasitic)
   - Morphology (cocci/bacilli/spirochete/arrangement; envelope/capsule for viruses)
   - Oxygen / growth requirements (aerobic, anaerobic, facultative, intracellular)
   - Key virulence factors (with linked clinical effects)
   - Clinical syndromes caused
   - Host risk factors / immunocompromise patterns
   - Diagnosis (culture, NAAT, serology, microscopy, antigen, imaging)
   - First-line antimicrobial class with rationale

2. **Discipline anchoring:**
   - Medicine/PA: dx and empiric vs targeted therapy decisions
   - Nursing: infection-prevention (isolation type, PPE), early sepsis recognition
   - Pharmacy: first-line agent, alternative for allergy, monitoring (levels, renal/hepatic dosing principle), durations
   - EMS: time-critical recognition (sepsis, meningococcemia, Ebola), PPE/transport
   - Allied health: relevant infection-control (e.g., MRSA precautions for PT/OT)
   - Dental: oral flora, endocarditis prophylaxis triggers, periodontal pathogens, post-surgical infections

3. **Twist-cases** (depth = standard or deep). At least two:
   - Atypical host (e.g., immunocompromised presentation differs)
   - Resistance variant (MRSA, ESBL, CRE, MDR-TB, fluconazole-R Candida)
   - Atypical site (UTI organism causing bloodstream infection)

4. **Bug-drug-disease pairing drill.** Provide 5 mini-scenarios; learner picks bug + antimicrobial class. Answer key separate.

5. **Retrieval self-check:**
   - State the canonical pattern from memory
   - For two virulence factors, give the clinical correlate
   - One twist-case scenario in your own words and what changes

## False-Positive Prevention

| ❌ Common Mistake | ✅ Correct Approach |
|---|---|
| Skip virulence-to-clinic linkage | Every virulence factor must connect to a clinical effect |
| Provide specific patient regimens | Antimicrobial class only |
| Cite local antibiogram percentages | Defer to actual antibiogram |
| Only canonical presentation | Always add twist-cases at depth ≥ standard |
| One-size emphasis | Discipline anchoring required |
| Skip retrieval | Drill must end with retrieval |

## Output Format

```
### Organism / Discipline / Depth

### Canonical Pattern
- Stain / category
- Morphology
- Oxygen / growth
- Virulence factors (with clinical correlates)
- Clinical syndromes
- Host risk factors
- Diagnosis
- First-line antimicrobial class with rationale

### Discipline Anchoring
- Role-specific emphasis

### Twist-Cases (depth ≥ standard)
1. Atypical host: ...
2. Resistance variant: ...
3. (optional) Atypical site: ...

### Bug-Drug-Disease Pairing Drill
1. Scenario → bug + class + rationale
...

### Self-Check
1. Canonical pattern (from memory)
2. Two virulence → clinical correlates
3. Twist-case in own words
```

## Verification Checklist
- [ ] Canonical pattern complete in standard sequence
- [ ] Virulence factors tied to clinical effects
- [ ] No patient-specific dosing
- [ ] No invented antibiogram numbers
- [ ] At least two twist-cases at depth ≥ standard
- [ ] Discipline anchoring applied
- [ ] Self-check uses retrieval
- [ ] Real-patient redirect language present
