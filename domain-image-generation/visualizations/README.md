# Visualizations Prompt Pack

This subtree contains cross-role visualization meta-prompts for generating structured, no-UI visual outputs.

## Scope (Sub-batch D)

- **Total prompts in `visualizations/`:** 14
- **Naming prefix:** `visualization_*.md`

- **Shared reliability requirements:** intake schema, no-UI/no-mockup constraints, repeated no-gradient/no-shadow constraints, physical context anchoring, deliverable lock, model-specific tweaks, and final validation checklist
