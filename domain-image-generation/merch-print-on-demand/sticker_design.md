# Die-Cut Sticker Design

**Objective:** Produce a die-cut sticker — a single isolated subject with a bold contour border (the classic white sticker keyline) on a transparent background, sized and margined so it cuts cleanly and any text renders verbatim.

**Why this model:** Stickers need clean subject isolation and a clear contour for the die-cut/kiss-cut path. Use **gpt-image-2** (`quality="high"`, `background="transparent"`) for crisp isolation. **Nano Banana Pro** (`gemini-3-pro-image`) when the sticker is text-led and needs exact font control. For purely illustrative, text-free stickers, Nano Banana 2 can iterate fast — then add the keyline and isolate.

**API parameters:**
- gpt-image-2 path: `model="gpt-image-2"`, `size="1024x1024"`, `quality="high"`, `background="transparent"`, `n=4`
- Nano Banana Pro path: `model="gemini-3-pro-image"`, square aspect, `quality="high"`; render on a flat solid field to key out if transparent isn't native

> The model renders the artwork + a visible bold contour border. The actual machine cut line is generated by your POD provider / vector tool from the contour — the prompt's job is to give a clean, offsettable silhouette and a thick border.

---

## Inputs

- `[SUBJECT]` — the single thing the sticker depicts ("a grumpy cartoon cactus")
- `[STYLE]` — kawaii, retro, line-art, flat-vector, holographic-ready, sketchy
- `[TEXT]` — verbatim text on the sticker (optional)
- `[PALETTE]` — hex codes
- `[BORDER STYLE]` — classic white keyline / colored border / no border (full-bleed shape)
- `[BORDER WIDTH]` — relative thickness ("thick, ~6% of subject width")
- `[BACKGROUND]` — transparent (default) / single solid hex
- `[SHAPE]` — die-cut to subject silhouette / circle / rounded square
- `[FORBIDDEN]` — to avoid

---

## Constraints (Must / Must Not)

**Must:**
- One isolated subject, centered, on a transparent background with clean margin.
- Render a bold, even contour border (the keyline) that traces the subject's outer silhouette — this defines the die-cut.
- Keep a simple, closed, offsettable silhouette (no thin tendrils or floating disconnected bits that won't cut).
- Render `[TEXT]` verbatim in an EXACT TEXT block when present.

**Must Not:**
- Render a background scene, gradient backdrop, drop shadow, or product mockup.
- Output multiple disconnected subjects (one sticker = one connected shape) unless the concept explicitly groups them inside one border.
- Use trademarked characters/logos.
- Make a ragged or broken silhouette that can't be die-cut.
- Misspell the text.

## Production Prompt (gpt-image-2)

```
DELIVERABLE:
A single die-cut STICKER design — the artwork ONLY on a [transparent / solid [HEX]]
background. No scene, no backdrop, no drop shadow, no product mockup, no sticker
sheet — just one isolated sticker subject with its border.

ARTWORK:
Subject: [SUBJECT]. Style: [STYLE]. Centered, bold, with clean margin all around.
Simple, closed, connected silhouette suitable for die-cutting (no thin tendrils,
no detached floating pieces). Shape: [SHAPE].

BORDER (the die-cut keyline):
- [BORDER STYLE] — [e.g., a classic thick white keyline] tracing the subject's outer
  silhouette evenly. Width: [BORDER WIDTH]. The border is uniform and unbroken —
  this is the cut path.

COLOR:
- Palette: [HEX], [HEX], [HEX]. Bold, saturated, sticker-friendly.

TEXT (if [TEXT] present — verbatim):
- "[TEXT]" — [face fitting the style], [weight], [HEX], integrated into the design,
  100% readable.

CONSTRAINTS:
- Background: [transparent / single flat [HEX]] only. Nothing else in the frame.
- One connected subject with one continuous keyline border.
- EXACT TEXT only, verbatim; no invented copy.
- Forbidden: background scenes, gradients behind the subject, drop shadows, mockups,
  sticker sheets, trademarked characters/logos, [FORBIDDEN], watermarks, lorem ipsum.
- Format: square, centered with margin.

If the output has a background scene, a broken/ragged silhouette, multiple
disconnected stickers, or misspelled text, the output is incorrect.
```

TASK: Design ONE die-cut sticker — artwork only on a [transparent / solid [HEX]]

BORDER: [BORDER STYLE] keyline tracing the outer silhouette evenly, width [BORDER
WIDTH], unbroken — this is the cut path.

COLOR: palette [HEX], [HEX], [HEX], saturated and sticker-friendly.

TEXT (if present, render exactly): "[TEXT]" — [face], [weight], [HEX].

CONSTRAINTS:
- MUST: isolated single subject; clean continuous keyline; offsettable silhouette;
  correct background; verbatim text.
- MUST NOT: render a scene/backdrop/shadow/mockup/sticker-sheet; produce a

## Iteration Plan

1. "It added a background scene — output the sticker ONLY on transparent, with just the subject + keyline."
2. "The silhouette has thin tendrils that won't cut — simplify the outline into a clean closed shape."
3. "Keyline is uneven/broken — make the white border uniform thickness all the way around."
4. "Subject too small — scale it up to fill the print area with a clean margin."

## Verification

- [ ] One isolated subject, centered, on transparent/solid background — no scene/shadow/mockup.
- [ ] Bold, even, unbroken contour keyline tracing the outer silhouette.
- [ ] Simple, closed, connected, die-cuttable silhouette.
- [ ] Any text in an EXACT TEXT block, verbatim.
- [ ] No trademarks.
- [ ] `quality="high"` (and `background="transparent"` on gpt-image-2 if applicable).
