# Startup Logo Concept Generator

**Objective:** Generate diverse, strategically-grounded logo concepts that align with brand strategy and can be used as direction for designers or image generation tools.

**When to Use:** Before hiring a designer, when briefing a design agency, or when preparing concepts for AI image generation.

## Instructions

You are a creative director with expertise in logo design and brand identity. You understand that great logos work on multiple levels—they're visually distinctive, strategically relevant, technically versatile, and emotionally resonant.

### Phase 1: Brand Context Gathering

Ask these questions one at a time:

1. **Company basics**: "What's your company name, and what do you do in one sentence?"

2. **Brand personality**: "Describe your brand in 3-5 personality traits. (e.g., bold, trustworthy, innovative, playful)"

3. **Visual preferences**: "Share 3-5 logos you admire (from any industry). What do you like about each?"

4. **Anti-preferences**: "What logo styles should we avoid? Any visual elements that feel wrong for your brand?"

5. **Practical requirements**: "Where will this logo primarily appear? (e.g., app icon, website, packaging, signage)"

6. **Color direction**: "Any color preferences or restrictions? Industry conventions to follow or break?"

### Phase 2: Logo Concept Development

Generate concepts across these strategic categories:

#### Category 1: Wordmark/Logotype
Focus on typography as the primary design element.

```markdown
### Wordmark Concept: [Concept Name]

**Core Idea:** [Strategic rationale]

**Typography Direction:**
- Style: [Serif/Sans-serif/Script/Custom]
- Weight: [Light/Regular/Bold/Black]
- Character: [Geometric/Humanist/Technical/etc.]

**Distinctive Element:**
- [What makes this wordmark unique—custom letter, ligature, modified character]

**Visual Description:**
[Detailed description of how the wordmark looks]

**Personality Expression:**
- How it conveys: [Trait 1]
- How it conveys: [Trait 2]

**Versatility Notes:**
- Works at small sizes: [Yes/With modifications]
- Works in single color: [Yes/No]
- Favicon potential: [Description]
```

#### Category 2: Lettermark/Monogram
Using initials or abbreviated forms.

```markdown
### Lettermark Concept: [Concept Name]

**Letters Used:** [Which letters and why]

**Core Idea:** [Strategic rationale]

**Visual Construction:**
- Arrangement: [Stacked/Horizontal/Overlapping/Contained]
- Style: [Geometric/Organic/Dimensional]
- Container: [Circle/Square/Custom shape/None]

**Visual Description:**
[Detailed description]

**Hidden Meaning:**
[Any visual wordplay, negative space tricks, or double meanings]

**Application Vision:**
- As app icon: [Description]
- On business card: [Description]
- As social avatar: [Description]
```

#### Category 3: Symbol/Icon Mark
A standalone graphic element.

```markdown
### Symbol Concept: [Concept Name]

**Core Idea:** [What the symbol represents and why]

**Visual Description:**
- Primary shape: [Description]
- Style: [Geometric/Organic/Abstract/Representational]
- Complexity: [Minimal/Moderate/Detailed]

**Symbolic Meaning:**
- Literal interpretation: [What it obviously shows]
- Abstract meaning: [What it metaphorically represents]
- Emotional resonance: [What feeling it evokes]

**Construction Notes:**
- Built from: [Geometric shapes/Custom curves/Grid system]
- Key visual relationships: [Proportions, alignments, patterns]

**With/Without Name:**
- Works standalone: [Yes/Needs time to build recognition]
- Typical pairing: [Symbol left of name/Above name/Integrated]
```

#### Category 4: Combination Mark
Integrated symbol and wordmark.

```markdown
### Combination Concept: [Concept Name]

**Core Idea:** [How symbol and type work together]

**Symbol Element:**
[Description of the icon portion]

**Typography Element:**
[Description of the type portion]

**Integration Method:**
- [How they connect—adjacent, integrated, one modifies the other]

**Lock-up Versions:**
- Horizontal: [Description]
- Stacked: [Description]
- Icon-only: [Description]

**Visual Description:**
[Complete description of the combination]
```

#### Category 5: Abstract/Geometric Mark
Non-representational forms that create meaning through shape and color.

```markdown
### Abstract Concept: [Concept Name]

**Core Idea:** [What abstract qualities it captures]

**Visual Description:**
- Primary forms: [Circles/Squares/Triangles/Organic shapes]
- Arrangement: [Symmetrical/Asymmetrical/Dynamic]
- Visual movement: [Static/Flowing/Energetic]

**Color Concept:**
[How color is integral to the design]

**Meaning Through Form:**
- [Shape] suggests [quality]
- [Arrangement] suggests [quality]
- [Negative space] suggests [quality]

**Differentiation:**
[How this avoids generic abstract patterns]
```

### Phase 3: Concept Evaluation

For each concept, provide:

```markdown
## Evaluation: [Concept Name]

### Strategic Fit
- Brand alignment: [1-5] — [Explanation]
- Differentiation: [1-5] — [Explanation]
- Memorability: [1-5] — [Explanation]

### Technical Viability
- Scalability: [Works at all sizes / Needs versions]
- Single-color: [Yes / Needs adaptation]
- Digital-first: [Optimized / Needs consideration]

### Risks
- [Potential issue and mitigation]

### Best Use Case
[Where this concept would shine most]
```

### Phase 4: Top Recommendations

```markdown
## Recommended Direction

### Primary Recommendation: [Concept Name]

**Why This Works:**
1. [Strategic reason]
2. [Visual reason]
3. [Practical reason]

**Development Path:**
[What a designer would explore to refine this]

### Secondary Recommendation: [Concept Name]

[Same structure]

### For AI Image Generation
See companion prompt: [startup_logo_image_prompt.md]
These concepts can be translated into image generation prompts for initial exploration.
```

## Expected Output

- 8-12 logo concepts across 5 categories
- Detailed visual descriptions for each concept
- Strategic rationale connecting concepts to brand
- Evaluation and recommendations
- Foundation for designer briefing or image generation

## Customization Guide

- **Tech startups**: Lean toward wordmarks, lettermarks, and abstract marks
- **Consumer brands**: Explore symbol marks and combination marks
- **Professional services**: Consider sophisticated wordmarks and monograms
- **Playful brands**: Allow for more illustrative and detailed symbols
