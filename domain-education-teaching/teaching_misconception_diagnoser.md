**Purpose:** Diagnose patterns in student errors using a structured misconception taxonomy, connect patterns to objectives, and generate a focused reteaching sequence.

**When to use:** After exit tickets, quizzes, short responses, or discussion evidence; during PLC data meetings; before reteach days.

**Input needed:**
- Learning objectives and standards
- Student evidence set (responses/work samples)
- Time available for reteach cycle
- Constraints (group size, materials, period length)

**Grade / Subject:** [e.g., Grade 4 Math]

**Class Data Snapshot:** [Optional % correct by item]  
**Reteach Time Box:** [e.g., one 45-min class, two 30-min blocks]  
**Constraints:** [staffing, supports, materials]

---

## Constraints

**Must:**
- Tie every coded error back to a stated learning objective.
- Use the misconception taxonomy consistently — assign at least one code per error pattern.
- Prioritize misconceptions by frequency × instructional impact, not by personal preference.
- Build a reteach sequence that fits inside the stated Reteach Time Box.
- Define explicit decision rules (met / partial / unmet) tied to a measurable proficiency cut.

**Must Not:**
- Do not produce general statements like "students are confused" without code-level evidence.
- Do not group students into more clusters than the staffing/time constraints support.
- Do not recommend reteach moves untethered to a specific misconception code or objective.
- Do not invent student work, scores, or demographics not present in the provided evidence.
- Do not omit a reassessment date and threshold — diagnosis without an exit gate is incomplete.

## Instructions

### Step 1: Objective-Evidence Match Check

Verify each evidence source against objectives:

| Objective | Evidence Available | Alignment Strength | Missing Evidence |
|----------|--------------------|--------------------|------------------|
| [SWBAT...] | [Item IDs / work samples] | [Strong/Partial/Weak] | [What to collect next] |

### Step 2: Misconception Taxonomy Coding

Code errors into a common taxonomy:

| Code | Category | Definition | Observable Indicators |
|------|----------|------------|------------------------|
| C1 | Conceptual | Misunderstands core concept/model | Explains using inaccurate principle |
| P1 | Procedural | Uses incorrect process/sequence | Repeated step-order or operation errors |
| L1 | Language | Misinterprets academic vocabulary | Confuses terms/symbols in prompt |
| T1 | Transfer | Cannot apply in new context | Accurate drill, inaccurate application |
| M1 | Metacognitive | Strategy selection/monitoring issue | Starts with ineffective approach, no self-check |

### Step 3: Pattern & Root-Cause Analysis

Summarize frequency and likely causes:

| Misconception Code | Frequency | Impact on Objective | Likely Root Cause | Priority |
|--------------------|-----------|---------------------|-------------------|----------|
| [C1] | [# / % students] | [High/Med/Low] | [Cause hypothesis] | [1,2,3] |

Then cluster students by need:

| Group | Student Criteria | Primary Need | Recommended Group Size |
|------|------------------|--------------|------------------------|
| A | [C1 + P1] | Concept rebuild + guided practice | [3-6] |

### Step 4: Time-Boxed Reteach Sequence

Create an instructional sequence tied to top priorities:

| Time Block | Group | Activity | Objective Alignment | Misconception Target | Check for Understanding |
|------------|-------|----------|---------------------|----------------------|-------------------------|
| 0-8 min | Whole class | [Model + contrast examples] | [Objective] | [C1] | [Cold call + mini-whiteboard] |
| 8-22 min | Group A | [Guided practice] | [Objective] | [P1] | [Teacher checkpoint] |

### Step 5: Next Reassessment Success Criteria

Specify what counts as readiness:

| Objective | Success Criterion | Evidence Tool | Proficiency Cut | Reassessment Date |
|----------|-------------------|---------------|-----------------|-------------------|
| [Objective] | [Observable behavior/score] | [Exit ticket / quick quiz] | [threshold] | [date/window] |

Include decision rules:
- If criterion met: move to next objective/extension.
- If partially met: repeat targeted small-group cycle.
- If unmet: reteach concept using alternate representation/modality.

---

## Output Format

1. Objective-Evidence Alignment Check  
2. Misconception Taxonomy + Coding Key  
3. Frequency/Priority Analysis  
4. Student Grouping Plan  
5. Time-Boxed Reteach Sequence  
6. Reassessment Success Criteria + Decision Rules

---

## Quality Indicators

- [ ] Diagnosis links errors directly to objectives
- [ ] Taxonomy categories are consistent and non-overlapping
- [ ] Prioritization reflects frequency and instructional impact
- [ ] Reteach sequence is feasible within available minutes
- [ ] Reassessment criteria are explicit and actionable

## Common Pitfalls

| Pitfall | Sign | Prevention |
|--------|------|------------|
| **Data without coding** | General statements like "students are confused" | Assign explicit misconception codes |
| **Over-grouping** | Too many tiny groups to manage | Cap groups to high-impact patterns |
| **No objective anchor** | Interventions drift from target skill | Require objective alignment column |
| **No time discipline** | Reteach plan exceeds period length | Build minute-by-minute blocks |
| **No exit criteria** | Endless reteaching | Set proficiency cut and decision rules |
