# Accreditation & Program Review

**5 prompts** for accreditation self-study drafting, program review cycle design, and evidence compilation. Parameterized for the major accreditor families.

| Prompt | Coverage |
|---|---|
| [`teaching_accreditation_self_study_he.md`](teaching_accreditation_self_study_he.md) | Regional HE accreditors: HLC, MSCHE, SACSCOC, WSCUC, NWCCU |

| [`teaching_accreditation_self_study_meded.md`](teaching_accreditation_self_study_meded.md) | Med-ed: LCME, ACGME, COCA, CODA, specialty boards |

## Notes on Accreditor Versions

All accreditation prompts require **verification against the accreditor's current published criteria/standards**. Standards change between cycles. The prompts include verification flags throughout.

For ACGME-specific specialty Milestones and Common Program Requirements, also see `../../domain-healthcare-clinical/prompts/medical-education/curriculum-design/`.
