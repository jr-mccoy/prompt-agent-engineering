# Capstone Assessment Designer

**Objective:** Design a culminating capstone assessment for a higher-ed degree, certificate, or workforce credential — an integrative performance that demonstrates multiple program outcomes simultaneously, produces a public artifact, includes a defense or external review component, and feeds program-improvement.

## When to Use
- ✅ Designing or redesigning a degree program's capstone
- ✅ Designing a portfolio-defense or thesis-style culminating experience
- ✅ Designing a workforce credential's culminating performance task
- ✅ Designing an integrative practicum/internship-defense
- ❌ Designing single-course signature assignment (use `teaching_signature_assignment_designer.md`)
- ❌ Designing in-program checkpoints (use the milestone designer)

## Inputs Required
- **Program and credential awarded**
- **PSLOs the capstone must demonstrate** (typically the integrative subset — not every PSLO)
- **Capstone format options:** independent research, design challenge, applied project, portfolio defense, comprehensive exam, performance recital, industry credential exam preparation + defense, internship-with-product
- **Duration:** single semester / two-semester / year-long
- **Required prerequisites** (PSLO mastery achieved before capstone)
- **External-review opportunity:** industry panel, community partner, faculty committee
- **Available faculty/mentor capacity**
- **Authentic context:** real client/audience, internship/practicum host, real problem domain

## Constraints

**Must:**
- Integrate ≥3 PSLOs (capstone's purpose is integration, not single-PSLO assessment)
- Include a public artifact (product, paper, performance, portfolio)
- Include defense or oral examination component
- Rubric criteria align directly to integrated PSLOs
- Include external review (industry panel / external reviewer / community partner) when feasible
- Specify scaffolding sequence within the capstone (proposal → IRB if applicable → progress checkpoints → final)
- Specify feedback-to-program-improvement workflow (capstone data → program review)

**Must Not:**
- Treat capstone as "really hard course assignment" — it's integrative by design
- Skip the defense (the oral component reveals what the written/produced artifact may hide)
- Use generic-quality rubric
- Run capstone without sufficient mentoring capacity
- Skip the prerequisite check (students arriving without M-depth in foundational PSLOs will struggle)

## Instructions

1. **Confirm scope.** Echo PSLOs to be integrated, format options, duration, external-review opportunity, mentor capacity.

2. **Choose format.**
   - Research-intensive program → independent research with thesis
   - Design / professional program → applied design challenge with deliverable
   - Performance program → recital or performance with documentation
   - Reflective / portfolio program → portfolio defense
   - Workforce credentialing program → industry exam + applied demonstration

3. **Design the integrative challenge.**
   - **Problem space:** open-ended enough to require integration; constrained enough to be tractable
   - **Authentic context:** real client / community partner / industry problem / internship setting
   - **Deliverables:** artifact + process documentation + defense

4. **Specify scaffolding sequence.**
   - Topic / problem selection
   - Proposal review (faculty/mentor sign-off)
   - Research/design phase with progress checkpoints
   - IRB or ethics review (if applicable)
   - Draft / prototype review
   - Final artifact
   - Defense / oral examination
   - Post-defense revisions / dissemination

5. **Specify mentoring structure.**
   - Faculty mentor: how assigned, time commitment, scope of guidance
   - External advisor (if any): role, touchpoints
   - Peer cohort: how structured for peer review and support

6. **Design the rubric.**
   - Criteria reflect integrative PSLOs
   - Performance levels with distinct observable descriptors
   - Defense criteria (intellectual command, response to questions, professional communication)
   - Separate criteria for artifact, process, defense

7. **Specify scoring.**
   - Committee composition (faculty mentor + program faculty + external reviewer if applicable)
   - Calibration before defense season
   - Decision rules (pass / pass with revisions / fail with retake plan)
   - Documentation requirements

8. **Specify external review** (if applicable).
   - Panel composition
   - Pre-defense materials provided
   - Panel role (scoring partner / advisory / public audience)

9. **Specify feedback-to-program workflow.**
   - Aggregate capstone scoring → annual program report
   - Pattern findings → curriculum improvement
   - Closing-the-loop documentation

10. **Audit feasibility.**
    - Mentor capacity adequate?
    - External reviewers identified and committed?
    - IRB/ethics process timeline fits semester?
    - Authentic-context partners secured?

## False-Positive Prevention

| Common Mistake | Why It's Wrong | Correct Approach |
|---|---|---|
| Capstone as single-PSLO assignment | Misses the integrative purpose | ≥3 PSLOs integrated |
| No defense | Written artifact can hide gaps in understanding | Always include oral defense or panel review |
| Generic-quality rubric | Doesn't produce PSLO signal | PSLO-aligned criteria primary |
| Insufficient mentor capacity | Project quality suffers; faculty burn out | Verify mentor capacity before launch |
| No prerequisite check | Students enter without M-depth foundations | Confirm PSLO mastery via curriculum map |
| No authentic context | Fabricated problems produce ceremonial work | Secure real client / community partner / internship |
| No external reviewer | Internal validity inflated | External review adds rigor and authentic standards |
| Data unused | Capstone evidence ignored in program improvement | Build closing-the-loop workflow |
