# Instructional Coaching Program Designer

**Objective:** Design an instructional coaching program — coaching model, observation-feedback cycle, observation tools, coach selection and training, fidelity protocols, and program evaluation — that produces measurable teaching-practice changes rather than ceremonial observation.

## When to Use
- ✅ Designing a district-wide K-12 coaching program
- ✅ Designing a higher-ed CTL coaching program
- ✅ Designing a med-ed faculty coaching for assessment/feedback skills
- ✅ Redesigning an existing program with low impact
- ❌ Single coaching conversation script (use a coaching-conversation prompt)
- ❌ PLC structure (use PLC designer)

## Inputs Required
- **Audience:** teachers/faculty count, career stages, current practice baseline
- **Coaching model:** instructional coaching (Knight model) / cognitive coaching / content-focused / data coaching / peer coaching
- **Coach availability:** dedicated coaches / peer coaches / hybrid; FTE
- **Time / cadence:** observation frequency, coaching conversation length
- **Goals:** specific teaching practices to develop
- **Fidelity expectations:** what counts as adherence to the model

## Constraints

**Must:**
- Specify coaching cycle (pre-conference → observation → debrief → goal setting → support → next observation)
- Specify observation tool aligned to teaching practices being developed
- Specify coach training and ongoing development
- Build fidelity protocol (coaches doing the work as designed)
- Build evaluation (does it work?)
- Address voluntary vs. assigned (consent, agency)
- Build differentiation by teacher career stage / need

**Must Not:**
- Conflate coaching with evaluation (different functions, different relationships)
- Generate a program where coach load is unrealistic
- Skip coach training (coaches need development too)
- Generate observation tools so long they're unused
- Skip evaluation
- Make coaching punitive

## Instructions

1. **Confirm inputs.** Echo audience, model choice, coach availability, time, goals.

2. **Design the coaching cycle.**
   - Pre-conference: focus, goal, observation lens
   - Observation: structured observation aligned to goal
   - Debrief: data presentation, reflection, planning
   - Implementation: try changes
   - Follow-up: next observation

3. **Design the observation tool.**
   - Aligned to teaching practices targeted
   - Distinct from evaluation rubric
   - Practical: usable in real time, focused
   - Inter-observer calibration possible

4. **Specify coach selection and training.**
   - Selection criteria (instructional credibility, relational skills, willingness)
   - Training (model fundamentals, observation skills, conferencing skills, equity-minded coaching)
   - Ongoing development (coach PLC, observation of coaches by lead coach)

5. **Build fidelity protocols.**
   - What's a "real" coaching cycle (frequency, components)
   - Coach logs
   - Coach observation by lead

6. **Build the coaching-vs-evaluation firewall.**
   - Coaching data does not feed evaluation
   - Coach is not the evaluator
   - Confidentiality conventions

7. **Differentiate by career stage / need.**
   - New: intensive scaffolded coaching
   - Mid: targeted on specific practice
   - Senior: peer / reciprocal coaching

8. **Design program evaluation.**
   - Implementation fidelity
   - Teacher / faculty practice change (observed)
   - Student / learner outcomes (where measurable)
   - Coach skill development

9. **Address voluntary vs. assigned.**
   - Default to voluntary participation when feasible
   - If assigned: clear conditions, supports, exit options

## False-Positive Prevention

| Common Mistake | Why It's Wrong | Correct Approach |
|---|---|---|
| Coaching = evaluation | Breaks the trust that makes coaching work | Firewall: data, role, confidentiality |
| Long observation tools | Unused | Focused tools aligned to specific practices |
| Coaches untrained | Skills not transferred | Robust initial + ongoing coach training |
| No fidelity | Program drifts | Logs + observation of coaches |
| Punitive coaching | Damages relationships | Coaching is supportive; accountability lives elsewhere |
| No evaluation | Can't improve program | Build implementation + impact evaluation |
| Same coaching for everyone | Wastes resources | Differentiate by career stage / need |
| Mandatory without supports | Breeds resistance | Voluntary when possible; supported when not |
