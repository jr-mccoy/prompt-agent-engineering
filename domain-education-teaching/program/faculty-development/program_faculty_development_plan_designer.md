# Faculty Development Plan Designer

**Objective:** Design a multi-semester faculty development plan for an institution, program, or department — anchored in a needs assessment, organized around 3-5 strategic priorities, with sequenced topics, mixed delivery modalities, expected participant outcomes, and an evaluation framework.

## When to Use
- ✅ Building a CTL / faculty-development office's annual or multi-year plan
- ✅ Designing department-specific PD aligned to program goals
- ✅ Designing K-12 district professional development calendar
- ✅ Designing residency program faculty development for ACGME requirements
- ❌ Designing a single faculty workshop (use workshop-design prompts)
- ❌ Designing PLC structure (use `teaching_professional_learning_community_designer.md`)

## Inputs Required
- **Institutional / department identity and faculty profile** (count, career stage distribution, disciplines)
- **Strategic priorities** the plan must serve (teaching effectiveness, assessment literacy, equity-minded teaching, technology integration, scholarship of teaching, etc.)
- **Needs assessment data:** survey, observation, student-evaluation patterns, accreditor feedback
- **Available time / format:** in-service days, opt-in workshops, ongoing communities, year-long programs
- **Budget and personnel**
- **Plan horizon:** semester / year / multi-year

## Constraints

**Must:**
- Ground topics in needs assessment data (not just trend topics)
- Differentiate by faculty career stage (new / mid-career / senior)
- Mix modalities (workshops + ongoing community + coaching + microlearning)
- Specify expected participant outcomes for each major topic
- Build evaluation framework (Kirkpatrick-style or equivalent)
- Build sustainability (knowledge persists beyond single events)

**Must Not:**
- Generate a plan that's just a list of trend topics
- Treat all faculty as monolithic (career stage matters)
- Default to one-shot workshops only
- Skip evaluation (PD without evaluation can't improve)
- Exceed budget or personnel capacity

## Instructions

1. **Confirm inputs.** Echo faculty profile, priorities, needs data, capacity.

2. **Build needs-driven topic priorities.**
   - From needs data, identify 3-5 high-leverage topics
   - For each: who needs it most (career stage, discipline), urgency

3. **Map topics to modalities.**
   - **Foundational knowledge:** workshops, asynchronous modules
   - **Skill development:** workshops + practice + feedback
   - **Ongoing improvement:** PLCs, coaching, peer observation
   - **Innovation / scholarship:** fellowships, research seminars

4. **Differentiate by career stage.**
   - **New faculty (Years 1-3):** onboarding, classroom basics, navigating the institution
   - **Mid-career:** advanced pedagogy, scholarship of teaching, leadership development
   - **Senior:** mentoring, curricular leadership, succession

5. **Sequence across the plan horizon.**
   - Per term: signature workshops, ongoing PLCs, coaching availability, online modules
   - Avoid clustering everything in start-of-term

6. **Specify expected outcomes per major topic.**
   - Knowledge changes
   - Practice changes (observable)
   - Student outcomes (where measurable)

7. **Design evaluation.**
   - Level 1 (Reaction): post-workshop surveys
   - Level 2 (Learning): pre-post knowledge / skill check
   - Level 3 (Behavior): follow-up observation or self-report
   - Level 4 (Results): student outcomes data over time

8. **Plan sustainability.**
   - PLC continuation between events
   - Asynchronous resources
   - Peer-coaching pairs
   - Recognition / incentives

9. **Budget and capacity audit.**

## False-Positive Prevention

| Common Mistake | Why It's Wrong | Correct Approach |
|---|---|---|
| Trend-topic chasing | Lacks alignment with actual needs | Anchor in needs-assessment data |
| One-shot workshops only | Limited transfer; little behavior change | Mix modalities; include ongoing structures |
| Treating all faculty alike | New faculty and senior faculty need different things | Differentiate by career stage |
| No evaluation beyond satisfaction | Can't improve what you don't measure | Build Levels 1-4 evaluation |
| No sustainability | Knowledge fades; investment wasted | Build PLCs, resources, coaching pairs |
| Over-scheduling early term | Faculty bandwidth limited then | Distribute across term |
| Generic outcomes ("improved teaching") | Unactionable | Specify observable changes |

## Verification Checklist

- [ ] Needs-assessment data anchors topics
- [ ] Career-stage differentiation
- [ ] Modality mix (not just workshops)
- [ ] Expected outcomes specified per topic
- [ ] Evaluation framework across Levels 1-4
- [ ] Sustainability mechanisms
- [ ] Budget and capacity realistic
- [ ] Calendar avoids early-term overload
