# Assessment Literacy Faculty Development Curriculum

**Objective:** Design a faculty / teacher development curriculum that builds assessment literacy across topics — assessment purposes, item and task writing, rubric design, data interpretation, equity audits, and closing-the-loop — in a sequenced modular structure that produces observable practice changes.

## When to Use
- ✅ Building a year-long assessment literacy curriculum for faculty
- ✅ Designing K-12 district assessment literacy professional development
- ✅ Med-ed assessment-skills curriculum for residency program educators
- ✅ Workforce trainer development on competency assessment
- ❌ Auditing a single rubric (use the rubric alignment prompt)
- ❌ Designing a single test (use the assessment blueprint builder)

## Inputs Required
- **Audience:** educators by role, prior assessment background
- **Sector:** K-12 / HE / workforce / med-ed
- **Available time:** total contact hours over the curriculum
- **Modality mix:** workshops, ongoing practice, peer review
- **Priority skills:** which assessment skills are most urgent in this context
- **Existing tools / artifacts** faculty currently use

## Constraints

**Must:**
- Cover six core domains: purposes of assessment / item & task writing / rubric design / data interpretation / equity in assessment / closing the loop
- Sequence from foundational to advanced
- Pair each module with application (faculty try a technique on their own work)
- Include peer review of faculty-generated assessments
- Address equity in assessment (bias detection, accommodations, alternative formats)
- Build cumulative artifact: each faculty member ends with a redesigned assessment

**Must Not:**
- Stay theoretical without application
- Skip equity-in-assessment module
- Generate a curriculum that fits in 2 hours
- Treat assessment as test-only (include performance tasks, observations, portfolios)
- Skip the closing-the-loop module

## Instructions

1. **Confirm inputs.** Echo audience, sector, time, modality, priority skills.

2. **Build the six-module curriculum.**

   **Module 1: Purposes of Assessment**
   - Formative vs. summative
   - Assessment FOR vs. AS vs. OF learning
   - Validity, reliability, fairness foundations
   - Diagnostic / placement / progress monitoring / certification distinctions

   **Module 2: Item & Task Writing**
   - Bloom's-aligned item design
   - Selected-response item quality (stems, distractors, cueing avoidance)
   - Constructed-response and performance task design
   - Authentic-assessment principles

   **Module 3: Rubric Design**
   - Analytic vs. holistic vs. single-point
   - Criteria selection (outcome-aligned, not generic-quality)
   - Level descriptors (observable, distinct, parallel)
   - Anchor papers and calibration

   **Module 4: Data Interpretation**
   - Item analysis (difficulty, discrimination, distractor analysis)
   - Trend analysis
   - Disaggregating by subgroup
   - Avoiding common errors (correlation/causation, regression to mean, etc.)

   **Module 5: Equity in Assessment**
   - Bias detection (cultural, linguistic, accessibility, contextual)
   - Universal Design for Assessment principles
   - Accommodations vs. modifications
   - Multiple modes of demonstration

   **Module 6: Closing the Loop**
   - From data to instructional action
   - Communication of results to learners and stakeholders
   - Documentation for program improvement
   - Continuous improvement cycle

3. **Specify per-module structure.**
   - Pre-work: reading or short asynchronous module
   - Workshop session: concepts + practice
   - Application: faculty redesign their own assessment
   - Peer review: small group critique
   - Reflection: what changed, what's next

4. **Build the cumulative artifact path.**
   - Faculty bring an existing assessment at the start
   - Each module sharpens one aspect of that assessment
   - Final artifact: substantially redesigned assessment with documentation

5. **Plan modality mix.**
   - Synchronous workshops for community and feedback
   - Asynchronous modules for foundational content
   - Coaching for individual support
   - PLC structure for ongoing peer review

6. **Evaluate.**
   - Pre-post knowledge check
   - Faculty-generated artifact quality (rubric)
   - Practice change (observable in subsequent assessments)
   - Student / learner outcomes (where measurable)

## False-Positive Prevention

| Common Mistake | Why It's Wrong | Correct Approach |
|---|---|---|
| Theory without application | Knowledge doesn't transfer | Each module includes faculty applying to own work |
| Skipping equity module | Bias and access issues persist | Equity is one of six required modules |
| Assessment = test | Misses performance, observation, portfolio | Cover full range of assessment types |
| No peer review | Faculty work in isolation; quality suffers | Build small-group critique into each module |
| No data interpretation skills | Faculty produce data but can't interpret | Module 4 is essential |
| No closing-the-loop | Data produced but unused | Module 6 makes the cycle complete |
| Generic "improve assessment" outcomes | Unmeasurable | Cumulative artifact + observable practice change |

## Verification Checklist

- [ ] Six modules sequenced from foundational to advanced
- [ ] Each module: pre-work + workshop + application + peer review + reflection
- [ ] Equity-in-assessment module included
- [ ] Cumulative artifact path specified
- [ ] Modality mix appropriate
- [ ] Evaluation plan across multiple levels
- [ ] Closing-the-loop module included
