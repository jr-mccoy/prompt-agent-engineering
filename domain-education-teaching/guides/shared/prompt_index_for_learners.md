# Prompt Index for Learners (Cross-Domain)

A curated index of every prompt in this repo a learner is likely to use, organized by job-to-be-done. The companion file `PROMPT_INDEX.json` has the same prompts tagged with `learner_audience: [college, adult-returning, career-changer]` for programmatic access.

## How to Use

Find your job-to-be-done in the table of contents. Each section lists prompts with:
- A short description
- Which audience(s) it applies to: 🎓 college / 🔄 returning / 🛤 career changer
- A link to the file

A few prompts apply to multiple audiences and are listed in each relevant section.
