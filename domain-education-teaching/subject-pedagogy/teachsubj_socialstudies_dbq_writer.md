# Document-Based Question (DBQ) Writer

## Objective

Construct a full DBQ aligned to a specific historical question, including 5–7 documents (with attributions and source notes), a student organizer, an analytic rubric (suitable for AP-style or state-test scoring), and a teacher-facing exemplar outline.

## When to Use

- Summative argument writing in middle or high school history
- AP US History, AP World, AP European History DBQ practice or assessment
- Document-analysis instruction with primary sources
- Teaching contextualization, sourcing, corroboration, and HAPP (Historical Argumentation, Periodization, Patterns)

## When NOT to Use

- Multiple-choice content quiz — use `assessment_mc_item_writer_with_distractors.md`
- Open inquiry without documents — use `teaching_socratic_discussion_facilitator.md`
- Need to teach the era first — use `teaching_unit_curriculum_planner.md`

## Inputs Needed

- **Course / band:** [US History / World History / Civics / Economics / Geography / AP / IB]
- **Era / topic:** [e.g., Reconstruction, Industrial Revolution, French Revolution, Cold War origins]
- **Historical question:** [Open argumentative question — e.g., "To what extent did Reconstruction succeed in protecting the rights of formerly enslaved people?"]
- **Document count:** [5, 6, or 7]
- **Time for assessment:** [Class period / 55-min AP-style / take-home]
- **Target standards / skills:** [HAPP, sourcing, contextualization, corroboration; CCSS RH 9-10.1, etc.]

## Instructions

### Step 1: Vet the Historical Question

Check the question against:

| Criterion | Pass / Fix |
|-----------|-----------|
| Argumentative (multiple defensible positions) | |
| Time-bounded and place-bounded | |
| Answerable with the document set you'll provide | |
| Aligned to course standards or AP rubric | |
| Avoids presentism / loaded framing | |

If "fix," propose a sharpened version.

### Step 2: Document Set — Plan for Diversity

Plan the document set to include diversity along these axes:

| Axis | Targets |
|------|---------|
| Type | Mix at least 4: text, image, map, chart/data, political cartoon, oral history, government document |
| Perspective / point of view | Multiple stakeholders (state, citizen, opposition, marginalized voice, foreign observer) |
| Date | Spread across the period in question; include at least one before, during, and after |
| Authorship demographics | Multiple author backgrounds — avoid all-elite-white-male sets |
| Tone toward question | Some support each defensible thesis |

### Step 3: Build Each Document

For each of the N documents, provide:

**Document N**
- **Source attribution:** [Author, title, date, type] — accurate and citable; if from a real archive, note where it's findable; if invented for testing purposes, label clearly as "fictionalized excerpt for assessment"
- **Excerpt** (50–200 words for text; image/data described in detail with caption)
- **Source line for student** (formatted exactly as students will see it)
- **Sourcing note** (what students should know about the source for HAPP — author position, audience, purpose, date significance)
- **What it offers the argument** (which thesis/es it supports or complicates)
- **Difficulty / language scaffolds** (any tier-3 vocabulary defined inline if it would block access)

⚠ **Authenticity rule:** If you cannot verify a real document exists, label any generated text as "fictionalized excerpt — do not cite as historical." Do not invent quotations attributed to real historical figures.

### Step 4: Student Organizer

Provide a one-page graphic organizer:

```
HISTORICAL QUESTION: [...]

MY THESIS (claim + reasoning):

EVIDENCE BY POINT
┌──────────────┬───────────────────────┬──────────────────────┬─────────────────┐
│ My point     │ Document(s) cited     │ Source / context     │ How it supports │
├──────────────┼───────────────────────┼──────────────────────┼─────────────────┤
│ 1.           │                       │                      │                 │
│ 2.           │                       │                      │                 │
│ 3.           │                       │                      │                 │
└──────────────┴───────────────────────┴──────────────────────┴─────────────────┘

COUNTERARGUMENT & RESPONSE:

CONTEXTUALIZATION (broader background that frames the question):
```

### Step 5: Analytic Rubric

Build a rubric aligned to the target style (general, AP-style, IB, or state). For AP-style (LEQ/DBQ skills), use:

| Criterion | Score | Descriptor |
|-----------|-------|------------|
| Thesis / Claim | 0–1 | Defensible thesis that responds to the prompt and establishes a line of reasoning |
| Contextualization | 0–1 | Broader historical context relevant to the question (not just topic) |
| Evidence — from documents | 0–2 | Uses content of N documents to support an argument; uses N+1 to bolster |
| Evidence — beyond documents | 0–1 | One specific historical example outside the documents |
| Sourcing (HAPP) | 0–1 | Explains POV, purpose, audience, or context for at least N documents |
| Complexity | 0–1 | Demonstrates complex understanding (qualifies, considers multiple perspectives, makes connections) |

If non-AP, build a 4-level rubric (Exemplary / Proficient / Developing / Beginning) with 3–4 criteria.

### Step 6: Exemplar Essay Outline (Teacher-Facing)

Provide a proficient-level essay outline:

- Thesis (one sentence)
- Contextualization paragraph (3–4 sentences with specific historical content)
- Body paragraphs (3 — each cites 2 documents + 1 outside example)
  - Topic sentence
  - Documents cited with sourcing
  - Reasoning
- Counterargument paragraph
- Complexity move (one sentence stating how the thesis is complicated)

### Step 7: Differentiation & Access

- **Below-level reader:** Reduce to 5 documents, pre-glossed key terms, sentence-frame organizer
- **Above-level / honors:** Add a 7th complicating document, require 2 outside examples
- **ELL:** Visuals prioritized over dense text where the standard allows; bilingual glossary for proper nouns
- **IEP — extended time:** Note where natural break points occur

## Output Format

1. Vetted historical question
2. Document plan (axes table)
3. Documents 1 through N (each with attribution, excerpt, sourcing note, role)
4. Student organizer (formatted)
5. Rubric
6. Teacher exemplar outline
7. Differentiation menu
8. Authenticity disclosure (which documents are real, which are fictionalized for assessment)

---

## False-Positive Prevention

❌ **DON'T:**
- Invent quotations from real historical figures
- Stack documents to one side of the argument — defeats DBQ purpose
- Use only text documents — students need to read images, charts, maps
- Strip sourcing information that students need for HAPP scoring
- Write a question where the documents reveal one obvious "right" answer

✅ **DO:**
- Label any generated/fictionalized excerpt clearly
- Build a balanced document set across type and perspective
- Provide complete source lines as students will see them
- Align the rubric to the actual target (AP/IB/state)
- Make the question genuinely argumentative — multiple defensible theses

---

## Quality Indicators

- [ ] Historical question is argumentative, time- and place-bounded
- [ ] Document set passes the diversity matrix
- [ ] Every document has a complete, formatted source line
- [ ] Generated/fictionalized content is explicitly labeled
- [ ] Rubric matches the target style (AP, IB, or state)
- [ ] Teacher exemplar outline scores at least proficient on the rubric
