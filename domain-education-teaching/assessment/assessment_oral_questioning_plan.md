# Oral Questioning Plan

## Objective

Produce a scripted oral questioning sequence for a single learning objective — with opening questions, follow-up probes, "if correct: deepen" branches, "if incorrect: redirect" branches, and listening guides — so that classroom questioning is a diagnostic tool, not a performance.

## When to Use

- At the start of a lesson to surface prior knowledge
- Mid-lesson to check understanding before releasing students to practice
- During a Socratic seminar or structured discussion
- In small-group pull-outs to diagnose struggling students
- When you want to train yourself to respond diagnostically rather than evaluatively

## When NOT to Use

- Whole-class summative assessment — use `assessment_mastery_check_designer.md`
- When you need written evidence of student thinking — use `assessment_short_answer_item_writer.md`
- As a script to read verbatim — this plan is a map, not a script

## Instructions

### Step 1: Define the Diagnostic Target

Write one sentence describing the understanding you're trying to surface: "By the end of this questioning sequence, I will know whether students [specific understanding criterion]."

Then write one sentence describing the most common wrong understanding at this point: "The most likely misconception I expect to encounter is [specific description]."

### Step 2: Design the Opening Question

The opening question should:
- Be open enough to generate a range of responses
- Require more than yes/no
- Be answerable from prior experience or knowledge
- Not inadvertently teach the answer

Write the question, then write a "warm call" framing — the sentence the teacher says to introduce it:

```
OPENING QUESTION
─────────────────────────────────────────────
Warm call framing: "[What to say before posing the question]"
Question: "[Full question text]"
Think time: [Seconds before calling on anyone]
Response mode: [Cold call / hands up / pair first then share / whiteboard show]

What a strong response sounds like:
[2–3 observable features of a good answer at this point]

What a concerning response sounds like:
[1–2 indicators of the target misconception]
```

### Step 3: Build the Questioning Sequence

Design a 3–5 step sequence. Each step is a node with two branches.

```
QUESTIONING SEQUENCE
─────────────────────────────────────────────────────────────────────

STEP 1: OPENING QUESTION
"[Question text]"

  → IF RESPONSE SHOWS UNDERSTANDING:
    Follow-up: "[Deepen — move toward application or nuance]"
    Teacher note: [What you're listening for to confirm depth]

  → IF RESPONSE SHOWS PARTIAL UNDERSTANDING:
    Follow-up: "[Probe — ask for an example, ask them to show their reasoning]"
    Teacher note: [What partial understanding sounds like here]

  → IF RESPONSE SHOWS MISCONCEPTION:
    Redirect: "[Question that targets the misconception without correcting it directly]"
    Teacher note: [What the misconception reveals — name it]

───────────────────────────────────────────────

STEP 2: FOLLOW-UP / DEEPENING QUESTION
"[Question text — typically moves to application or asks 'why']"

  → IF CORRECT: [Next deepening move]
  → IF INCORRECT: [Redirect move]

───────────────────────────────────────────────

STEP 3: CONCEPT CHECK (if needed)
"[Question that tests the core objective directly — can be hinge-style]"

  → IF CORRECT: → STEP 4 (consolidation)
  → IF INCORRECT: → RETEACH (see Step 4B)

───────────────────────────────────────────────

STEP 4A: CONSOLIDATION (if students showed understanding)
"[Closing question — asks students to synthesize or extend]"
[Teacher narrates what was learned together]

STEP 4B: RETEACH ENTRY (if misconception was persistent)
"[Reframe question — new angle, new context, or concrete example]"
[2-sentence reteach move — use a different example or modality than Step 1]
Then re-ask: "[Simplified version of Step 3 concept check]"

─────────────────────────────────────────────────────────────────────
```

### Step 4: Listening Guide

For each major step, provide a listening guide — what to pay attention to in student responses:

```
LISTENING GUIDE
─────────────────────────────────────────────
STEP 1 listening:
✅ Understanding indicators: [Words/ideas to hear]
⚠️  Partial understanding: [What sounds right but isn't complete]
❌  Misconception indicators: [Specific phrasing or reasoning that signals the named misconception]

STEP 2 listening:
[Same structure]
```

### Step 5: Cold-Call Protocol (Optional)

If the teacher wants to use cold-calling rather than volunteering, provide a brief equity protocol:

- Pre-announce topics the day before so students can prepare
- Use a randomizer (popsicle sticks, name cards) visibly
- Allow think time before calling the name — "Everyone think for 30 seconds. [Pause.] [Name]…"
- Normalize revision: "How would you change your answer after hearing [peer's] response?"

## Output Format

1. Diagnostic target statement (2 sentences)
2. Opening question with framing and warm call
3. Full questioning sequence (Steps 1–4A/4B) with branches
4. Listening guide for each step
5. Optional cold-call equity protocol
6. Time estimate (with step-by-step pacing)

---

## False-Positive Prevention

❌ **DON'T:**
- Write questions that have obvious correct answers visible in the phrasing ("Wouldn't you say that photosynthesis is…")
- Design a sequence with only one branch (as if students always get it right)
- Use only high-cognitive-demand questions — the sequence should start accessible and build
- Skip the listening guide — the point of a plan is knowing what to hear, not just what to say
- Treat a "correct" answer as confirmation of understanding without probing for reasoning

✅ **DO:**
- Include a misconception-redirect branch at every step
- Write listening guides that name specific words or reasoning patterns to listen for
- Build in at least one "convince me" or "say more" probe to push beyond surface responses
- Include a reteach entry for when the sequence reveals the misconception is widespread
- Design pacing so the full sequence fits the stated time window

---

## Quality Indicators

- [ ] Opening question is open-ended and generative
- [ ] Each step has both a "correct" and "incorrect" response branch
- [ ] Listening guide names specific indicators (not just "shows understanding")
- [ ] Named misconception is addressed in a redirect branch
- [ ] Reteach entry uses a different angle than the original instruction
- [ ] Full sequence fits within stated time window
