# Program Review Cycle Designer

**Objective:** Design a periodic (typically 5-7 year) program review cycle: the timeline, required artifacts, data sources, internal and external review-committee processes, decision points, and continuous-improvement loop that turn review into change rather than producing shelf-ware reports.

## When to Use
- ✅ Establishing a new institutional program-review process
- ✅ Redesigning an ineffective existing process
- ✅ Aligning program review with accreditor expectations
- ✅ Building a workforce or training-program internal review cycle
- ❌ Single-cycle self-study writing (use accreditation self-study prompts)
- ❌ Continuous improvement at the course level (use the continuous-improvement cycle prompt)

## Inputs Required
- **Institution / sector** and program scope
- **Cycle length:** typically 5-7 years for HE; varies for workforce
- **Accreditor schedule** (if applicable): when does program review feed accreditation?
- **Available data sources:** assessment data, enrollment, completion, post-graduation, financials
- **Review-committee structure:** internal, external, hybrid
- **Existing process** (if any): for redesign

## Constraints

**Must:**
- Specify timeline from kickoff through decision and follow-up
- Define artifacts and data sources required
- Define internal and external reviewer roles
- Build decision points (continue / modify / consolidate / sunset)
- Build follow-up mechanism (action plan accountability, mid-cycle check)
- Tie to budget and strategic planning where possible

**Must Not:**
- Generate a process that produces a report no one acts on
- Skip external review (loses independent perspective)
- Bury weak programs (review should surface and act on underperformance)
- Treat review as one-time event (it's part of a cycle)
- Disconnect from accreditation timeline

## Instructions

1. **Confirm inputs.** Echo cycle length, accreditor schedule, data sources, committee structure.

2. **Build the cycle timeline.**
   - Year 0: Charge issued to program; review kickoff
   - Year 0-0.5: Program prepares self-study
   - Year 0.5: External reviewer site visit (or remote review)
   - Year 0.5-0.75: Report finalization; recommendations drafted
   - Year 0.75: Decision and action plan
   - Years 1-3: Mid-cycle check-ins on action plan
   - Year 4-5: Pre-next-cycle review

3. **Define required artifacts.**
   - Self-study (sections on mission, outcomes, curriculum, faculty, resources, students, future plans)
   - Outcomes attainment evidence
   - Curriculum map
   - Enrollment / completion / placement data
   - Financial data
   - Comparator data (peer programs, regional)
   - Student / alumni / employer feedback

4. **Define reviewer roles.**
   - Internal: faculty from other programs, assessment office, academic affairs
   - External: 1-2 disciplinary peers from peer institutions; industry partners for workforce programs
   - Reviewer charge: questions to address, format of feedback

5. **Define decision points.**
   - Continue at current scale
   - Modify (specific changes recommended)
   - Consolidate with another program
   - Sunset (with teach-out plan)
   - Provide additional resources / investment

6. **Define follow-up.**
   - Action plan with owner, timeline, measure
   - Mid-cycle check (typically year 2-3)
   - Accountability mechanism (where action plan progress is reported)

7. **Tie to accreditation cycle.**
   - Sequence program review before accreditation reaffirmation cycles to feed self-studies
   - Document the alignment

## False-Positive Prevention

| Common Mistake | Why It's Wrong | Correct Approach |
|---|---|---|
| Reports without action | Wastes resources; demoralizes participants | Build action plan + accountability + mid-cycle check |
| Internal review only | Loses outside perspective | Always include external disciplinary reviewer |
| No decision options beyond "continue" | Hides underperforming programs | Include modify / consolidate / sunset options |
| Disconnected from accreditation | Duplicative work; missed opportunity | Sequence to feed accreditation cycles |
| Vague action plans | Won't drive change | Action + owner + timeline + measure |
| No mid-cycle check | Plans get forgotten | Schedule mid-cycle progress review |
| Treating review as bureaucratic compliance | Wastes the opportunity | Frame as strategic decision-making tool |
