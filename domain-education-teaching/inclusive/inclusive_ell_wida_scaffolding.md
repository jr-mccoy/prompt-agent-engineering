# ELL Scaffolding by WIDA Proficiency Level

## Objective

Take a content lesson and produce WIDA-aligned scaffolds for each of six English language proficiency levels (Entering 1, Emerging 2, Developing 3, Expanding 4, Bridging 5, Reaching 6). Each level gets a language objective, scaffolds for receptive and productive language across the four domains (listening, speaking, reading, writing), modified output expectations, and assessment accommodations — all while keeping the content objective intact.

## When to Use

- Mixed-proficiency classrooms with English Learners
- Co-planning between content and EL/ESOL teachers
- Sheltered instruction settings
- Newcomer support
- Curriculum review for language access

## When NOT to Use

- Reading-level adaptation only — use `teaching_reading_level_adapter.md`
- Vocabulary plan only — use `teaching_vocabulary_builder.md`
- General differentiation across abilities — use `teaching_differentiation_planner.md`

## Instructions

### Step 1: Identify Language Demands

Audit the lesson for the language students must comprehend and produce:

| Domain | Demand in this lesson |
|--------|----------------------|
| Listening | [Teacher language, peer talk, audio/video] |
| Speaking | [Discussion, partner talk, presentation] |
| Reading | [Texts, problems, instructions] |
| Writing | [Notes, responses, products] |

| Language function | Where it appears |
|------------------|-----------------|
| [e.g., compare and contrast] | [Activity 2: Venn diagram] |
| [e.g., justify with evidence] | [Exit ticket] |

### Step 2: Write a Language Objective

In addition to the content objective, write a language objective:

> **Students will [domain verb — listen for / discuss / read / write] [language function] using [specific structures or vocabulary].**

Example: "Students will write a comparison of two ecosystems using comparative structures (more __ than, both __ and, while __ , __ )."

The language objective is the same across all WIDA levels; only scaffolds differ.

### Step 3: Build Per-Level Scaffold Cards

For each WIDA level present, produce:

```
WIDA LEVEL [N] — [NAME]
─────────────────────────────────────────────

What this learner can typically do (per WIDA Can-Do descriptors for this grade band):
[2–3 bullet points specific to grade band]

CONTENT OBJECTIVE: [unchanged — same as whole class]

LANGUAGE OBJECTIVE (modified for level):
[Same target function, scaffolded expectation]

RECEPTIVE SCAFFOLDS (listening + reading):
- [e.g., visuals beside key terms; bilingual glossary; teacher slow speech with chunking; cognate highlighting; pre-loaded annotation; audio access]

PRODUCTIVE SCAFFOLDS (speaking + writing):
- Sentence frames: [Level-appropriate frames — see frame ladder below]
- Word bank: [Tier 2 + Tier 3 words pre-loaded]
- Modality alternatives: [e.g., draw + label; bilingual response; partner share before solo write]
- Wait time / processing time: [Specific minimum]

OUTPUT EXPECTATION FOR THIS TASK:
[What product looks like at this level — same content, scaffolded form]

ASSESSMENT ACCOMMODATIONS:
- [e.g., extended time, simplified directions, native-language clarification of directions, oral response option]
- (Note: scaffolds support access; they do not lower the content standard)

PARTNER / GROUPING NOTES:
[Suggested pairing — bilingual peer, near-peer model, mixed-proficiency group]
```

### Step 4: Sentence Frame Ladder

Provide level-appropriate frames for the lesson's key language function. Example for "compare":

| Level | Frame |
|-------|-------|
| 1 Entering | "[A] is [adjective]. [B] is [adjective]." (with picture support) |
| 2 Emerging | "[A] has ___. [B] has ___." |
| 3 Developing | "[A] and [B] both have ___, but [A] is ___." |
| 4 Expanding | "While [A] is ___, [B] is ___ because ___." |
| 5 Bridging | "Although both [A] and [B] ___, [A] differs in that ___." |
| 6 Reaching | (grade-level expectation; no frame required) |

### Step 5: Vocabulary Triage

Tier the lesson's vocabulary:

| Word | Tier | Scaffold by level |
|------|------|------------------|
| [Word] | T3 (academic, content-specific) | Pre-teach for all levels; visual + cognate |
| [Word] | T2 (cross-disciplinary academic) | Pre-teach for levels 1–3; embed for 4–5 |
| [Word] | T1 (everyday) | Embed; clarify only for level 1 if needed |

### Step 6: Cognate Audit

If students have a shared L1 (especially Spanish, Portuguese, French, etc.), list cognates with the lesson's key terms:

| English | Cognate (L1) | Note |
|---------|-------------|------|
| [...] | [...] | [True cognate / partial / false cognate warning] |

### Step 7: Newcomer Provision (Level 1) Special Notes

For students with no English, additional supports:

- Visual schedule of class period
- Buddy with bilingual peer if available
- Total Physical Response option for routine directions
- Acceptance of L1 written responses for content demonstration when language is not the construct
- Concrete demonstration before any instruction

### Step 8: Equity & Asset-Based Audit

- [ ] Scaffolds described as access supports, not deficiencies
- [ ] Content rigor unchanged across levels
- [ ] L1 framed as an asset, not a barrier
- [ ] No assumption that ELL = below grade level academically
- [ ] Scaffolds fade — plan for which scaffolds the student can release as language develops

## Output Format

1. Language demand audit
2. Content + language objectives
3. Six (or selected) WIDA level scaffold cards
4. Sentence frame ladder for the lesson's key function
5. Vocabulary tier table with per-level scaffold notes
6. Cognate audit
7. Newcomer provision notes
8. Equity and asset-based audit

---

## False-Positive Prevention

❌ **DON'T:**
- Lower the content objective for any level — language scaffolds, not content reduction
- Assume ELLs are below grade level in content
- Treat L1 as a problem to be replaced
- Use generic "differentiate" advice — WIDA levels are specific
- Pile scaffolds the student doesn't need (over-scaffolding stalls language growth)

✅ **DO:**
- Keep content rigor constant; vary form and support
- Provide level-specific frames, not one-size-fits-all
- Audit for cognates as bridges to academic language
- Plan for scaffold fading
- Frame scaffolds as access, not as ceilings

---

## Quality Indicators

- [ ] Language objective is distinct from content objective
- [ ] Each WIDA level has its own scaffold card
- [ ] Sentence frame ladder spans levels 1–5 with grade-level at 6
- [ ] Vocabulary triaged by tier with per-level notes
- [ ] Cognates identified when L1 supports them
- [ ] Asset-based language throughout
- [ ] Content objective unchanged across levels
