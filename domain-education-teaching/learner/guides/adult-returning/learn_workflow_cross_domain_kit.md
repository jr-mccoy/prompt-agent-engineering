# Adult Returning to School: Cross-Domain Prompt Kit

The academic workflows handle the schoolwork. This kit covers the surrounding life. Returning adults touch at least 6 domains of this repo regularly — these are the prompts that show up most.

## Sample Semester Sequence

A realistic semester for a returning adult:

**Pre-term (1–2 weeks before):**
- `adult_cold_start_return_to_school.md` (in this guide)
- `adult_working_learner_time_architecture.md` (in this guide)
- `deepwork_focus_parameters_estimator.md`
- `identity_confidence_calibration.md` (if anxious)

**Weeks 1–4:**
- Weekly: `reviews_weekly_systems_review.md`
- Once: `bottleneck_capture_triage_system_design.md`
- Before first paper: `adult_writing_rust_recovery.md` (in this guide)

**Weeks 5–10:**
- Weekly: `reviews_weekly_systems_review.md`
- As needed: `agency_stuck_diagnosis.md`, `bottleneck_procrastination_systems_diagnostic.md`
- Once: `adult_imposter_age_cohort_calibration.md` (in this guide) when the mid-term crisis hits
- After each graded return: `agency_feedback_extraction.md`

**Weeks 11–end:**
- Weekly: `reviews_weekly_systems_review.md`
- Once: `bottleneck_perfectionism_ship_threshold.md` for final papers
- Once: `learnstudy_finals_week_plan.md` (in `learner-study-skills/`)

**End of semester:**
- `reviews_monthly_quarterly_cadence.md`
- `agency_weekly_review.md` for an end-of-term version

This is the operating system. Sustain it; the systems compound.
