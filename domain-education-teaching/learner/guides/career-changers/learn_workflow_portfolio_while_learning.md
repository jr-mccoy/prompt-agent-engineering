# Workflow: Portfolio While Learning

## Who This Is For

- Career changer 3+ months into a pivot who has nothing public to show
- Learner whose work has been invisible — only known to themselves and a study group
- Anyone whose pivot has been quietly stalled because they don't think they're "ready" to publish

## What You'll Have at the End

- A compounding portfolio plan with 3–5 specific artifacts
- A weekly shipping cadence you'll actually keep
- Distribution plan for each artifact (platforms + direct outreach)
- Honest-labeling standards so your work signals correctly
- The first artifact actively in flight by end of week 1

## What You Need to Bring

- Target role and field
- Honest self-assessment of current skill level (beginner / advanced beginner / intermediate)
- Time per week available
- Where the target field's audience lives (platforms, communities)
- Existing related work (anything reusable / adaptable)
- Specific fears about shipping (be honest — the workflow addresses these)

## The Chain

### Step 1 — Run the portfolio strategy prompt

**Prompt:** [`../../adult-learner/learn_portfolio_while_learning.md`](../../adult-learner/learn_portfolio_while_learning.md)

**Input:** target field, current skill level, time budget, platforms, existing work, specific fears

**What you'll get:**
- Honest level audit
- Field convention map
- 3–5 compounding artifacts with skill level, demonstration, platform, time
- Labeling standards
- Distribution plan per artifact
- Specific fears addressed
- Cadence (weekly + monthly shipping)
- First artifact spec for this week

**Carry forward:** the portfolio plan + first artifact spec

**Time:** 90–120 min

---

### Step 2 — Ship the first artifact (Week 1)

The first artifact should be small. The goal of Week 1 is to break the "I haven't shipped anything" pattern.

**Sub-steps:**
1. Build the artifact (this is real work — 5–15 hr depending on the artifact)
2. Honest-label it per the standards from Step 1
3. Publish on the primary platform
4. Announce on distribution platforms
5. Direct-message 3 people in the target field with a "love your thoughts when you have 10 minutes"

**Carry forward:** the published artifact + the responses (if any) + your own reactions

**Time:** matches the artifact's time estimate from Step 1

---

### Step 3 — Process the responses

After the first artifact ships:

**Prompt:** [`../../../../domain-personal-development/prompts/agency/agency_feedback_extraction.md`](../../../../domain-personal-development/prompts/agency/agency_feedback_extraction.md)

**Input:** any responses, comments, DMs, silence

**What you'll get:** what to incorporate, what to ignore, what to revise; signal vs. noise

**Carry forward:** edits to the artifact (if needed) and adjustments to the next artifact's plan

**Time:** 30 min per artifact

**Silence is data, not failure.** If no one responded, the questions are: did the work reach the audience? was the labeling clear? was the topic interesting to that audience? The next artifact will be sharper.

---

### Step 4 — Run the shipping cadence weekly

Each week:
- 1 small public thought (LinkedIn / Twitter / Substack short / community post)
- 25% progress on the current major artifact

Each month:
- 1 major artifact shipped
- 1 update / extension to a prior artifact (corrections, follow-ups, deeper dives)
- 1 informational interview or community event

This is the operating system. Sustain it for the duration of the pivot.

## Time Budget

| Step | Time |
|------|-----|
| 1. Portfolio strategy prompt | 1.5–2 hr |
| 2. Ship first artifact (week 1) | 5–15 hr |
| 3. Process responses | 30 min |
| 4. Weekly cadence | 5–10 hr/week ongoing |

The shipping cadence is the actual ongoing investment. The first three steps are setup.

## Common Failure Modes

| Failure | What to do |
|---------|-----------|
| Building the first artifact too big | Cut it in half. Ship smaller. Bigger artifact comes next. |
| Hiding the work behind privacy (private GitHub, no LinkedIn, etc.) | Defeats the entire purpose. Make it public. If specific employer policy prevents — pen name + generic-industry topics, but still public. |
| Perfectionism on labeling and distribution | Honest-labeling is supposed to be slightly uncomfortable. Lean in. |
| Posting once, no follow-up | Distribution is not "press publish." Direct outreach to 3 specific people matters more than the post itself. |
| Silence after first artifact = "no one cares" | Silence usually means the work didn't reach. Refine distribution; ship again. After 3 artifacts with zero engagement, get a 30-min call with someone in the field to debug. |
| Building artifacts that don't compound | Each should build on the prior. If artifact 2 doesn't use anything from artifact 1, redesign artifact 2. |

## Special Case: Employer Policy

If your current employer has policies about publishing about your pivot field:

- Read the policy carefully; most allow personal work on personal time
- Avoid your employer's trade secrets and direct competitors
- Use a pen name if needed (and disclose to a few trusted contacts)
- Stick to general industry topics, not your specific work
- If in doubt, ask HR; the conversation is usually friendlier than the policy reads

If you genuinely can't publish at all under current employer policy, the pivot will be 30–50% slower. Factor that into your timeline.

## What Counts as Shipping

| Counts | Doesn't count |
|--------|--------------|
| Public GitHub repo | Private GitHub repo |
| Public LinkedIn article | Draft saved in Notes |
| Substack post sent to subscribers | Word doc in a folder |
| Public design portfolio with case studies | Private Figma file |
| Conference / meetup talk (in person or recorded) | "I'll do a talk someday" |
| Open-source contribution merged | Local commits |
| Public Twitter / X thread that names what you did | Telling friends what you did |
| 30-min talk to your skip-level manager about pivot work | "I'll bring it up next 1:1" |

If it's not visible to people in the target field, it's not shipped.
