# Stuck & Confused

*8 prompts · part of [`domain-education-teaching`](../../README.md)*

## Use these when

Repair after a failure: one step of a solution makes no sense, you got an answer wrong and cannot see why, the explanation is not landing in the representation you were given, or you want to debrief what went wrong. Distinct from `tutoring/`, which teaches forward.

## Go elsewhere when

- **You have not been taught it yet** → [`../tutoring/`](../tutoring/)
- **Systematically logging mistakes over time** → [`../self-assessment/`](../self-assessment/)
- **The confusion is in your own maths working** → [`../math-science/`](../math-science/)
