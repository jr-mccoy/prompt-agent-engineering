# Academic Writing Coach

*9 prompts · part of [`domain-education-teaching`](../../README.md)*

## Use these when

Coaching your own essay without having it written for you — thesis development with critique, counterarguments, outlining, revision, peer-review framing, citation, annotated bibliography, source credibility, and an academic-integrity self-check before you submit. None of these produce submittable prose.

## Go elsewhere when

- **You are grading writing, not producing it** → [`../../instructor/grading-feedback/`](../../instructor/grading-feedback/)
- **Research question and search strategy come first** → [`../research/`](../research/)
- **Creative rather than academic writing** → [`../../../domain-creative-writing/`](../../../domain-creative-writing/)
