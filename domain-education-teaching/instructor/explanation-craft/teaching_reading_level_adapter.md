**Purpose:** Adapt existing texts to multiple reading levels (above, on, and below grade level) while preserving core content, academic vocabulary, and instructional value — including ELL-specific adaptations by language proficiency level.

**When to use:** Differentiating reading materials for diverse classrooms; adapting grade-level texts for struggling readers; creating ELL-accessible versions of content; preparing materials for inclusion settings; building text sets at varied complexity levels.

**Input needed:**
- Original text (or topic to create text about)
- Current reading level of the text
- Target reading level(s)
- Grade level of students
- Key vocabulary and concepts that must be retained

### Step 2: Generate Level-Adapted Versions

**Below Grade Level (Scaffolded):**

Apply these adjustments:
- Shorten sentences (target 8-12 words per sentence)
- Replace Tier 2 vocabulary with common synonyms (keep Tier 3 domain words with embedded definitions)
- Add explicit text structure signals ("First... Next... Finally...")
- Break long paragraphs into shorter ones (3-4 sentences max)
- Add subheadings for navigation
- Use simple sentence structures (subject-verb-object)
- Include context clues for key vocabulary
- Add visual supports (suggest where images, diagrams, or icons would help)

**Embedded Definition Format:**
> "The colonists decided to boycott — refuse to buy — British goods."

**On Grade Level (Standard):**

Apply these adjustments:
- Maintain original complexity appropriate to grade level
- Ensure vocabulary is challenging but accessible with context clues
- Keep original text structure with clear transitions
- Verify sentence variety (mix of simple, compound, complex)
- Include 2-3 Tier 2 vocabulary words students should learn
- Add glossary for Tier 3 domain-specific terms if not in original

**Above Grade Level (Extended):**

Apply these adjustments:
- Increase sentence complexity (compound-complex sentences)
- Introduce advanced Tier 2 vocabulary (e.g., "significant" → "pivotal")
- Add nuance, counterarguments, or multiple perspectives
- Include additional primary source excerpts or data
- Extend with analysis questions embedded in the text
- Reference connections to other topics or disciplines
- Reduce scaffolding (fewer subheadings, less explicit signposting)

### Step 3: ELL-Specific Adaptations (if requested)

Adapt using WIDA English Language Proficiency levels:

| WIDA Level | Adaptations |
|-----------|-------------|
| **Level 1 — Entering** | Short, simple sentences. Illustrated vocabulary. Native language glossary for key terms. Visual representations of main ideas. Sentence frames for response. |
| **Level 2 — Emerging** | Simple and compound sentences. Repeated language patterns. Vocabulary with visual support. Phrase-level glossary. |
| **Level 3 — Developing** | Compound sentences with some complex. Context-embedded vocabulary. Graphic organizers provided. General academic vocabulary support. |
| **Level 4 — Expanding** | Near grade-level text with strategic vocabulary support. Glossary for technical terms only. Content-area language scaffolds. |
| **Level 5 — Bridging** | Grade-level text with minimal support. Focus on nuanced academic language. Idiom and figurative language notes. |

**For all ELL levels:**
- Preserve cognates when possible (words similar across languages)
- Avoid idioms, slang, and culturally-specific references (or explain them)
- Use present tense where possible (past tense narrative is harder for ELLs)
- Include visual vocabulary support suggestions

- **Above level:** Semantic mapping, usage in original writing

### Step 5: Comprehension Check by Level

**Aligned Questions (same skill, different scaffolding):**

| Skill | Below Level | On Level | Above Level |
|-------|-------------|----------|-------------|
| **Identify main idea** | "What is this text mostly about?" (multiple choice) | "What is the main idea? How do you know?" (short answer) | "How does the author develop the central argument across paragraphs?" (extended response) |
| **Vocabulary** | "Look at paragraph 2. What does [word] mean?" (context + choices) | "Use context clues to determine the meaning of [word]." | "How does the author's word choice affect the reader's understanding?" |
| **Analysis** | "What happened first? What happened next?" (sequencing) | "Why did [event] happen? Give evidence." | "Compare [two perspectives]. Which is more convincing and why?" |

## Quality Indicators

**Effective text adaptations include:**
- [ ] Core content preserved across ALL levels (same main ideas)
- [ ] Key domain vocabulary retained (with appropriate support at each level)
- [ ] Academic rigor maintained (below-level is not "dumbed down")
- [ ] Text structure appropriate to level (more explicit at lower levels)
- [ ] Comprehension questions target the same skills at different depths
- [ ] ELL adaptations address language, not cognitive level
- [ ] Versions could be used in the same classroom simultaneously
- [ ] Teacher notes explain how to facilitate cross-level discussion

**Common Text Adaptation Pitfalls:**

| Pitfall | Sign | Prevention |
|---------|------|------------|
| **Content removal** | Below-level version missing key ideas | Simplify language, not content |
| **Watering down** | Easier version requires no thinking | Maintain cognitive demand; simplify the language path, not the destination |
| **Vocabulary stripping** | Domain words removed from lower levels | Keep Tier 3 words with embedded definitions |
| **Patronizing tone** | Simplified text sounds like it's for younger students | Adapt syntax and vocabulary, maintain age-appropriate topics and tone |
| **Same questions** | Identical questions for all levels | Scaffold the question format, not just the text |
| **ELL = below level** | Treating language learners as low-ability | ELL adaptations target language barriers, not cognitive ability |
