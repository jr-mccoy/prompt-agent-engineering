# Classroom Routines & Transitions Designer

## Objective

Design 6–10 high-leverage classroom routines and transitions, each with a signal, sequence, expected time, materials handoff, re-teach protocol, and visible anchor. Output is a routine catalog the teacher can teach in week 1 and rely on all year.

## When to Use

- Pre-year planning
- Mid-year reset when transitions are losing minutes daily
- Substitute coverage prep — well-defined routines run themselves
- Co-teachers aligning expectations
- After observation feedback names "transitions" as the bottleneck

## When NOT to Use

- Whole-management plan needed — use `classops_management_plan_and_norms.md`
- Behavior intervention for one student — use `teaching_behavior_support_planner.md`
- Single-day sub plan — use `teaching_substitute_plan_generator.md`

## Instructions

### Step 1: Inventory the Day's Movements

List every moment students transition or follow a procedure. Default catalog:

| Moment | Frequency per day | Current time cost (estimate) |
|--------|------------------|------------------------------|
| Entering the classroom | 1+ | |
| Beginning-of-class signal | 1 | |
| Distributing/collecting materials | 3–8 | |
| Whole-class to small-group | 1–3 | |
| Small-group to whole-class | 1–3 | |
| Restroom request | as needed | |
| Tech device pickup/login | 1–2 | |
| Tech device close-down/return | 1–2 | |
| Cleanup before transition | 1–3 | |
| Lining up (elementary) | 1–4 | |
| Dismissal | 1 | |
| Substitute or guest expectations | as needed | |

For each, estimate current time cost. Sum the daily total — this is what's recoverable.

### Step 2: Prioritize the Top 6–10 Routines

Rank by frequency × time cost. Build only the top 6–10. A class with 10 well-engineered routines runs better than one with 25 partial ones.

### Step 3: Design Each Routine

For each routine, output:

```
ROUTINE: [Name]
─────────────────────────────────────────────
WHEN:           [Trigger / when in the day]
SIGNAL:         [How the routine starts — bell, hand signal, verbal phrase]
TARGET TIME:    [Seconds or minutes]
SEQUENCE:
  Step 1: [Specific action by student]
  Step 2: [...]
  Step 3: [...]
  (3–6 steps; if more, the routine is too complex — simplify)

TEACHER ROLE:   [What teacher does — typically minimal once taught]
MATERIALS:      [Any materials involved and where they live]
VISIBLE ANCHOR: [Anchor chart, icon, or visual posted where the routine happens]

WHEN IT BREAKS:
- Common breakdown: [...]
- Re-teach move: [Stop-and-redo without shame; "Let's try that again — back to your seats."]

ACCESSIBILITY:
- Sensory considerations: [Volume of signal, lighting changes]
- Mobility considerations: [Path of travel]
- Communication considerations: [Visual + verbal signal pairing]
```

### Step 4: Signal Discipline

Every routine has exactly one signal. Avoid signal proliferation. Limit to:

- **Universal attention signal** (e.g., "Class — yes" call-and-response, hand raised, chime) — used to start any whole-class signal
- **Specific routine signals** that flow from the universal signal

If a teacher needs five different signals, students will follow none.

### Step 5: Teach the Routine in Week 1

For each routine, plan:

| Day | Move | Time |
|-----|------|------|
| Day 1 | Tell — name the routine, show the anchor, walk through | 3 min |
| Day 1 | Show — model with student volunteer | 2 min |
| Day 1 | Try — whole class practices once | 3 min |
| Day 2 | Re-do — practice with cold start (no warmup) | 2 min |
| Day 2 | Refine — name what's working, name what's still off | 2 min |
| Days 3–5 | Use it — every time it occurs, hold the bar |
| Week 2 | Re-teach if needed |

### Step 6: Re-teach Protocol

When a routine starts to slip:

1. **Notice** — the routine is taking longer than target time
2. **Pause** — stop class, return to start
3. **Re-teach (without shame)** — "Let's reset. The routine is X. Back to start."
4. **Practice once** — then continue
5. **Don't lecture** — re-teach is silent on motive

This is the single highest-leverage move in routine maintenance.

### Step 7: Routine Audit Cadence

Schedule periodic audits:

- **End of week 2:** which routines need re-teach?
- **End of week 6:** which routines need redesign? (If a routine has been re-taught 3+ times and still breaks, the design is the problem)
- **Quarterly:** are routines still needed? Add only what students cannot run themselves.

### Step 8: Substitute Compatibility

For each routine, write a 1-line summary a substitute can read:

> "Bell rings → students take seats, open notebooks, copy the agenda from the board (3 min). Anchor on right side of room."

Bundle these as a substitute-friendly card.

### Step 9: Equity & Access Audit

- [ ] Routines don't disadvantage students with mobility, sensory, or communication differences
- [ ] Restroom routine doesn't shame
- [ ] Materials routine doesn't expose food/economic insecurity
- [ ] Signals are paired (visual + auditory)
- [ ] Re-teach is shame-free

### Step 10: Recoverable Minutes Estimate

Sum: (current time cost − target time cost) × frequency = minutes recovered per day. Multiply by school days per year. Big number motivates the investment.

## Output Format

1. Day movement inventory with time costs
2. Prioritized routine list (top 6–10)
3. Per-routine cards (full format)
4. Signal map (universal + routine-specific)
5. Week-1 teach schedule
6. Re-teach protocol
7. Audit cadence
8. Substitute compatibility cards
9. Equity audit
10. Recoverable minutes estimate

---

## False-Positive Prevention

❌ **DON'T:**
- Engineer 25 routines — students follow ~10 reliably
- Add signals without retiring others
- Re-teach with lecture — re-teach is silent on motive
- Skip the audit at week 2 — minor breaks become baseline
- Confuse compliance with culture — efficient routines free time for relationships and learning

✅ **DO:**
- Pick high-leverage routines first
- Make every step observable
- Pair every routine with a visible anchor
- Re-teach without shame
- Build substitute-readable summaries
