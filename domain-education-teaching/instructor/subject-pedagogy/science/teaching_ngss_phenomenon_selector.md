# NGSS Phenomenon Selector & Storyline Anchor

## Objective

Identify and frame an anchoring phenomenon for an NGSS unit. Output includes the phenomenon described in observation-first language, vetting against NGSS phenomenon criteria, alignment to performance expectations and the three dimensions (DCI/SEP/CCC), a student-driving-question routine, and a storyline arc of investigation questions.

## When to Use

- Unit launch in K–12 NGSS-aligned science
- Coherent storyline curriculum design (OpenSciEd-style)
- Reframing a topic-list unit into a phenomenon-anchored unit
- Selecting between candidate phenomena for the same set of PEs

## When NOT to Use

- Single-lesson investigation — use `teaching_lesson_plan_generator.md`
- Lab activity that isn't unit-anchoring — design as a routine investigation
- Topic-list curriculum (non-NGSS) — use `teaching_unit_curriculum_planner.md`

## Instructions

### Step 1: Phenomenon Generation or Vetting

If candidates were provided, evaluate each. If none, propose 3 candidate phenomena anchored to local context where possible.

For **each candidate**, evaluate against NGSS phenomenon criteria:

| Criterion | Pass / Concern | Evidence |
|-----------|---------------|----------|
| Observable & concrete (not a topic) | | |
| Puzzling — invites questions students can't immediately answer | | |
| Requires the target DCI(s) to fully explain | | |
| Affords the target SEPs (asking questions, modeling, argumentation, etc.) | | |
| Affords the target CCCs (cause/effect, systems, energy, etc.) | | |
| Accessible to all students (no cultural/access barriers, no required prior knowledge) | | |
| Connects to students' lives or community | | |
| Generative — can sustain a multi-week storyline | | |

Rank candidates and recommend one with a one-paragraph rationale.

### Step 2: Frame the Phenomenon (Observation First)

Write the phenomenon in **observation-first language** — no explanatory terms.

❌ "The chemical reaction in the bottle"
✅ "When we mix what's in cup A with what's in cup B, the bottle inflates a balloon over the next 30 seconds."

Provide:
- 2–3 sentence student-facing description
- The artifact students will see (video / live demo / image / data set / news story)
- What's intentionally withheld

### Step 3: Three-Dimensional Alignment

Map the unit to the three dimensions:

| Dimension | Element | How phenomenon affords it |
|-----------|---------|--------------------------|
| **DCI** | [Code + name] | [Specifically how the phenomenon requires this idea to explain] |
| **SEP** | [Practice name] | [What students will do with the practice] |
| **CCC** | [Crosscutting concept] | [Lens through which the phenomenon is examined] |

### Step 4: Initial Models & Driving Question Board

Provide the routine for Day 1:

1. **Notice & Wonder protocol:** exact teacher prompts
   - "Write down everything you notice."
   - "Write down everything you wonder."
2. **Initial model:** prompt students to draw/write their best current explanation
3. **Driving Question Board:** group student questions into clusters; identify the **driving question** that frames the unit (write it as a student-voiced question)
4. **Sentence frames** for ELLs and emerging writers

### Step 5: Storyline Arc — Investigation Questions

Build the unit storyline as a sequence of student questions, each addressed by a lesson set:

| Lesson set | Student question | What we figure out | New question this opens |
|------------|------------------|---------------------|-------------------------|
| 1 | [Question] | [DCI element] | [Next question] |
| 2 | | | |
| ... | | | |
| Final | (loops back to driving question) | (full explanation of phenomenon) | (transfer task) |

Each lesson set's "what we figure out" should be a piece of the explanation — together they form the full model of the anchoring phenomenon.

### Step 6: Equity & Access Audit

For the chosen phenomenon, check:

- [ ] No assumed prior experiences that exclude students
- [ ] Multiple entry points for students with different background knowledge
- [ ] Cultural relevance considered; not extractive of any community
- [ ] Materials and access feasible in this school/district
- [ ] Investigation can be modified for students with sensory or mobility differences

Flag any concerns with mitigations.

### Step 7: Transfer Task

Describe a brief transfer task (end of unit) where students apply the model to a **new but related** phenomenon. State the new phenomenon and what students must do (predict, explain, design).

6. Storyline arc table
7. Equity & access audit
8. Transfer task

## False-Positive Prevention

❌ **DON'T:**
- Use a topic ("photosynthesis," "weather") as the phenomenon — phenomena are events, not topics
- Smuggle the answer into the framing (don't name the mechanism)
- Choose phenomena that require prior knowledge to even notice
- Cite specific videos, news articles, or data sets that may not exist
- Skip the equity audit — phenomena can carry hidden access barriers

✅ **DO:**
- Lead with what students see, not what's happening
- Map every PE to a specific moment in the storyline
- Build the storyline as a chain of student questions
- Plan Day 1 as eliciting questions, not explaining anything
- Choose phenomena where the explanation requires the target DCI

---

## Quality Indicators

- [ ] Phenomenon is observable and described without explanatory vocabulary
- [ ] Vetting table addresses all NGSS criteria
- [ ] All target PEs map to specific lesson sets in the storyline
- [ ] Storyline questions chain — each opens the next
- [ ] Transfer task uses a different but related phenomenon
- [ ] Equity audit identifies and mitigates access concerns
