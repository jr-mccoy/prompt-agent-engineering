# Writer's Workshop Minilesson Designer

## Objective

Design a 10–15 minute Lucy Calkins / Atwell-style minilesson on a single craft move: connection, teaching point, model with mentor text, active engagement (try-it), link to today's independent writing. One move per minilesson — no scope creep.

## When to Use

- Daily writing workshop in grades 1–12
- Targeting a specific craft skill students need (revealed by conferring or rubric data)
- Building writers' independence — minilessons end, then students write
- Anchor chart creation

## When NOT to Use

- Conventions / grammar-only — use a grammar minilesson template
- Whole-genre teaching that needs multiple sessions — use `teaching_unit_curriculum_planner.md`
- Conferring with a single writer — use `teaching_student_feedback_composer.md`

---

## Inputs Needed

- **Grade band:** [K–2 / 3–5 / 6–8 / 9–12]
- **Genre / unit:** [Personal narrative / argument / poetry / informational / literary essay]
- **Teaching point (one craft move):** [e.g., "Writers stretch the most important moment by slowing time with sensory detail."]
- **Time available:** [10 / 12 / 15 minutes]
- **Mentor text (if known):** [Title, author, excerpt — or "suggest one"]
- **Where students are in the process:** [Generating ideas / drafting / revising / editing / publishing]

---

## Instructions

### Step 1: Sharpen the Teaching Point

Rewrite the teaching point in this exact frame:

> **"Writers, today I want to teach you that [craft move], and one way they do this is by [specific technique]."**

Constraints:
- One craft move (not "many techniques")
- Transferable beyond today's piece
- Observable in student writing tomorrow

If the input teaching point is too broad, return a sharpened version and 2 alternative narrower points.

### Step 2: Connection (1–2 minutes)

Write the exact teacher script that links to:
- Yesterday's lesson or this week's work
- The bend / phase of the unit
- Why this matters now

End with: "So today, I want to teach you that…"

### Step 3: Teach with Mentor Text (3–5 minutes)

Choose or recommend a 1–3 sentence mentor text excerpt that demonstrates the craft move. Provide:

- **Excerpt** (with citation if from a real text; if "suggest one," generate an original example labeled as such)
- **What to notice** — the specific craft move highlighted
- **Teacher think-aloud script:** 3–5 sentences modeling what you notice as a reader/writer
- **Anchor chart entry:** 1 line that captures the move — bullet, sketch description, mentor sentence

### Step 4: Active Engagement (2–4 minutes)

Students try the move briefly — not a full draft. Provide:

- **Task:** [Try the move on one sentence in your current piece / try it with this shared topic / sketch and label / turn and share]
- **Exact directions** the teacher says
- **Time call:** "You have 2 minutes — go."
- **Share-out:** 1 student or 2 partners share an attempt

### Step 5: Link to Independent Writing (1 minute)

Exact teacher script that:
- Names the move again
- Releases students to writing time
- Specifies the choice: "If you're working on [phase], you might try this today. If you're not there yet, hold onto it for when you are."

### Step 6: Anchor Chart Plan

Provide the anchor chart text/sketch:

```
[Title — the craft move]
─────────────────────────
What writers do:  [verb phrase]
How:              [bullets]
Mentor:           [short example]
[Optional: small sketch description]
```

### Step 7: Conferring Look-Fors (post-minilesson)

3–5 things to look for during independent writing time that signal the lesson is taking hold:

1. [Observable behavior in student writing]
2. [What student says when conferred with]
3. [Visible attempt with revision or addition]

For each, provide a follow-up conferring move:
- "I noticed you tried…" (compliment-and-extend)
- "Have you thought about…" (teach a related move)

### Step 8: Differentiation

- **Emerging writers:** Sentence frame or shared writing of one example before they try
- **Advanced writers:** Stretch the move (e.g., "try it twice in the same piece for different effects")
- **ELL:** Visual mentor (image + words), partner before solo attempt
- **Students with IEPs:** Pre-loaded sentence stems, optional dictation/scribing

## Output Format

1. Sharpened teaching point in the standard frame
2. Connection script
3. Mentor text excerpt + think-aloud
4. Active engagement directions
5. Link script
6. Anchor chart text
7. Conferring look-fors and follow-up moves
8. Differentiation menu
9. Time budget summing to ≤ requested minutes

---

## False-Positive Prevention

❌ **DON'T:**
- Teach more than one craft move
- Run past 15 minutes — minilessons stay mini
- Have students draft a full piece during active engagement
- Skip the anchor chart — students need a visible reference
- Cite mentor texts that may not exist; clearly label invented examples as such

✅ **DO:**
- One transferable move per lesson
- Use real mentor text when given; clearly label generated examples
- Provide exact teacher language in connection and link
- Make active engagement a try-it, not a full draft
- Link conferring look-fors to the day's teaching point

---

## Quality Indicators

- [ ] Teaching point uses the exact frame and contains one move
- [ ] Mentor text excerpt is short (≤3 sentences) and clearly demonstrates the move
- [ ] Total minilesson runtime ≤ requested time
- [ ] Anchor chart is reproducible by a teacher in 2 minutes
- [ ] Conferring look-fors are observable, not abstract
- [ ] Active engagement is a try-it, not a full draft
