# ELA Close Reading Minilesson Designer

## Objective

Design a complete 20–30 minute close reading minilesson on a short passage (1 page or less). Output includes the passage selection rationale, three sequenced reads with text-dependent questions, vocabulary plan, discussion protocol, and a written constructed response with rubric.

## When to Use

- Building textual evidence skills (CCSS RI/RL anchor standards 1–3, 4–6)
- Modeling annotation routines
- Teaching how to read like a writer
- Preparing for AP-style or state-test passage analysis
- Launching or anchoring a literary or informational text unit

## When NOT to Use

- Whole-novel discussion — use `teaching_socratic_discussion_facilitator.md`
- Need to lower reading level — use `teaching_reading_level_adapter.md`
- Vocabulary-only focus — use `teaching_vocabulary_builder.md`

## Inputs Needed

- **Grade band:** [3–5 / 6–8 / 9–12 / college]
- **Text:** [Title, author, full passage text or accessible reference]
- **Text type:** [Literary fiction / poetry / literary nonfiction / argument / informational / primary source]
- **Standard focus:** [e.g., RI.7.4 word meanings; RL.9-10.3 character development]
- **Time available:** [20 / 30 / 45 minutes]
- **Annotation format:** [On hard copy / digital with comments / shared doc / margin codes]

## Instructions

### Step 1: Passage Vetting

Confirm the passage is appropriate for close reading by checking:

| Check | Pass criteria |
|-------|---------------|
| Length | Fits 3 reads in time available (poetry: ≤30 lines; prose: ≤500 words for 30-min lesson) |
| Complexity | Quantitative (Lexile/grade band) AND qualitative (purpose, structure, language, knowledge demands) match learners |
| Re-reading reward | Yields more meaning on second/third pass — not transparent on first |
| Standard fit | Affords text-dependent questions in the target standard |

Flag the passage as fit / unfit. If unfit, propose a shorter or alternate excerpt.

### Step 2: First Read — What does it say?

**Purpose:** Literal comprehension; gist.

- Reading mode: [Teacher read-aloud / silent / paired]
- Annotation directive: [Circle unfamiliar words; mark confusing parts with "?"]
- Post-read questions (2–3, literal):
  1. [Question]
  2. [Question]

### Step 3: Second Read — How does it say it?

**Purpose:** Structure, craft, word choice.

- Reading mode: [Silent re-read with annotation focus]
- Annotation directive: [Underline shifts in tone, mark repeated words, box transitions]
- Post-read text-dependent questions (3–4):
  1. [Question that requires citing specific words/lines]
  2. [Question on structural choice]
  3. [Question on word/image choice and effect]
  4. [Optional: question on point of view or rhetorical move]

For each question, provide:
- The exemplar response
- The specific text evidence the student must cite (with line numbers)
- A common partial-credit answer and how to redirect

### Step 4: Third Read — What does it mean / why does it matter?

**Purpose:** Inference, theme, argument, author's purpose.

- Reading mode: [Partner re-read with discussion]
- Post-read text-dependent questions (2–3, inferential/evaluative):
  1. [Inference question grounded in text]
  2. [Theme/argument question]
  3. [Author's purpose / context question]

### Step 5: Vocabulary Plan

Identify 3–5 words for instruction. Tier each:

| Word | Tier | Definition (student-friendly) | Where it appears | Why teach it |
|------|------|-------------------------------|------------------|-------------|
| [Word] | T2/T3 | [Definition] | Line [#] | [Access / transfer / academic] |

Plan: pre-teach Tier 3 only if it blocks comprehension; teach Tier 2 in context.

### Step 6: Discussion Protocol

Choose one and provide the script:

| Protocol | When | Teacher moves |
|----------|------|---------------|
| Pair-share → whole-class | Small classes / shy groups | "Turn and tell your partner…" then call 3 |
| Save the Last Word | Building independence | Student shares quote, peers respond, then student speaks last |
| 3-2-1 | End-of-text synthesis | Students write 3 things they noticed, 2 questions, 1 connection |

Provide 3 teacher discussion moves with exact language:
- Press for evidence: "Where in the text do you see that?"
- Build on a peer: "[Name], can you add to what [other student] just said?"
- Push depth: "Why does the author choose [specific word/structure] there instead of [alternative]?"

### Step 7: Constructed Response

Provide:
- **Prompt:** A single text-dependent prompt requiring evidence from the passage (RACE / claim-evidence-reasoning structure)
- **Length expectation:** [Sentence / paragraph / multi-paragraph]
- **Rubric (3-criterion analytic):**
  | Criterion | 4 Exemplary | 3 Proficient | 2 Developing | 1 Beginning |
  |-----------|-------------|--------------|--------------|-------------|
  | Claim | | | | |
  | Evidence | | | | |
  | Analysis | | | | |
- **Exemplar response** at the proficient level

### Step 8: Differentiation

- **Below-level reader:** Pre-loaded annotations on first paragraph, audio of passage available, sentence frames for evidence ("On line ___, the author writes ___. This shows ___.")
- **Above-level reader:** Comparison passage offered for synthesis; deeper craft analysis question
- **ELL:** Glossary of 3–5 key terms, partner pairing, gist statement modeled before second read

---

## Output Format

1. Passage and vetting summary
2. Three reads with mode, annotation directive, and questions
3. Vocabulary table
4. Discussion protocol with teacher moves
5. Constructed response prompt + rubric + exemplar
6. Differentiation menu
7. Time budget table summing to ≤ requested minutes

---

## False-Positive Prevention

❌ **DON'T:**
- Use questions answerable from background knowledge alone — they aren't text-dependent
- Pre-teach so much vocabulary that the close read becomes vocabulary instruction
- Skip the literal first read — comprehension precedes analysis
- Assign a written response without an exemplar — teachers can't norm without one
- Use a passage that doesn't reward re-reading

✅ **DO:**
- Anchor every question to specific text evidence
- Sequence questions by Costa's levels or DOK 1 → 3
- Provide exemplar responses at the proficient level
- Build annotation routines that students can transfer to other texts
- Cite line numbers for every text-dependent answer

---

## Quality Indicators

- [ ] Passage passes complexity and re-read-reward checks
- [ ] All questions in reads 2 and 3 require text evidence to answer
- [ ] Vocabulary plan distinguishes Tier 2 from Tier 3 with rationale
- [ ] Rubric has 3 distinguishable criteria with descriptors at all 4 levels
- [ ] Exemplar response is provided and would earn proficient
- [ ] Total time fits the budget
