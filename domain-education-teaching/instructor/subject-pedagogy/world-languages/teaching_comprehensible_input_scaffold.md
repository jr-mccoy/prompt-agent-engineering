# World Language Comprehensible Input Scaffold (TPRS-Style)

## Objective

Produce a comprehensible-input (CI) lesson that delivers target-language input at students' i+1 level via story, repetition with variation (circling), personalized question-and-answer (PQA), and gradual production. Output specifies the target structures, the story, the circling moves, comprehension checks, and the next-day extension. Designed for novice–intermediate learners building acquisition before forced production.

## When to Use

- Early-acquisition phase (Novice Low → Intermediate Low)
- Introducing high-frequency structures students will encounter repeatedly
- Building listening / reading proficiency before pushing speaking
- Engaging classes where forced output has produced anxiety or shutdown

## When NOT to Use

- Task-based output activity for intermediate+ — use `teachsubj_worldlang_communicative_task.md`
- General lesson planning — use `teaching_lesson_plan_generator.md`
- Pure vocabulary instruction — use `teaching_vocabulary_builder.md`

## Instructions

### Step 1: Choose 3 Target Structures (the TPRS Triad)

Select 2–3 structures students will encounter many times in the lesson. Properties:

- High-frequency in the language overall
- Useful immediately ("there is," "wants to," "doesn't have")
- Translatable to a single English chunk students can recognize

Output a translation guide:

| Target structure | Direct translation chunk |
|------------------|--------------------------|
| [Structure 1] | "[English chunk]" |

Limit to 3. More than 3 dilutes repetition.

### Step 2: Establish Meaning

Before any story or input, establish what each structure means:

```
Display the target structure (board, slide).
Say it.
Translate it into English (chunk-for-chunk if needed).
Confirm comprehension: "What does ___ mean?" (students answer in English).
```

Students must know what the structure means before encountering it in story input. This is the "establish meaning" step — non-negotiable.

### Step 3: Build the Story or Input Vehicle

For TPRS, build a 3–5 sentence "story" that uses the target structures heavily. The story is intentionally simple and absurd — easy to follow, memorable, and recyclable.

```
SAMPLE STORY ARC:
1. There is a [character with a quirk].
2. The character wants [something specific].
3. The character has a problem (doesn't have / can't get).
4. The character goes to [funny place] to ask for it.
5. Resolution (often absurd, often involving a third character).
```

Output the story in plain English first. The teacher will deliver it in the target language during class.

For story-listening or non-TPRS CI variants, substitute an authentic short text or a teacher narrative that recycles the structures.

### Step 4: Circling Plan

For each story sentence, plan circling questions — yes/no, either/or, and information questions that recycle the structure with minor variation.

For a sentence like "*Hay un chico que quiere un perro*" (There is a boy who wants a dog):

| Question type | Example | What it does |
|---------------|---------|--------------|
| Yes (positive) | "Hay un chico, ¿sí?" | Confirms structure |
| No (negative) | "¿Hay una chica?" | Highlights contrast |
| Either-or | "¿Hay un chico o una chica?" | Forces choice |
| What | "¿Qué hay?" | Production at lowest demand |
| Who | "¿Quién quiere un perro?" | Information question |
| Personalize | "¿Tú quieres un perro?" | Connects story to students |

Plan 4–6 circling questions per sentence to push the structure toward 50+ exposures across the lesson.

### Step 5: Personalized Question and Answer (PQA)

Build the bridge from story to students' lives:

```
After establishing each structure in the story, run PQA:
- "What about you, [student name]? Do you want a dog?"
- "Class, who in our class wants a dog?"
- "If you had a dog, what would you name it?" (stretch)
```

PQA does two things: makes input compelling, and lets students contribute when they're ready (one-word answers, gestures, "yo" with a thumbs up).

### Step 6: Comprehension Checks

Embed checks throughout, not just at the end:

| Check type | Example |
|-----------|---------|
| Translation pop-check | "What did I just say?" (one student translates) |
| Story summary in English | "Tell me what just happened in the story." |
| True / False statements | "Was the dog blue?" (in target language; students respond with thumbs) |
| Pop-up grammar | "Why did I say *quiere* and not *quieren*?" — 30-second mini-explanation |

If comprehension drops below 90%, slow down, recycle, simplify — don't push forward.

### Step 7: Reading Extension (Same or Next Day)

Build a short reading that recycles the same structures with new content:

```
- Same triad of structures
- New story (variant, sequel, or related)
- Length appropriate to level (5–10 sentences for novice)
- Followed by 3–5 comprehension questions in target or native language
```

Reading is the second exposure to the structures — critical for retention.

### Step 8: Production (Optional, Late)

Production is invited, never forced. If you include a production step:

- Make it low-stakes (one-word answer, ranking, sentence completion)
- Allow students to opt for written instead of spoken
- Don't grade accuracy — grade engagement
- Recognize that quiet students may be acquiring without producing

### Step 9: Differentiation

- **Anxious / silent students:** Allow gestures, written, native-language responses; never single out
- **Heritage learners:** Tier into the lesson at a more advanced level (custom comprehension questions, extended reading)
- **Stronger learners:** Stretch by varying the structures, asking them to suggest plot extensions
- **Visual learners:** Use images, props, or board sketches alongside spoken input

### Step 10: Anti-Patterns Audit

Check the lesson against:

- [ ] Are you front-loading too many structures? (>3 = anti-pattern)
- [ ] Are you skipping "establish meaning"? (Comprehension fails)
- [ ] Are you forcing production from anxious novices? (Bad for acquisition)
- [ ] Is the story compelling? (Boring stories lose attention; CI fails when input is ignored)
- [ ] Are you correcting student errors during input? (Disrupts acquisition)

### Step 11: Self-Check

- [ ] Does the lesson hit 50+ exposures of each target structure?
- [ ] Is meaning established before input?
- [ ] Are circling questions varied?
- [ ] Does PQA personalize without singling out anxious students?
- [ ] Are comprehension checks embedded throughout?
- [ ] Is the reading extension aligned to the same structures?

## False-Positive Prevention

❌ **DON'T:**
- Cover too many structures — pick a triad and recycle hard
- Skip "establish meaning" — students who don't know what it means can't acquire it
- Force production from silent students — that suppresses input
- Correct grammar errors during input — undermines the input flow
- Run the same lesson day after day — variety in story keeps input compelling

✅ **DO:**
- Pick high-frequency structures and recycle 50+ times
- Establish meaning explicitly before input
- Circle with varied question types
- Personalize via PQA
- Check comprehension constantly
- Treat reading as the second-exposure cement

---

## Quality Indicators

- [ ] Three target structures, no more
- [ ] Meaning established before input
- [ ] 50+ exposures across the lesson
- [ ] Comprehension checks every 2–3 minutes
- [ ] Reading extension uses same structures
- [ ] Production is optional, not forced
