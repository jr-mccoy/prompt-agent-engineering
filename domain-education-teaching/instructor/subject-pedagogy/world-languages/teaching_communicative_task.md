# World Language Communicative Task Designer

## Objective

Produce a task-based language-teaching (TBLT) activity in which students must use the target language to accomplish a real communicative goal — exchanging information, making a decision, solving a problem, or expressing opinions. Output specifies the task type, proficiency target (ACTFL or CEFR), language students need access to, scaffolds, and outcome-based assessment.

## When to Use

- Building communicative competence beyond grammar drill
- Designing performance-based assessments that match ACTFL Can-Do statements
- Replacing dialogues-from-the-textbook with authentic communication
- Targeting a proficiency level (Novice High → Intermediate Low transition is a common stuck point)

## When NOT to Use

- Comprehensible-input lesson where students aren't yet producing — use `teachsubj_worldlang_comprehensible_input_scaffold.md`
- General lesson planning without a specific communicative goal — use `teaching_lesson_plan_generator.md`
- Conversation practice for an individual learner — see `domain-conversation-practice/`

## Inputs Needed

- **Target language:** [Spanish / French / Mandarin / ASL / etc.]
- **Grade level / course level:** [Spanish 1, French 3, etc.]
- **Proficiency target:** [ACTFL: Novice Low/Mid/High, Intermediate Low/Mid/High, Advanced; or CEFR: A1–B2]
- **Communicative mode:** [Interpersonal speaking / interpersonal writing / presentational / interpretive]
- **Theme or unit:** [What's the topic — daily routines, community, food, identity, social issues]
- **Time available:** [One period / two periods / multi-day]
- **Class size and configuration:** [Whole class / pairs / small groups]

## Instructions

### Step 1: Choose the Task Type

Select one. Justify why this type fits the proficiency target and theme.

| Task Type | What students do | Best for |
|-----------|------------------|----------|
| Information gap | Each partner has different info; both needed for completion | Novice → Intermediate; question forms |
| Decision-making | Choose among options based on shared/different criteria | Intermediate; expressing preferences, justifying |
| Problem-solving | Address a constraint or scenario together | Intermediate → Advanced; hypothetical, conditional |
| Opinion exchange | Discuss a topic where defensible disagreement exists | Intermediate Mid → Advanced |
| Narrative co-construction | Build a story together | Across levels with appropriate scaffolds |
| Real-world transactional | Order food, book a room, file a complaint | Novice High → Intermediate; functional |

### Step 2: Define the Communicative Goal

State in one sentence what students must accomplish, in observable terms:

- "Each partner finds out which classmate matches a profile by asking and answering yes/no questions about routines."
- "Pairs decide which of three apartment listings best fits a roommate's needs and justify the choice in writing."

The goal must require the target language to complete. If it can be solved through pointing or English, redesign.

### Step 3: Identify the Language Students Need

Specify:

- **Vocabulary domain:** [Core terms and useful phrases]
- **Grammatical structures:** [Forms that will be useful, but not "the grammar lesson"]
- **Discourse moves:** [How to ask, clarify, agree, disagree, request, justify in the target language]
- **Recycled language:** [What students should already know that this task uses]
- **Stretch language:** [What's just outside their range that the task may pull them toward]

### Step 4: Pre-Task Phase

Plan the warm-up that activates language without front-loading every form students might use:

```
0–5 min — Activate
Quick visual / video / question that gets students thinking in the target language about the theme.

5–10 min — Strategic input
Brief exposure to a model — a recording of someone doing the task, a written exchange, an authentic source.
"Notice ___" — point students at structures or moves they'll need.

10–12 min — Frame the task
Present the task and the goal. Show the success criterion ("You'll know you finished when ___").
```

Avoid the trap of pre-teaching every form — let some of the language emerge from need.

### Step 5: Task Phase

```
12–30 min — Task execution
Students do the task. Teacher circulates, conferring briefly with pairs.
Teacher notes errors and successes for post-task.
Teacher does NOT correct grammar in the moment unless communication breaks down.
```

Specify:
- Pair / group configuration
- Materials each student receives (information cards, prompts, etc.)
- Output requirement (what they produce: notes, a decision, an artifact)
- Time pressure (some, but not crushing)

### Step 6: Language Focus (Post-Task)

After students complete the task, surface 2–3 language points that came up:

```
30–40 min — Language focus
"I heard several pairs needed to ___. Here's how that works in [target language]…"
- Brief explanation
- Examples from student work (anonymized)
- Quick try-it
```

This is when grammar gets attention — after meaning, in service of meaning. This is the TBLT inversion of "grammar first, then communicate."

### Step 7: Scaffolding Tiers by Proficiency

Provide scaffolds tied to the proficiency target:

| Target | Heavy scaffold | Medium | Light |
|--------|---------------|--------|-------|
| Novice Low/Mid | Word bank + sentence starters | Word bank only | Open task |
| Novice High → Int Low | Sentence frames for key moves | Frames for stretch moves only | Open task with optional supports |
| Intermediate Mid+ | Pre-task brainstorm shared | Optional reference card | Open with cultural/contextual prompts |

### Step 8: Assessment

Design rubric aligned to ACTFL or CEFR:

| Domain | What "meets target" looks like at this proficiency level |
|--------|---------------------------------------------------------|
| Task completion | Did the pair achieve the communicative goal? |
| Comprehensibility | Could a sympathetic native speaker follow? |
| Language use | Range of vocabulary and structures used appropriately |
| Communication strategies | Did students negotiate meaning when stuck? Use circumlocution? |
| Cultural appropriateness | Did students use register and conventions appropriate to the context? |

Score on completion-and-process, not error count.

### Step 9: Authentic Materials

If possible, ground the task in authentic input — a real recipe, real apartment listings, a real public-service announcement, a real conversation snippet from the target culture. Output:

- Source(s) you'd use
- Adaptations needed for the proficiency level
- Cultural note about what students will encounter

### Step 10: Self-Check

- [ ] Does the task require the target language to complete?
- [ ] Is the communicative goal observable, not vague?
- [ ] Does the pre-task activate without over-pre-teaching?
- [ ] Is grammar handled post-task in service of meaning?
- [ ] Does the rubric assess communication, not error-count?

## False-Positive Prevention

❌ **DON'T:**
- Pre-teach every grammar form before the task — that's PPP, not TBLT
- Set a "task" that can be solved without using the target language
- Correct every error in the moment — interrupt only when meaning breaks
- Score on error count — score on communication
- Treat scaffolds as cosmetic; they should genuinely support the proficiency level

✅ **DO:**
- Make the task require the language to complete
- Activate language before, focus on form after
- Confer during, don't drill
- Design rubrics aligned to ACTFL/CEFR proficiency
- Use authentic materials as input where feasible

- [ ] Pre-task activates without front-loading every form
- [ ] Post-task surfaces 2–3 forms from student work
- [ ] Scaffolds are proficiency-appropriate
- [ ] Rubric assesses communication, not error count
