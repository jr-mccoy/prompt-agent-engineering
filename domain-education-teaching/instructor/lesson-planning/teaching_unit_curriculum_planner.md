**Purpose:** Design comprehensive multi-week instructional units using the Understanding by Design (UbD) backward design framework — starting with desired results, then designing assessments, then planning learning experiences.

**When to use:** Planning a new unit of study; designing multi-week thematic units; creating scope and sequence for a course; aligning existing materials to a coherent structure; preparing for curriculum mapping meetings.

**Input needed:**
- Subject and unit topic
- Grade level
- Unit duration (number of weeks)
- Standards to address
- Available resources and constraints

## Output Format

Structure the complete unit plan as:
1. **Unit Overview** (1-page summary with essential questions, enduring understandings, standards)
2. **Stage 1: Desired Results** (full detail)
3. **Stage 2: Assessment Evidence** (performance task with rubric + other evidence)
4. **Stage 3: Learning Plan** (day-by-day calendar + activity details)
5. **Differentiation Plan**
6. **Resource List**
7. **Unit Reflection Template** (post-unit teacher reflection prompts)

## Quality Indicators

**Strong unit plans include:**
- [ ] Clear alignment: Standards → Enduring Understandings → Essential Questions → Assessments → Activities
- [ ] Assessments designed BEFORE activities (true backward design)
- [ ] Authentic performance task with real-world connection
- [ ] Multiple formative checkpoints that inform instruction
- [ ] Differentiation built into the plan (not an afterthought)
- [ ] Realistic pacing with buffer days for reteaching
- [ ] Student self-assessment and reflection opportunities
- [ ] Essential questions revisited throughout (not just Day 1)

**Common Unit Planning Pitfalls:**

| Pitfall | Sign | Prevention |
|---------|------|------------|
| **Activity-driven design** | Fun activities with unclear learning purpose | Start with Stage 1 outcomes, design backward |
| **Coverage over depth** | Rushing through topics without understanding | Focus on fewer enduring understandings, go deeper |
| **Assessment afterthought** | Test created the night before | Design Stage 2 before Stage 3 |
| **No formative checks** | Only a final test | Build in checks every 2-3 days |
| **Rigid pacing** | No flexibility for student needs | Include buffer days and reteach options |
| **Isolated unit** | No connection to prior or next units | Reference vertical alignment and prior knowledge |
