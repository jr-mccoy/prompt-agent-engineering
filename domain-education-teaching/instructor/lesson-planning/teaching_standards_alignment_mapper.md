**Purpose:** Map existing curriculum content, lessons, and assessments to educational standards — identifying coverage gaps, creating crosswalk documents between standard sets, and generating standards-tagged activity suggestions to fill gaps. Essential for curriculum planning, accreditation, and instructional coherence.

**When to use:** Aligning a course or unit to specific standards; preparing for curriculum audit or accreditation; crosswalking between state standards and Common Core or NGSS; identifying which standards need more instruction time; vertical alignment across grade levels; documenting standards coverage for administrators.

**Input needed:**
- Standards framework(s) to align to
- Existing curriculum content (units, lessons, assessments)
- Grade level and subject
- Alignment purpose (planning, audit, crosswalk)

## Instructions

Generate the standards alignment through these structured phases:

### Step 1: Standards Inventory

**List all applicable standards for the grade/subject:**

| Standard Code | Standard Text | Domain/Strand | Priority |
|--------------|---------------|--------------|----------|
| [e.g., 5.RI.1] | [Full text of the standard] | [e.g., Reading: Informational Text] | [Power / Supporting / Enrichment] |
| [e.g., 5.RI.2] | [Full text] | [Domain] | [Priority] |

**Priority Classification:**
| Priority | Definition | Instruction Time |
|----------|-----------|-----------------|
| **Power Standard** | Assessed on state/national tests; essential for next grade level; high leverage across subjects | Deepest instruction, most practice, multiple assessments |
| **Supporting Standard** | Supports understanding of power standards; important but not assessed independently | Taught in connection with power standards |
| **Enrichment Standard** | Extends learning; enhances depth; may be grade-specific expectations beyond core | Addressed when time allows or through extension activities |

### Step 2: Curriculum-to-Standards Alignment Map

**Map each existing unit/lesson to the standards it addresses:**

| Unit/Lesson | Standards Addressed | Depth (I/D/M) | Assessment |
|-------------|-------------------|----------------|------------|
| [Unit 1: Topic] | [Standard codes] | [I=Introduced, D=Developed, M=Mastered] | [How assessed] |
| [Unit 2: Topic] | [Standard codes] | [I/D/M] | [Assessment] |
| [Unit 3: Topic] | [Standard codes] | [I/D/M] | [Assessment] |

**Depth Legend:**
- **I (Introduced):** First exposure to the standard; students are building awareness
- **D (Developed):** Ongoing instruction and practice; students are building proficiency
- **M (Mastered):** Standard is assessed for mastery; students demonstrate independent application

### Step 3: Coverage Analysis

**Standards Coverage Heat Map:**

| Standard | Unit 1 | Unit 2 | Unit 3 | Unit 4 | Unit 5 | Unit 6 | Total Touches | Status |
|----------|--------|--------|--------|--------|--------|--------|---------------|--------|
| [Code] | I | D | | M | | | 3 | Adequate |
| [Code] | | | I | | | | 1 | **Gap** |
| [Code] | I | D | D | D | M | | 5 | Strong |
| [Code] | | | | | | | 0 | **Missing** |

**Gap Analysis Summary:**

| Status | Count | Standards | Action Needed |
|--------|-------|-----------|---------------|
| **Missing** (0 touches) | [#] | [List codes] | Add explicit instruction |
| **Undertaught** (1 touch, no mastery) | [#] | [List codes] | Add practice and assessment opportunities |
| **Adequate** (2-3 touches, mastery assessed) | [#] | [List codes] | Maintain current coverage |
| **Strong** (4+ touches) | [#] | [List codes] | Verify depth, not just repetition |

### Step 4: Gap-Filling Recommendations

**For each gap or undertaught standard, recommend activities:**

| Standard (Gap) | Recommended Activity | Where to Embed | Time Needed | Materials |
|---------------|---------------------|----------------|-------------|-----------|
| [Code + brief text] | [Specific activity that addresses the standard] | [Which existing unit it fits into] | [Estimated time] | [What's needed] |
| [Code] | [Activity] | [Unit] | [Time] | [Materials] |

**Activity Types for Gap-Filling:**
- **Embed into existing lessons:** Add a standard-aligned component to a lesson you already teach
- **Warm-up / Bell-ringer:** 5-minute daily practice targeting the gap standard
- **Center / Station:** Add as a rotation activity during workshop time
- **Assessment item:** Add questions targeting the standard to existing assessments
- **Independent practice:** Homework or classwork assignment specifically addressing the standard
- **Mini-unit:** If the gap requires dedicated instruction, design a focused 2-3 day mini-unit

### Step 5: Standards Crosswalk (Optional — for comparing two frameworks)

**When aligning between two standards sets (e.g., old state standards → new state standards, Common Core → state standards, AP → college competencies):**

| Framework A Standard | Framework B Standard(s) | Alignment Strength | Notes |
|---------------------|------------------------|-------------------|-------|
| [Code A + text] | [Code B + text] | [Full / Partial / No match] | [What's different] |
| [Code A] | [Code B] | [Strength] | [Notes] |

**Alignment Strength Definitions:**
| Strength | Meaning |
|----------|---------|
| **Full** | Standards are essentially equivalent; teaching one satisfies the other |
| **Partial** | Standards overlap but one is broader or narrower; supplemental instruction may be needed |
| **No match** | Standard has no equivalent in the other framework; unique instruction required |

### Step 6: Vertical Alignment (Optional — for grade-level coherence)

**Show how standards progress across grade levels:**

| Concept/Skill | Grade Below | Current Grade | Grade Above |
|--------------|-------------|---------------|-------------|
| [e.g., Fraction understanding] | [3rd: Understand fractions as parts of a whole] | [4th: Equivalent fractions, compare fractions] | [5th: Add/subtract fractions with unlike denominators] |
| [Concept] | [Below-grade standard] | [Current-grade standard] | [Above-grade standard] |

**Vertical Alignment Insights:**
- What prerequisite skills must students have from the prior grade?
- What must students master this year to be prepared for the next grade?
- Where are the biggest "jumps" in complexity between grade levels?

---

## Output Format

Structure the alignment document as:
1. **Standards Inventory** (complete list with priorities)
2. **Alignment Map** (curriculum-to-standards matrix)
3. **Coverage Analysis** (heat map + gap summary)
4. **Gap-Filling Recommendations** (specific activities for each gap)
5. **Crosswalk** (if comparing frameworks)
6. **Vertical Alignment** (if examining grade-level progression)
7. **Summary Report** (metrics and action items)

---

## Quality Indicators

**Effective standards alignment includes:**
- [ ] Every power standard has a clear I → D → M trajectory
- [ ] No power standard is missing from the curriculum
- [ ] Assessments explicitly tied to specific standards
- [ ] Gap-filling suggestions are realistic and embeddable
- [ ] Vertical alignment shows clear progression
- [ ] Document is usable by administrators and other teachers (not just the author)
- [ ] Priority classification is defensible (based on assessment weight and transfer value)
- [ ] Both breadth (coverage) and depth (rigor) are addressed

**Common Standards Alignment Pitfalls:**

| Pitfall | Sign | Prevention |
|---------|------|------------|
| **Check-the-box alignment** | Standards listed but not actually taught to depth | Verify with assessment evidence, not just lesson titles |
| **Overtag everything** | Every lesson claims to address 10 standards | Be honest — a lesson meaningfully addresses 1-3 standards |
| **Ignore priority** | All standards treated equally | Classify power vs. supporting vs. enrichment and allocate time accordingly |
| **No assessment link** | Standards "covered" but never assessed | Every standard needs at least one assessment touchpoint |
| **Breadth without depth** | All standards touched once, none mastered | Power standards need I → D → M progression across multiple units |
| **Static document** | Created once, never updated | Revisit quarterly; update as instruction evolves |
