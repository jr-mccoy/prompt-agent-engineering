# Dyslexia Structured Literacy Plan

## Objective

Build a structured-literacy intervention plan grounded in the Science of Reading, for a student with diagnosed dyslexia or with characteristics of dyslexia. Output sequences instruction across phonological awareness, phonics/decoding, fluency, vocabulary, and comprehension — with daily lesson architecture, progress monitoring, and gen-ed classroom accommodations.

## When to Use

- Tier 2 / Tier 3 reading intervention planning
- IEP/504 team building literacy goals
- Reading specialist or interventionist designing a small-group plan
- General-ed teacher needing to coordinate with intervention
- Family asking what should be happening for their child

## When NOT to Use

- Whole-class core reading instruction (different scope)
- Building IEP goals only — use `teaching_iep_goal_writer.md`
- Reading-level text adaptation only — use `teaching_reading_level_adapter.md`

## Instructions

### Step 1: Confirm Structured Literacy Principles

Confirm the plan will follow these non-negotiables:

- **Explicit:** Skills directly taught, not discovered
- **Systematic and cumulative:** Sequence from simple to complex; each lesson reviews prior skills
- **Diagnostic:** Continuously assesses; instruction adjusts to student response
- **Multisensory:** Visual, auditory, kinesthetic-tactile pathways used together
- **Phonologically grounded:** Phonological/phonemic awareness is foundational
- **Code-based decoding:** Direct phonics instruction; no whole-word memorization-only approach
- **Connected to meaning:** Vocabulary and comprehension woven through, not deferred

### Step 2: Skill Diagnostic Map

From the data, identify which skills need direct instruction. Build a map:

| Strand | Sub-skill | Current performance | Instructional priority |
|--------|----------|---------------------|------------------------|
| Phonological awareness | Rhyme, syllable, onset-rime, phoneme blending, segmenting, manipulation | | High / Med / Low |
| Letter-sound correspondence | Single letters, digraphs, blends, vowel teams, r-controlled, diphthongs | | |
| Syllable types | Closed, open, magic-e, vowel team, r-controlled, consonant-le, diphthong | | |
| Morphology | Prefixes, suffixes, roots, inflectional endings | | |
| Decoding fluency | Real-word and pseudo-word lists at level | | |
| Spelling/encoding | Sound-symbol mapping in writing | | |
| Reading fluency | WCPM at instructional level | | |
| Vocabulary | Tier 2 academic words, depth | | |
| Comprehension | Listening comprehension, then reading comprehension | | |

Confirm: comprehension instruction continues at grade level (often via listening comprehension and read-alouds) while decoding is built up — do not gatekeep grade-level texts behind decoding skill.

### Step 3: Sequence the Scope

Choose a starting point in the scope and sequence. Default sequence (adjust to assessment data):

1. Phonological/phonemic awareness to mastery
2. Letter-sound correspondence: consonants, short vowels
3. CVC blending and segmenting in real and pseudo words
4. Digraphs (sh, ch, th, wh, ck)
5. Closed-syllable two-syllable words
6. Magic-e (silent-e)
7. Vowel teams
8. R-controlled vowels
9. Open syllables and multisyllabic words
10. Morphology: high-frequency prefixes/suffixes
11. Greek and Latin roots (upper grades)

Pinpoint the student's instructional level and the next 4 skills in sequence.

### Step 4: Daily Lesson Architecture

Build a daily lesson template for the available session time. Standard 45-minute structured literacy session:

| Component | Time | What happens |
|-----------|------|-------------|
| Phonological warm-up | 3–5 min | Phoneme manipulation tasks at student's level |
| Sound-symbol review | 5 min | Drill of taught letter-sound correspondences |
| New skill introduction | 5–10 min | Explicit teach: rule, examples, multisensory |
| Word-level practice | 8–10 min | Decoding lists, spelling dictation |
| Connected text | 8–10 min | Decodable passage at instructional level; teacher monitors and provides corrective feedback |
| Comprehension / vocabulary | 5–8 min | Listening comprehension or oral language work |
| Wrap and progress note | 2 min | Teacher logs accuracy, student self-rates |

Adjust component time based on session length. Provide a 30-minute and 60-minute alternative.

### Step 5: Multisensory Routines

For each skill type, name a specific multisensory routine:

| Skill | Routine |
|-------|---------|
| Letter-sound | "See it / Say it / Trace it / Write it" — student sees grapheme, says sound, traces in air, writes |
| Blending | Tapping syllables / using sound boxes (Elkonin) / arm-blend |
| Spelling | Sound dictation: teacher says word, student segments, spells, reads back |
| Syllable type recognition | Marking syllables in colored pencils with type label |

### Step 6: Progress Monitoring Plan

| Probe | What it measures | Cadence | Decision rule |
|-------|-----------------|---------|---------------|
| Weekly nonsense-word fluency | Decoding accuracy | Weekly | Trend below aimline 4 weeks → instructional change |
| Real-word fluency | Generalized decoding | Bi-weekly | |
| Oral reading fluency (WCPM) | Reading rate + accuracy | Bi-weekly | |
| Spelling dictation | Encoding | Weekly | |
| Curriculum-based mastery checks | Specific skill mastery | After each new skill | 80% accuracy = proceed |

Define the **aimline** (expected growth trajectory). If trend falls below aimline for 4 consecutive data points, change instruction (more time, smaller group, different routine, or revisit foundational skill).

### Step 7: Concurrent Classroom Accommodations

For the gen-ed classroom (where intervention is not happening), provide:

- **Audiobook access** for grade-level texts so comprehension can grow at grade level
- **Text-to-speech / read-aloud** for content-area assignments
- **Speech-to-text** for written output where writing is not the construct
- **Reduced reading load** when the construct is not reading
- **Spelling accommodations** on content assessments
- **Extended time** on reading-heavy tasks
- **Pre-loaded vocabulary** with cognates and morphological breakdowns

State explicitly: accommodations supplement, not replace, structured literacy intervention.

### Step 8: Family Partnership

Provide:

- A 1-page family-facing explanation of structured literacy
- What the family can do at home: shared reading, audiobooks, NOT drilling sight words via memorization
- Frequency of progress communication
- Signs of progress to celebrate, signs that should prompt a team conversation

### Step 9: Plan Audit

- [ ] All structured literacy principles confirmed
- [ ] Skill diagnostic map drives the sequence
- [ ] Daily architecture fits available time
- [ ] Multisensory routines named for each skill type
- [ ] Progress monitoring includes aimline and decision rule
- [ ] Comprehension is not deferred — happens in parallel
- [ ] Classroom accommodations support access without replacing intervention
- [ ] Family voice included

### Step 10: Disclaimers

State:

> "This plan is instructional design support, not a clinical evaluation. Diagnostic determination of dyslexia, evaluation for special education eligibility, and ongoing supervision of intensive intervention should involve a qualified professional (educational diagnostician, school psychologist, certified structured-literacy instructor, or speech-language pathologist as appropriate). Local laws and policies governing dyslexia services vary by state and country; consult district guidelines."

## False-Positive Prevention

❌ **DON'T:**
- Recommend three-cueing or whole-language strategies (counter to Science of Reading)
- Defer comprehension until decoding is fluent — listening comprehension continues at grade level
- Memorize sight words via flashcards alone — orthographic mapping requires phonics
- Skip progress monitoring or aimline — without it, intervention drifts
- Replace intervention with classroom accommodations — accommodations supplement

✅ **DO:**
- Anchor in Science of Reading principles
- Sequence from phonemic awareness through morphology
- Pair every skill with a multisensory routine
- Monitor weekly and adjust on data
- Keep grade-level comprehension going via audio access
- Be explicit that this is instructional design, not diagnosis
