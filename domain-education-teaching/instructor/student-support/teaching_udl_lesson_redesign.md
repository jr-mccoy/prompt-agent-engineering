# UDL Lesson Redesign

## Objective

Take an existing lesson and rebuild it through the UDL framework. Output a side-by-side audit (current vs. redesigned), an options menu for engagement, representation, and action/expression, and a learner-variability check naming who each option helps.

## When to Use

- Existing lesson is "one-size-fits-all" and not reaching all students
- New curriculum adoption or lesson refresh
- Teacher prep / coursework on UDL
- Co-planning with a special-ed or instructional coach
- Closing the gap between IEP/504 accommodations and what's actually happening

## When NOT to Use

- Building a lesson from scratch — use `teaching_lesson_plan_generator.md` (then UDL-audit it)
- Specific accommodation menu only — use `inclusive_504_accommodation_menu.md`
- Differentiation by ability tier — use `teaching_differentiation_planner.md`

## Inputs Needed

- **The current lesson:** [Plan, slides, or summary — enough to identify what's there]
- **Subject and grade:** [...]
- **Learning objective:** [Stays constant through redesign]
- **Known learner variability:** [IEPs, 504s, ELLs, gifted, attention/sensory profiles, technology access]
- **Time and resources:** [Class period, available tech, materials]
- **Constraints:** [What you can't change — required text, set assessment, district pacing]

## Instructions

### Step 1: Audit the Current Lesson Against UDL

Build a 3×3 audit matrix:

| Principle | Current state in lesson | Gaps |
|-----------|------------------------|------|
| **Engagement** (the "why") — recruiting interest, sustaining effort, self-regulation | | |
| **Representation** (the "what") — perception, language/symbols, comprehension | | |
| **Action & Expression** (the "how") — physical action, expression/communication, executive function | | |

Mark each cell:
- ✅ Multiple options present
- ⚠ Single option (functional but exclusive)
- ❌ Missing entirely

### Step 2: Lock the Goal, Open the Path

UDL principle: the learning goal is fixed; the path to it is variable. Restate the objective and confirm:

- The objective names what students must demonstrate, not how
- If "how" is the construct (e.g., "write an argumentative essay"), state the genuine flexibility (length, drafting tools, voice-to-text)
- If "how" is incidental (e.g., "demonstrate understanding of cell structure"), open up: model, video, written, oral, diagram

### Step 3: Engagement Options Menu

Provide options for each of three engagement subgoals:

**Recruiting interest:**
- [Option 1: choice within task]
- [Option 2: relevance / value connection]
- [Option 3: novelty / threat reduction]

**Sustaining effort and persistence:**
- [Option 1: clear goal + collaboration]
- [Option 2: graduated challenge]
- [Option 3: feedback frequency]

**Self-regulation:**
- [Option 1: goal-setting prompt]
- [Option 2: reflection / monitoring tool]

### Step 4: Representation Options Menu

**Perception (how content reaches students):**
- [Auditory option — read-aloud, audio file]
- [Visual option — chart, diagram, image]
- [Tactile / kinesthetic option — manipulatives, demonstration]
- [Tech accommodations — captions, alt text, screen reader compatibility]

**Language and symbols:**
- [Vocabulary support — preview, glossary, cognates]
- [Decoding support — chunked text, annotated]
- [Translation / L1 access where applicable]

**Comprehension:**
- [Background-activation prompt]
- [Big-picture organizer / advance organizer]
- [Worked example with think-aloud]

### Step 5: Action & Expression Options Menu

**Physical action:**
- [Multiple input methods — pencil, keyboard, voice, sketch]
- [Movement-friendly options]
- [Assistive tech compatibility]

**Expression and communication:**
- [Multiple output formats accepted: written, oral, video, model, diagram]
- [Tools for composition: outlines, sentence starters, dictation, drawing software]
- [Drafting and revision built in]

**Executive function:**
- [Goal-setting and planning tool]
- [Time management — visible schedule, timer]
- [Self-monitoring checkpoint]

### Step 6: Learner-Variability Map

For each known student profile, name which options serve them:

| Student profile | Options that serve them | Options NOT to require of them |
|-----------------|------------------------|-------------------------------|
| Student with reading IEP | Audio + visual representation; oral expression option | Solo timed silent reading as only access |
| Student with ADHD / executive-function needs | Goal-setting prompt; chunked timer; movement break | Long undifferentiated work block |
| ELL level 2 | Cognate-glossed text; sentence frames; partner before solo | Solo extended writing without scaffold |
| Gifted student | Stretch option; audience expansion; complexity choice | Forced repetition of mastered skill |
| Sensory-sensitive student | Quiet workspace option; predictable structure | High-stimulation group work as only path |

### Step 7: Side-by-Side Redesign

Produce a 2-column comparison:

| Original lesson element | UDL redesigned version |
|------------------------|------------------------|

For each redesigned element, note which UDL options are now present and which learners benefit.

### Step 8: Implementation Reality Check

- [ ] Redesign fits available class time
- [ ] Materials/tech for added options are accessible
- [ ] Teacher load is sustainable (not 10x prep)
- [ ] Choice is real (≥2 viable options where stated)
- [ ] Assessment still measures the objective fairly across paths
- [ ] No new accessibility barriers introduced

### Step 9: Equity Frame

UDL is design-up, not retrofit-down. Confirm:

- Options are part of the design, not "extras for some students"
- The lesson works the same way whether or not specific students are present
- The lesson reduces stigma around accommodations by making options general

## Output Format

1. Current-state audit matrix
2. Goal-locked statement and goal-vs-path analysis
3. Engagement options menu
4. Representation options menu
5. Action & Expression options menu
6. Learner-variability map
7. Side-by-side redesign
8. Implementation reality check
9. Equity frame confirmation

---

## False-Positive Prevention

❌ **DON'T:**
- Treat UDL as "differentiate after the fact"
- Add 17 options when 3 well-chosen ones serve everyone
- Open up the construct itself when it's the actual learning target
- Frame UDL options as "for the kids who need it" — design-up means available to all
- Confuse UDL with universal accommodations checklist — UDL is design philosophy

✅ **DO:**
- Lock the goal; open the path
- Audit before redesigning
- Map options to learner profiles to confirm coverage
- Keep assessment fair across paths
- Reduce stigma by universalizing options

---

## Quality Indicators

- [ ] All three UDL principles addressed with multiple options
- [ ] Goal preserved across redesign
- [ ] Learner-variability map shows coverage
- [ ] Side-by-side redesign concrete
- [ ] Reality check confirms feasibility
- [ ] Options framed as universal, not exceptional
