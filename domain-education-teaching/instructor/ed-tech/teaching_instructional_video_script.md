# Instructional Video Script

## Objective

Write a tight, replayable script for an instructional video (default 3–10 minutes; up to 15 max) that teaches one concept or skill. Output is a timestamped two-column script (narration + on-screen text/visual), optional B-roll/animation cues, and embedded retrieval prompts.

## When to Use

- Flipped-classroom pre-work
- Module video inside an LMS course
- Skill explainer for performance support library
- Replacement for a lecture that learners can re-watch
- Open educational resource (OER) production

## When NOT to Use

- Live class — use `teaching_lesson_plan_generator.md` or slide-deck designer
- Quick on-screen tutorial / demo (often shorter, different conventions) — adapt or use a screencast template
- Infographic image — use image-generation domain
- Marketing or promo video — different intent

## Instructions

### Step 1: Squeeze the Outcome

State in one sentence: "After watching, the learner can [observable action]."

If you can't state it, the video is unfocused. If the sentence has more than one verb, split into two videos.

### Step 2: Time-Budget the Script

For a 5-minute video:

| Segment | Time | Words (~150 wpm) |
|---------|------|-------------------|
| Hook | 0:00–0:20 | ~50 |
| Frame | 0:20–0:40 | ~50 |
| Concept / step 1 | 0:40–1:30 | ~125 |
| Concept / step 2 | 1:30–2:30 | ~150 |
| Worked example | 2:30–3:45 | ~190 |
| Retrieval prompt | 3:45–4:00 | ~30 |
| Synthesize | 4:00–4:30 | ~75 |
| Close + transfer cue | 4:30–5:00 | ~75 |

Adjust proportionally. Word count = pacing constraint.

### Step 3: Write the Hook

First 10–20 seconds determine whether the learner stays. Effective hooks:

- A specific, concrete problem the learner has felt
- A surprising or counterintuitive result (with reveal coming)
- A scenario the learner will immediately recognize
- A question with stakes

Avoid:
- "Hi everyone! In this video we're going to..."
- Channel intro animations
- Disclaimers that aren't legally required

### Step 4: Write the Two-Column Script

Format:

| Time | Narration (spoken aloud) | Visual / on-screen text |
|------|---------------------------|--------------------------|
| 0:00 | [Hook line] | [Title card or scene] |
| 0:20 | [Frame] | [Outcome on screen, plain language] |
| 0:40 | [Concept] | [Visual representation, label] |
| ... | ... | ... |

Spoken narration ≠ on-screen text — avoid reading the screen aloud. On-screen text reinforces, signposts, or visualizes.

### Step 5: Apply Multimedia Principles

Defaults:

- **Coherence:** Cut anything that doesn't directly support the outcome
- **Signaling:** Highlight key terms / steps as they're introduced
- **Redundancy:** Don't simultaneously narrate and display identical sentences
- **Spatial contiguity:** Put labels next to what they label
- **Temporal contiguity:** Sync narration to corresponding visual
- **Segmenting:** Break into chunks; pause between
- **Pre-training:** Define key terms before using them
- **Personalization:** Conversational voice, "you," not "the learner"
- **Voice:** Human voice over synthetic when possible (or label clearly if synthetic)

### Step 6: Build Retrieval Into the Video

Replayability ≠ effective learning. Embed:

- A pause-and-think prompt mid-video ("Pause and predict — what would happen if...")
- A worked example followed by a try-yourself problem (with answer revealed after)
- An end-of-video micro-quiz (or follow with one in the LMS)

### Step 7: Worked Example Discipline

If teaching a procedure or problem-solving:
- Narrate the *thinking*, not just the steps
- Show the misstep a learner might make and why it's wrong
- Connect to the underlying principle
- Avoid jumping steps that the learner doesn't yet have

### Step 8: On-Screen Text Plan

Decide:

- Title card content
- Recurring lower-third labels (concept names, steps)
- Highlight color / animation for key terms
- Captions: open captions vs. closed captions vs. both
- End card with next-action call

Specify font, size, contrast — the deck is unwatchable if low-contrast.

### Step 9: B-Roll / Animation / Visual Cues

For each segment, decide:

- Live presenter / talking-head?
- Slide / screen recording?
- Animation (whiteboard / motion / 2D)?
- Diagram or infographic?
- B-roll footage (if relevant)?

Note rights/licensing for any third-party footage.

### Step 10: Accessibility Spec

- Accurate captions (not auto-generated only)
- Full transcript
- Alt text for screenshots if shown statically elsewhere
- Color contrast and color-not-sole-cue
- Audio description for visual-heavy content where critical info isn't narrated
- Reading level appropriate

### Step 11: Production Notes

Provide the producer:

- Recording setup (mic, lighting, camera, screen-record settings)
- Wardrobe / background (if talking head)
- Pause cues for editing
- Re-take strategy (cuts on natural breaks)
- File naming convention
- Delivery format (resolution, codec, captions file)

### Step 12: Pilot Test

Before publishing:
- Watch with audio off — does on-screen text carry meaning?
- Watch at 1.5× — does pacing collapse?
- Have one target-audience learner watch with verbal think-aloud
- Time check vs. budget
- Caption accuracy spot check

## Output Format

1. One-sentence outcome
2. Time-budget breakdown with target word counts
3. Hook (full text)
4. Two-column script (timestamp, narration, visual)
5. Multimedia-principle declarations
6. Retrieval prompts placement
7. Worked-example narration (if applicable)
8. On-screen text plan
9. B-roll / animation / visual cues
10. Accessibility spec (captions, transcript, alt content)
11. Production notes
12. Pilot-test plan

## False-Positive Prevention

❌ **DON'T:**
- Open with org throat-clearing
- Read your slides aloud
- Stack 10 minutes of content into 5 (pace collapses)
- Skip captions and transcript — non-optional
- Forget the retrieval prompt — replayable ≠ learnable
- Let the "video" become a recorded lecture without segmentation

✅ **DO:**
- Squeeze to one outcome
- Plan word count to length
- Apply multimedia principles
- Embed retrieval
- Specify on-screen text and visuals
- Pilot before publishing

---

## Quality Indicators

- [ ] Outcome stated and tight
- [ ] Word count fits length
- [ ] Hook earns the next 4–10 minutes
- [ ] Two-column script complete
- [ ] At least one retrieval prompt embedded
- [ ] Captions, transcript, accessibility spec present
