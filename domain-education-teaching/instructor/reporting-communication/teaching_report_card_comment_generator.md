**Purpose:** Generate thoughtful, individualized report card comments that communicate academic progress, social development, and growth areas with strengths-based language calibrated to grade level and school culture.

**When to use:** Writing end-of-term or mid-year report card comments; drafting progress report narratives; preparing interim reports; composing student portfolio summaries.

**Input needed:**
- Grade level
- Subject or development area
- Performance level (exceeding, meeting, approaching, below expectations)
- Key strengths and growth areas
- School tone/culture (formal, conversational, growth-mindset focused)

---

## Your Input

**Grade Level:** [Grade or age range]
**Subject/Area:** [e.g., Mathematics, Reading, Science, Social Development, Work Habits]
**Reporting Period:** [Q1 / Q2 / Midyear / Q3 / Q4 / End of Year]
**Performance Level:** [Exceeding / Meeting / Approaching / Below grade-level expectations]
**Key Strengths:** [2-3 specific things the student does well]
**Growth Areas:** [1-2 specific areas for improvement]
**Notable Observations:** [Optional — specific anecdotes, projects, breakthroughs, challenges]
**School Tone:** [Formal / Conversational / Growth-Mindset / Standards-Based]
**Character Limit:** [Optional — many systems have 500-1000 character limits]

---

> **PRIVACY REMINDER:** Use placeholders like [Student] rather than real names when generating with AI. Never include disability status, family information, or other confidential details in AI prompts.

## Instructions

Generate report card comments through these structured phases:

### Step 1: Analyze Performance Profile

Map the student's profile to the comment structure:

| Element | Details |
|---------|---------|
| **Performance tier** | [Exceeding / Meeting / Approaching / Below] |
| **Primary strength** | [Most notable academic/behavioral strength] |
| **Secondary strength** | [Supporting strength or character trait] |
| **Growth area** | [Specific, actionable area for development] |
| **Trajectory** | [Improving / Maintaining / Declining from previous period] |

### Step 2: Select Comment Framework

**For Exceeding Expectations:**
```
[Student] + [exceptional performance evidence] + [specific strength highlight]
+ [how they elevate learning] + [enrichment or next challenge]
```

**For Meeting Expectations:**
```
[Student] + [solid performance evidence] + [specific strength]
+ [growth area with encouragement] + [next step for continued progress]
```

**For Approaching Expectations:**
```
[Student] + [genuine strength or effort recognition] + [specific growth area]
+ [what support looks like] + [confidence in capacity to grow]
```

**For Below Expectations:**
```
[Student] + [authentic strength or positive quality] + [honest description of gap]
+ [specific support plan in place] + [partnership invitation]
```

### Step 3: Generate Comments

**Write 2-3 comment options per student profile using these guidelines:**

**Sentence Starters by Performance Level:**

| Level | Starters |
|-------|----------|
| **Exceeding** | "[Student] consistently demonstrates..." / "[Student] has shown exceptional..." / "[Student] brings depth to..." |
| **Meeting** | "[Student] shows solid understanding of..." / "[Student] has made steady progress in..." / "[Student] demonstrates competence in..." |
| **Approaching** | "[Student] is developing skills in..." / "[Student] shows growing understanding of..." / "With continued practice, [Student] is building..." |
| **Below** | "[Student] shows effort in..." / "[Student] benefits from..." / "We are working together to support [Student] in..." |

**Subject-Specific Language:**

| Subject | Strong Performance | Growth Area |
|---------|-------------------|-------------|
| **Reading** | "reads fluently with expression" / "makes insightful text connections" | "developing stamina for longer texts" / "building inferencing skills" |
| **Writing** | "organizes ideas clearly" / "uses vivid, precise vocabulary" | "expanding sentence variety" / "strengthening supporting details" |
| **Math** | "demonstrates strong number sense" / "explains reasoning clearly" | "building fluency with facts" / "applying concepts to word problems" |
| **Science** | "asks thoughtful investigative questions" / "applies the scientific method independently" | "recording observations with greater detail" / "supporting claims with evidence" |
| **Social Studies** | "connects historical events to current issues" / "engages thoughtfully in civic discussions" | "using primary sources to support arguments" / "considering multiple perspectives" |
| **Social/Behavioral** | "is a kind and supportive classmate" / "shows strong leadership" | "developing self-regulation strategies" / "building collaborative skills" |
| **Work Habits** | "consistently completes work with care" / "manages time effectively" | "building organizational skills" / "following through on multi-step tasks" |

### Step 4: Calibrate Tone and Length

**Tone Adjustments:**

| School Culture | Style |
|---------------|-------|
| **Formal** | Third person, complete sentences, measured language. "The student demonstrates proficiency in..." |
| **Conversational** | Warm but professional. "I've really enjoyed watching [Student] grow as a reader this quarter..." |
| **Growth-Mindset** | Emphasize effort, strategy, and progress. "[Student] has shown that practice and persistence pay off in..." |
| **Standards-Based** | Reference specific standards. "[Student] meets standard 3.OA.7 by demonstrating fluency with multiplication facts..." |

**Length Guidelines:**

| Context | Length | Structure |
|---------|--------|-----------|
| **Brief** (character-limited systems) | 2-3 sentences, ~300 characters | Strength + progress/growth |
| **Standard** | 4-6 sentences, ~500-700 characters | Strength + evidence + growth + encouragement |
| **Narrative** | 1-2 paragraphs, ~1000+ characters | Full picture with anecdotes and goals |

### Step 5: Add Specificity

Replace generic language with specific evidence:

| Generic (Avoid) | Specific (Use Instead) |
|-----------------|----------------------|
| "is doing well in math" | "confidently solves multi-step word problems and explains her reasoning to classmates" |
| "needs to work harder" | "would benefit from practicing multiplication facts for 5 minutes daily to build automaticity" |
| "is a good student" | "consistently comes prepared, asks thoughtful questions, and supports peers during group work" |
| "behavior is an issue" | "is learning to manage frustration during challenging tasks — we are practicing deep breathing and break strategies" |
| "participates in class" | "eagerly shares ideas during science discussions and asks questions that push the class's thinking deeper" |

---

## Output Format

Structure the output as:
1. **Comment Option A** (standard version)
2. **Comment Option B** (alternate phrasing)
3. **Brief Version** (for character-limited systems)
4. **Home Support Suggestion** (one sentence families can act on)

---

## Quality Indicators

**Strong report card comments include:**
- [ ] Specific academic evidence (not just personality descriptions)
- [ ] Strengths-first framing (even for struggling students)
- [ ] Growth areas stated constructively with clear next steps
- [ ] Appropriate for families (no jargon, no codes)
- [ ] Consistent tone with school culture
- [ ] Accurate to the performance level (not inflated or deflated)
- [ ] Actionable — families know what to reinforce or practice
- [ ] Within character/word limits of the reporting system

**Common Report Card Comment Pitfalls:**

| Pitfall | Sign | Prevention |
|---------|------|------------|
| **Generic praise** | "Great student!" with no evidence | Include specific academic performance details |
| **Personality-only** | "Friendly and outgoing" without academics | Lead with academic progress, then character |
| **Sugar-coating** | Below-level student sounds on-track | Be honest with compassion — families need accurate information |
| **Deficit framing** | "Can't do X" / "Fails to Y" | Reframe: "Is developing..." / "Is working toward..." |
| **Copy-paste feel** | Same comment for multiple students | Include at least one unique detail per student |
| **Jargon** | "DRA level 28" without context | Add meaning: "reading slightly below the 3rd grade target" |

---

## Batch Generation Guidance

When writing comments for a full class:

1. **Group students by performance level** — draft one strong comment per tier, then personalize
2. **Keep a running list of unique details** — one anecdote or data point per student
3. **Vary sentence starters** — don't begin every comment with "[Student] is..."
4. **Read comments back-to-back** — they should feel individual, not templated
5. **Check for equity** — ensure similar performance levels get similar depth regardless of student demographics
