# Portfolio Assessment Designer

## Objective

Produce a complete portfolio assessment system: what students collect, how they curate, what they reflect on, how the teacher scores, and how the system stays calibrated across many portfolios. Output specifies inclusion criteria, the student-curated narrative, reflection scaffolds, scoring rubric, and defensibility moves.

## When to Use

- Capstone or course-long assessment
- Replacing a single-test summative with growth-oriented evidence
- Documenting standards mastery across multiple artifacts
- Building toward graduation portfolios, defenses, or exhibitions

## When NOT to Use

- Single-task performance assessment — use `assessment_performance_task_designer.md`
- Calibrating writers across a stack — use `assessment_anchor_paper_exemplar_generator.md`
- Building a rubric for a single rubric-graded task — use `teaching_assessment_rubric_builder.md`

## Instructions

### Step 1: Define the Portfolio's Purpose

Choose one and write a one-paragraph rationale:

| Purpose | Implications |
|---------|-------------|
| **Best work / showcase** | Curated to demonstrate peak ability |
| **Growth / process** | Includes early drafts, reflection on revision |
| **Standards-mastery** | Each standard has anchored evidence |
| **Identity / development** | Demonstrates becoming-a-something (writer, scientist) |
| **Hybrid** | Combines purposes; must specify weight per |

The purpose drives everything else. Most failure modes come from purpose drift.

### Step 2: Specify Inclusion Criteria

Output:

- **Required artifacts:** [Specific items every portfolio must include — e.g., "one informational essay," "one science investigation report," "one mathematical argument"]
- **Required count:** [Minimum / maximum number of pieces]
- **Date range:** [Window of work eligible for inclusion]
- **Quality floor:** [Any baseline — e.g., "all included pieces must have been completed"]
- **Format constraints:** [Multimodal allowed? Length? Citation format?]

The student-curated component (Step 3) operates within these criteria.

### Step 3: Curation by the Student

The portfolio is the student's argument about their learning. Specify:

- **What the student chooses:** [Beyond required artifacts, e.g., 2 more pieces of student choice]
- **Why-this-piece rationale:** [Each chosen piece accompanied by 100–200 words explaining why it represents the student's growth, mastery, or identity]
- **Sequencing decision:** [Student decides order; orders matter — gradual vs. dramatic vs. thematic]

Output the student-facing curation guide:

```
For each piece you include:
1. Why this piece matters in your portfolio (100–200 words)
2. What it shows about you as a [writer / scientist / historian / mathematician / etc.]
3. What it doesn't show — what you'd add if space allowed
```

### Step 4: Reflection Scaffolds

Reflection is what makes a portfolio more than a folder. Provide three reflection scaffolds:

**Per-piece reflection (short):**
```
- Why I chose this piece: ___
- What I'm proud of: ___
- What I'd change: ___
- What this taught me about my work: ___
```

**Cross-portfolio narrative (medium, 500–1000 words):**
```
- The story across these pieces: ___
- Patterns I see in my own work: ___
- The learning I most claim: ___
- Where I'm still growing: ___
```

**Forward-looking statement (short):**
```
- What I want to keep doing: ___
- The next move I'm planning as a [discipline-identity]: ___
```

Reflection without specificity is generic. Demand evidence and quotation from the student's own work.

### Step 5: Standards Map

If the portfolio must demonstrate specific standards, build a coverage map:

| Standard | Pieces that evidence this standard | Strength of evidence (1–4) |
|----------|------------------------------------|---------------------------|
| [Standard] | [Piece A, Piece C] | 3 |

Require the student to map their pieces to standards. Where coverage is thin, the student must either add a piece or argue the strength is sufficient.

### Step 6: Scoring Rubric

Build a multi-domain rubric:

| Domain | Weight | What "meets" looks like |
|--------|--------|-------------------------|
| **Quality of work** | 30–40% | The pieces themselves meet rubric criteria |
| **Standards coverage** | 20–30% | Each required standard has anchored evidence |
| **Curation argument** | 15–20% | Student's rationale for inclusion is defensible |
| **Reflection depth** | 15–20% | Reflections are evidence-based, not generic |
| **Growth or development** | 10–15% | Trajectory is visible across the work |

Adjust weights to match the portfolio's purpose (Step 1).

### Step 7: Anchor Calibration

Before grading the stack, the teacher (and any co-graders) calibrate against 2–3 anchor portfolios at each scoring level. Output:

- A description of what an "exemplary" portfolio looks like across all rubric domains
- A description of "developing"
- A description of "not yet meeting"

The anchors prevent rater drift across many portfolios.

### Step 8: Defense / Conference Component (Optional)

If the portfolio includes a defense or conference:

- Format: [Solo presentation / panel / one-on-one]
- Time: [Length]
- Required moves: ["Tell us about one piece you'd revise — and what you'd change"]
- Scoring: [Whether the defense is part of the rubric or separately graded]
- Audience: [Teacher / peers / outside reviewer]

A defense surfaces whether the student can speak to their work — a powerful validity check.

### Step 9: Feasibility Check

Compute:

- Time per portfolio review (estimate)
- Total grading time at class size N
- Time to set up and onboard students at the start
- Mid-course conferring time

If feasibility is questionable, propose adjustments — fewer required pieces, peer-review components, staged grading.

### Step 10: Self-Check

- [ ] Is the portfolio's purpose defined and consistent?
- [ ] Do inclusion criteria match the purpose?
- [ ] Does student curation include rationale, not just selection?
- [ ] Are reflection scaffolds specific enough to demand evidence?
- [ ] Is the rubric weighted to the purpose?
- [ ] Are anchors set before grading begins?
- [ ] Is the system feasible at scale?

---

## False-Positive Prevention

❌ **DON'T:**
- Let students submit a folder of work without curation argument
- Accept generic reflection ("I learned a lot")
- Grade the portfolio without anchor calibration
- Confuse purposes — best-work and growth portfolios score very differently
- Assign a portfolio that's infeasible to grade at scale

✅ **DO:**
- Define one purpose clearly
- Require student curation with rationale
- Demand evidence-based reflection
- Calibrate with anchors before grading
- Map to standards explicitly
- Build feasibility into the design
