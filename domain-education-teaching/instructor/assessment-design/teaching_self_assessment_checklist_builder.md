# Self-Assessment Checklist Builder

## Objective

Produce a student-facing self-assessment checklist tied to assignment criteria — not a generic "did you try your best?" form, but a specific, observable set of indicators students can apply to their own work to identify where they are and what to do next before submitting or revising.

## When to Use

- Before submission (pre-submission self-check) — helps students revise before the teacher sees it
- After grading (post-grade reflection) — builds understanding of why they earned what they earned
- During a revision cycle — guides students through targeted improvement
- As a metacognitive routine students do repeatedly across an assignment type
- When you want students to give more accurate self-assessments instead of "I think I did fine"

## When NOT to Use

- When the assignment has no defined criteria — build rubric criteria first using `teaching_assessment_rubric_builder.md`
- For teacher-only internal grading — this is a student-facing tool
- As a formal grade substitution — self-assessment complements, doesn't replace, teacher evaluation

## Instructions

### Step 1: Translate Rubric Criteria into Student-Facing Indicators

For each rubric criterion, produce a student-language version — observable, specific, and free of teacher jargon:

```
CRITERION TRANSLATION
─────────────────────────────────────────────
Original rubric criterion: "[Teacher-language description]"

Student-facing indicator: "[Rewritten as an observable behavior — what the student can look for in their own work]"
Reading level: [Grade N — simplify if above grade level for this assignment]

What "yes, I have this" looks like: [Concrete behavioral description]
What "not yet" looks like: [Concrete behavioral description — without judgment]
```

### Step 2: Build the Checklist

Choose format based on input. Default is a combined checklist + self-rating.

**FORMAT A: Pre-Submission Checklist**

```
BEFORE YOU SUBMIT: CHECK YOUR WORK
─────────────────────────────────────────────
Name: _______________________   Assignment: _______________________

For each item, read your work carefully and check the box:

[ ] [Criterion 1 — student language]: [Observable indicator]
    If not checked: [1-sentence "what to do" — e.g., "Add a sentence that explains why…"]

[ ] [Criterion 2]: [Observable indicator]
    If not checked: [What to do]

[ ] [Criterion 3]: [Observable indicator]
    If not checked: [What to do]

[ ] [Criterion 4]: [Observable indicator]
    If not checked: [What to do]

[ ] I read my work from beginning to end before submitting.

REFLECTION:
One thing I'm proud of in this work:
_______________________________________________________

One thing I would change if I had more time:
_______________________________________________________
```

**FORMAT B: Self-Rating Scale (for assignments with performance levels)**

```
SELF-ASSESSMENT: RATING YOUR WORK
─────────────────────────────────────────────
Rate yourself on each criterion.

Scale: 4 = I nailed it | 3 = I got most of it | 2 = I'm getting there | 1 = I need help here

[Criterion 1 — student language]:
  4 — [What a 4 looks like in observable terms]
  3 — [What a 3 looks like]
  2 — [What a 2 looks like]
  1 — [What a 1 looks like]
  My rating: ____   Evidence from my work: ___________________________

[Criterion 2]:
  4 — [...]  3 — [...]  2 — [...]  1 — [...]
  My rating: ____   Evidence: ___________________________

[Criterion 3–N] [Same structure]

Total score: ___ / [max]

REFLECTION PROMPTS:
1. Which criterion are you most confident about, and why?
2. Which criterion do you want your teacher's feedback on most?
3. What would you do differently next time?
```

### Step 3: Add Grade-Level Vocabulary Adjustments

Flag any words in the checklist that may be unfamiliar to students at this grade level. Provide simpler alternatives.

```
VOCABULARY CHECK
─────────────────────────────────────────────
[Word or phrase used] → [Simpler alternative if above grade level]
[...]
All other vocabulary: appropriate for Grade [N]
```

### Step 4: Teacher Guide for Use

```
TEACHER GUIDE: HOW TO USE THIS CHECKLIST
─────────────────────────────────────────────

BEFORE SUBMISSION (recommended):
1. [When to distribute — e.g., "Day before due date, last 5 minutes of class"]
2. [How long it takes — typically 5–8 minutes]
3. [What to do with it — collect and review before grading to see where students think they are]
4. [How to use it instructionally — if many students check "not yet" on the same item, address it before submission]

AFTER GRADING (alternative use):
1. Return checklist with graded work
2. Ask students to compare self-rating to teacher evaluation
3. Discussion prompt: "Where were you accurate? Where did you over- or under-estimate? What does that tell you?"

CALIBRATION NOTES:
[If students tend to rate themselves too high (grade inflation)]
[If students tend to rate themselves too low (common in high-anxiety classes)]
[How to model using the checklist once before releasing independently]
```

## Output Format

1. Criterion translations (rubric language → student language)
2. Student-facing checklist (Format A: checklist / Format B: rating scale / or both)
3. Vocabulary check
4. Teacher guide for use (before and after submission options)

---

## False-Positive Prevention

❌ **DON'T:**
- Write indicators that require teacher interpretation ("demonstrates understanding" is not observable)
- Use more than 6 criteria — students stop reading and just check everything
- Write "not yet" descriptions as failures ("you didn't…") — describe the gap as a gap, not a failure
- Treat self-assessment ratings as accurate — they're a starting point for conversation, not a grade
- Distribute the checklist once and never teach students how to use it accurately

✅ **DO:**
- Write observable behavioral indicators students can apply without the teacher present
- Include a "what to do if not checked" in the pre-submission version
- Include reflection prompts that require thinking, not just self-rating
- Write the teacher guide — the checklist is more useful when teachers know how to deploy it
- Plan a calibration step: model using the checklist on a sample piece of work before students use it independently

---

## Quality Indicators

- [ ] All indicators are observable (student can check without teacher judgment)
- [ ] Grade-level vocabulary throughout
- [ ] "Not checked" items include a concrete next step
- [ ] Reflection prompts require thinking, not just completing
- [ ] Teacher guide includes both pre-submission and post-grade use options
- [ ] Vocabulary check completed
