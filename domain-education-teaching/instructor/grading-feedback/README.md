# Grading & Feedback

*8 prompts · part of [`domain-education-teaching`](../../README.md)*

## Use these when

Getting through a stack of student work without the feedback going generic. Comment libraries, rubric-criterion feedback, subject-specific feedback (essays, labs, maths working, presentations), triage under time pressure, and whole-class memos.

## Go elsewhere when

- **Writing to families rather than students** → [`../reporting-communication/`](../reporting-communication/)
- **Analysing the assessment rather than responding to it** → [`../assessment-analysis/`](../assessment-analysis/)
- **The student wants to self-assess** → [`../../learner/self-assessment/`](../../learner/self-assessment/)
