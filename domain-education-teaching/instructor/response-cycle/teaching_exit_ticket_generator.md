**Purpose:** Generate quick, targeted exit tickets and formative check-for-understanding items (2-5 minutes) that reveal student thinking, identify misconceptions, and inform next-day instruction — aligned to specific Bloom's taxonomy levels.

**When to use:** End-of-lesson comprehension checks; mid-lesson pulse checks; pre-lesson warm-ups; transition assessments between unit sections; quick data collection for instructional grouping.

**Input needed:**
- Learning target for the lesson
- Bloom's taxonomy level to assess
- Grade level
- Subject area
- Time available (2-5 minutes)

---

## Your Input

**Learning Target:** [Today's specific learning objective — e.g., "SWBAT identify the main idea and two supporting details"]
**Bloom's Level:** [Remember / Understand / Apply / Analyze / Evaluate / Create]
**Grade Level:** [Grade or age range]
**Subject:** [e.g., Math, Reading, Science, Social Studies]
**Specific Topic:** [Narrow topic from today's lesson]
**Time Available:** [2 / 3 / 5 minutes]
**Format Preference:** [Multiple choice / Short answer / Visual / Self-assessment / Mixed]
**Misconceptions to Target:** [Optional — known student misconceptions you want to reveal]

---

## Instructions

Generate exit tickets through these structured phases:

### Step 1: Align to Bloom's Level

Select question types matched to the cognitive level you want to assess:

| Bloom's Level | Question Types | Signal Words |
|---------------|---------------|--------------|
| **Remember** | Recall, list, label, match, identify | Who, what, when, where, define, list, name |
| **Understand** | Explain, summarize, paraphrase, classify | Explain, describe, summarize, what does this mean |
| **Apply** | Solve new problems, use in context, demonstrate | Solve, use, demonstrate, apply, calculate |
| **Analyze** | Compare, contrast, categorize, find patterns | Compare, contrast, why, how is X different from Y |
| **Evaluate** | Judge, justify, critique, defend a position | Which is better, do you agree, justify, defend |
| **Create** | Generate, design, propose, combine ideas | Design, create, what if, propose a solution |

### Step 2: Generate Exit Ticket Items

**Format A: Multiple Choice (2-3 minutes)**

Create 2-3 items where wrong answers reveal specific misconceptions:

| Item | Question | Correct Answer | Distractor A (Misconception) | Distractor B (Misconception) | Distractor C (Misconception) |
|------|----------|---------------|------------------------------|------------------------------|------------------------------|
| 1 | [Question stem] | [Correct] | [Common error: what misconception this reveals] | [Common error: misconception] | [Common error: misconception] |
| 2 | [Question stem] | [Correct] | [Misconception] | [Misconception] | [Misconception] |

**Distractor Design Principles:**
- Each wrong answer should represent a *plausible* student error
- Distractors should reveal *diagnostic* information (not trick students)
- Label the misconception each distractor targets for teacher reference

---

**Format B: Short Answer / Open Response (3-5 minutes)**

| Item | Prompt | Exemplar Response | Look-Fors | Common Errors |
|------|--------|-------------------|-----------|---------------|
| 1 | [Prompt requiring explanation] | [What a strong answer includes] | [Key elements to check] | [Typical mistakes] |
| 2 | [Prompt] | [Exemplar] | [Look-fors] | [Errors] |

**Effective Short Answer Stems:**
- "Explain in 2-3 sentences why..."
- "Show your work for... and explain your thinking."
- "What is one example of [concept] and why does it fit?"
- "What is the difference between [A] and [B]?"

---

**Format C: Visual / Non-Verbal (2-3 minutes)**

Good for younger students, ELL students, or quick sorting:

| Type | Description | What It Reveals |
|------|-------------|-----------------|
| **Thumbs up/down/sideways** | "Show me: do you understand [concept]?" | Confidence level (not accuracy) |
| **Card sort** | "Sort these [items] into [categories]" | Classification understanding |
| **Diagram label** | "Label the parts of [diagram]" | Vocabulary and concept knowledge |
| **Number line / continuum** | "Place yourself: 1=confused, 5=could teach it" | Self-awareness of understanding |
| **Draw it** | "Sketch a quick picture showing [concept]" | Conceptual understanding |
| **Emoji response** | "Circle the emoji that shows how confident you feel" | Affective check |

---

**Format D: Self-Assessment / Metacognition (2 minutes)**

| Prompt | Student Response Options |
|--------|------------------------|
| "Today I learned..." | [Open response] |
| "I'm still confused about..." | [Open response] |
| "I could teach someone else about..." | [Open response] |
| "The muddiest point for me was..." | [Open response] |
| "On a scale of 1-4, I understand today's target" | 1: Lost / 2: Getting there / 3: Got it / 4: Could teach it |

### Step 3: Create the Student-Facing Exit Ticket

**Important:** The student-facing ticket must NOT include answers, answer keys, or misconception labels. Keep all scoring information in a separate **Teacher Copy Only** section (see Step 4). Students should see only the questions and response spaces.

**Exit Ticket Template (suggested format — adapt layout as needed for your context):**

```
EXIT TICKET — [Date]
Learning Target: [Target in student language]

1. [Question 1]

   ________________________________________
   ________________________________________

2. [Question 2]

   ________________________________________
   ________________________________________

3. How confident are you?
   □ Got it   □ Almost   □ Need help
```

The exact formatting (boxes, borders, spacing) is flexible — the key requirements are: (1) learning target is visible, (2) questions are clearly numbered with response space, and (3) a confidence self-assessment is included.

### Step 4: Data Analysis Plan

**Quick Sort Method (recommended for 25+ students):**

After collecting exit tickets, sort into three piles:

| Pile | Criteria | Next Step |
|------|----------|-----------|
| **Got It** (Green) | Correct answer with sound reasoning | Ready to move on; potential peer tutors |
| **Almost** (Yellow) | Partial understanding or minor error | Small-group reteach with targeted support |
| **Not Yet** (Red) | Significant misconception or no response | Individual or small-group intervention before proceeding |

**Data Recording (optional):**

| Student | Q1 | Q2 | Confidence | Pile | Notes |
|---------|----|----|-----------|------|-------|
| [Placeholder] | ✓/✗ | ✓/✗ | [1-4] | [G/Y/R] | [Specific misconception if applicable] |

**Instructional Response Decision Tree:**
```
Results Analysis
├── 80%+ Got It → Proceed to next lesson; enrich for advanced
├── 60-80% Got It → Brief reteach (10 min) then proceed
├── 40-60% Got It → Significant reteach needed; adjust tomorrow's plan
└── <40% Got It → Rethink approach entirely; the lesson didn't land
```

---

## Output Format

Structure the exit ticket package as:
1. **Exit Ticket** (student-facing, print-ready)
2. **Answer Key with Misconception Notes** (teacher reference)
3. **Data Analysis Template** (quick-sort instructions)
4. **Instructional Response Plan** (what to do with each pile)

---

## Quality Indicators

**Effective exit tickets include:**
- [ ] Directly aligned to today's learning target (not last week's)
- [ ] Assesses at the intended Bloom's level (not easier)
- [ ] Completable in the time allocated (2-5 minutes)
- [ ] Reveals thinking, not just right/wrong
- [ ] Wrong answers provide diagnostic information
- [ ] Accessible to all students (including ELL and IEP)
- [ ] Provides actionable data for tomorrow's instruction
- [ ] Includes student self-assessment component

**Common Exit Ticket Pitfalls:**

| Pitfall | Sign | Prevention |
|---------|------|------------|
| **Too easy** | Everyone gets it right but can't apply it tomorrow | Match Bloom's level to the lesson objective |
| **Too long** | Students rushing, unfinished tickets | Limit to 2-3 items; test your timing |
| **Misaligned** | Questions don't match what was taught | Write the exit ticket BEFORE the lesson |
| **No follow-through** | Collecting tickets but not using data | Build 5 minutes into next day's plan for response |
| **Binary only** | Only know right/wrong, not why | Include at least one "explain your thinking" item |
| **One format always** | Students tune out routine tickets | Rotate formats weekly |
