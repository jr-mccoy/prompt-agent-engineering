# Instructional Response Cycle

*5 prompts · part of [`domain-education-teaching`](../../README.md)*

## Use these when

The diagnose-and-respond loop, in order: pre-assess before teaching, diagnose the misconception from student work, plan the reteach, regroup for small-group work, and exit-ticket to check. Run these as a sequence rather than picking one.

## Go elsewhere when

- **Building the assessment instrument itself** → [`../assessment-design/`](../assessment-design/)
- **Reading whole-class results statistically** → [`../assessment-analysis/`](../assessment-analysis/)
- **The student needs individualized support beyond reteaching** → [`../student-support/`](../student-support/)
