## Key Patterns

### Conversation Simulation
- Role-play scenarios (ordering food, asking directions, etc.)
- Skill-level adaptation (beginner to advanced)
- Cultural context inclusion
- Correction and feedback

### Practice Types
- **Situational** - Restaurant, airport, shopping
- **Professional** - Business meetings, interviews
- **Casual** - Making friends, small talk
- **Travel** - Navigation, hotels, emergencies

---

## When to Use This Domain

Use these prompts when you need to:
- Practice a foreign language conversationally
- Simulate real-world language scenarios
- Get corrective feedback on language use
- Prepare for travel or business in another language

**Do NOT use for:**
- Language worksheets (use domain-image-generation)
- Formal language education curriculum (use domain-education-teaching)
- Translation tasks (use general prompts)
